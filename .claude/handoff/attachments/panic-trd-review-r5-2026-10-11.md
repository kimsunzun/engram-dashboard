## Main decisions for v6

### E — shell pulled exit: stop routing through `app.exit` (codex BLOCK · lens N1 · arch N3)
Holes found: (i) tauri `AppHandle::exit` on failed `request_exit` calls `log::error!` → `cleanup_before_exit` → `std::process::exit` on the caller thread (`tauri-2.11.3/src/app.rs:574-579`; `tauri-runtime-wry-2.11.3/src/lib.rs:2748`) → `ExitProcess` kills the watchdog before DLL detach (MS documents the detach deadlock). (ii) tao runs the `RunEvent::Exit` (LoopDestroyed) handler inside its own `catch_unwind` and `reset_runner` discards the panic, then `run` calls `process::exit(0)` (`tao-0.35.3/.../event_loop/runner.rs:95-108,242-256`, `event_loop.rs:225-231`) → a panic inside the Exit callback (e.g. `cleanup_before_exit` `tray.icons.lock().unwrap()` `app.rs:1110-1121`) ends with code 0 via ExitProcess. (iii) a pull landing after the Exit callback's entry check (e.g. during tray-quit `exit_session.shutdown()` ≤2 s) → nobody re-checks → tao `process::exit(0)`, `Final` written.
- E1 The shell waker NEVER calls `app.exit`. On pull it posts ONE closure to the main thread via `AppHandle::run_on_main_thread` (verify it exists in tauri 2.11.3 and what it returns when the loop is gone): the closure does `cleanup_before_exit()` inside `catch_unwind` (best effort — tray icon) then `terminate_self(101)`. If posting fails (loop gone) the waker does nothing more — the watchdog's deadline ends the process. `Final` is never written on the pulled path (no `RunEvent::Exit` is reached). Residual: tauri's own `exit` failure branch is no longer on our path.
- E2 The `RunEvent::Exit` callback body runs inside `catch_unwind(AssertUnwindSafe(..))`; at its END: `if caught || esc.is_pulled() { terminate_self(101) }` (re-check, like the daemon tail). Decide precedence vs the existing `startup_failed` exit (pulled/caught → 101 wins). Add a U6 lib test: panicking shutdown seam → one recorded terminate(101); pull-after-entry → terminate(101).
- E3 Daemon `main.rs`: before ANY non-101 exit (Ok / Err(1)), `if is_pulled() { terminate_self(101) }` (low impact, symmetric).
- E4 Update §4-9, M18, M19, §4-11 (remove "app.exit failure branch" residual; list tao-swallow as closed by E2), §9-12, §5, U6 size/tests. The shell main-thread-panic path (tao `resume_unwind` → `main.rs` catch → `terminate_self`) stays; note it skips `cleanup_before_exit` (ghost tray icon accepted — or have the `main.rs` catch skip it: there is no AppHandle there).

### D — contained-panic diagnostics slot (lens N2 N3 N4 · arch C10 nit)
