LLM 조작 — engram CLI

확정 원칙

프리셋 · 라이브러리 조작은 전부 데몬 명령 — 화면 버튼과 LLM이 같은 것을 부른다. 명령 이름은 자리표시.

# 라이브러리 · 프리셋 engram preset list --folder 프리셋/ engram preset show 프리셋/리뷰어 --final # 펼친 최종 구성 · 충돌 · 경고 # 에이전트 engram agent create --name 리뷰봇 --preset 프리셋/리뷰어 engram agent preset add 리뷰봇 프리셋/실험/night-rules
