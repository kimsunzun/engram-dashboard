## Main decisions for v5 (design/doc corrections — main decides)

- C1 (codex BLOCK) Contained NON-poison panic: the hook returns right after the allocation-free decision — no tracing log, no previous/default hook call. Reason: a panic raised while the thread holds a tracing lock (e.g. a `Debug` impl panicking inside `info!(?x)` under the reload layer's read lock, `base/src/logging/mod.rs:404`) would self-deadlock in the hook BEFORE any pull → watchdog idle, thread (and soon every logger) stuck. (Same self-deadlock exists in today's abort hook — pre-existing — but the fix is cheap.) Diagnostics move to the containment boundary: the hook copies the panic location allocation-free into a const thread-local fixed buffer (file truncated to 256 bytes + line + column); `contain`/`Contained` on catch logs payload message (`PanicHookInfo`-free: from the caught payload) + that location. Escalating panics keep: decision → mark → pull → reason → log → default hook.
- C2 (arch N1 · lens N1) `ExitProcess` (behind `process::exit`) terminates all other threads — the watchdog included — BEFORE `DLL_PROCESS_DETACH` under the loader lock → a detach hang (WebView2/COM DLLs in the shell — unverified) is uncovered. End every PULLED exit path with platform `terminate_self(101)` after the last log line: daemon tail end + M6 catch (`main.rs` 101 branches); shell `RunEvent::Exit` panic branch after `cleanup_before_exit`; shell main-thread panic → shell `main.rs` wraps `run()` in `catch_unwind` (tao `resume_unwind` out of `App::run`) → `terminate_self(101)`. Normal (unpulled) exits keep `process::exit`. Correct §9-12 / §4-11 "남는 것 = 감시 스레드가 스스로 멎는 경우뿐".
- C3 (arch N2) ADR mechanics: `/adr new` writes no links; bidirectional Amends + status stamps come only from `/adr supersede` (partial mode) or `/adr link`; clauses cannot contain `·`, `—`, link keywords, unbalanced parens (`~/.claude/skills/adr/references/flow.md:33`). → Create ADR-0292 with `/adr supersede --mode partial` naming 0288 and 0290 in ONE run, each with one short noun-phrase clause; put the ①~⑤ detail in ADR-0292's 결정/영향 body; no later `/adr link` for those pairs. Fix §8-1/§8-2/U9 wording.
- C4 (arch N3) Add 0290 ⑤ (conditional on (다)=거절 or (바)=감시): ADR-0290 결정 trailer "ADR-0288 의 나머지(… 3 · 4 의 전용 장치를 두지 않는다 · 미룬 장치)는 그대로다" (branch file line 15).
- C5 (arch N4 · lens N6) `terminate_self(code) -> !`: Windows = `TerminateProcess(GetCurrentProcess(), code)` then a sleep loop (it is asynchronous and can return FALSE; NOT `abort()` — fastfail races a different exit code).
