# 사용량 슬롯 — 사용자 답 원문 (2026-09-30 오후 세션)

ADR-0259 · ADR-0260 · S21 사용량 슬롯 TRD/PRD 가 「사용자 답 2026-09-30」 으로 인용하는 발언의 원문이다. 질문은 메인 세션이 던졌고, 아래는 사용자 발언을 글자 그대로 옮긴 것이다(맞춤법 그대로).

1. **팝업 머리 「N분 전」 기준(가장 오래된 값 vs 가장 최근 값)** (메인 추천 = 가장 오래된 값) — 「ㅇㅇ 오래된쪽으로 해줘. 근데 그런 케이스가 무슨경우임?」
2. **비율 한계를 양쪽(0.1·0.9) 다 풀까** — 「양쪽 다 풀어.」
3. **리셋 낱말 → 모래시계로 바꾼 이유** — 「리셋이라고 하면 뭔가 지저분함.」
4. **다른 시계 아이콘을 버린 이유** — 「추천으로한거 다른거 추천하려면 해줘」 (모래시계는 메인 추천이었다. 메인이 「모래시계 유지」 를 다시 권했고 사용자는 이의 없이 다음 질문으로 넘어갔다 — 명시 재확인은 없다.)
5. **높이 부족 시 작은 단계로 내려가던 방식을 버린 이유** — 「아마 높이 때문에 가장 긴거에서 중간거로 안가고 짧은거로 바로해서였나 잘 기억이 안남」 (★사용자 기억 불확실★)
6. **끈 회사를 팝업에서도 숨기는 이유** — 「다른데가 그래서 그랬고, 보여주면 갱신도 해야되잖아. n/a로 표시해도 되긴 한데 어쨋든 표시가 애매하고 다른곳도 그래서」
7. **머리 나이에 모델별 창을 넣을까(문서 리뷰가 잘못된 전제를 잡은 뒤 재질문 — A 넣기 / B 5시간·주간만 — 메인 추천 = B 「넣지 않기 (추천)」)** — 「ㅇㅇ 그냥 오래된쪽을 봐.」 → (A/B 재확인 질문) → 「음? B이긴한데 어떻게 되는건지 간단하게 컨텍스트에 그림 그려봐.」 → (팝업 그림 제시) → 「ㅇㅇ 그렇게해.」
