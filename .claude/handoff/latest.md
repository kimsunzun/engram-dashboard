## 이번 세션 결정 (요약 — 정본은 결정 메모)

- **라이브러리 슬롯:** 뒤로/앞으로 = 슬롯 전체 폭 맨 위 줄에 경로와 한 줄(`← → 라이브러리 › 스킬 › 리뷰`) · 그 아래 목록 칸 위 줄 = `필터 ▾`(종류 체크만 — 상태 필터 없음) · 검색 · `★ = 대상`. 칸 사이 선은 표시 없이 전부 끌어서 폭 조절. **라이브러리 슬롯 = 1~4 번호 고정**(언리얼 콘텐츠 브라우저 1~4) · 슬롯 메뉴 「라이브러리 ▸ 1~4」 · 번호마다 보기 상태(칸 폭 · 마지막 폴더 · 뒤로/앞으로) 저장 · 열린 번호를 다시 고르면 그 슬롯으로.
- **라이브러리 폴더:** 하나(여러 개 안 함 — 프리셋도 그 안). 참조 = 라이브러리 맨 위부터 `/` 경로. 루트 바꾸기 = 트리 머리 메뉴 「라이브러리 폴더 바꾸기…」 + 설정 창 + `engram` 명령. **자동 기본 폴더 없음** — 처음엔 빈 트리 안에 VS Code 식 안내(「아직 라이브러리 폴더를 고르지 않았습니다.」 + [폴더 열기] + [새로 만들기](배포판\library 미리 채움)) · 폴더가 없어지면 같은 자리 「…를 찾을 수 없습니다」 + 같은 단추 · 설정 유지.
- **프리셋 편집 칸(라이브러리 오른쪽 칸):** 따로 된 편집 슬롯 없음 · 옛 프리셋 슬롯(`src/components/slot/PresetPalette.tsx`) 없앰. **종류별 칸**(프리셋 · 지시서 · 스킬 · 설정) · 순서는 지시서 · 설정만 끌어서 · 스킬 이름순. 칸 제목 단추 = `+`(그 종류 검색 — ▾ 없음) · `⇐`(다른 라이브러리 슬롯 중 마지막으로 만진 곳에서 고른 것) · **폴더+돋보기 아이콘**(그 종류 폴더로 라이브러리 열기 = 슬롯 B 띄우기). 맨 위 「+ 담기」 · 「← 선택한 것 담기」 유지. 라이브러리 우클릭 「프리셋에 추가」 없음. 「실제로 받는 전체」 평평한 보기 없음.
- **안에 든 프리셋:** 그 자리에서 ▸/▾ 펼침 · **바깥과 같은 레이아웃을 한 단 들여서(같은 부품 재귀)** · 안쪽은 보기만(+ · × · 순서 없음 — 공유 파일이라). 바깥에서 그 줄 자체를 빼는 건 됨.
- **줄 누르기:** 지시서 · 스킬 · 설정 한 번 누름 = 상세 패널이 슬롯 가장자리에 붙어 **옆 슬롯 위로 겹쳐** 나옴(옆 슬롯 크기 · 내용 그대로 — JetBrains Undock 류) · 같은 줄 다시 누르면 닫힘(토글) · 창 끝이면 잘린 채 둠(넓히면 보임). 줄 호버 폴더 돋보기 · 더블클릭 = 그 항목 자리로 이동(← 로 복귀).
- **에이전트 쪽:** 에이전트 프리셋 편집 = **슬롯 종류 하나 = 편집 칸만 켠 라이브러리**(느리면 로직만 재사용) · 에이전트 트리 우클릭 「프리셋…」로 열고 이미 있어도 하나 더 · 팝아웃(OS 창) · 도킹 가능. **공용 부품으로 세심하게**(사용자 주의 — 라이브러리 오른쪽 칸과 에이전트 슬롯이 같은 편집 부품 하나). 맨 위 따로 구분된 「기본」 칸 = 내장 기본 프리셋만 + 무엇을 하는지 한 줄 · 떼면 확인 창 + 「다시 묻지 않기」. 모델 · 강도 = 설정 에셋 값(공유 · 고정) · 에이전트별 기억 없음 · 바꿔 쓰려면 프리셋에 모델을 안 넣음. 돌고 있는 에이전트에 바꾼 프리셋 = 다음 실행부터 · 안내 없음.
- **도킹:** wt2(`v0.4.1/feat/slot-docking` · `docs/process/S21-slot-docking/` PRD · TRD 진행 중 · 미커밋)가 한다. 프리셋 쪽은 「라이브러리 · 에이전트 슬롯은 평범한 슬롯 종류 → 도킹이 그대로 적용」만 지키면 된다. 이 세션이 넣었던 T-63 은 겹쳐서 걷었다.

## 사용자 응대 — 반복 금지

- **채팅에 글자로 상자 그림(ASCII) 그리지 말 것** — 한글 폭이 어긋나 깨진다(사용자 스크린숏으로 지적). 화면은 브리핑 HTML 에 그리고 「몇 절 어디」만 말한다. 그림 안엔 실제 화면 글자만, 설명은 번호 캡션으로(「(편집 중)」 같은 설명 라벨 금지).
- **레이아웃은 관례 기준** — 세션 발상과 관례를 구분해 말한다(이번에 「담은 것 | 최종 구성」 탭 · 상태 필터 · 라이브러리 오른쪽 칸에 에이전트 띄우기가 세션 발상이었다가 걷혔다). 툴팁 · 팝업 규칙(뒤집기)을 붙박이 패널에 가져다 쓰는 식의 엉뚱한 관례 차용 주의.
- 사용자가 쓴 말을 그대로 · 결론 먼저 · 하나씩 묻기 · 이미 정한 걸 다시 묻지 않기. 사용자가 다음으로 넘어가면 추천대로 적고 「다르면 말씀」 한 줄.
- 숫자를 거꾸로 읽은 실수: `git rev-list --left-right --count A...B` 의 왼쪽 = A 에만 있는 커밋.
- 서브에이전트 지시서에 외부 요청 헤더(User-Agent 등)를 쓰게 하면 **값을 직접 박아 줄 것** — 이번에 워커가 사용자 이메일을 crates.io 요청 헤더에 넣었다(사용자에게 보고함). 공개 정보는 로컬 → 웹 검색 순.
