## 검증 상태

### 돌린 것

- ★**A/B/C/D 4갈래 실측**★ — 수치 정본 = 조사 보고서 §8. 요지: **탐색 금지가 유일하게 효과 있는 절감 레버**
  (입력 9배·미캐시 3배). **diff 를 건네는 것만으로는 거의 안 준다**(미캐시 84% 유지).
  **권고적 허용은 비용·품질 둘 다 최악.**
- **새 경로 실사용 검증 3건**(위 §9 표).
- 조사 3갈래 병렬 수집 + 후속 1갈래 + 메인 grounding.

### ★검증 안 된 것 / 실패한 것★

- ★**`--resume` 가 조용히 엉뚱한 스레드를 물었다**★. 내부가 `--last`(**그 cwd 의 최신**)라 **병렬로 돌린 뒤엔 못 믿는다.**
  **원인은 플러그인 결함이 아니라 메인이 둘을 동시에 띄운 것.** 해법 둘 = **순차로 돌린다**(기본) ·
  병렬이 필요하면 **렌즈마다 cwd 를 가른다**. 그리고 **첫 질문에 「직전에 무엇을 했는지 한 줄로 먼저 말하라」**를 붙인다.
- ★**조사 보고서가 「열화(degraded)」 상태**★ — 규약상 붙어야 할 **cross-family 적대 리뷰 미실시**
  (그 슬롯이 codex 자신이라 한도를 아꼈다). 라벨을 떼려면 그 리뷰를 거쳐야 한다.
- **렌즈 2 의 실효 미검증** — 채택은 했으나 렌즈 1 이 놓친 것을 실제로 잡는지 안 쟀다.
- **「강한 것 하나」 교정 규칙이 결함 수를 깎는가** — 새 경로가 1건만 냈는데 규명 못 했다(resume 실패 탓).
- **캐시 토큰이 플랜 한도에 full 로 잡히는지** — 사용자 제보뿐. ★단 절감 결론은 이와 무관하게 선다★.
- **한도 사망의 겉모습** · **`fork`** · **캐시 유지 시간** · **resume 3회차 이후 손익분기** — 전부 미측정.
- **품질 축은 전부 n=1.**

## ★사용자 결정 대기 6건★ (그대로 이월 — 근거는 모여 있다)

1. **리더 쪽 보류 — 버퍼 상한과 넘칠 때 처분.** 결정 = 상한 얼마 · 넘치면 (조용히 버림 / 화면에 오류 한 줄 /
   연결 실패). ★중간에 끼면 프론트가 `seq <= lastSeq` 를 버려 그 뒤 이력이 화면에서 사라진다★.
2. **활성화 중 취소가 뒤에 줄 선다**(최대 ~11초). 리뷰어의 3번째 해법 유력 — **kill 프레임 하나만** 앞질러 처리.
   확인할 것 = 클라가 순서 뒤바뀐 응답을 견디나.
3. **프로필 락이 막혔을 때의 처분(ADR-0071 재론).** 막히면 활성화 하나가 아니라 **명부 전체**가 멈춘다.
4. **멈춘 프로필이 낡은 실패 기록 때문에 「막힘」 글리프로 그려진다**(`statusGlyph.ts`).
5. **`old_session_ids` 무한 증가** — 상한 둘지.
6. **연결 미성립 실패에 전용 종류를 줄지** — 나중에 더해도 호환된다.

3. ★**`--json` 의 usage 를 그 턴 값으로 읽지 말 것**★ — **세션 누적값**이다. 요청별은

4. **codex 에 권고적 제한을 주지 말 것** — 실측 기각. **금지는 먹히고 권고는 안 먹힌다.**
5. **「로컬에 없다」를 「존재하지 않는다」로 굳히지 말 것** — 이 세션에서 실제로 그랬다. 스카우트에게
   네트워크 조회를 금지해 놓고 그 사실을 잊은 채 반복했다. **플러그인은 실재했다.**
6. **Bash heredoc 에 한글·따옴표 많은 본문을 넣지 말 것** — 두 번 깨졌다. Write/Edit 를 쓴다.
7. **`git checkout -- <file>` 금지** · **통과 개수로 테스트 유실을 못 본다**(이름 목록 대조) ·
   **앱을 셸에서 직접 띄우지 말 것** · **루트 bare `cargo test` 금지** ·
   워크스페이스 회귀에 `-- --test-threads=4` 유지.
