## 무엇을 했나 (요약)

### ① 하네스 — 왜 6주간 안 돌았나

lib 내장 테스트 타깃이 로드 단계에서 `0xC0000139`로 즉사했다. `tauri-build`/`embed-resource`가 Windows `RT_MANIFEST`를 `cargo:rustc-link-arg-bins=`로만 흘리고 cargo는 그 인자를 `[[bin]]`에만 적용하는데, **lib 내장 유닛테스트 타깃은 kind=test가 아니라 `-tests` 인자도 못 받는다.**

해법 = 같은 `src/lib.rs`를 **`[[test]] lib_unit`으로 한 번 더 선언**해 kind=test 타깃으로 만들고 `build.rs`가 `rustc-link-arg-tests=`를 낸다. **테스트 소스는 한 줄도 안 옮겼다.** 정본 = **ADR-0174**.

### ② 실패 32건 — 제품 결함이 아니었다

`DaemonClient`가 emit 용도로만 들던 `app: Option<AppHandle>`이 `None`이면 `start_connection`이 **연결 태스크를 안 띄우고** `Ok(())`로 단락했다. 테스트 생성자가 전부 `None`. `ffcd766`(2026-07-01)부터.

가짜 `AppHandle` 주입은 불가능하다(`mock_app()`은 `AppHandle<MockRuntime>`, `R: Runtime` 일반화는 커맨드 시그니처 전부로 번진다). 그래서 **emit 전용 포트**를 뽑았다 — `trait DaemonEvents` + `TauriEmitter` + `NoDaemonEvents`, 보유는 `Arc<dyn DaemonEvents>`. ★운영 동작 불변★(emit 11곳 이름·페이로드·순서·조건 동일, 프론트 리스너까지 대조).

### ③ ★진짜 수확 — 제품 결함 8곳★

연결을 `Down`으로 내리면서 **창에 아무것도 고지하지 않는** 경로들. 최악 = 핸드셰이크까지 끝난 뒤 `connect()` 호출자가 사라진 경우 → 모든 창이 `connected`로 굳은 채 **죽은 연결에 출력 채널이 묶인다**(프론트 자가복구는 새로고침 시점 pull뿐이라 살아 있는 페이지엔 안 온다). `close()`도 같은 구멍(닫는 창만 알고 나머지는 모른다).

`publish_if_current` **운영 호출 14곳 전수 감사** → 일곱은 세대 가드 아래 고지, 둘은 사유를 적고 침묵(연결 태스크가 같은 세대로 이미 고지 = 이중 보고 방지 · `Drop` 경로는 전이 성립 보고 불가 + 패닉 금지). **사유 없는 침묵 0.**

## ★미해결 — 이번에 일부러 안 고친 것★

### 1. 가드→emit이 원자적이지 않다 (이번 작업이 표면을 늘렸다)

`publish_if_current`가 `true`를 돌려준 뒤 emit 실행 전에 후속 `connect()`가 `connected`를 얹으면 **늦은 `down`이 최신 화면을 덮는다.** 선존 4곳과 구조가 같지만 표면이 대략 두 배가 됐고, `close()`가 가장 노출됐다(닫기→연결은 평범한 사용자 순서).

★**락 보유 중 emit으로는 못 푼다(ADR-0006).**★ 옳은 해법은 계통적 — **순서 있는 emit 큐를 락 안에서 밀고 단일 소비자가 빼거나, 세대 표식을 실어 프론트가 정렬**. 반쪽짜리를 짓지 않으려고 코드에 기록만 했다(`mod.rs::close()` 주석).

**옛 동작 대비로는 순증이다** — 전엔 명시 종료 때마다 100% 다른 창이 멎었고, 지금은 이 경합에서만 어긋난다.

## 남은 일

### 이번 세션에서 나왔고 사용자가 미룬 것

1. **CI 경로 필터** — 문서 한 줄만 바뀐 push도 7분 파이프라인을 통째로 돈다. 비용은 0(공개 저장소)이라 얻는 건 시간·소음뿐. 사용자 판단 = 「복잡하면 놔두자」. ★재개하면 주의 둘★ — `.github/workflows/**`는 절대 제외하지 말 것(CI를 고쳐도 CI가 안 돈다) · 필터를 켜면 **「이 SHA엔 실행이 없다」가 정상 상태**가 되므로 커밋 단위 초록을 요구하는 머지 규약 문구를 「코드가 마지막으로 바뀐 SHA」로 고쳐야 한다
2. **CI에서 UI를 띄울 수 있나** — `windows-latest`는 진짜 VM이라 데스크톱 세션이 있고 WebView2도 이미지에 있다. **「못 한다」가 아니라 「안 해 뒀다」에 가깝다.** 미검증 셋 = CDP 포트가 러너에서 열리나 · 데몬 기동이 그대로 도나 · 소프트웨어 렌더링에서 시각 검증이 값어치가 있나. 사용자 판단 = **「너무 큰 주제라 나중에」**. 싸게 확인하는 법 = 일회용 잡으로 앱 띄워 스크린샷 하나 아티팩트로 올리기(앞의 둘이 한 번에 판가름)

### 결정 대기

3. **crate 분리 모양** — `docs/tracking.md` T-27. 검증 공백은 닫혔고 **분리 동기 ㉠(앞으로 쓸 테스트가 워크스페이스 회귀에 실린다)은 분리 없이 달성됐다.** 남은 실질 동기는 ㉡(의존 방향을 컴파일러가 강제) 하나. 사용자 결정
4. **`cargo check --all-targets` 게이트 승격** — 원래 근거(「미실행 209개를 그물로 쓴다」)가 사라졌다. 지금은 스위트가 실제로 도니 컴파일 전용 게이트는 값싼 대역일 뿐. 다시 판단할 사안
5. **ADR 0170 빈 번호** — `/adr` 스크립트가 max+1로만 채번하고 지정 수단이 없어 예약을 못 지켰다. 이번 결정은 **0174**로 갔다. 억지로 채우지 않기로 돼 있으나 스크립트에 `--number`를 넣을지는 미결

### 두꺼운 것 (이전 핸드오프에서 계속 이어짐 — 이번 세션에서 안 건드림)

6. **`agent.spawnInto` 오류에 id가 데이터로 안 실린다** — 버그가 아니라 ADR-0059 설계. 진짜 결함은 그 id가 한국어 산문 안에만 있어 호출자가 못 받는 것. 추천안 = 오류에 id를 데이터로 싣기(공유 `command` crate 계약을 건드린다)
7. **릴리스에 무가드로 열린 전역 핸들 둘** — `src/api/clientFactory.ts:29,31`. ★핸들을 지워도 구멍이 안 닫힌다★ — `withGlobalTauri: true`라 `window.__TAURI__.core.invoke`로 셸 명령 직통 호출이 되고 spawn·kill·stdin이 그대로 노출된다. 즉 「핸들 철거」가 아니라 **「릴리스에서 제어 표면을 어디까지 열 것인가」 정책 결정**
8. **클라이언트 자작 식별자 = 주인 모델** — 몸통 작업. 지금은 연결 번호에서 파생해 재접속마다 새 주인이 된다. 안정 식별자를 넣으면 「연결 하나 = 주인 하나」 전제가 깨져 봉투 배달·답장 경로·끊길 때 지우는 단위를 같이 설계해야 한다
9. **`mail.*` 선언 0건** — ADR-0155 결정 1이 못 박았는데 미실현. ★보안 구멍이 딸려 온다★ — 우편 게이트는 **주소**로 막는데 표는 **이름**으로 부른다. 상충하는 해법 둘이 적혀 있고 어느 쪽인지는 사용자 결정
10. **저장 시스템** — 레이아웃은 디스크 영속이 없다. 기반이 둘로 갈렸다(코어 프로필 JSON vs 셸 `ui-settings.json`) — 합칠지가 ADR-0167이 남긴 미결이자 저장 시스템의 첫 결정

## do-not (누적)

1. ★**`v*` 태그를 승인 없이 push하지 말 것**★ — 릴리스가 발행되고 재시도가 안 된다. **master push는 릴리스를 발행하지 않는다**(발행 트리거는 태그뿐)
2. ★**CI 판정을 종료코드로 하지 말 것**★ — `gh run watch --exit-status`가 **취소에도 0**을 준다. `gh run view <id> --json conclusion`으로 직접 읽고, **머지할 그 SHA에 붙은 실행인지 대조**한다. 감시 중 같은 브랜치에 새 커밋을 밀면 `cancel-in-progress`로 그 감시가 무효가 된다
3. ★**`gh -q` 표현식에 `/`를 쓰지 말 것**★ — Git Bash가 경로로 바꿔 먹어 폴링 루프가 안 끝난다. 구분자는 `" "`·`":"`, 또는 `MSYS_NO_PATHCONV=1`
4. ★**`--lib`·`--all-targets`는 여전히 즉사한다**★ — `[lib] test = false`는 **기본 선택**에서만 뺀다. 부르는 법은 `--test lib_unit` 하나뿐
5. ★**`[lib] test = false` · `[[test]] lib_unit` · `build.rs`의 링크 인자 — 셋 중 하나도 지우지 말 것**★. 하나만 빠져도 **조용히** 무너진다. CI의 두 층이 각각 다른 다리를 지킨다(기본 선택 쪽 = `[lib] test = false` 소실 / 이름 지정 쪽 = `[[test]]` 소실 — 후자는 침묵이라 앞쪽이 구조적으로 못 본다)
6. ★**`cargo fmt`가 파일을 다시 쓰면 CRLF→LF로 뒤집는다**★(실측). 스크립트 기반 편집도 같다. **Edit 툴을 쓰고, 끝나면 줄바꿈을 확인**한다(`.gitattributes`가 `.rs`를 안 걸어 둔다)
7. ★**분리 실행 래퍼가 `npm`/`npx`에서 완료 마커를 못 붙인다**★ — `.cmd` shim을 `call` 없이 불러서 `__EXIT`가 안 나온다. **0바이트 로그 = 성공인지 미실행인지 구분 불가.** `call npx …`로 부른다
8. ★**문서를 고칠 땐 그 수정이 무효화하는 다른 기록을 먼저 찾을 것**★ — 이번에도 반복 발생했다(수치가 하루에 세 번 낡았다: 185/30/2 → 217 → 220 → 228). **총계를 여러 곳에 적지 말 것** — 정본은 `CLAUDE.md` 「빌드·검증 명령」의 `lib_unit` 줄 하나
9. ★**곁문 명단을 문서에 적지 말 것**★ — 찾는 법 = `rg "\)\.__ENGRAM_|\)\.__engram" src/ -g '!*.test.*'`
10. **`launch/실행.bat`을 개발 중에 쓰지 말 것** — 이미지 이름으로 모든 데몬을 죽인다
11. ★**앱을 셸에서 직접 띄우지 말 것**★ — 터미널 자손이 되면 반복 크래시한다. `scripts/`의 런처나 `launch-detached.ps1`
