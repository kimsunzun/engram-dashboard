## 실패한 접근 (반복 금지)

- **흐름 점검이 넣은 「막힌 실행 = CONFLICT」가 만드는 명령에서 재시도 때 에이전트를 둘 만든다**(ADR-0122 · `commands.rs` 가 일부러 INTERNAL) — 리뷰 두 명이 독립적으로 잡음. 오류 코드를 바꿀 땐 `retains_the_id`(command_delivery.rs)가 그 코드에서 요청 번호를 놓는지 먼저 본다.
- **잠금 규약을 고칠 때마다 새 경합이 나왔다**(4회) — 고친 방향마다 「늦게 도착하는 쓰기」 · 「기다리는 쪽에게 차례가 넘어가나」 · 「실패 길」을 같이 대 볼 것. 표준 Mutex 는 공정하지 않다(놓았다 바로 다시 잡으면 기다리던 쪽이 못 들어감).
- Git Bash 에서 `sed`/`node -e` 로 긴 한글 · 백슬래시 문자열을 고치면 깨진다 → node 스크립트를 파일로. TRD 는 CRLF 라 정규식에 `\r?\n`.
