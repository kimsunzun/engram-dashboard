## 사용자 결정 (2026-09-30 · 실사용 피드백)

1. **위아래 최소 크기:** 분할 비율 하한(`RATIO_MIN` 0.1)을 낮춘다. 「아예 겹쳐서 올릴 수 없는 정도가 아니라면 괜찮다」 → 칸 최소 30px(`MIN_PANE_PX`)만 남기는 방향.
   - 원인 추정: 10% 비율 하한. 실측은 안 했다.
2. **모드 전환:** 높이 때문에 단계를 바꾸지 않는다. 폭으로만 정하고, 높이가 모자라면 아래가 잘려 가려진다.
   - 지금 코드는 2단의 높이 조건(`pickStage`의 `fitsHeight`) 때문에 1단에서 바로 3단으로 간다.
3. **「몇 분 전」:** 회사 머리에 한 번, 시계 아이콘 없이 「Claude 플랜: max · 1분 전 ⟳」로 둔다. 줄마다 반복하는 것은 없앤다.
   - 사용자 원문: 「아이콘 2개 나와서 난잡 … 1분 전 하고 바로 리프래시 버튼이 있으면 리프레시라는게 인지가 되니깐」.
   - 조사상 합친 한 요소는 선례 없음 · 나란히가 관용.
4. **팝업 ⟳:** 회사마다 둔다. 작은 표시의 전역 ⟳ 하나는 그대로다.
   - 9/29 ADR-0257의 「팝업에 ⟳ 없음」을 팝업에 한해 번복한다 → 새 ADR.
5. **리셋 표기:** 모래시계 아이콘(lucide `Hourglass`)으로 통일한다(작은 표시·팝업). 툴팁·스크린리더는 「리셋 11:29」.
   - 사용자 원문: 「그냥 모레시계 통일로 하자」. 선례 없음은 사용자에게 알렸다.
6. **켜고 끄기:** 팝업 「슬롯에 표시」를 유지하고, 끈 회사는 팝업에서도 사라진다(현행 = 관용).
- 착각으로 끝난 것: 퍼센트 방향(남은 양 = PRD R1).
- 설명만 한 것: 「1분 전」 = 값을 받은 시각.
