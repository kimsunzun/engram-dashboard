## 확정된 성과 (실측)

- **`discovery → agent` 간선 소멸**, `net` 도 agent 를 의존으로조차 모른다. ADR 이 목표로 명시한 자리다.
- **셸의 agent 심볼이 정확히 1개**(`commands::COMMAND_SPECS`)로 떨어졌다 — ADR 결정 4 가 예고한 상태. 다만 **간선 자체는 남아 있다**(매니페스트 선언 + `daemon` dev-dependency 가 전량을 끌어온다).
- 워크스페이스 회귀 **2,102 통과 / 0 실패**가 세 단계 내내 불변. 셸 `lib_unit` 228 → **248**.

## ★미결 — 사용자 결정★

1. **4단계 `ui.` 접두의 적용 범위** ← **지금 막고 있는 것.** ADR 결정 5 는 "웹뷰가 답하는 명령에만" 이라고만 정했고 구체 범위는 미정이다. 5단계(`COMMAND_SPECS` 간선 제거)가 여기 매달려 있다 — ADR §근거가 순서를 못 박는다(접두 먼저, 필터 삭제 나중. 안 그러면 매 부팅 등록이 통째로 반려돼 셸의 창·탭·슬롯 이름이 명부에 못 오른다).
2. **flaky 2건.** `daemon_client::tests::buffered_command_on_disconnect_…`(셸) · `connection_core::tests::subscribe_emits_ack_then_replay_…`(데몬). 기록만 했고 단정은 안 건드렸다 — `docs/backlog.md` 「검증 절차」가 정본. ★재실행 초록은 원인을 설명하지 않는다★ · ★개명이 원인일 가능성 배제 안 됨★ · ★sleep 금지(ADR-0038)★. **경계선: 같은 테스트가 두 번째로 터지면 우연이 아니니 멈추고 판다**(사용자 합의).
3. **★게이트 커버리지 이탈 검사를 규약에 넣을지★** — 아래 「이번에 배운 것」 참조. 규약 변경이라 세션이 임의로 안 넣었다.
4. **맨 `core` 잔여를 막는 CI 게이트** — 보류 중. 이제 잔여 집합이 확정돼 세울 수 있다.
5. **`base` 세 번째 입주자** — 나타나면 멈추고 ADR-0175 「거부한 대안」 첫 항목 재론. 게이트가 아니라 규약이라 자동으로 안 걸린다.

## ★이번에 배운 것 — 다음 이사에 그대로 적용된다★

**게이트의 스코프는 경로인데, 이사는 그 경로가 덮는 파일 집합을 바꾼다. 그 둘을 대조하는 것이 아무것도 없다.**

한 세션에 **두 번** 발동했다 — 2단계에서 `base` 로 나간 코드가 `use tauri` 게이트 밖으로 빠졌고(코더가 새 집에 게이트를 세워 막음), 3단계에서 `replay_flight` 의 순수성 게이트 둘이 통째로 떨어졌다(리뷰가 잡음). **두 번 다 테스트·빌드·CI 전부 초록이었다.**

- **검사 방법:** CI 의 소스 스캔 게이트 스코프를 경로 목록으로 뽑고, 그 경로들이 이사 **전/후에 덮는 tracked 파일 집합**을 `comm -23` 으로 대조한다. 출력에 남는 이름이 시야에서 빠져나간 파일이다. 게이트의 뜻을 몰라도 되고 두 사고를 다 잡는다.
- **한계 둘:** `cargo tree` 상한 게이트는 패키지 스코프라 안 보인다(대신 미지 `-p` 이름에서 요란하게 죽는다) · 경로 모양이 손으로 박혀 있어 새 형태가 생기면 늘려야 한다.
- **진짜 원인은 문면이다.** ADR 이 이미 "새 crate 는 게이트를 세 곳에 등재한다"고 적어 뒀는데 **「새 crate」가 「기존 패키지 안으로의 이사」를 안 덮어서** 체크리스트가 통과된 것처럼 읽혔다. 최소 수정 = 트리거를 **"새 crate 또는 게이트 스코프를 벗어나는 이사"** 로 넓힌다.
- 전문은 `~/.claude/skills/qa/feedback.md` 2026-08-26 절.

## 안 한 것

- **4·5단계 미착수**(1번 결정 대기).
- **ADR-0175 본문의 사실 오류 5종** — 정찰·코더·리뷰어가 각각 발견. ① §근거의 `stdio.rs:30`(실제 `:24`) ② §맥락 소비자 표의 `src-tauri` 13·`daemon` 94(둘 다 이미 옮겨간 간선을 센다 — 현재 셸은 1) ③ §근거의 `rg` 명령이 이제 없는 문자열을 겨눈다 ④ §거부한 대안의 "재생 상태기계 610줄"이 366(프로덕션)·860(전체) 어느 쪽도 아니다 ⑤ 옛 정규식 모양을 인용하는데 그 결함이 이번에 고쳐졌다. **전부 결정이 아니라 수치·경로·인용이다.** ADR 이 자기가 서술한 상태보다 세 걸음 앞서간 결과라 손대지 않고 모아 뒀다.
- **`README.md:74-75`** — 워크스페이스 회귀를 아직 `--exclude engram-dashboard` 로 적는다. CLAUDE.md·qa.md·testing-strategy.md·ci.yml 넷과 어긋나는 **실제 드리프트**. 이사와 무관해 별건으로 남겼다.
- **`daemon` 의 미사용 `tracing-subscriber`** — production 의존으로 선언돼 있고 사용 0줄. `CLAUDE.md` 「의존성」에 사실대로 적어 뒀다.
- **`docs/reference/architecture-overview.md` 에 `base` crate 절 없음** — 다른 crate 는 절이 있다. 의존 그래프 다이어그램도 ADR 목표 그래프와 대조 안 했다.
- **`docs/reference/logging-conventions.md:53` 의 거짓 서술** — "`mask_secrets` 호출처 0" 인데 실제로 둘이 부른다.
- **`protocol/bindings/AgentProfile.ts` 의 `cwd` 서술 모순 의혹** — 생성물은 "정규화된", agent 필드는 "raw". 타입이 달라 자동 모순은 아니다. 미확인.
- **`CLAUDE.md` 선재 자기모순 1곳** — "이 네 줄이 유일한 경로다 — 워크스페이스 회귀가 이 패키지를 빼기 때문"이 거짓(제외는 걷혔다).
- **게이트 구멍 하나는 못 닫았다** — `use   tokio :: time;`(`::` 좌우 공백)이 새 게이트와 기존 형제 게이트 전부를 빠져나간다. 정규식을 크게 나쁘게 만들지 않고는 못 막아 **한계로 명시**했다.

## 실패한 접근 / do-not

- ★**경계를 넘는 이사는 게이트도 함께 옮긴다**★ — 위 「이번에 배운 것」.
- ★**개명·이사를 crate 이름 문자열 grep 으로 끝내지 말 것**★ — 맨 낱말 산문이 안 잡혀 3라운드를 헛돌았다. 커밋 **전에** 전수 열거.
- ★**`#[ts(export)]` 타입의 doc 주석을 고치면 생성물 `.ts` 가 밀린다**★ — 주석만 바꿔도 재생성 필요. CI 가 잡았다.
- ★**CI 에 `-- --test-threads=4` 를 붙이지 말 것**★ — CLAUDE.md 가 의도된 예외로 못 박는다. **이 세션 메인이 지시서에 잘못 넣었고 코더가 거부한 게 옳았다**(리뷰 확인).
- ★**0 기대 게이트를 짝 없이 세우지 말 것**★ · ★**게이트 정규식의 자기일치**★(`(a)gent` 괄호 형태로 막는다 — 현재 네 곳) · ★**게이트에 경로 부재 가드**★(경로가 사라지면 매치 0 = 통과로 읽힌다).
- ★**`git mv` 로 rename 검출을 살리라는 지시는 목적지가 이미 추적 중이면 불가능하다**★ — 어떤 플래그로도 안 된다. 재수출 shim 을 먼저 지우는 커밋을 앞에 두는 것이 유일한 방법.
- **CI 스텝 본문을 로컬에서 돌릴 땐 `( . step.sh )`** — `rg` 가 하네스 셸 함수라 새 bash 는 죽는다.
- **역사 기록의 옛 이름을 고치지 말 것** — `docs/decisions/` 본문 · `docs/process/` · `docs/research/` · `.claude/handoff/history/`.
