## GUI QA 요령 (필수)
- 부팅 오류 포착 = 같은 CDP 세션에서 `Page.addScriptToEvaluateOnNewDocument` → `Page.reload`(팝아웃은 따로).
- 프론트 view 캐시 = performance entries 에서 페이지가 실제로 로드한 모듈 URL 을 dev `import()` — ★다른 URL 은 별도 빈 인스턴스★.
- `cdp.mjs` 에 마우스·키 입력이 없다 → `Input.dispatchMouseEvent`/`dispatchKeyEvent` 소형 스크립트.
- `Browser.setWindowBounds` 는 뷰포트만. 네이티브 창 = **컴파일 헬퍼**(예: `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 로 `SetWindowPos` exe). ★**PowerShell P/Invoke·Add-Type 금지**★(보안 에이전트 경보 위험·훅 차단).
- 버스 동사 CLI 실측 불가(`engram.exe` = NO_TOKEN) → 같은 서비스를 `invoke('set_split_ratio', …)` 로.
- 다른 워크트리 dev 앱이 떠 있으면 identifier 뮤텍스로 이 워크트리 앱이 즉시 죽는다.
- 여러 번 움직이는 드래그 테스트는 rAF 를 스텁한다(`Splitter.test.tsx:32`).

## 실패한 접근 · 함정
- 지시서가 TRD 를 의역하면 없는 요구가 생긴다(6단계 「lostpointercapture = 취소」). **TRD 절·줄 인용**.
- 상태 기계(보고 직렬화·미리보기·드래그)는 **모양을 먼저 못 박고**, 「그 규칙이 없으면 실패하는 테스트」를 요구 번호별 변이로 확인하게 한다 — 이번 라운드에 codex·React 렌즈가 실제 경합·수명 결함을 여러 번 잡았다.
- CRLF: `cargo fmt`·Git Bash `sed -i` 가 줄끝을 망친다 → Edit 도구 + python 바이트 검사. 변이 검사는 백업→변이→실행→복원→sha1 을 한 셸 호출로(한도 사망으로 변이된 소스가 남은 적).
- 30만 토큰 넘은 코더·리뷰어에 재지시하지 말고 새 에이전트에 FIX 목록만(4단계 코더 38만·도구 131회).
- ADR 채번: 다음 새 ADR = **0230**(0226 은 다른 브랜치에만).
