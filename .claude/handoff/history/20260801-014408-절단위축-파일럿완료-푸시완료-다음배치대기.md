dashboard 전량 주석 retrofit 중. **커밋 5개 · origin/wt2 푸시 완료**(다른 PC 승계용). 이번 세션에 **절 단위(clause-level) 축을 파일럿으로 검증**했고 — 통째 판정이 놓친 *거짓 동시성 계약* 2건이 실제로 나왔다.

## 운영 방식 (유지 — 이번 세션에서 실효 확인)

1. **편집 = 메인 직접.** 워커 위임 안 함. 이번 세션이 그 근거를 하나 더 만들었다 — 절 판정은 "이 문장이 이력 잔여물인가 load-bearing WHY인가"를 문장마다 코드로 그라운딩하는 일이라 지시서로 안 쪼개진다.
2. **컨텍스트는 잦은 핸드오프로.** 파일·배치 경계마다 끊는다.
3. **리뷰어·QA 게이트 유지.** `/review doc full` + `/qa standard`. 이번에 게이트가 메인의 SEALED 위반을 잡았다(↓ do-not 6).
4. **워커는 대량 기계 작업만**, 쓸 때는 전량 Opus(`worker-senior`) 고정.
5. **사용자 방침(2026-08-01): "뭔가 문제 있으면 수정 안 하는 방향".** 애매한 삭제·재량 정리는 전부 폐기하고 **확정 거짓만** 손댄다. 정정할 때도 *새 설명을 쓰지 말고* 거짓 절 제거 + 정본 코드로의 포인터화를 우선한다.

## 이번 세션 수확 (핵심 — 다음 세션이 이 패턴을 찾아야 한다)

파일럿 대상 = `daemon_client/mod.rs` · `lifecycle.rs` (+ 같은 거짓 절이 있던 `connection.rs` 1곳). 커밋 `25f5028`, 30추가/51삭제, **코드 토큰 변경 0**(기계 확인).

**진짜 수확은 "완료된 로드맵 삭제"가 아니라 거짓 동시성 계약이었다:**
- 삭제: `"완전한 동시-시도 abort·백오프 재연결은 T4"` — T4는 이미 합류(`MAX_RECONNECT_ATTEMPTS`·`backoff_delay`·`handshake_cancellable`·`reconnect_guard` 전부 실재).
- **실제 갭은 다른 곳이었다:** cancel 구독이 `connected` **직후**(connection.rs:261 — 첫 `handshake()`는 :217, Connected 발행 :222)라 **첫 핸드셰이크 세대는 취소 가드 밖**이다. 그런데 `lifecycle.rs`·`mod.rs`가 "옛 세대는 소켓을 못 연다"를 **범위 없이** 단정하고 있었다 → 둘 다 범위 한정으로 정정.
- `"소켓을 열기 전에 즉시 탈출"` = 거짓 — Auth/Hello 단계 취소는 **이미 연 소켓을 self-close** 한다(connection.rs:392-394). 단계별 계약(`handshake_cancellable`) 포인터로 축소.
- `start_connection`의 `app=None` 분기 = 자기모순 심의 서술 + **실코드에 없는 `unwrap_or_else` 언급** → 제거. 위양성 경고 본문은 보존.

**교훈:** 고가치 블록일수록 *그 안*에 거짓이 숨는다(누구도 지우자고 제안하지 않으니 검사도 안 받는다). 절 판정 없이 통째 판정만 하면 이 유형은 영구히 안 잡힌다.

## 확정 기준 (앞 세션 것 유지 + 이번 추가)

이전 세션 확정분(parrot=식별자 번역 doc · 죽은 심볼 스캔 의무 · 경계 관례 3부류 보존 SEALED · 의도적 부재의 이유 보존 · 재작성은 실코드 그라운딩만)은 **그대로 유효**. 추가:

- **정정도 삭제만큼 위험하다 — 보호 토큰 수지를 기계 확인한다.** 거짓 절을 고치면서 보호 대상 태그를 같이 지우는 사고가 실제로 났다(↓ do-not 6). 확인법:
  ```bash
  git diff -- <경로> | rg "^-" | rg -o "T[0-9][a-z]?|ADR-[0-9]{4}|Fix [A-C]|FIX-[0-9]|M[0-9]" | sort | uniq -c
  git diff -- <경로> | rg "^\+" | rg -o "T[0-9][a-z]?|ADR-[0-9]{4}|Fix [A-C]|FIX-[0-9]|M[0-9]" | sort | uniq -c
  ```
  두 출력이 **1:1 균형**이어야 한다.
- **주석 전용 변경 기계 증명** (qa 강도 판정·리뷰 근거로 쓴다):
  ```bash
  git diff -U0 -- <경로> | rg "^[+-]" | rg -v "^(\+\+\+|---)" | rg -v "^[+-]\s*(//|///|//!)" | rg -v "^[+-]\s*$"
  ```
  출력 0줄 = 코드 토큰 변경 없음.

## 실패한 접근 (do-not)

1. **`cargo fmt --check` 생략 금지** — 주석 삭제는 포맷 중립이 아니다(doc 주석을 지우면 rustfmt가 struct variant 줄바꿈 판정을 바꾼다).
2. **경량(Sonnet) 워커에 재작성 몰아주기** → 창/뷰 어휘 혼동·거짓 단정·의도 날조. 재작성은 상급 티어 + 전건 검사.
3. **blind 리뷰어 제안 그대로 수용 금지** — blind는 프로젝트 규약·사용자 결정을 모른다(설계상). **재제안 목록(매번 나온다, SEALED 기계 기각 — 에스컬레이션 대상 아님):** 경계 관례 3부류 · **loom 유보 블록**(= 의도적 부재의 이유) · **`AtomicU64`/"Codex 적출" TOCTOU 서술**(= 최고가치 WHY) · **`app:None` 위양성 경고 블록**(= 확정 참인 load-bearing 경고).
4. **`git checkout -- <file>`은 자동 모드 분류기에 막힌다.** 원복이 필요하면 다른 경로를 쓸 것.
5. **수확 보고 시 "군더더기가 거의 없다" 식 단정 금지** — "규칙상 대상이 아니어서 남긴 것"과 "정말 좋은 주석"을 구분해 말할 것.
6. **★신규★ 거짓 절을 정정하면서 보호 토큰을 부수적으로 지웠다(SEALED 위반).** T4×3·T2×1이 재작성 과정에서 사라졌고 blind는 구조상 못 잡아 doc-aware가 잡았다. **정정 = 사실만 고치고 태그는 문장에 남긴다**("T4에서 합류해 …" 식). 커밋 전 위 §확정 기준의 토큰 수지 대조를 돌 것.
7. **★신규★ `src-tauri/gen/schemas/*.json` "dirty"는 블로커가 아니었다** — 내용 차이 0, CRLF/LF 정규화 노이즈였다(`git diff --numstat` 빈 출력). `git add`로 해소된다. 이전 핸드오프가 이걸 "다음 스윕 전 처리 필요"로 올린 건 오판이었다.
