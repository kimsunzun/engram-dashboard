## 실패한 접근 / do-not

1. ★**`drop_link` 에 제어 팔을 되살리지 말 것**★ — 9/08 인계 그대로 유효.
2. ★**돌연변이는 「고친 줄 제거」만으로 부족하다**★ — 이번에 새 테스트 4개 중 3개가 헛통과할 수 있었다(프레임이 큐에서 안 나가도 `fail_pending` 이 같은 수를 세서 초록). **테스트가 기대는 전제를 깨는 변이**도 돌려라(implement feedback 적립 2026-09-26).
3. ★**줄끝을 추측하지 말 것 — 9/08 인계의 「crates/**/*.rs 는 CRLF」는 이 crate 에선 틀렸다**★. 실측: transport 의 `peer.rs`·`lib.rs`·`link.rs`·`ws.rs`·`testing.rs`·`frame.rs` = i/lf w/lf, `event.rs` 만 작업본 CRLF, `docs/process/step-log.md` = w/crlf. **`git ls-files --eol <파일>` 로 확인**한다.
4. **QA 바인딩(`.claude/skill-bindings/qa.md`)에 transport 격리 게이트가 없다**(CI 에는 있다 — 드리프트). 지금은 crate 헤더 「격리 게이트」 ①~⑤가 정본이니 그걸로 돌린다. 바인딩 수정은 사용자 승인 사항.
5. **nmfc 플러그인 훅(HANDOFF-TRIGGER · WIKI-PRECONSULT)은 이 저장소와 무관하다** — Origin(UE5) 용. 핸드오프는 전역 `handoff` 스킬.
6. **codex 리뷰 슬롯** = `codex:codex-rescue` 서브에이전트(`~/.claude/skills/review/codex-call-spec.md`). `--background`·`--write` 금지, 재리뷰는 `--resume` + 「첫 줄에 직전 턴 한 줄 요약」으로 스레드 확인 — 이번에 세 번 다 제대로 물었다.
7. **`.claude/handoff/latest.md` 는 git 추적 + 워크트리 공용이다** — 이 인계는 이 브랜치에만 커밋했다(master 에 실으면 다른 워크트리 인계를 덮는다). ★**load 한 뒤 master 에서 새 브랜치를 따면 작업본 latest.md 가 master 판으로 바뀐다**★ — 이 인계의 영구본은 history 파일이다.
