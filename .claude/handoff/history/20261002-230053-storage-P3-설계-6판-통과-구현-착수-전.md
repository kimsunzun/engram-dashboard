## P3 설계의 핵심 (정본 = TRD §6 · §14-9~14-11)
- 평소: 바뀔 때마다 약 1초 뒤 `shell\state\state.json` 통째 원자 쓰기 · 시작 때 「실행 중」 표식 → 정상 종료 때 「깨끗이 끝남」.
- 정상 종료 뒤: 조용히 복원. **비정상 종료 뒤: `state.json` → `state.crash.json` 한 부 복사 → 기본 화면 + 앱 안 모달 「복원할까요?」**(사람·LLM 같은 `restore.answer`). 답(복원/무시)만이 사본을 거둔다. 답은 `state.json` 의 `resolved_crash_copy` 해시로 남고 지울 때마다 해시 재확인.
- 프로세스 간 잠금 `shell\run\state.lock`(단일 인스턴스 플러그인이 종료 쓰기 전에 뮤텍스를 놓으므로) · 부팅 파일 작업은 단일 인스턴스 바로 뒤 · 창 전에 도는 작은 플러그인(tauri 2.11.3 소스로 순서 확인 — GUI 미확인).
