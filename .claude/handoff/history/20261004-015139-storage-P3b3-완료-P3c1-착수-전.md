## P3c1 로 넘기는 제약 (리뷰가 남김 — 놓치면 깨진다)
- **런타임 수락은 `restore_windows`/`open_restored_popouts` 를 통째로 쓰지 말 것**(부팅 전용 — 살아 있는 팝아웃 label 과 부딪혀 모델에서 빼고 OS 창은 고아로 남는다). ⑧의 `locate`·`place` 만 쓴다(TRD §6-5 ⑧ · §6-7 ④ 고침).
- **version · attrs_rev 를 절대 되감지 말 것** — 수락 커밋은 `version = live.version + 1` 을 스스로 세운다. `unknown_content` 곁표를 views 와 함께 옮기고 옛 view 는 `remove_view` 로. `attrs_rev` 는 private 이라 **manager 에 메인 탭·속성을 통째로 바꾸고 두 카운터를 올리는 메서드를 새로 둬야 한다**(밖에서 `main.attrs = …` 직접 쓰면 기록기가 놓친다).
- `boot.rs` 확장 지점: `run_actions(&mut BootPlan)` — ④ 결과(사본 못 뜬 가드 · carry_resolved)를 계획에 접는다. `TODO(P3c1)` 표식.
- 프론트 `applyLayoutUpdated` 가 `foreign_slots` 를 버린다 → **P3c3 없이 복원 배선을 내보내지 말 것**(지금 곁표가 채워질 길은 새 버전 파일을 읽을 때뿐이라 실해 없음).
- saver 스냅숏 포트는 **창 게터를 부르지 않는다**(종료가 메인 스레드에서 기다리면 교착 → 모든 종료가 크래시로 읽힌다).

## 실패한 접근 · 주의 (do-not)
- **병렬 코더를 같은 워크트리에 돌리지 말 것** — 시험 결과가 섞이고 커밋을 손으로 갈라야 했다(P3b1a ∥ P3b2). 병렬이면 `isolation: worktree`.
- **기대는 쪽 API 가 리뷰 FIX 로 바뀌는 중에 소비 쪽을 돌리지 말 것** — B1 FIX 와 B2(saver)를 동시에 돌려 B2 가 빌드 깨짐을 맞췄다.
- 서브에이전트 하나에 큰 조각(manager.rs 2.7k줄 대상)을 몰면 35–40만 토큰 — 이번엔 조각을 둘로 나눠 버텼다. 수정 라운드는 fresh 코더로.
- codex 블라인드 리뷰어에게 **범위(「배선 없음」 · TRD 가 수용한 위험 R11/R12)를 지시서에 박을 것** — 안 박으면 설계 의도를 BLOCK 으로 친다(이번 2회).
- 메인 기억으로 선례를 단정하지 말 것 — 「window-state 는 크기를 논리로」가 틀렸다(원본 확인으로 정정).
- 훅이 Bash 텍스트의 PowerShell 형식 주입 키워드를 막는다(피드백 기록에도 그 낱말을 쓰면 막힘).
