## 실패한 접근 · 함정 (다시 하지 말 것)
- **ADR 채번 스크립트는 로컬 폴더만 센다.** 지금 이 브랜치엔 0227·0228·0229 가 있고 **0226 은 `v0.3.2/fix/resume-after-first-turn` 에만 있다** → 다음 새 ADR 은 **0230**. 우회 = 빠진 번호 파일을 `git -c core.quotepath=off show <브랜치>:<경로> > <경로>` 로 잠시 복사 → 스크립트 → 삭제(`quotepath` 빼면 한글 경로가 조용히 실패). 채번 직후 스캐폴드를 커밋·push 해 선점.
- **`cargo fmt` 가 CRLF 파일을 LF 로 뒤집는다**(이번에 또 났다 — implement feedback 재발 2회째). 코더 지시서에 「fmt 뒤 CRLF 복원 + `git ls-files --eol` 확인」을 넣는다.
- **옛 주석을 믿지 말 것 — 트레이 메뉴엔 「UI 보이기·숨기기」 항목이 없다**(좌클릭이 대신 · `tray/core.rs:7-8`). 이번에 그 낡은 주석을 따라 ADR 에 틀리게 적었다가 리뷰가 잡았다. 옛 ADR 에 도장을 찍거나 사실을 적기 전에 코드로 확인.
- **GUI QA:** 웹뷰 권한상 메인 `close()`·창 `minimize()` 가 JS 로 막힌다 → OS `WM_SYSCOMMAND` 컴파일 헬퍼가 필요. **PowerShell 로 Win32 를 직접 부르는 스크립트(P/Invoke)는 쓰지 말 것** — 사내 보안 에이전트 경보 위험, 훅이 명령 텍스트만 봐서 파일 실행은 못 막았다(이번에 5회 실행됨 — 사용자에게 보고함). 그 cmdlet 이름을 **명령 텍스트에 적기만 해도** 훅이 막는다. 다른 워크트리의 dev 앱이 떠 있으면 같은 identifier 뮤텍스 때문에 이 워크트리 debug 앱이 즉시 죽는다.
- **서브에이전트가 사용량 한도로 죽으면** `SendMessage` 로 같은 에이전트를 깨워 이어 가게 하면 된다(QA 가 그렇게 완주했다) — 깨우기 전에 `git status`·남은 프로세스·포트부터 확인.
- 런처 `.bat` 은 끝에 `pause` 가 있다 — `scripts/run-detached.ps1 -Command "scripts\rebuild-run-debug.bat"` 로 돌리면 입력 없이 끝난다.
- (앞 세션부터) GUI QA 는 「자리 잡은 뒤 스크린샷」만으로 하지 말 것 — 렌더러 교체(7단계) QA 는 프레임 단위 기록으로 칸 재생성 없음·첫 프레임 크기·소수 픽셀 글자 흐림을 본다.
