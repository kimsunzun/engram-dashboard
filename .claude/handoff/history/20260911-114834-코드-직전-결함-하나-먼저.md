## 다음 첫 액션 — ADR-0195 결함 (codex 보다 먼저)

**무엇이 문제인가:** 셸↔데몬 소켓이 끊길 때, 대기 중이던 명령을 「못 보냈음」으로 깨우는 처리가 **그 순간 한 번 훑고 마는** 것이고 명령 채널은 소켓보다 오래 산다. 훑은 직후 들어온 명령은 **다음 연결에서 실행된다.** 드문 race 가 아니라 **재연결이 도는 동안(500ms~십수 초) 들어온 명령 전부**가 그렇다. 데몬이 갈아타면 **A 에 보내려던 명령이 B 에서 실행되고 호출자는 성공했다고 듣는다.**

**결정(ADR-0195):** 끊긴 동안에는 명령을 **안 받는다** — 즉시 「연결 안 됨」 오류. 다시 보낼지는 호출자 몫. ★명령은 한 연결 경계를 넘지 않는다★가 지킬 불변식.

**손댈 곳(규명 결과):**
- `src-tauri/src/daemon_client/lifecycle.rs:257`·`:260-261` — 주석이 이미 「끊김이면 None」·「항상 current 연결의 채널」이라 적는데, 비우는 것은 **승계·종료 둘뿐**이라 평범한 끊김에 안 걸린다.
- `src-tauri/src/daemon_client/connection.rs:630` — 반대편 주석은 정직하다: 「`cmd_rx` 는 닫지 않는다 — 재연결 너머로 carry 되는 채널」. **같은 모듈의 두 주석이 서로 반대를 말한다.**
- `connection.rs:621`·`:635` — 끊김 edge 의 드레인 두 지점. `:1021` 이 `cmd_rx` 를 소켓 검사 없이 소비한다. ★비교 대상 = `connection.rs:1064-1073`★ — **응답 쪽에는 세대 표식 대조가 이미 있고 그 주석이 이 위험을 이름으로 적어 뒀다.** 명령 쪽에만 안 걸려 있다.
- `connection.rs:80`·`:85` — 재연결 지연 500ms, 상한 10s.

**구현 시 정할 것:** 「연결을 처음 세우는 중」과 「끊겨서 재시도 중」을 같게 볼지. ★ADR-0195 는 「끊긴 동안」만 정했다.★

**테스트도 같이:** `src-tauri/src/daemon_client/tests.rs:2961` 의 그 테스트는 수정 뒤 **결정적**이 된다. 더해서 ① 「늦게 실행됐나」 계수기가 **새 서버만** 세어 옛 서버 재연결을 못 잡는다 ② 실패 메시지에 어느 서버가 응답했는지가 안 찍힌다(이번 판정이 CI 로그 값 하나에 운이 좋았다).

## 검증 상태

### 돌린 것
- **적대 리뷰 3 라운드** — 1·2 라운드 full(blind + doc-aware), 3 라운드 blind 단독. **지적 전부 닫힘.**
- **외부 관행 조사(light)** — ADR-0195 근거. ★적대 리뷰 없음★. gRPC 세 줄만 메인이 원문 대조, 나머지는 수집자 자기보고.
- **결함 규명** — 로컬 90 회 반복(0 회 재현, 1% 미만) + CI 로그 실측.
- 착지 브리핑(`briefing.html`) 13 장, `/review doc light` 통과.

### 검증 안 된 것
- ★**TRD 6 판은 리뷰를 안 거쳤다**★ — 3 라운드는 5 판을 봤다.
- ★**착지 브리핑은 결정 넷(0187~0190)까지만 반영**★ — 0191~0195 가 없다. **코드 다 하고 맞추기로 함(사용자 결정).**
- **GUI 실측 없음**(소스 0 변경) · **`master` 미머지**.
- 이월 미측정 — 도구 실행 codex 턴(승인 요청 11 종 실제 도착) · 턴 도중 stdin 닫기 · 재부착 시 턴 상태 재통보 · 살아 있는 대화의 승인 정책 변경 · claude 6 값 동작 · `app-server` 에 최상위 `-s`/`-a` 공존.

- **사용자 결정 하나** — 대기 표시(§10-17): 큐에 걸린 입력을 화면에 보일지. 구현을 막지 않는다.
- **메인 판정 몫** — `InputEncoder` 셋째 태그 여부(§10-7 ②, 기본 기울기 = `Raw`).
- **T-35** — 같은 스위트 두 번째 간헐 실패(`tests.rs:2232`, 30 회 중 1 회). ADR-0195 수정이 건드리는 축이 아니라 별건. 원인 규명 안 함.

## do-not

1. ★**지어낸 낱말을 쓰지 말 것**★ — 이번 세션에 **두 번** 걸렸다(「담김」·「덱」). 저장소가 쓰는 이름이 있으면 그걸 쓴다 — 그 파일의 정본 명칭은 ★**착지 브리핑**★이다(`docs/reference/structure/agent-backend.md:209`).
2. ★**묻기 전에 코드를 먼저 볼 것**★ — 모드 표현을 선택지로 세 번 올렸는데, 답이 코드에 있었다(gemini 가 이미 claude 이름 타입을 빌려 쓰고, 바깥 이름은 이미 중립). 사용자에게 지적받았다.
3. **워커에게 주는 전제를 실측 없이 적지 말 것** — 「MCP 없음」을 조건으로 줬는데 실측 기록에 MCP 알림이 찍혀 있었다(`codex-measurements-2026-09-09.md:53`).
4. **ADR 을 위임할 땐 「채번 커밋만 허용」을 명시할 것** — 「커밋 금지」가 바인딩의 「채번 즉시 선점」과 충돌한다(2 회 연속 발생, `/adr` feedback 적립).
5. **blind 리뷰어에게 「결정 기록을 스스로 읽지 말라」를 명시할 것.**
6. **없는 메커니즘을 있다고 적지 말 것** — 없으면 **알려진 한계**로.
7. **긴 보고를 한 번에 쏟지 말 것 · 목록은 한 줄씩, 펼치는 건 하나만.**
