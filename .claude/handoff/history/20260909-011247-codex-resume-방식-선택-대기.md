## 이번 세션이 한 것

### 1. 트리 우클릭 → 코덱스 경로 실측 (코드 변경 0)

**이미 다 있었다.** 「만들어야 한다」가 아니라 「확인하면 된다」였다.

- 에이전트 트리 pane 은 **기본 레이아웃에 이미 있다** (빈 슬롯을 먼저 채울 필요 없음)
- 우클릭 → 「에이전트 생성 ▶ 코덱스 터미널」(`agentlist.createCodex`) 실재
- 예약 프로필이 `agents.json` 에 `"kind": "Codex"` 로 저장됨 (파일로 직접 확인)
- 활성화하면 실 codex 프로세스가 뜨고 TUI 가 슬롯에 렌더됨
- **사용자가 손으로 클릭까지 확인 완료 — 「잘됐음」**

**「우클릭 한 번에 뜨게」(예약 단계 건너뛰기)는 사용자 결정으로 보류.** 「어차피 클로드도 안 됐었잖아. 나중에 기능 필요하면 하지뭐.」 지금 셋(claude JSON·claude 터미널·코덱스)이 다 예약 방식이라 코덱스만 바꾸면 어긋난다.

### 2. TUI 렌더 열화 수정 → `d798020`

**증상** = codex TUI 가 우리 xterm 슬롯에서 헤더 박스 테두리와 프롬프트 회색 배경을 잃음. Windows Terminal 에선 멀쩡.

**원인** = PTY 자식에게 `TERM`·`COLORTERM` 이 **아예 없었다.** 데몬이 WMI 로 떠서(부모 = `WmiPrvSE.exe`) 상속 환경이 서비스 환경이고, portable-pty 도 TERM 을 합성하지 않으며, 저장소에 그 이름을 심는 줄이 0 줄이었다.

**수정** = `transport/pty.rs` 의 `build_pty_command` 가 `TERM=xterm-256color`·`COLORTERM=truecolor` 주입. 규율은 **ADR-0049 를 그대로 따름**(explicit-skip + `eq_ignore_ascii_case`). 상속값은 덮고 양보 대상은 프로필뿐. ADR-0184 신설 + 코드 앵커.

★**claude 터미널 모드도 같은 경로였다**★ — codex 만의 문제가 아니었고, 수정 후 육안 확인 정상.

### 검증 안 된 것

- ★**claude 터미널의 *수정 전* 모습을 안 찍었다**★ — 「원래 멀쩡했다」인지 「같이 나아졌다」인지 구분 불가.
- **대소문자 무시 가드는 Windows 에서 실패할 수 없다** — portable-pty 가 키를 소문자로 접는다. **CI 신호 0**, unix 대비 그물로만 존재.
- **`resume_failure_kind` 미측정** — ANSI 를 안 벗긴 출력 꼬리에서 문자열을 찾는다. 터미널 능력을 올리면 제어 문자 배치가 달라질 수 있다(ADR-0184 「영향」에 기록).
- **셸 백엔드 페이저 멈춤** — 능력 있는 `TERM` 을 받은 자식이 `less` 를 대화형으로 띄우면 LLM 셸 에이전트가 멈출 수 있다. **지금은 wire `AgentBackendKind` 가 `Claude`·`Codex` 뿐이라 도달 불가.** 셸 백엔드를 wire 에 올리면 되살아난다.
- **`master` 미머지** — 통합은 push → CI 초록 → 머지.
- **app-server 로 실제 스레드를 만들어 본 적 없다** — `initialize` 왕복만 실측했다(아래).

## 미결 결정 ★다음 세션의 첫 일★

**codex 는 세션 id 를 클라이언트가 지정할 수 없다.** `ThreadStartParams` 27개 속성에 id·name 이 없고, `Thread.id` 는 codex 가 UUIDv7 로 발급한다. 우리 「세션 복원」 원칙은 「복원은 **우리가 통제하는** sid 에만 의존한다」라 글자 그대로면 안 맞는다.

**4안 (적대 리뷰가 4번을 추가했다):**

| 안 | 내용 | 대가 |
|---|---|---|
| 1 | 원칙에 갈래 추가 — 「서버 발급 + 프로토콜 응답 수령 + 우리가 보관」 | ★리뷰어가 **합리화**라고 지적★ — 통제의 정의를 넓히는 것 |
| 2 | codex 만 원칙 예외 | 예외가 하나 늘고, 셋째 백엔드가 같은 길을 요구한다 |
| 3 | Phase 2 안 함 | resume·구조화 챗·우편이 통째로 막힌다 |
| 4 | **우리 id(E) 를 만들고 `E → codex thread id(T)` 매핑을 디스크에 확정** | 원칙 무수정. 단 **T 를 받고 E→T 를 커밋하기 전 크래시하면 복원 불가** → 크래시 복구 명세 필요. `turn/start` 를 허용하기 **전에** 커밋해야 한다 |

**세션 판단으로는 4안이 유력하다** — 원칙을 안 건드리고, 리뷰어가 1안을 합리화로 판정했으니. 다만 **결정은 사용자 몫이고 근거·거부 대안도 사용자가 준다**(CLAUDE.md 「결정 날조 금지」).

## do-not (이번에 실제로 데인 것 위주)

1. ★**ADR 채번 전에 `git fetch` + 전 ref 조회**★ — **3회째 재발.** 스크립트는 로컬 폴더만 스캔한다. 이번엔 로컬 max 가 0179 인데 원격에 **0183 까지** 있었다(다른 워크트리 = transport crate 작업). 조회 명령 = `git log --all --diff-filter=A --name-only --pretty=format: -- 'docs/decisions/0*' | grep -oE '0[0-9]{3}' | sort -u | tail`
2. ★**앱을 셸에서 직접 띄우지 말 것**★ — `launch-detached.ps1`. 빌드·테스트도 `run-detached.ps1`.
3. **데몬이 안 뜨면 `.engram-data/daemon.json` 의 `protocol_version` 을 먼저 볼 것** — 이번 세션 초반에 낡은 v3 파일이 데몬 기동을 통째로 막았다. 데이터 폴더는 **repo-로컬 `.engram-data/`**(포터블)이고 OS app-data 아래 동명 폴더는 옛 잔재다.
4. **테스트가 개발 셸 환경변수로 공전할 수 있다** — Git Bash 가 `TERM=xterm-256color`·`COLORTERM=truecolor` 를 이미 갖고 있어서, `CommandBuilder::get_env` 로 단언하면 코드를 지워도 통과했다. `iter_extra_env_as_str()` 로 **부모 환경에서 온 값을 걸러야** 한다. ★새 테스트는 변이 실험으로 실패 가능함을 증명할 것★
5. **`/research` 설계-결정 모드는 직접 피어 서베이가 첫 갈래(강제)** — 이번에 건너뛰고 메커니즘부터 돌렸다가 뒤늦게 추가했는데, **그 갈래가 결론을 바꿀 재료를 냈다**(paseo·Codexia 가 우리 구조 그대로 app-server 를 쓴다는 것). 다음엔 순서를 지킬 것.
6. **긴 보고를 한 번에 쏟지 말 것** — 사용자가 두 번 「뭔소리야」·「혓바닥이 길어」로 끊었다. 질문 하나에 답 하나.
