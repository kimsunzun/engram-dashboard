## do-not (이번 세션이 실제로 물린 것)

1. ★**앱 런처를 파이프로 부르지 말 것**★ — `scripts\*.bat` 은 끝에 `pause` 가 있어 배치가 거기서 멈춘다. 사용자가 프롬프트에 `! scripts\rebuild-run-debug.bat` 로 직접 친다.
2. **`cmd /c` · `cmd //c` 로 배치를 부르면 Git Bash 경로 변환 때문에 배너만 뜨고 안 돈다**(두 번 실패했다).
3. ★**PowerShell 에서 .NET 타입을 직접 불러오는 cmdlet 을 쓰지 말 것**★ — 환경 가드가 P/Invoke 패턴으로 보고 **명령 전체를 차단한다**(앞에 붙은 `gh release download` 까지 통째로 안 돈다). ★그 낱말은 **핸드오프 본문에 적기만 해도** 차단된다 — 실제로 이 문서를 쓰다 한 번 막혔다★. zip 내용은 `unzip -l` 로 본다.
4. ★**여러 줄 블록을 head/tail 스플라이스로 갈아끼울 때 tail 오프셋을 틀리면 블록이 중복된다**★ — 실제로 테스트 함수 둘을 복제해 컴파일이 깨졌고, ★`cargo build` 는 lib 만 빌드해서 못 잡았다★. 스플라이스 뒤엔 **테스트 컴파일까지** 확인할 것.
5. **blind 리뷰어에 diff 만 주지 말 것** — 화면이 문서화하는 **명령 선언부**가 자료에서 빠져 오독한다(`layout.setSlotContent` 를 틀렸다고 지적했는데 그가 연 것은 같은 이름의 프론트 레지스트리였다).
6. **로컬에서 이 플레이키를 재현하려 하지 말 것** — 전체 agent 스위트를 CI 와 같은 무제한 병렬로 돌려도 764건 전부 통과한다(4.87초). 이미 해 봤다.

## 미결 · 밀린 것

**이 세션이 새로 찾은 것**
- ★**같은 개념에 철자가 둘인 자리 둘**★ — 분할 방향(CLI `LeftRight`/`TopBottom` ↔ 프론트 직결 `left_right`/`top_bottom`) · `layout.setSlotContent`(선언은 평평·PascalCase ↔ 프론트 레지스트리는 중첩·snake_case). 밑줄은 대소문자 축이 아니라 ADR-0221 의 관용이 안 메운다.
- `src/main.tsx` 의 theme 전역 핸들은 검증이 **아예 없다**(DEV 전용).
- `transport` crate 가 CLAUDE.md 모듈 맵에 없다.
- **enum 대소문자 관용이 `backend` 밖으로 번졌다** — `output_format`·`SlotContentKind`·`ThemeOrigin` 까지. 되돌릴 자리는 `command/src/table.rs:131` 한 줄.
