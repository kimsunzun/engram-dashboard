## master 머지하는 법 (막힐 수 있다)

**master가 다른 워크트리에 체크아웃돼 있으면 여기서 `git checkout master`가 안 된다.** 이번 세션은 wt1이 잡고 있어서 **임시 워크트리**로 우회했다:

```bash
git worktree add <tmp> --detach origin/master
cd <tmp> && git merge --no-ff <브랜치> && git push origin HEAD:master
cd - && git worktree remove <tmp>
```

**부작용:** 그 워크트리의 로컬 `master` ref는 안 움직인다(git이 거부한다). 거기서 작업할 때 `git pull` 한 번 필요하다.

1. **`__ENGRAM_AGENT__`·`__ENGRAM_DAEMON__`가 릴리스에 무가드로 열려 있다** — `src/api/clientFactory.ts:29`/`:31`. 방금 지운 둘보다 넓다(spawn·kill·프로필·프리셋 + 데몬 기동·정지). 그 파일 헤더가 스스로 「임시 경로」라 자인한다. ★`/qa` 실측 조리법이 이걸 의존한다★(프로필 생성·삭제에 대응 커맨드가 없다) — 지우려면 대체 경로가 선행.
2. **`agent.spawnInto` 고아 프로세스** — 슬롯 점유로 거절할 때 **에이전트는 이미 떠 있다**. 호출자가 "아무 일 없었다"로 읽으면 claude 프로세스가 샌다. 우회 = `layout.setSlotContent {type:'agent', agent_id}`. ★가장 값싸고 이득이 크다★
3. **Step 3의 마지막 조각 — 클라이언트 자작 식별자.** 완결로 기록됐으나 미구현. 셸이 재접속하면 데몬 눈에 다른 주인으로 보인다.
4. **Step 2를 완결로 볼지** — 설계 문서 넷이 데몬 `mail.*` 선언을 전제하는데 코드엔 0건. **사용자 결정**.
5. **챗 스타일을 저장 시스템 설정 항목으로** — ADR-0169. 그때까지 릴리스에서 챗 여백·글자 크기를 못 바꾼다.

**선존 결함 하나 더:** `docs/reference/architecture-overview.md`의 renderMode 다이어그램이 구독 deps를 `[viewId, agentId, epoch]`로 적었는데 ADR-0164는 화신 표식을 **넣지 않는다**고 못 박는다.
