## ★빚 — 결정 기록 하나가 안 박혔다★

**겹친 요청 번호 처리를 뒤집었는데 ADR 이 없다.** TRD §4-1 과 `pending.rs`·`lib.rs` rustdoc 에만 있다.

- **뒤집은 내용:** 옛 문안 = 「옛 대기자를 `Superseded` 로 깨우고 **새 것이 승계** — 오늘 동작 보존」 → 지금 = 「그 번호를 **은퇴**시켜 **양쪽 다 실패**」(옛 것 `Superseded`, 새 것 `TagRetired`).
- **근거:** 승계를 두면 먼저 나간 요청의 늦은 답장이 나중 요청 주인에게 배달된다(상관 키가 그 번호 하나뿐). ★틀린 답이 실패보다 나쁘다★.
- **대가:** 이 경로에서 오늘 셸 동작이 보존되지 않는다. 살아 있는 번호를 되쓰는 소비자는 **성공 하나 대신 실패 둘**을 받는다.
- **거부한 대안:** 승계 유지(오배달 수용) · `Wire` 에 일곱째 칸을 더해 둘을 가르기(모든 소비자가 깨진다).
- 결정 주체 = 메인이 정하고 사용자에게 근거와 함께 보고, 사용자 이의 없음(2026-09-06).
- **회귀망** = `pending::tests::a_reply_for_a_collided_tag_reaches_nobody`
- TRD 에 「결정 기록은 이 문서가 아니다 — 별도로 정리된다」로 자리를 비워 뒀다. **ADR 번호가 붙으면 그 줄만 고치면 된다.**

## 이번 세션이 사용자와 확정한 것

**알림 표면(ADR-0180):** 띠는 알리고 팝업은 「네가 눌러야 한다」를 말한다 · 팝업 자격 = **사용자가 행동하지 않으면 영영 복구되지 않는 상태만** · 팝업은 **범용 컴포넌트**로 짓고 경고는 그 위 한 용례(나중 콘텐츠 팝업이 같은 토대를 쓴다) · **판정은 앱 전체 기준** — 데몬이 하나라도 남아 있으면 띠, 전부 잃었을 때만 팝업 · 재연결 컨트롤·횟수는 **셸 소유**(기본 3회, 설정 파일에 얹는다 — ADR-0166 방식) · 붙었다 거절당하면 카운트 안 쓰고 즉시 포기 · 버전 불일치 팝업 = **문구 + 닫기**(강제 종료 버튼 없음).

**요청 시한(ADR-0181):** 명령 무관 **공용 하나, 8초** · 만료는 **그 요청만** 실패시키고 연결은 유지 · ★**자동 재전송 금지**★(무응답은 「실패」가 아니라 「모른다」 — 중복 생성) · 늦은 답장 버리고 그 번호 재사용 금지 · 「기다리는 중」 표시 1초는 **화면 몫**(제안 기본값, 셸 단계에서 확정).

**사건 방출(ADR-0182):** transport 가 붙음/끊김·거절 사유·재시도 회차·유실 구간을 **구조화해 올린다** · 화면은 안 만든다 · 자기가 아는 것만 올린다(에이전트 오류·명령 실패는 위층 몫).

**그 밖:** crate 는 **붙는 쪽·받는 쪽 양쪽**을 다 만든다(받는 쪽이 있어야 crate 혼자 양쪽을 붙여 검증할 수 있다 — 사용자 결정) · 상대 이름표는 **소비자(셸)가 붙인다** · 모바일은 **앱을 깐다**(그래서 이 Rust crate 가 폰에서도 돈다 — 소비자 셋을 다 덮는다) · 데몬끼리 중계는 **나중 리서치**(이 crate 는 안 바뀐다 — 받는 쪽 + N 개 명부가 양쪽 위상을 다 받친다) · 「표시는 이름, 배달은 고유키」 — 내부는 **이미 UUID**(`protocol/src/ids.rs:4`)고 **우편만 이름을 주소로 쓴다**, 동명 배달 규칙은 나중 리서치.

## 실패한 접근 / do-not

1. ★**대량 수정을 한 워커에게 통째로 맡기지 말 것**★ — 리뷰 결함 23건을 한 명에게 줬고 **571k 토큰·도구 93회에 API 한도로 죽어 컴파일 불가 트리를 남겼다.** 그때 crate 가 미추적이라 초록 상태의 커밋이 없어 **되돌릴 기준점조차 없었다.** 이 사고로 전역 규칙 「위임 우선」에 조항 넷이 추가됐다(착수 시점 크기 판정 · 쪼개는 축 = **파일 겹침** · 「중간 어디서 멈춰도 빌드가 서게 순서를 짜라」 · **위임 전에 되돌릴 지점 만들기**). **그 조항을 읽고 따를 것.**
2. ★**「한도 가까우면 멈춰라」를 워커 지시로 쓰지 말 것**★ — 워커는 자기 컨텍스트를 못 본다(실측). 대신 **순서**를 지정한다.
3. ★**저자에게 「변이 증명」을 시키는 것만으로는 가짜 회귀망을 못 막는다**★ — 두 라운드 연속 났다. 저자는 **자기 하네스가 만들 수 없는 조건을 모른다.** 유효했던 것 = **리뷰어에게** 「이 테스트가 이름값을 하나 — 그 동작을 제거·반전해도 통과하나」를 명시 항목으로 주는 것(두 라운드 다 그 항목에서 적출). 적립 = `~/.claude/skills/review/feedback.md` 2026-09-06 절.
4. ★**하네스도 리뷰 대상에 넣을 것**★ — 그렇게 지시하니 하네스 결함 3건이 나왔다(멈춘 쓰기를 깨울 waker 없음 → 두 테스트가 장식 · 수동 시계가 등록 순으로 깨움 · `settle()` 이 멀티스레드에서 무보장).
5. ★**수정이 만든 새 표면을 아무도 안 본다**★ — 재리뷰에 「새로 생긴 데를 제일 세게 쳐라」를 넣으니 **블로커 4건 중 3건이 거기서 나왔다.**
6. **「팝업이 하나도 없다」로 단정하지 말 것** — 컴포넌트 **이름** 검색(`Dialog|Modal|AlertDialog|createPortal`)은 0이지만 화면을 덮는 표면은 이미 있다(`SlotContextMenu.tsx` 의 `position:fixed` · `@tauri-apps/plugin-dialog` 3곳). 없는 것은 **재사용 가능한 모달 컴포넌트**다.
7. **「데몬 kill 은 금지 경로」로 읽지 말 것** — ADR-0158 결정 3 이 금지한 것은 ★**자동**★ kill 이다. 사용자가 눌러 죽이는 것은 그 조항에 안 걸린다(지난 세션 인계가 이걸 틀리게 적었다).
8. **「요청별 시한이 아예 없다」는 거짓** — `src-tauri/src/commands/agent.rs:263` 에 `REPLY_TIMEOUT = 30초` 가 **한 경로에만** 있고 나머지 핸들러는 맨몸이다. 8초 채택은 **그 30초를 낮추는 것**이다.
9. **여러 항목을 한 번에 올리지 말 것** — 목록은 한 줄씩, 펼치는 것과 묻는 것은 **하나만**.
