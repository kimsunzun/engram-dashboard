## S18 확정 설계 요지 (정본은 spec — 여긴 지도만)
XML 봉투 단일화(콜론 기본 폐지·스위치 잔존) · `<message from …>` vs `<notice>`(데몬 통지, from 없음) · 타입 최소형: 기본(통보)/`request`(단일 수신자만, 장부 미회신+`reply_by` 타임아웃→발신자 notice)/회신=`in_reply_to` **필드**(엄격 매칭) · 그룹=런타임 등록 명단(이름 기반)+내장 `@all`, 스냅샷 fan-out·죽은 멤버 skip·파킹 없음 · 메일박스=인메모리 파킹(미존재 이름 포함), TTL 1h·수신자당 100·초과 반려, notice는 cap 예외 · 입구=MCP 주력 3툴(send_message/messages/group)+CLI 예비(`--body-stdin` 추가) · **allowedMcpServers 유저 전역 `[]` 차단 → 데몬이 스폰 시 `--settings`로 engram 허용 조각 세션 주입**(전역 무변경 — 사용자 원칙).

## do-not (재발 방지)
- 직전 세션 do-not 승계: 재실행 전 stray 프로세스 kill(`Stop-Process -Name engram-dashboard,engram-dashboard-daemon -Force`) · 소스 변경 후 릴리즈 재빌드 필수(이제 `launch\빌드.bat` 또는 `pwsh scripts/build-release.ps1 -OutDir <abs>\launch\release`) · 순수 `cargo build --release`로 Tauri 앱 빌드 금지 · bare `cargo test` 금지(워크스페이스 -p 열거).
- **에이전트 출력 구독을 JS API로 직접 검증하지 말 것** — viewId 누락 오용으로 error-phase 오탐 전례(2026-07-24). 실 UI 슬롯 DOM 관측이 정본 경로.
- 스폰 검증 에이전트는 `spawnAgent(cwd)`가 아니라 claude 프로필 생성+`spawnProfile`(spawnAgent=Shell 백엔드). 수신자는 stream-json만(TUI 수신 불가 — by design, TUI는 시연용).
- 유저 전역 `~/.claude/settings.json`의 `allowedMcpServers: []`를 고치지 말 것(사용자 원칙: 전역=차단 유지) — 해법은 스폰 `--settings` 주입뿐.
- 이 세션 실패 접근: 전역 allowlist 수정 시도(권한 분류기 거부 + 사용자 원칙 위반) · 프로젝트 로컬 settings 허용(에이전트 cwd 임의라 무력).
