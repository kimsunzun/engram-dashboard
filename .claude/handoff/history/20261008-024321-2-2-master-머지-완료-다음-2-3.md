## do-not
- **채번 전 원격 전부 확인 — ADR 만이 아니라 tracking T 번호도**(이번에 storage 가 T-48~T-51 을 먼저 써서 충돌 · 재번호). ADR: `git -c core.quotepath=off ls-tree --name-only <ref>:docs/decisions`(quotepath 없으면 한글 파일명이 따옴표로 나와 grep 이 빗나간다).
- **master 머지 직전 `git merge-tree` 를 다시 돈다** — 그 사이 다른 브랜치가 master 에 들어올 수 있다(이번 실발생 → 흡수 머지). 흡수 머지 리뷰는 `git show --remerge-diff <merge>` 를 리뷰어에게 준다.
- CRLF 저장소 — 코더 지시서에 「Edit 도구만 · sed -i 금지(CRLF→LF 무음 변환) · `cargo fmt` 뒤 `file`/`git ls-files --eol` · `unix2dos -q`」. Git Bash `grep $'\r$'` 는 거짓 결과.
- 하네스 `rg` 는 셸 함수 — 서브셸 전에 `export -f rg`.
- codex `--resume` 첫 줄에 「직전 턴에 무엇을 했나」(이번 세션 전부 정상 물림).
- 리뷰어 스냅숏 diff 는 만든 명령(`git diff -U5 …`)을 지시서에 그대로 적는다(재생성 비용).
- TRD 는 고치지 않는 설계 문서 — 착지 뒤 갈린 것(이번: U2 +14 · U4 −65 · O3 전제 오류 · ws_e2e 레인 가정)은 step-log 에 적는다.
