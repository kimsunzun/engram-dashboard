## 실패한 접근 (다시 하지 말 것)
- **자동 포커스를 「첫 콘텐츠 칸」으로** — 사용자가 고른 적 없는 에이전트 칸에 포커스가 앉아 트리 「열기」가 그 화면을 덮어썼다(1 라운드 리뷰 적출 → 되돌림).
- **Allotment key `${dir}:${ratio}`** — 부팅 기본이 빠진 뒤 운영의 분할은 전부 0.5 라 사실상 `dir` 만 가른다. **첫 슬롯 id key** — 무관한 형제까지 재마운트된다. 둘 다 ADR-0223 의 거부 대안.
- **CRLF 파일을 Git Bash `sed -i`·단일 파일 `rustfmt` 로 고치기** — 파일 전체가 LF 로 뒤집힌다. 이번 세션에 세 번 났다(Edit 도구 뒤에도 한 번). 편집 뒤 `grep -c $'\r$'` = 줄 수를 확인한다.
- **`codex exec` 에 프롬프트를 `cmd //c "…"` 로 넘기기** — 따옴표가 풀려 `unexpected argument` 로 죽는다. `-` + `< prompt.txt`(stdin)로 넘긴다.
- **읽기 전용 리뷰어에게 `lib_unit` 필터 실행을 허용할 때** — `layout::spatial` 처럼 `export_bindings` 테스트에 걸리는 필터는 바인딩 파일을 다시 쓴다.

## 정지 조건 (멈추고 사용자에게 묻는다)
- **ADR-0224 결정 5**: 포커스된 칸이 내용 교체로 트리가 될 때 — (a) 직전 콘텐츠 칸으로 폴백(일관되지만 `LR{A: 에이전트, B: 빈 칸(포커스)}` 에서 B 를 트리로 바꾸면 포커스가 A 로 가고, 「열기」가 A 를 덮는다 = 되돌린 회귀와 같은 시나리오) vs (b) 포커스 없음(안전, 대신 상대 방향 기준점 소실). **이게 정해지기 전엔 구현하지 않는다.**
- 머지 때 `git merge-tree` 종료코드가 0 이 아니면 멈춘다(충돌 해소는 임시 워크트리에서).
- ADR-0225 구현 전 재확인(결정 3)에서 `agent-tree` 를 띄우는 경로가 하나라도 나오면 멈춘다.
