## 이번 세션이 한 것

**codex resume 방식 4안은 선택지가 아니었다.** 지난 세션이 올린 4안 중 1·4 안은 **코드상 같은 것이고 이미 구현돼 있었다** — 우리 id = `AgentId`, 백엔드 id = `backend_session_id`(`profile.rs:165`), 수령 = `observe_session_id`(`profile.rs:629`). 발급 주체 중립 구조가 이미 서 있어서, 남은 일은 원칙 문장을 원래 뜻대로 적는 것 하나였다.

**사용자 결정 = 「고치고 진행」.** 그래서:

- **ADR-0185 신규** — 0008(`sid 발급 주체`) · 0076(`우리 쪽 sid 발급 전제`) · 0082(`살아남는 상위 결정 중 sid 발급 조항`) **부분 개정**, 양방향 도장 전부 스크립트로.
- **원칙 문장 교체** — CLAUDE.md 「세션 복원」 · `docs/reference/architecture-overview.md` 「세션 복원 / 활성화」. 「복원은 프로필에 저장된 backend sid 단독에 의존하고, **발급 주체는 백엔드가 정한다**」.
- **코드 변경 0.**

### ★리뷰가 결정 내용을 고쳤다 — 여기가 이 세션의 핵심★

「코드 변경 0」을 글자 그대로 따르면 **조용한 대화 유실**이 무장된다:

- 활성화 입구 둘(`commands.rs:521` · `connection_core.rs:1126`)이 저장된 sid **하나만** 보고 `SpawnMode::Resume` 을 유도하며 `needs_session()` 을 **보지 않는다**(부팅 복원 `manager.rs:1376` 은 본다).
- codex 는 `needs` 가 false 라 `spawn_agent` 이 sid 를 안 넘기고(`manager.rs:954-962`) `build_spec` 이 `_mode` 를 무시해(`backend/codex/mod.rs:93`) **새 대화가 열린다.**
- ★**그것이 새 대화라는 표식이 wire 에 하나도 없다**★ — `AgentSpawnOk`(`commands.rs:807-814`)도 `AgentEvent::Spawned`(`protocol/src/messages.rs:468-471`)도 resume 여부를 안 싣는다. ★`resumed` 를 grep 하지 말 것★ — `commands.rs:1090` 의 `#[cfg(test)]` 지역변수 하나뿐이다.

그래서 ADR 결정 2 가 **Phase 2 요구사항 셋**을 명시한다: ① 수령 배선 ② `needs_session()` 쪼개기 ③ 활성화 입구 가드.

★**②가 ①을 열어 주지 않는다**★(2라운드가 잡은 오해) — claude watcher 는 `backend::session_id_source` 가 **우리가 발급한 기준 sid**(`expected_sid: Uuid`)를 요구하는 **파일 폴러**이고(`backend/mod.rs:348-353`) codex 의 id 는 JSON-RPC 응답으로 온다. 수령을 켜는 것은 **배선 하나**다. ②를 쪼개는 이유는 따로다: `restore_one` 이 codex 를 resume 가능으로 보게 하려면 그 플래그를 켜야 하는데 켜면 **발급도 함께 켜진다.**

## 미결 쟁점 ★다음 세션의 첫 일 · 이것만 정하면 push★

**CLAUDE.md 「세션 복원」에 트랩 한 줄을 남길지 지울지.**

지금 남아 있는 문장 = 「★단 발급받는 쪽은 배선이 아직 없다 — 그 상태로 sid 를 심으면 codex 가 새 대화를 열고, 그것이 새 대화라는 표식이 wire 에 하나도 없다★(활성화 입구가 `needs_session()` 을 안 본다. 가드는 ADR-0185 결정 2 = Phase 2 요구사항)」.

| | 주장 | 근거 |
|---|---|---|
| **blind(cut-advocate)** | **지워라** | 그 절 자신이 「매핑 근거·예외·혼동쌍은 여기 되올리지 않는다 — 정본은 architecture-overview」라고 적는다. 2라운드 내내 이것을 1순위로 냈다 |
| **doc-aware(load-bearing)** | **문구를 고쳐 남겨라** | 트랩이 사라지면 Phase 2 세션이 근거 없이 sid 를 심는다. 실제로 문구 오류(`resumed: true`)를 지적해 고치게 했고 삭제는 요구하지 않았다 |

**자율 모드 보수 취합 = 유지(잠정).** 판결이 아니라 안전측 대기다. 판정 후 push 하면 된다 — 지우기로 정하면 그 한 문장만 빼고 재커밋하면 되고, 상세는 이미 architecture-overview 에 전부 있다.

## do-not (이번에 실제로 데인 것)

1. ★**python heredoc 안에 한글을 넣지 말 것**★ — Git Bash 경유 `python - <<'EOF'` 에서 한글 문자열 리터럴이 **부분 손상**됐다(주체→주잴, 규→굴, 측→찬 등 10곳). 검증된 경로 = `cat > file <<'EOF'`(안전) **+ python 은 그 파일을 `rb` 로 읽어 바이너리로 스플라이스**. 손상은 조용해서 `grep` 으로 찍어 봐야 보인다.
2. ★**`rg -c ... | head -1` 로 0줄 게이트를 판정하지 말 것**★ — 파이프 종료코드가 `head` 것이라 `||` 가 안 걸리고, **0줄과 경로 부재가 똑같이 빈 출력**이 된다. `--count-matches ... | wc -l` + `test -d` 를 따로 찍는다.
3. ★**ADR 채번 전 `git fetch` + 전 ref 조회**★ — 4회째다. 이번엔 걸렀다(로컬 max 0179, 원격 0184 → 0185). 명령 = `git log --all --diff-filter=A --name-only --pretty=format: -- 'docs/decisions/0*' | grep -oE '0[0-9]{3}' | sort -u | tail`
4. ★**`adr.mjs index --write` 가 큐레이션 셀을 덮어쓴다**★ — `link`/`supersede` 로 정형 링크가 박히면 보존이 아니라 파생으로 바뀌어, ADR-0082 행의 「Failed 는 일상어」 단서가 사라졌다. 손으로 복원했지만 **`index --check` 가 여전히 `rewritten` 을 예고한다 → 다음 `index --write` 가 또 지운다.** 스킬 feedback 에 적립함(`~/.claude/skills/adr/feedback.md` 2026-09-09).
5. **빌드·테스트는 `scripts/run-detached.ps1`** — 셸에서 직접 돌리지 않는다. 완료 판정은 프로세스 부재가 아니라 로그 끝의 `__EXIT=` 마커.
6. **긴 보고를 한 번에 쏟지 말 것** — 사용자가 「뭔소리야」로 한 번 끊었다. 4안 표를 그대로 올린 것이 원인이었다(그 표 자체가 틀렸다). 질문 하나에 답 하나.
