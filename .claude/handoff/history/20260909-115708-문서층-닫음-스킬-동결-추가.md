## do-not (이번에 실제로 데인 것)

1. ★**python heredoc 안에 한글 문자열을 넣지 말 것**★ — Git Bash 경유 `python - <<'EOF'` 가 한글을 **부분 손상**시켰다(주체→주잴, 규→굴, 측→찬 등 10곳). 손상이 조용해서 `grep` 으로 찍어야 보인다. **안전 경로 = `cat > file <<'EOF'` 로 쓰고, python 은 그 파일을 `rb` 로 읽어 바이너리로 스플라이스.**
2. ★**`rg -c ... | head -1` 로 0줄 게이트를 판정하지 말 것**★ — 파이프 종료코드가 `head` 것이라 `||` 가 안 걸리고 **0줄과 경로 부재가 똑같이 빈 출력**이 된다. `--count-matches | wc -l` + `test -d/-f` 를 따로 찍는다. (이 함정을 do-not 에 적어 두고도 같은 세션에서 또 밟았다.)
3. ★**바이트와 문자를 섞어 세지 말 것**★ — 「729 바이트」로 적은 것이 실제로는 문자 수였고, 그 하나가 **가짜 축소 궤적**을 만들어 ADR 본문·step-log 를 동시에 오염시켰다. 적대 리뷰가 잡았다. 크기를 주장할 땐 `wc -c` 로 재고 단위를 적는다.
4. ★**ADR 채번 전 `git fetch` + 전 ref 조회**★ — 4회째 걸렀다. 명령 = `git log --all --diff-filter=A --name-only --pretty=format: -- 'docs/decisions/0*' | grep -oE '0[0-9]{3}' | sort -u | tail`
5. ★**`adr.mjs index --write` 는 큐레이션 셀을 매번 덮어쓴다 — 이번 세션에서 3회**★. ADR-0082 행의 「Failed 는 일상어」 단서가 매 실행마다 사라졌다. `index --write` 뒤엔 `grep -c 'Failed" 는 일상어' docs/decisions/README.md` 로 확인하고 복원한다. (스킬 결함, feedback 적립분 — 미반영)
6. **빌드·테스트는 `scripts/run-detached.ps1`** — 완료 판정은 프로세스 부재가 아니라 로그 끝의 `__EXIT=` 마커.
7. **문서 전용 델타에 워크스페이스 회귀를 다시 돌리지 말 것** — CI 가 그것을 소유한다. `/qa` 바인딩의 「산문 문서 전용」 조건이 브랜치 diff 로 판정하게 돼 있어 형식상 면제가 안 떨어지지만, 델타가 문서뿐이면 정보량 0 이다.
8. **긴 보고를 한 번에 쏟지 말 것** — 사용자가 「뭔소리야」로 한 번 끊었다. 원인은 틀린 4안 표를 그대로 올린 것. 질문 하나에 답 하나.
