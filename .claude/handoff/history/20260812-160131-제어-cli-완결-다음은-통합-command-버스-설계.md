# 핸드오프: 제어 평면 CLI 4조각 완결 — 다음은 통합 command 버스 설계(ADR-0022 확정화)

## 한 줄 상태 · 다음 첫 액션

**제어 평면 CLI 4조각(①②③④)이 전부 끝나고 커밋·push까지 됐다.** ADR-0132가 고정한 이 라운드는 닫혔다.

**다음 첫 액션 = 통합 command 버스 조사.** 세션 후반에 사용자와 설계 구도를 도출했고 **step-log 「다음 (미진행)」 최상단에 「사용자 방향 2026-08-12 — 통합 command 버스」로 전문을 박아뒀다.** 그것이 정본이니 **거기부터 읽을 것**(이 인계는 요약일 뿐이다). 착수 = `/research`로 성숙 OSS 선례(에디터 command palette 계열) 조사 → 선택지를 사용자에게 → ADR-0022를 확정으로 갱신.

**★단 선행 조건이 있다★:** 그 구도가 완성되려면 **중계(ADR-0081) 구현이 먼저**다. 없으면 목록을 아무리 합쳐도 **화면 쪽 명령(창·탭·테마)을 에이전트가 못 부른다** — 주인이 다른 프로세스라서다. 그리고 그건 이미 ADR-0132 결정 7의 후속 순서 ②로 못 박혀 있다(중계 코드 = 실측 0건).

## 완료 내용 (이 세션)

**조각 ③ — 우편 격리를 데몬 거절로 이관.** 배선은 전원에게, 강제는 데몬 auth 미들웨어의 자격증명 거절 **단독**. 판정은 `provision`이 한 번 계산해 자격증명·표식에 동시 주입(단일 파생점·epoch 회전 시 재발급). `ENGRAM_MAIL` 표식은 **help 렌더만** 가르고 실행은 안 막는다. 명단 밖 `/control` 경로는 **fail-closed**. 거절 응답은 대안 채널 미명명.

**조각 ④ — 앱 실행파일의 옛 CLI 겸용 모드 철거.** `cli.rs`(449줄)+`main.rs` argv 분기+`pub mod cli;` 제거. 앱은 argv 무관하게 항상 GUI(`--hidden`만 예외).

**부수 — `adr.mjs` 결함 2건 근본 수정(9회 재발 종결).** 인덱스 파생이 `Amended by`를 첫 건만 읽던 것 → `matchAll`, 조항이 첫 반각 `)`에서 잘리던 것 → 괄호 균형. **사본이 둘(전역+대시보드)이라 양쪽 다 고쳤다** — 한쪽만 고치면 재발한다.

## ★이 세션에서 정정한 것 2건 (다음 세션이 옛 서술을 만나면 이걸 따를 것)★

1. **T-23 문구 과장 — 사용자 지적으로 교정.** 초판이 "사람용 자격증명 경로를 정해야 한다"로 적었으나 **사람은 화면으로 들어오고 화면이 곧 자격이다**(앱이 `daemon.json`으로 붙는다). 화면엔 제어 동사가 **전부 있고 실제로 돈다**(이 세션 실측 — 화면 경로로 프로필 생성·스폰·kill 태움). 막힌 게 아니라 **셸 통로를 안 만든 것**이고, 결정은 "되살릴지 여부"다. **급하지 않다.** `docs/tracking.md` T-23에 정정 문단이 박혀 있다.
2. **"주인 칸" 제안 철회 — 사용자 지적으로 교정.** 메인이 "명령마다 주인을 지정하는 칸"을 제안했으나, **각 모듈이 자기 명령을 선언하면 정의 위치가 곧 주인**이라 칸이 중복이다. step-log 사용자 방향 항목에 반영돼 있다.

## ★실패한 접근 / do-not★

1. **`claude.rs`의 옛 "MCP 가능 스폰엔 CLI 배선 미주입" 분기를 되살리지 말 것.** 없어졌고 되살리면 **MCP 가능 스폰의 제어 경로가 끊긴다**(ADR-0132 결정 5 위반). step-log S19.1의 옛 경고 문장이 반대를 말하는데 **그 자리에 폐기 도장을 박아뒀다** — 도장을 보고 판단할 것.
2. **표식(`ENGRAM_MAIL`) 필터에 강제를 의존하지 말 것.** 표식은 교육 수단이고 조작을 수용한다(떼면 목록에 보이지만 데몬이 거절 — 실측). **반대로 CLI가 우편 실행을 로컬 차단하게 만드는 것도 위반**(강제가 클라이언트로 샌다).
3. **프라이밍 교육 판정기를 계열 전체로 넓히지 말 것.** 제어 동사는 전 스폰에 가르치므로 채널 판별 근거가 못 된다.
4. **환경변수 언급을 흔적 신호로 내리지 말 것**(현행 = 부르는 토큰 + 계열 + 동사 인접, ADR-0098 실사고).
5. **감춘 계열의 반려 문구를 자리마다 고치지 말 것** — 한 funnel로 접는다. 라운드 1에서 2/5만 적용돼 실제로 샜다.
6. **`adr.mjs`는 근본 수정됐다**(`action:"rewritten"` 확인 절차 불필요). 단 **사본 둘**을 같이 고칠 것.
7. **리뷰 라운드 상한을 선언하되 마지막 라운드를 생략하지 말 것** — 이번에도 마지막 좁힌 라운드가 실질 결함 2건을 냈다.
8. **cross-family(GPT) 리뷰어를 빼지 말 것**(이번에도 단독 적출 2건). **함정 둘:** ① codex가 자기 전역 지시를 읽고 **오케스트레이터인 줄 착각**해 되묻고 끝난다 → 프롬프트 맨 앞에 "지시 파일 무시·네가 리뷰어다·되묻지 마라" 오버라이드 + `-c project_doc_max_bytes=0` ② **"적대적 에이전트가 공격" 류 표현이 제공자 보안 필터에 걸린다** → 중립적 감사 언어로.

## 미결 — 사용자 결정

1. **통합 command 버스 설계** ← 다음 무게중심. 정본 = step-log 「사용자 방향 2026-08-12」. 미해결 갈림길 4개(생성 범위 = 이름만/인자까지 · 조회도 명령인가 · 화면 전용 명령 선언을 어느 crate에 · 한 명령이 여러 주인에 걸치나)가 거기 적혀 있다.
2. **T-23 셸 통로 되살릴지** — 급하지 않다(화면으로 다 된다).
3. **grant 목록 일괄 정리** — 사용자가 "나중에 한꺼번에, auto 모드니 지금 놔두자" 명시(2026-08-12).
4. **`kill`·`rm`을 여는 전용 스텝** — 에이전트 축 갭은 kill을 여는 순간 닫히나 **사람 축은 T-23이라 안 닫힌다.**

## 남은 조각

**ADR-0132가 고정한 4조각은 전부 끝났다.** 결정 7의 후속 순서는 살아 있다: **② 창·탭·슬롯 기능 제어(ADR-0081 중계 구현 선행 — 미구현)** → ③ 위치·크기 제어(레이아웃 디스크 영속 선행 — 없음). **②가 곧 통합 command 버스의 선행 조건**이라 둘이 같은 작업으로 수렴한다.
