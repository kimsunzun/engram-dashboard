## 다음 할 일 (ADR-0175 실행 순서)

1. ~~개명~~ ← 여기까지 옴. 리뷰 → QA → 푸시 → CI 초록 남음.
2. **`base` 신설** — `logging`(692줄) + `platform/process.rs` PID 헬퍼(325줄)를 새 잎 crate 로. **Job Object(`platform/windows.rs`)는 `agent` 에 남긴다**(소비자가 agent 안뿐). 딸려 이사하는 의존 = `regex`·`tracing-subscriber`·`windows`. 가시성 승격 불필요(`pub(crate)` 0건 실측). **헤더에 입주 조건 3개를 박을 것**(소비자 2 이상 · 도메인 지식 0 · 서로 참조 0). 게이트를 **세 곳**(ci.yml · CLAUDE.md · qa.md)에 등록.
3. **`replay_flight` → 셸 모듈** — `src-tauri/src/daemon_client/replay_flight.rs` 의 4줄 재수출을 실물로. 헤더의 죽은 근거("headless 에서 테스트가 실행된다" — ADR-0174 로 죽음)와 `daemon/src/connection_core.rs:1494` 주석 경로도 같이 고친다.
4. **`ui.` 접두** — 웹뷰가 답하는 명령에만. 데몬(`agent.*`)·셸(`tab.*`·`slot.*`)은 그대로. ★**착수 전에 사용자에게 적용 범위를 물을 것**★(어느 웹뷰 명령까지 붙일지 미확정).
5. **`COMMAND_SPECS` 간선 제거 + 충돌 시 앱 표면 고지** — 4번이 끝나야 가능하다(아래 정지 조건).

## 정지 조건 (사용자에게 물어야 하는 자리)

- **4단계 `ui.` 접두의 적용 범위** — 아직 안 정했다. 사용자 결정.
- **`base` 에 세 번째 입주자를 넣고 싶어질 때** — ADR-0175 「거부한 대안」 첫 항목을 다시 여는 지점이다(리뷰어 둘 다 `base` 묶음에 반대했고, 사용자 판단으로 채택했다).
- 리뷰가 **BLOCK** 이면 임의 판정 금지 → 사용자.

## 실패한 접근 / do-not

- ★**`git stash pop` 충돌을 `git add` 로 삼키지 말 것**★ — 이번 세션에서 실제로 저질렀다. 충돌 마커 6줄이 커밋·푸시됐고 후속 커밋으로 걷었다. 리팩터 브랜치와 `chore/misc` 는 피드백 파일 이력이 갈라져 있어 그 사이 이동은 **항상 충돌한다.**
- **`--exclude engram-dashboard` 붙이지 말 것** — 2026-08-25 에 걷혔다. 워크스페이스 회귀는 이제 셸 패키지를 포함해 돈다.
- **net 게이트 2 를 「0줄 기대」로 내리지 말 것** — 개명 후 옛 이름이 사라졌다고 0 으로 바꾸면 **어떤 위반으로도 못 깨지는 죽은 게이트**가 된다. `engram_dashboard_agent::` 로 재조준하고 개수 2 를 유지하는 것이 맞다(이미 그렇게 해 뒀다).
- **codex(blind) 리뷰어를 전경으로 띄우지 말 것** — Bash 기본 10분 타임아웃에 죽는다. 처음부터 백그라운드로.
