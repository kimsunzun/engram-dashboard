## 실패한 접근 · 함정 (다시 하지 말 것)
- **GUI QA 를 「자리 잡은 뒤 스크린샷」 만으로 하지 말 것** — 한 프레임짜리 쭈그러짐을 놓쳤다. 이번 구현 QA 는 프레임 단위 기록(rAF 기록기 또는 CDP screencast)으로 **칸 재생성 없음 · 첫 프레임 크기 · 소수 픽셀 글자 흐림**을 본다.
- **ADR 채번 스크립트는 로컬 폴더만 센다** — 다른 워크트리가 push 한 번호(0226)를 못 본다. 우회 = 그 파일을 `git -c core.quotepath=off` 로 찾아 잠시 복사 → 스크립트 → 삭제. `quotepath` 를 빼면 한글 경로가 이스케이프돼 조용히 실패한다.
- **ADR-0063 에 「드래그 되쓰기 범위 밖」 조항은 없다** — `src/components/layout/ViewLayoutRenderer.tsx:291` 주석의 오인용이다(구현 때 이 주석은 어차피 교체된다). 옛 ADR 에 부분 폐기 도장을 찍기 전에 **그 조항 문구가 본문에 있는지 grep** 할 것.
- 서브에이전트가 **사용량 한도로 두 번 작업 도중 죽었다** — 이어받기 전에 `git status`/diff 로 실제 반영 범위를 먼저 확인한다(한 번은 아무것도 안 쓰고 죽었다).
- (앞 세션부터) CRLF 파일을 Git Bash `sed -i` 로 고치지 말 것 · `codex exec` 프롬프트는 `-` + stdin.
