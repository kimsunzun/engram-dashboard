## 선택지 (메인 추천 = 1)
1. 위치(게이트 ④)는 지금 꼴로 닫고 남은 꼴(cfg_select! · cfg_aliases · cfg_if! · 술어 앞 주석 · cfg!{}/[] · 깊은 중첩)을 헤더 한계에 적는다 + U8 에 의존 층 게이트(OS API crate `windows`·`windows-sys`·`libc`·`nix` 의 운영 의존 = 멤버 중 platform 만 · `cargo tree --target all` 또는 `cargo metadata`) 추가 → 1-3 머지. 이식성 층(교차 타깃 `cargo check` · 셸 제외 · build script 실측 먼저)은 별도 단위.
2. 위치만 닫고 머지 — 의존 · 이식성은 후속 메모.
3. 세 층 다 1-3 안에서(교차 타깃 실측이 막히면 머지 지연).

## 조사 결론 요지
위치 검사를 CI 로 하는 곳은 rustc tidy `pal` 하나만 찾음(텍스트 스캐너 · 알려진 빈틈 둔 채 필수 게이트) → 드문 꼴 추적 중단이 관행에 맞다. 층 셋(위치 · 의존 · 이식성)은 서로 대신하지 않는다 — 교차 타깃 check 는 위치를 강제 못 함(거짓 cfg 갈래는 컴파일에서 빠짐). 거부: Dylint · cargo-deny wrappers · 정규식 추적 지속.
