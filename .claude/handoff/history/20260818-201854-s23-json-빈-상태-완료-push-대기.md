## 이번 세션 완료분

1. **빈 슬롯 좌클릭 컨텍스트 메뉴 제거** — 우클릭 전용. ADR-0143이 거부했던 안의 부분 번복(ADR-0144).
2. **메뉴 라벨** → 「클로드코드 터미널」·「클로드코드 JSON」.
3. **JSON 모드 빈 상태** — 마스코트 + "Claude Code" + 가운데 둥근 입력창. 판정 = **복원 완료 신호 + 0건 + 미전송**(ADR-0145). 마스코트는 공식 스티커 기준 26×17 격자 SVG(노드 442→37), 색 `#c97b5c`.
4. **에이전트 부재 표현** — 죽음·연결 끊김을 같게 보고, 화면을 그 시점 모습으로 고정 + 전체 흐림 + 가운데 심볼, 문구 없음(ADR-0148).
5. **★앱 전역 여백 유틸리티 부활★** — `src/index.css`의 계층 밖 `*` 리셋이 Tailwind 여백 유틸리티를 전부 무효화하고 있었다(Tailwind 채택 이후 계속). preflight가 같은 일을 이미 하므로 블록 삭제(ADR-0147) + 재유입 회귀 게이트 신설(`src/index.css.test.ts`).
6. **임계 높이 접힘 폐지** — 마스코트가 툭 사라지던 것을 자연 잘림으로(ADR-0146). 높이 관측 장치·상수·분기·debounce 전부 삭제.

## ★남은 갭 — 다음 세션 1순위(사용자 결정 대기)★

**사용자가 kill한 에이전트의 슬롯은 ADR-0148의 "내용 고정"이 성립하지 않는다.**

- kill = 명부에서 프로필 삭제(ADR-0019 disposition)라 슬롯이 가리킬 대상이 사라진다 → `ViewLayoutRenderer`가 챗 뷰 대신 **"에이전트 연결 중…" 플레이스홀더**를 그린다.
- 결과: **대화가 통째로 사라지고**, 문구도 사실과 다르다(영구히 없는데 "연결 중"으로 보인다).
- 실측 확인(2026-08-18): kill 직후 `[data-rich-live]`가 사라지고 해당 슬롯이 그 문구만 남았다.
- 손댈 곳이 **layout 소관**이고 데이터가 이미 없어(데몬 ring도 함께 사라짐) "고정할 내용"이 존재하지 않는다 → **표현 방침을 사용자와 다시 정해야 한다.** 임의로 문구만 바꾸지 말 것.

## 실패한 접근 (do-not)

- **`agent.spawnInto`로 JSON 모드 에이전트를 못 만든다** — 그 command는 `outputFormat`을 받지 않아 터미널 모드로 뜬다(xterm의 숨은 textarea가 챗 입력창처럼 보여 오판했다). JSON 에이전트가 필요하면 `forward_daemon_command`로 `CreateProfile{output_format:'StreamJson'}` → `SpawnProfile` → `__engramLayout.assignAgent(viewId, slotId, agentId)`.
- **`tab.close`에 `viewId`를 넘기면 무시된다** — 인자 이름이 `view`다. 잘못 넘기면 **활성 탭이 닫힌다**(실발생: 작업 중이던 탭을 잃었다).
- **CDP eval에서 상태 변경 직후 같은 호출로 DOM을 읽지 말 것** — React가 아직 커밋하지 않아 "안 열렸다"로 오판한다. dispatch와 read를 **별도 eval 2회**로 나눠라(그 사이 `sleep 1`).
- **`ListProfiles` 응답 키는 `ProfileList`다** — `r.Profiles`로 읽으면 빈 배열이 나와 "명부가 비었다"고 오판한다(실제로 오판했다).
- **1420 포트를 wt2가 잡고 있으면 디버그 경로를 쓰지 말 것** — 남의 화면을 측정한다. 이번 세션은 전부 **릴리스 빌드**(`npm run tauri build -- --no-bundle`, 약 5분)로 실측했다.

## 함정 (기술적)

- **릴리스 재빌드 전에 앱·데몬을 반드시 종료** — 데몬 exe가 잠겨 빌드가 `os error 5`로 하드 실패한다. 데몬은 앱 종료(`/T`)에 안 걸리니 따로 죽인다. **단 실측 시작 전부터 떠 있던 데몬·남의 워크트리 데몬은 불가침.**
- **`src-tauri/Cargo.toml`이 내용 변경 0인데 `M`으로 잡힌다**(줄바꿈 노이즈) — 이번에도 두 번 발생. `git diff`가 비면 `git checkout --`로 되돌리고 커밋에 담지 않는다.
- **vitest 기본값이 CSS import를 빈 문자열로 갈아버린다** — 이번에 CSS 회귀 게이트가 그 때문에 조용히 통과했다. `vitest.config.ts`에서 `index.css`만 stub을 끊어 뒀다. 다른 CSS를 테스트로 읽으려면 같은 함정을 확인할 것.
- **게이트 명령에 `src/index.css.test.ts`가 빠지기 쉽다** — 코더에게 지시한 세 경로(`src/components/slot/`·`src/api/`·`src/i18n/`)에 안 들어간다. `npm test`(전체)로 돌리면 포함된다.
