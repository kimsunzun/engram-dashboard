## 내가 틀렸던 것 (같은 실수 반복 방지)

1. ★**「구조도를 조감도에 넣자」고 권고한 것이 오독이었다.**★ 사용자 지적: 「오버뷰는 말그대로 전체를 보는건데 거기다 하나하나 다 넣게?」 조감도와 주제별 상세는 다른 물건이다.
2. ★**ADR-0044 를 렌더 모드 우선순위 근거로 인용했는데 거짓이었다.**★ 그 ADR 엔 `override` 라는 낱말이 0회다. 정본은 **ADR-0078** + `src/store/viewStore.ts` 의 필드 JSDoc, 실물 판정은 `ViewLayoutRenderer.tsx`.
3. **rich 렌더의 축을 decoder 로 적었는데 인과가 뒤집혔다** — `TransportShape::StdioNdjson` 이 고르고 decoder 는 그 모양에만 붙는다.
4. **버전 불일치 서술이 절반이었다** — 파싱 실패 앞에 **discovery 가 먼저 거부**한다(`DiscoveryError::VersionMismatch`).
5. **앵커 경로를 전부 가짜로 썼다**(`agent/src/…`) — 실제는 `crates/engram-dashboard-agent/src/…`. 워커에게 「실존 확인 후 쓰라」를 명시해야 안 샌다.
6. **덱을 문서처럼 만들었다** — 한 장에 문단·그림·경고·앵커·표를 함께 넣었다. 사용자 반려: 「야 이게 PPT야?」
7. ★**보고가 두 번 안 읽혔다 — 원인은 길이보다 표기 밀도였다**★(★·굵은 글씨·중첩 목록을 겹쳐 씀). 사용자: 「텍스트 레이아웃이 이상해서」·「텍스트가 깨져서 뒤에 내용을 못본다」.
8. **ADR 번호를 로컬 스캔만 믿고 뽑아 충돌했다** — `0177`·`0178` 은 다른 워크트리(transport crate)가 이미 쓴 번호였다. `git fetch` + 전 ref 조회(`git log --all --diff-filter=A --name-only -- 'docs/decisions/0177*'`)로 잡아 `0179` 로 옮겼다.

## do-not

1. ★**`v*` 태그를 승인 없이 push 하지 말 것**★
2. ★**앱을 셸에서 직접 띄우지 말 것**★ — 터미널 트리 밖 + 출력은 파일로. `start`·백그라운드 잡·`nohup` 은 대체재가 아니다
3. ★**`--lib`·`--all-targets` 로 셸 패키지를 부르지 말 것**★ — `0xc0000139` 즉사. `--test lib_unit` 하나뿐
4. **게이트 명령을 파이프에 물리지 말 것** — `| tail` 은 tail 의 종료코드를 읽는다
5. **CI 판정을 종료코드로 하지 말 것** — `gh run list/view` 로 결론을 직접 읽는다
6. ★**ADR 채번 전에 `git fetch` + 전 ref 조회를 먼저 할 것**★ — 스크립트 채번은 로컬 폴더만 스캔한다(이번에 실제로 충돌)
7. ★**전달본 HTML 에서 mermaid 로더를 지우지 말 것**★ — 지우면 로컬에서 소스가 글자로 보인다. 호스트가 이미 그렸으면 건너뛰는 가드가 함께 있다
8. **`--figure-ink` 를 지우지 말 것** — 그림 카드 배경만 테마 불변으로 두면 다크에서 글자가 안 보인다
9. **긴 HTML 본문을 bash heredoc 으로 쓰지 말 것** — 워커 둘이 각각 실패했다. Write 툴을 쓴다
10. **워커에게 파일 경로를 쓰게 할 땐 「실존 확인 후 기록」을 명시할 것** — 안 하면 그럴듯한 가짜 경로가 들어온다
