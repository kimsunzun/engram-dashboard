## GUI QA 요령
- **프론트 view 캐시 읽기:** performance entries 에서 페이지가 실제로 로드한 모듈 URL(`/src/store/viewStore.ts?t=…`)을 dev `import()` — ★다른 URL 은 별도의 빈 인스턴스★.
- **부팅 시점 콘솔 오류 포착:** 같은 CDP 세션에서 `Page.addScriptToEvaluateOnNewDocument` → `Page.reload`(팝아웃은 따로).
- **클릭·우클릭·키:** `cdp.mjs` 에 없다 → `Input.dispatchMouseEvent`/`Input.dispatchKeyEvent` 소형 스크립트.
- **네이티브 창 리사이즈:** `Browser.setWindowBounds` 는 뷰포트만. 실제 창은 **컴파일 헬퍼**(작은 exe 로 `SetWindowPos`) — ★PowerShell P/Invoke 금지★(보안 에이전트 경보 위험·훅 차단).
- **버스 동사 실측 불가**(`engram.exe` = `NO_TOKEN`) — Tauri invoke 로 같은 서비스를 친다.
- 다른 워크트리 dev 앱이 떠 있으면 identifier 뮤텍스로 이 워크트리 debug 앱이 즉시 죽는다 — 기동 전 점검.
- 위 요령들은 qa 스킬 `feedback.md` 에 적립해 두었다(바인딩 §full 승격 후보).
