## 사용자와 나눈 설명(다시 물으면 같은 답 — 근거 위치)
- `daemon\state` = 지킨다(agents · presets) · `daemon\run` = 버려도 된다(`daemon.json` 잠금+WS 토큰 · `mcp-config\` · `usage-probe\`) — TRD S21-storage §2-1 · ADR-0264.
- `mcp-config\` = 에이전트 스폰 때 `--mcp-config`(제어 채널 Bearer 토큰)와 `--settings` 조각을 파일로 넘김 — 에이전트 끝나면 삭제 · 기동 때 스윕(`daemon/src/control/mcp_config.rs`). 파일로 넘기는 이유 = Windows `cmd.exe /c` 인용이 인라인 JSON 을 깨뜨림(`agent/src/backend/claude/usage_probe.rs:146`). 파일명 `<id>-<epoch>` 라 동시 실행에 안 겹친다.
- `usage-probe\` = 사용량 조회용 UUID 임시 폴더(배타 생성 · `agent/src/usage/scratch.rs:36`) — `claude -p` 에 `get_usage` 제어 요청 한 줄만 보내 모델 호출 · 컨텍스트 소모 없음(훅 끔 · MCP 0 · 세션 미저장). 그 요청은 claude 쪽 실험 기능.
- `daemon.json` 의 WS 토큰은 데몬 종료 뒤에도 파일에 남는다(의도 — `daemon/src/lib.rs:832`). 지우게 바꾸는 것은 사용자 결정 사항으로 제시만 했다.
- `shell\config\settings.json` = 취향(기본값과 다른 값만 저장 · 지우면 코드 기본값) · `shell\state\state.json` = 레이아웃 · `shell\run\state.lock` = 빠른 재시작 때 앞 인스턴스의 마지막 저장 뒤로 줄 세우는 잠금(3초 · 못 잡아도 뜸 — `src-tauri/src/state/lock.rs`).
- 설정 명령은 범용 넷(`settings.get/set/reset/schema --key`) · 창 하나 테마만 `window.setTheme`.
