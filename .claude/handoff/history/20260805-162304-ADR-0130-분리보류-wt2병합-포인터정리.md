## ★이번 세션이 실측으로 뒤집은 것 (다시 재지 말 것)★

세 세션에 걸쳐 "슬라이스 2의 주된 리스크" 로 이월돼 온 **모듈 순환 3개가 반증됐다.**

- `connection_core ↔ status_fanout` · `messaging_host → status_fanout → connection_core → messaging_host` — **둘 다 `#[cfg(test)] mod tests` 안의 픽스처가 형제 모듈로 손을 뻗어 생긴 것**이고, 기본 빌드의 의존 그래프는 단방향 DAG다.
- production DAG: `agent_conn → {connection_core, control}` · `connection_core → control` · `status_fanout → connection_core` · `messaging_host → {status_fanout, control}` · **`control → 없음`**(leaf).
- 리뷰어가 독립 재측정해 **7건 전부 CONFIRM**(반증 0). `experiment`·`test_doubles` 까지 포함하면 `control` 의 나가는 간선은 더 강하게 0이다.

**교훈:** 미검증 항목이 결정을 좌우하고 있으면 먼저 재라. 이 미검증치가 "슬라이스 2 = 설계 변경" 이라는 **잘못된 난이도 평가**를 만들고 있었다.

## 실패한 접근 (do-not)

**이번 세션에서 새로 겪은 것:**

- **★파일 편집 워커와 `tauri dev` 를 동시에 돌리지 말 것 — 실발동★.** 워커가 `.rs` 를 저장할 때마다 tauri 가 리빌드·재시작해 **CDP 타깃이 `about:blank` 로 초기화**된다. GUI 실측은 **모든 편집이 끝난 뒤** 띄운다. (do-not 에 있던 "다른 세션의 `docs/` 편집 → vite 리로드" 의 Rust 판.)
- **★`/adr index --write` 전에 반드시 `index --check` 를 돌릴 것 — 안 해서 회귀를 만들었다★.** 스크립트가 본문 상태줄에 개정 도장이 **2개인 행에서 두 번째를 조용히 지운다**(알려진 결함 7회째, 이번이 **첫 미탐지**). 지운 행 = 0099·0108·0111·0112·0113·0116. 복구 = `git checkout -- docs/decisions/README.md` 후 **손으로 최소 편집**(신규 행 추가 + 개정 대상 상태 갱신만). 이 `--check` 선행은 **스킬 문서에 없고 세션 간 구전으로만 전해져 왔다** — adr feedback 에 적립함.
- **★ADR 에만 못을 박으면 새어나간다 — 리뷰가 BLOCK 으로 잡았다★.** ADR-0130 을 쓰고도 코드 8곳이 "다음은 슬라이스 2" 라 말하고 있었고, **그중엔 그 ADR 이 정본으로 지목한 `net/src/lib.rs` 헤더 자신**과 **방금 헤더를 고친 `daemon/src/lib.rs` 의 다른 줄**(자기모순)도 있었다. 결정을 박으면 **CLAUDE.md 가 말하는 두 발견 표면**(ADR 인덱스 + 코드 앵커)을 **둘 다** 쓸어야 한다. 핸드오프 `latest.md` 도 그 표면 중 하나다(다음 세션이 가장 먼저 읽는다).
- **★git-bash 에서 `taskkill /PID` 는 `MSYS_NO_PATHCONV=1` 없이는 실패★**(`/PID` 를 경로로 변환). 실발동.
- **★대규모 병합 충돌은 파일별로 워커에 분배하면 잘 된다(성공 패턴)★** — 17파일 63헌크를 5명에게 겹치지 않게 나눠 병렬 처리, 충돌 0. 지시서 핵심 = **원칙 한 줄**("주석은 theirs, 코드는 ours") + **"theirs 주석이 없어진 코드를 가리키면 베끼지 말고 드롭"** + 빌드 금지(락 회피) + git state 변경 금지. 워커들이 실제로 stale 을 걸러냈다.

  - **★혼동 쌍 미등록 — `AgentCommand`★:** 러스트 = **WS wire 명령**(`Spawn`/`Kill`…) / 프론트 `src/api/types.ts` 의 `AgentCommand` = **에이전트 실행 명령**(`{kind:'Claude'|'Shell'}`, 러스트 대응 = `protocol::AgentSpawnCommand`). 같은 이름이 경계 양쪽에서 다른 뜻 — CLAUDE.md 「혼동 쌍」 등록 후보.
  - **유일한 검문소 = 셸의 serde**(`src-tauri/src/daemon_client` 의 `send_command`). 직결 경로(`wsTransport` 의 auth 손조립 · `scripts/engram.mjs`)는 그마저 우회.
- **CLAUDE.md 주석 규약 자리가 여전히 "미설정"** — wt2 세션이 **기준 v2 를 확정하고 clean-comment 스킬 정본에 반영 완료**(정본 = `~/.claude/skills/clean-comment/references/{rules.md, style-base.md}`). 그 자리를 채울 재료가 이제 있다. **단 그 작업은 wt2 세션 소관**(사용자 지시).
- **wt2 세션이 지정한 다음 주제 = "스킬 논의"**(그쪽 핸드오프 §미결 3건).
- **MCP 제어 평면·`engram-send` 배치 등 옛 슬라이스 2 예정 항목은 전부 무효** — ADR-0130 보류로 착수 대상이 아니다.
- **`agents.json` 에 cdp 실측이 남긴 백슬래시 먹힌 프로필 3건**(`I:Engramappsengram-dashboard` 계열) — 사용자 데이터라 안 지웠다. 트리에서 제거하면 된다.
- **스킬 피드백 적립됨:** adr(인덱스 생성기 `.match()` 결함 7회째 + `--check` 선행이 문서화 안 됨) · handoff(load 시 repo 실측 대조 없음).
- 승계분: `reply_failed` 조회 표면 부재 · `profiles_cb` 주입 잔존 · `--disallow-mcp` 존폐 · 실측 ⑧ 프로덕션 훅 · ws_e2e `case09` flaky(부하 민감, 임계값 튜닝 금지 — ADR-0038) · 허수 테스트 1건(`subscribe_control_order_ack_then_complete`).
