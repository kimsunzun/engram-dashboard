## do-not
- Bash 인라인에 `\` 금지(하네스가 접는다). 하네스 `rg` 는 셸 함수 — `bash <파일>` 전에 `export -f rg`(안 하면 게이트가 가짜 FAIL).
- ADR 채번은 로컬 max+1 이라 미머지 원격 브랜치 번호를 못 본다 — 채번 전 `git -c core.quotepath=false ls-tree` 로 `origin/*` 전부의 최대 번호 확인(storage 가 0274/0276/0277 을 쥐고 있다).
- 이미 박힌 Amends 조항은 스크립트로 넓힐 수 없다(손편집 금지) — supersede 때 조항을 충분히 넓게.
- 코더 지시서에서 시험 범위를 좁히지 말 것 — ts-rs 내보내기 타입의 doc 한 줄이 바인딩 생성물을 바꿔 CI 동기 게이트를 깬다(U1 실발생).
- codex 리뷰를 `--resume` 로 이을 땐 첫 줄에 「직전 턴에 무엇을 했나」를 묻는다(스레드 확인).
