## ★확정된 구조 (이게 정본 — TRD 구판보다 이걸 따를 것)★

```
① 선언 + 본문 = 한 세트, 생산자 모듈 옆에
     core        agent.*            (에이전트 관리자가 실제 일을 하니 여기)
     daemon      mail.*
     src-tauri   window/tab/slot
     webview     theme/chat

② 공통 도구 crate (신규) — 봉투 · 오류 · 선언 매크로만. 워크스페이스 의존 0. 명령은 0개
     protocol 에 명령을 넣지 않는다. core 가 이 crate 만 보면 되게 한다
     (core 는 현재 워크스페이스 의존 0 — 실측. protocol 을 보게 하면 통신 타입까지 보게 된다)

③ 조립은 실행 파일에서 — 인스턴스를 넘겨 꽂는다
     이름·인자 스키마는 자동 수집(링커 수집 crate), 실물(관리자·메일함)은 조립 때 주입
     MakeTable(Manager) 형태. 명령이 늘어도 조립 코드는 안 바뀐다

④ 배달은 홉마다 같은 3단계 — 내 표에 있나 → 명부에 있나 → 오류
     특별 케이스 없음. 그래서 모바일이 붙어도 배달 코드는 안 바뀐다(등록만 하나 는다)
```

**봉투:** `{ name, request_id, owner, proto_ver, args }` + 프레임 종류(Request/Reply/Event).
**방향 필드는 없다** — 어느 연결에 썼는지가 방향이다. 봉투는 대칭이라 모든 홉에서 같은 형태다.

**등록:** 붙을 때 자기 이름 목록을 **패킷 하나로** 보낸다. 웹뷰 것은 앱 본체가 대신 얹는다. 바뀌면 델타만 다시 보내고, 연결이 끊기면 그 이름들은 명부에서 빠진다.

**이름을 아는 두 층:**
- 빌드 때 — Rust 선언 → TS 타입 생성 → 화면이 타입 안전하게 호출. 인자가 틀리면 컴파일이 막는다.
- 런타임 — 지금 부를 수 있는지는 **등록 상태**가 답한다. **데몬은 빌드 목록을 안 쓴다.**

**오류 2종을 구분한다:** `NoOwner`(이름은 아는데 주인이 지금 없음 → 나중에 다시) / `Unknown`(그런 이름 없음 → 오타·구버전). 부르는 쪽 대응이 갈린다.

**2단 배달:** 데몬은 웹뷰와 직접 연결이 없다. `theme.set` = 데몬 → 앱 본체 → 웹뷰. 각 홉이 같은 3단계를 반복할 뿐이다.

**새로 짓는 것은 둘뿐:** 공통 도구 crate + **데몬→앱 본체 인바운드 수신**(실측 0건). 나머지는 이관이다.

## ★세션 중 뒤집힌 판단 3건 (TRD 구판이 반대를 말한다)★

1. **선언을 protocol 한 곳에 모으는 안 → 폐기. 생산자 옆으로.** 사용자 지적("생산자와 사용자가 명확히 분리돼야 한다")으로 교정. **결과로 두 문제가 사라졌다** — 주인 칸이 불필요해졌고(정의 위치가 곧 주인), ADR-0081 「Opaque 결합 가드」 폐기 도장도 불필요해졌다(데몬이 화면 명령 타입을 컴파일에 넣지 않고 이름만 런타임 등록으로 알기 때문).
2. **전역 자동등록 → 금지. 인스턴스 주입 고정.** 전역 표에 핸들러를 박으면 테스트가 가짜 관리자를 못 꽂아 실제 프로세스 생성이 딸려온다. 자동 수집은 이름·인자 스키마까지만.
3. **데몬이 빌드 목록을 조회 → 폐기.** 데몬이 그걸 컴파일에 넣으면 화면·셸 이름을 정적으로 알게 되고, 앱이 안 떠 있을 때도 "있다"고 잘못 안다.

## ★실패한 접근 / do-not★

1. **선언을 `protocol`에 모으지 말 것** — TRD 구판이 그렇게 적혀 있다. 폐기됐다.
2. **명령 정의에 "주인" 칸을 만들지 말 것** — 정의 위치가 주인이다. 사용자가 두 번 철회시킨 제안이다(2026-08-12, 이번 세션).
3. **ADR-0081 「Opaque 결합 가드」에 폐기 도장을 찍지 말 것** — 필요 없어졌다.
4. **전역 자동등록으로 핸들러를 박지 말 것** — 테스트 바꿔치기가 막힌다.
5. **봉투에 방향 필드를 넣지 말 것** — 연결이 방향이다.
6. **받은 자리(연결 태스크)에서 실행하지 말 것** — 복합 명령이 자기 자신을 기다려 멈춘다. 반드시 분리 실행.
7. **데몬이 인자를 뜯게 만들지 말 것** — 이름·짝번호·버전만 본다. 단 **겉봉에 이름은 반드시 노출**한다(명령 단위 권한·관측이 여기 달렸다).
8. **조사 보고서를 확정으로 읽지 말 것** — BLOCK 판정이고 §9에 반증 6건이 표로 남아 있다.
9. **채팅에서 영어 용어·비유를 새로 만들지 말 것** — 이번 세션에서 사용자 이해가 40%까지 떨어져 재설명이 반복됐다. 코드 식별자를 그대로 쓰거나 역할로 말한다. C++ 예시가 가장 잘 통했다.
