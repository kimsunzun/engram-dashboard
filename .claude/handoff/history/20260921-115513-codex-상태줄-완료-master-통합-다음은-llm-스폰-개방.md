## ★1번을 시작할 때 먼저 알아야 할 것 — 막고 있는 것이 무엇인지 확인했다★

**막는 것은 「폴더 신뢰 모달」이지 훅 신뢰가 아니다.** 이번 라운드가 훅을 지웠다고 이 조건이 풀리지 않는다.

- 사유 정본 = `crates/engram-dashboard-agent/src/commands.rs` 의 `CODEX_NEEDS_A_HUMAN_AT_THE_TRUST_MODAL` — 「codex 는 **처음 보는 폴더**에서 자기 신뢰 확인 모달을 띄우는데 사람이 아닌 호출자는 그 모달을 못 지난다(키를 넣어도 안 먹는다 — 실측 2026-09-07)」. 여는 시점 = 「Phase 2, codex 신뢰 확인 모달 처리가 정해질 때」.
- ★**그런데 범위가 좁다**★ — 폴더 신뢰는 **폴더당 한 번**이고 `config.toml` 에 영구 저장된다(`[projects.'<경로>'] trust_level`). **상속은 안 된다**(부모가 신뢰돼도 하위에서 다시 묻는다 — 실측). 그리고 **`i:\` 가 통째로 신뢰돼 있어 우리 작업 폴더 대부분은 이미 뚫려 있다.** 즉 진짜 미해결은 **「codex 가 처음 보는 폴더」 한 갈래**다.
- **그래서 설계 갈림길이 이렇게 선다(사용자 결정 대상):** ⓐ 스폰 전에 신뢰 상태를 **읽어** 확인하고 미신뢰 폴더에서만 거절 ⓑ 그냥 열고 모달이 뜨면 사람에게 넘김 ⓒ 지금처럼 전면 거절 유지. ⓐ 는 `config.toml` 을 **읽는** 것이라 ADR-0210 의 「사용자 기기에 쓰지 않는다」와 충돌하지 않지만 **읽기도 벤더 저장소 접근**이라 ADR-0203 결과 함께 저울질할 것.

**함께 볼 것 둘(코드에 이미 적혀 있다):**
- ★**낱말만 열면 「만들 수는 있는데 원하는 모드로는 못 만든다」가 남는다**★ — `AgentBackend` enum 은 `Claude` 하나뿐인데, **출력 모드 축에는 LLM 표현이 아예 없다.** 그래서 백엔드 낱말만 열면 LLM 은 codex 를 만들 수 있어도 **JSON 모드로는 못 만든다**(사람은 트리 메뉴에서 고른다). 모드를 고르는 LLM 경로를 낼지는 **별개 결정**이고 1번과 함께 봐야 한다.
- ★**같은 사유를 말하는 문구가 프론트에 따로 있다**★ — `src/commands/agentCommands.ts` 의 `CODEX_HUMAN_ONLY`. 언어가 달라 상수를 공유 못 해 **사본이 아니라 각자 쓴 문장이고, 아무 게이트도 둘을 맞춰 주지 않는다.** 사유가 바뀌면 그쪽도 같이 고칠 것.
- **넓히는 것 자체의 대가** = `agents.json` **디스크 호환 이주**(옛 빌드가 명부를 통째로 잃는다).

### 스폰 인자 정리(1번의 뒷부분) — 오늘 실제로 나가는 것

터미널 모드 codex 의 실 명령줄(GUI 실측에서 그대로 받아 적은 것):

```
codex.exe [resume <id>] --cd <cwd> -s workspace-write -a on-request
          -c mcp_servers.engram={...} -c tui.status_line=['thread-id']
          [-c developer_instructions='<한 줄>']
```

**모델·effort 를 고르는 칸이 지금 하나도 없다.** codex 는 `-c model=…` · `-c model_reasoning_effort=…` 를 받는다(전역 사전의 비주도 CLI 기본형이 `model_reasoning_effort="high"` 를 쓰는 것이 그 증거). 조립 지점은 `crates/engram-dashboard-agent/src/backend/codex/mod.rs` 의 `build_spec` 한 곳이고, **override 는 사용자 passthrough 뒤에 붙이고 덮으면 경고**하는 규칙이 이미 서 있다(ADR-0216 이 ADR-0210 에서 물려받았다).

## do-not (이 세션에서 실제로 겪은 것만)

1. ★**빈 로그를 통과로 읽지 말 것**★ — `npx tsc --noEmit` 은 성공 시 아무것도 안 찍어 **「안 돈 것」과 「통과」가 둘 다 빈 파일**이다. 분리 실행 래퍼가 `.cmd` 를 `call` 없이 부르면 마커가 안 찍히는데 그 조합이면 **false PASS** 다. `call` 을 붙이고 마커로 판정한다.
2. ★**ADR 에 「측정했다」를 쓰기 전에 그 측정이 어디 있는지 확인할 것**★ — 이 세션에 **내가 쓴 주장 넷이 거짓**이었고 전부 리뷰가 잡았다(락 · 첫 매치 규칙 · 재개 미측정 · 따옴표).
3. ★**폐기 범위를 「주제가 같으니 통째로」로 정하지 말 것**★ — ADR-0210 전체 폐기를 시도했는데 그 결정 3·4 에 우편·지시서가 기대고 있었다.
4. ★**「무엇이 막고 있나」를 이름만 보고 단정하지 말 것**★ — 「신뢰 모달」이 훅 신뢰인 줄 알았는데 **폴더 신뢰**였다(상수 본문을 읽고서야 갈렸다). 이번엔 읽어서 막았다.
5. **codex TUI 입력은 Enter 를 별도 write 로** 보내야 제출된다. **합성 viewId 로 건 `subscribeOutput` 은 replay 가 안 온다**(실 슬롯 배정이 선행).
6. **앱을 셸에서 직접 띄우지 말 것 · 빌드·테스트도 분리 실행** · `-- --test-threads=4` 유지 · 루트 bare `cargo test` 금지.
7. ★**데몬이 하나도 없으면 앱이 스스로 못 띄운다**★ — `ensure` 가 attach-only 다. 복구 = `window.__TAURI__.core.invoke('daemon_connect')`.
