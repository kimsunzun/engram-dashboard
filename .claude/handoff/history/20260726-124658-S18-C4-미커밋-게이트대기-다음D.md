## C4가 담은 것(요지)
그룹 발송 `@name` fan-out: 발송 순간 로스터 스냅샷 1회 → 멤버별 (idle=즉시배달 / busy=파킹 pending / 죽음·부재·비structured=skipped, **파킹 없음**=방송 소급 금지) → 응답은 멤버별 1행. 봉투 `to="@그룹"`. 장부 1:N + 만료는 (msg_id, recipient) 키.
**리뷰가 잡은 굵은 것 4개(전부 수정됨):** ①방송 파킹분이 이름 폴백으로 **재스폰 동명에게 배달**되던 소급 구멍 → 발송 순간 개체 `(id,epoch)` 결박 + **코어에 epoch 조건부 쓰기 API 신설**(`write_stdin_observed_if_epoch` — 확인↔쓰기 사이 재시작 창까지 차단) ②배달 불가 결박분이 정원을 물어 **재스폰 에이전트가 24h 굶던** 문제 ③fan-out 판정이 N번의 블로킹 write 동안 stale → 멤버별 주입 직전 재확인 ④입구 trim이 이름 정확주소를 깨던 문제 → 그룹 축에만 trim.
**마지막 라운드(정원 단순화 — 사용자 동의):** 2단 정원+면제 폐기 → **정원 하나(100, 전부 셈) + 가득 차면 잔해(배달 불가 결박분) 오래된 순 은퇴(장부 `skipped` 기록) + notice 전용 레인(20, 넘치면 가장 오래된 통지 은퇴 — 통지는 반려 금지)**. 큐 총량이 `MAILBOX_CAP+NOTICE_CAP`으로 구조적 유계.

## 이 세션 확정 결정(사용자)
1. **장부 링버퍼 1024→4096** 적용됨. 메모리 실측 프로필: 기록이 본문 전문을 보관 → 인간 규모 본문이면 1~2MB, **최악(64KiB 본문 4096건) ≈ 256MiB**. 후속 항목으로 명시만: 런타임 설정/커맨드 노출 · 장부 본문 절단 저장.
2. **push 승인** — 이번 게이트 통과분부터 밀린 19커밋과 함께 push.
3. **notice 자기식별** — 본문 머리표 `[engram]` + 프라이밍 양 변형에 "`<notice>`=엔그램 데몬(시스템) 통지, `from` 없음이 표시, 회신 대상 아님" 1절 추가.
4. **중요도(priority) 필드는 계속 비채택** — 기준 애매 + 기아·TTL 교차버그(AMQP 실무 경고) + LLM 프레임워크 전원 미채택(ADR-0103 거부 대안). 대신 **성격이 다른 것만 레인 분리**(= notice 레인)가 우리 방식.
5. **D는 설계 논의 불요** — spec §6이 이미 확정(툴 3개·CLI 미러·`--settings` 주입).

## 검증 상태(쌍)
- **돌린 것:** C4 review deep 3인 5라운드(doc-aware·blind codex·동시성 렌즈) — 마지막 라운드 산출은 **판정 미수령**. 코더 자체 게이트 868 pass. 이전 증분들은 qa full 통과 이력 있음(C3까지 커밋됨).
- **안 된 것:** ① C4 종결 판정 ② C4 qa full(프론트·격리·라이브) ③ **최종 인수 실측 3건**(D 이후): 실 claude가 8자 id를 `reply_to`로 옮겨 적는가 · `--settings` allowedMcpServers merge 실증 · 중첩 Task 서브에이전트 `result` 누수(부모 턴 종료 오판) ④ 코더 지적: `deliver_notice`의 current 전달은 **회귀 테스트가 못 잡는 방어 코드**(레인 분리로 이미 구조적 차단 — 알고 있을 것).

## do-not (누적)
- 게이트(판정+qa) 전에 C4 커밋 금지 · v2 항목(wake·cc·그룹 request·priority) 슬쩍 편입 금지 · 실험 bin 3종은 게이트 미적용(C1 동작)이라 게이트 검증에 쓰지 말 것 · bare `cargo test` 금지(멤버 열거) · `cargo test -p engram-dashboard --lib`(src-tauri)는 pre-existing DLL 로더 오류로 실행 불가 — 게이트 목록에 없음, 무시 · blind 리뷰어 payload엔 "의도적 미배선"을 반드시 명시(아니면 false BLOCK) · replay로 busy 부트스트랩 금지(false-busy) · 유저 전역 `allowedMcpServers: []` 수정 금지(해법=스폰 `--settings`).
