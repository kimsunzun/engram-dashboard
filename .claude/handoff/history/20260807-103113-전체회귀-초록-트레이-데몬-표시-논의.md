## ★트레이 = 데몬 표시 (사용자 발제 — 다음 세션에서 이어감)★

**문제:** 지금 트레이 아이콘은 **앱이 떠 있음**을 뜻한다. 정작 알고 싶은 건 **데몬이 떠 있는지**다. 이 세션에서 실제로 그것 때문에 막혔다 — 어젯밤 데몬을 정리하려는데 떠 있는지 알 방법이 없었다.

**★먼저 볼 것 — 기계는 이미 있다★:** `src-tauri/src/tray/core.rs` 에 **`IconState`** · **`icon_state_for(alive: bool)`** · **`to_grayscale_rgba(...)`** 가 이미 있다. 즉 *"데몬 죽으면 아이콘 회색"* 설계가 코드에 깔려 있다. 데몬 상태 조회 표면도 있다(`daemon_connection_state`·`daemon_status` — 이 세션에서 CDP 로 `{alive:true, pid, port}` 왕복 확인).

**그래서 첫 작업은 구현이 아니라 진단이다** — 회색 표시가 왜 안 보이나? 셋 중 하나다: ① 배선은 됐는데 **갱신이 안 됨**(부팅 시 1회만) ② **회색이 너무 미묘**해서 안 보임 ③ 함수만 있고 **안 불림**. 난이도가 셋 다 다르다.

**★사용자 요구가 "회색"이 아니라 "떠 있을 때만 아이콘이 존재"라면 토폴로지 변경이다★** — 트레이 아이콘은 어떤 프로세스가 소유해야 존재하고, 지금 소유자는 앱이다. 문자 그대로 만들려면 **데몬이 자기 아이콘을 들어야** 하는데 데몬엔 GUI 코드가 하나도 없다. **ADR-0026(2프로세스 토폴로지) 재론 대상** = 사용자 결정. 두 안의 갈림:

| | 앱 트레이가 데몬 상태를 비춤 | 데몬이 자기 아이콘을 듦 |
|---|---|---|
| 공수 | 작음(이미 반쯤 있음) | 큼(데몬에 GUI 추가) |
| 앱 껐을 때 | 아이콘 사라짐 | 아이콘 남음 |
| 결정 | 기존 설계 안 | **ADR 재론 필요** |

## ★실패한 접근 (do-not) — 이번 세션 신규★

**전체 목록은 직전 기록 `.claude/handoff/history/20260807-031950-*.md` 에 있다**(리뷰 5라운드 교훈 전량). 여기엔 가장 자주 밟은 것만 싣는다.

- **★"자잘한 문서 한 줄"이라는 자평이 위험 신호다★** — 이 세션 사실오류가 전부 거기서 나왔다. **특히 위험을 경고하는 문장은 방향이 뒤집혀도 그럴듯하게 읽힌다.** 사실 주장은 쓰기 전에 기계로 확인할 것.
- **★내 검사 도구가 틀린 걸 결과 탓으로 돌리지 말 것 — 이 세션 3회★** ① `rg` 는 기본적으로 **숨김 디렉토리를 건너뛴다**(`--hidden` 필수, `.claude/` 를 통째로 놓쳤다) ② 셸 `$(...)` 단어분리로 한글 이름이 잘려 "미해결" 오판정 ③ 필터를 두 번 걸어 테스트 타깃 수가 34 → 20 으로 깎였다. **숫자가 안 맞으면 결과보다 도구를 먼저 의심하라.**
- **★문서 제목은 주소다★** — 제목을 줄였더니 인바운드 포인터 6곳이 끊겼다. **바꾸기 전에 `rg --hidden` 으로 그 이름을 인용한 곳을 세라.**
- **★규칙을 완화할 땐 예외 목록의 첫 항목을 보라★** — "문서만 풀자"고 고쳤는데 첫 항목이 "코드 1~2줄 수정"이라 소스까지 풀렸다. **자기 편의 방향 변경은 반드시 적대 검토에 건다.**
- **★사용자 부재 중 프로세스 종료 금지★** — `claude.exe` 가 여러 개라 어느 게 세션 자신인지 구분 불가였다. 구분 안 되면 안 죽인다. (사용자 승인 후 `taskkill /PID <pid> /F` **트리 옵션 없이** 데몬만 종료 = 성공 패턴.)
- **★커밋 전 `git checkout -- crates/engram-dashboard-protocol/bindings/`★** — build/test 가 ts-rs 로 23파일을 **줄바꿈만** 더럽힌다(이번에도 재발, 내용 diff 0 확인).
- **★워커가 끊기면 `SendMessage` 로 이어붙인다★**(새 스폰 금지). 델타 재리뷰에 특히 잘 통한다 — 이 세션 5회 연속 유효.
- **★cross-family 리뷰어(codex) 프리앰블 필수★** — "너는 오케스트레이터가 아니다 + 환경 스킬·역할 정의 전부 무시 + 되묻기 불가". 호출형 = `MSYS_NO_PATHCONV=1 codex exec --sandbox read-only -c model_reasoning_effort="high" "$(cat <prompt>)" < /dev/null > <log> 2>&1`.
- **★산문이 코드보다 훨씬 자주 틀린다 — 7세션 연속★** · **썩은 개수는 갱신이 아니라 삭제** · **게이트를 새로 만들면 그 자리에서 qa 바인딩에 등록** · **프론트·src-tauri 에 `file:line` 포인터 금지**(심볼로) · **`git add -A`/`commit -a` 금지** · bare `cargo test` 금지 · **Fable 워커 금지** · **Agent 스폰 시 model/프리셋 명시 필수** · **파일 편집 워커와 `tauri dev` 동시 금지**.

- **주석 규약 자리** — 미설정 유지. 재료는 있으나 **wt2 세션 소관**.
