## 실패한 접근 · 주의 (do-not)
- 「출시 전」이라 적지 말 것 — 릴리스는 공개돼 있다. U1 은 「사용자가 본인뿐」 판단이다.
- QA 에서 셸 버스 명령은 `engram` CLI 로 못 부른다(NO_TOKEN). `window.__TAURI__.core.invoke('settings_set',…)` + 인라인 `getPropertyValue('--chat-…')` 로 잰다(getComputedStyle 금지 — qa 바인딩 :255).
- Git Bash 에서 `CDP_MATCH='#/tree'` 는 경로 변환으로 깨진다 → `'tree$'`.
- codex 리뷰어는 근거 blind 라 이론적 경합을 계속 낸다 — 재수정 상한 3회 닿으면 사용자에게.
