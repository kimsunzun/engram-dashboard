- **Phase 1 범위 = 「그냥 딱 codex 띄우는 정도만」** — LLM 제어 표면(§6-G)·배너(§6-E) 둘 다 Phase 2 로.

4. ★**「거부 목록에 `"Codex"` 가 이미 박혀 있어 할 일이 없다」 — 틀렸다. 문이 둘이었다.**★ `agent.new` 는 막혔지만 `agent.spawnInto` 가 열려 있었다. `41f703c` 가 정책 표 하나로 닫았다 — ★단 리뷰 지적 4 번이 그 시험이 주장보다 약하다고 한다★.

## do-not (이번 세션 누적 · 이전분 유지)

1. ★**`v*` 태그를 승인 없이 push 하지 말 것**★
2. ★**게이트 명령을 파이프에 물리지 말 것**★ — `cargo test ... | tail` 은 **tail 의 종료코드**를 읽는다. 로그 파일로 받고 `$?` 를 따로 찍는다
3. ★**`run-detached.ps1` 에 `&` 로 명령을 이어 붙이지 말 것**★ — 첫 명령 뒤가 통째로 사라지고 실패 마커까지 소실된다(조용한 false PASS 경로). 별도 `.bat` 을 만들어 `call` 로 넘긴다
4. ★**Git Bash 에서 `cmd /c "codex exec ... \"긴 프롬프트\""` 금지**★ — 중첩 따옴표가 깨져 명령이 시작조차 못 한다. 지시서를 파일로 빼고 프롬프트는 한 줄로
5. ★**`--lib`·`--all-targets` 로 셸 패키지를 부르지 말 것**★ — `0xc0000139` 즉사. `--test lib_unit` 하나뿐
6. **CI 판정을 종료코드로 하지 말 것** — `gh run view <id> --json conclusion` 으로 결론을 직접 읽는다
7. **`gh -q` 표현식에 `/` 를 쓰지 말 것** — Git Bash 가 경로로 바꿔 먹는다
8. **`launch/실행.bat` 을 개발 중에 쓰지 말 것** — 이미지 이름으로 모든 데몬을 죽인다
9. **codex 는 스스로 자동 업데이트한다** — 측정 중 한 번 발생했고 우리 teardown 이 업데이터를 죽여 전역 shim 이 잠깐 깨졌다. 측정 전후 버전을 기록할 것
10. **실 CLI 를 상대하는 하네스에서 「환경을 격리한다」는 수정은 파일럿 1 건(격리 후 화면 덤프)을 먼저 돌릴 것** — 임시 홈으로 돌리자 **모달이 하나 더 뜨는** 조건이 드러났고, 그걸 모른 채 전체 레인을 두 번 버렸다
