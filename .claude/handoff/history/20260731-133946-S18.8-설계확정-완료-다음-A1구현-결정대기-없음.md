## 확정된 결정 (전부 ADR에 박제 — 재론 금지)

1. **이름은 트리에서 오직 하나** — 잠든 프로필 포함 **전역 유일**. 겹치면 자동 접미사 `bob(1)`(단조 증가·재사용 금지). 잠든 프로필도 이름을 점유하고 회수는 복원 또는 삭제뿐. (0120)
2. **편지 순서 보장** — 새 편지가 묵은 것을 앞지르지 않고 **오래된 순으로 함께** 나간다. 배치 도중 실패하면 거기서 멈추고 앞부분 `delivered` / 나머지 `pending` 유지. (0121)
3. **`@all`(명부 전원) / `@here`(산 전원) 분리** — 현행이 `@here`이므로 "개명 + `@all` 신설". **둘 다 발신자 제외**(정본 = **spec §4**, ADR-0111 아님 — 0111엔 그 문구가 없다). (0121)
4. **장부는 `delivered` 유지** — 터미널 모드 별도 표기 안 함(증거 동일). 모달 먹힘이 실측되면 재론. (0121)
5. **명부 단일 입구** — 프로필을 `AgentManager` 안으로 감추고(`manager.profiles()` 제거), "전체 에이전트 + 살아있음/잠듦"을 주는 **통합 조회 하나**. 우편·트리가 그것만 본다. (0119)
6. **에이전트 사실 계층의 거처 = 코어** — 턴 상태(0113)도 여기 얹는다. 0113의 "코어/데몬" 갈림길 해소. (0119)
7. **프리셋은 안 건드림** — 코드도 문서도. 비대해지면 재검토.
8. **기존 데이터 마이그레이션 안 만듦**(2026-07-31 — "현재 프로필 실작업 단계가 아니라서 아무 필요없다"). 동명이 남아 있으면 정리하고 간다. **단 조건부** — 실사용 데이터가 쌓인 뒤 같은 상황이 생기면 그때 정규화 설계 필요.

**매니저 타입 분리는 실측으로 기각**(사용자 위임 판단): `manager.rs` 1320줄 중 운영 순수 코드 574줄, 무거운 로직은 이미 형제 파일. 응집이 갈리는 선은 I/O 버킷 하나뿐인데 떼면 같은 락을 두 타입이 나눠 갖는다. 내부 완전 통합도 보류 — **한 클래스는 되지만 한 락은 안 된다**(프로필 맵이 락을 쥔 채 디스크 저장).

## 슬라이스 순서 · 테스트 방침

**A1**(백엔드 명부 통합 — **동작 불변**, `/qa standard`) → **A2**(명령 어휘를 에이전트로 + 프론트 단일 목록 — 화면 닿음이라 `/qa full` GUI 실측 필수) → **B**(턴 상태 코어 이사, 0113) → **C**(우편 순서·`@all`/`@here`, 0121).

**테스트 방침(확정):** 이동·재배선분엔 **새 테스트를 만들지 않는다** — 기존 회귀가 그대로 초록인 것이 "동작 불변"의 증거다. **새 계약(이름 유일성 · 통합 조회)에만** 붙인다. 무거운 검증(뮤테이션·GUI)은 A2.

**A1 수용 기준:** 우편 입구와 트리가 같은 조회를 쓴다 · 바깥에서 프로필 타입을 직접 만지는 경로가 없다 · 이름 유일성이 한 곳에서 강제된다 · 기존 회귀가 **손대지 않고** 그대로 초록.

## ★A1 착수 전 반드시 알 것

**① 사문화 목록 항목 3을 오독하지 말 것.** 죽는 건 `allow_name_fallback`의 **동명 가드**뿐이고 **이름 폴백 arm 자체는 운영 경로다**(잠든 수신자 계약은 실체 id가 없어 이름으로 닫는다). `ledger.rs` 주석이 "그 팔은 dead code 가 아니다"라고 이미 경고한다 — 리뷰가 잡아준 것으로, 그대로 뒀으면 조용히 깨졌다.

**② 통합 조회는 원자적이지 않다.** ADR-0116이 "원자적 단일 뷰"를 락 순서 때문에 기각했고 경합 잔여분의 TTL 유계 수용은 그대로다. **"이제 통합됐으니 원자적으로 만들자"는 이미 기각된 방향.**

**③ 메시징 커널 격리 불변**(0110) — 커널은 여전히 `AgentManager`를 모른다. 포트 그대로, 데몬 어댑터(`messaging_host.rs`)가 얇아질 뿐.

**④ 사문화 목록 제거는 A1 범위가 아니다** — 이름 유일성이 실제로 들어온 뒤(C 슬라이스 전후) 항목별로 "조용히 무의미해졌는지"를 판정해 지운다. 도달 불가 분기는 초록으로 남으므로 테스트가 빨개지길 기다리면 안 된다.

- **[신규] 내가 쓴 ADR의 코드 주장도 반드시 대조시킬 것** — 이번에 6건이 거짓이었다. 결정은 사용자에게서 왔지만 **근거는 지어낸 부분이 있었다.**
