1. **★`v*` 태그를 승인 없이 push하지 말 것★** — 릴리스가 발행되고 재시도가 안 된다(`release already exists`). 수습하려면 릴리스·태그를 둘 다 지워야 한다.

3. **★ADR 채번을 작업 끝으로 미루지 말 것★** — 이번에 두 워크트리가 같은 0168을 만들었다. 번호를 잡으면 그 자리서 스캐폴드를 커밋·푸시해 선점한다(비용 = CI 7분, 무료). 규약이 `/adr` flow.md + `.claude/skill-bindings/adr.md`에 박혔다.
4. **★ADR 번호를 일괄 치환하지 말 것★** — 같은 문자열이 두 ADR을 가리킬 수 있다. 이번에 내 참조 16곳만 옮기고 그쪽 9곳(코드 앵커 3 + 도장 6)은 손대지 않았다.
5. **★챗 스타일을 커맨드로 만들지 말 것★** — ADR-0169가 거부했다. 표시 상태는 설정 데이터 + refresh다(ADR-0167 결정 1).

## master 머지하는 법 (막힐 수 있다)

master가 다른 워크트리에 체크아웃돼 있으면 여기서 `git checkout master`가 안 된다. **임시 워크트리**로 우회한다:

```bash
git worktree add <tmp> --detach origin/master
cd <tmp> && git merge --no-ff <브랜치> && git push origin HEAD:master
cd - && git worktree remove <tmp>
```

부작용 = 그 워크트리의 로컬 `master` ref는 안 움직인다. 거기서 작업할 때 `git pull` 한 번 필요하다.

## 남은 일 (다섯 — 다음 세션이 고를 후보)

1. **`agent.spawnInto` 고아 프로세스** ★추천★ — 슬롯 점유로 거절할 때 **에이전트는 이미 떠 있다**. 오류 문구가 스스로 그것을 밝힌다("에이전트 …는 살아있음"). 호출자가 「아무 일 없었다」로 읽으면 claude 프로세스가 샌다. 우회 = `layout.setSlotContent {type:'agent', agent_id}`. **비용 대비 이득이 가장 크다.**
2. **`__ENGRAM_AGENT__`·`__ENGRAM_DAEMON__`가 릴리스에 무가드로 열려 있다** — `src/api/clientFactory.ts:29`/`:31`. 방금 지운 둘보다 넓다(spawn·kill·프로필·프리셋 + 데몬 기동·정지). 그 파일 헤더가 스스로 「임시 경로」라 자인한다. ★`/qa` 실측 조리법이 이걸 의존한다★(프로필 생성·삭제에 대응 커맨드가 없다) — 지우려면 대체 경로가 선행.
3. **Step 3의 마지막 조각 — 클라이언트 자작 식별자.** 완결로 기록됐으나 미구현. 셸이 재접속하면 데몬 눈에 다른 주인으로 보인다.
4. **Step 2를 완결로 볼지** — 설계 문서 넷이 데몬 `mail.*` 선언을 전제하는데 코드엔 0건. **사용자 결정**.
5. **저장 시스템** — 레이아웃·챗 스타일을 디스크에 남긴다. 챗 스타일이 여기 딸려 간다(ADR-0169). 그때까지 릴리스에서 챗 여백·글자 크기를 못 바꾼다.

**선존 결함:** `docs/reference/architecture-overview.md`의 renderMode 다이어그램이 구독 deps를 `[viewId, agentId, epoch]`로 적었는데 ADR-0164는 화신 표식을 **넣지 않는다**고 못 박는다.

**사용자가 관심 보인 개선:** CDP 포트를 고정하지 말고 빈 포트를 찾아 portfile로 넘기기(데몬이 이미 쓰는 패턴). 런처 + `cdp.mjs` 양쪽 수정.

**릴리스 운영 메모:** 코드 서명이 없어 SmartScreen 경고가 뜬다 — 정상이고 노트에 안내를 넣었다. 인증서는 발급 주체당이라 하나로 모든 프로그램에 쓸 수 있으나, OV는 평판이 쌓일 때까지 경고가 남는다.
