# 핸드오프: 제어 CLI — 조각 ①② 완료, 다음은 우편 거절(③)

## 한 줄 상태 · 다음 첫 액션

제어 평면 CLI 4조각 중 **①(개명·계열·help)·②(제어 창구 + `agent` 계열)가 완료·커밋·push·CI 초록**이다. 다음 첫 액션 = **조각 ③ 착수** — 데몬이 자격증명으로 우편 요청을 거절하게 만들고, 그게 서면 CLI를 **모든 스폰에 배선** + 프라이밍에 제어 한 줄 추가.

**★순서 제약(이번에 드러난 것) — ③ 없이는 제어를 모든 에이전트에게 못 연다★**
ADR-0132 **결정 5(제어 전원 개방)가 결정 3(데몬 우편 거절)에 의존**한다. 지금 CLI는 **비-MCP 스폰에만** 깔린다(우편을 MCP 하나로 묶으려고 ADR-0128이 그렇게 해둠). 제어를 위해 MCP 스폰에도 깔면 **막아둔 우편 CLI가 같이 살아난다.** 그래서 ②는 "표면만 만들고 배선·프라이밍은 안 건드림"으로 끝냈다. ③이 그 매듭이다.

- 커밋 2개: `ba3d3a5`(조각 ①) · `0547560`(조각 ②). 둘 다 CI 3잡 초록.

## 완료 내용

**조각 ①** — `engram-send` → `engram`, 평평한 표면 → 계열 구조(`engram mail send|status|pending`), 그룹 help 신설(자격증명 검사보다 **먼저** 답한다), 이름·계열·플래그·동사 어휘를 코어 상수로 수렴(Rust 리터럴 중복 0), `ENGRAM_SEND_EXE` → `ENGRAM_CLI_EXE`. **우편 의미·wire·exit code 3분법 불변.**

**조각 ②** — `/control/agent` 신설(기존 라우터·기존 bearer 미들웨어, 몸통에 verb). 동사 5 = `list`·`spawn`(이름=깨우기 / `--cwd`=새로 만들어 띄우기)·`new`·`rename`·`move`. `engram help agent`. 매니저 로직 복제 0. 폭주 상한 512를 **코어 신규 등록 두 지점**에 원자적으로(이름 배정 게이트 안) — 기존 에이전트·복원·재스폰은 안 막힌다. `roster()`가 profiles를 **한 번만** 읽어 우편 발송 경로가 오히려 싸졌다.

**`kill`·`rm`은 의도적 제외**(사용자 결정) — 지우기가 프로세스를 안 죽여 ADR-0122와 어긋나는데 그 구현이 미정. 근거·갭은 ADR-0132 §영향. **그동안의 갭 = 에이전트가 띄울 순 있는데 CLI로 멈출 순 없다.** kill 자체는 이미 완전히 정의된 동작이라, 여는 순간 갭이 닫힌다.

## 검증 상태

**돌린 것 (재실행 명령 포함)**
```bash
cargo test --workspace --exclude engram-dashboard   # 전 회귀. 루트 bare cargo test 금지
cargo test -p engram-dashboard-net --all-features   # ★--all-features 필수★(기본 feature 비어 있음)
cargo build && cargo fmt --check
rg "^\s*use tauri" crates/engram-dashboard-core/src/                                 # 0줄
rg "engram_dashboard_(core|daemon|protocol|discovery)" crates/engram-dashboard-messaging/src/  # 0줄
rg -U -n "(crate|(super::)+)::[^;]*\b(connection_core|agent_conn|status_fanout|messaging_host)\b" crates/engram-dashboard-daemon/src/control/  # ADR-0130 트리거, 0줄
./target/debug/roundtrip-smoke.exe --cli-only        # 실 claude 2개 CLI-only 왕복(조각 ① 실측)
```
- **CI 초록 2회**(push마다 자동). **게이트 성립 = CI 초록** — 로컬에서 standard 범위를 선행 반복하지 않는 게 이 프로젝트 분담(`.claude/skill-bindings/qa.md` §CI와의 분담).
- 조각 ① 실측: `B_SENT=true ENTRANCE=cli`, 배달 3/3 delivered. **CI가 영구히 못 덮는 축**(러너에 claude 없음).
- 조각 ② 실측: CLI 표면 직접 실행(계열 목록·`help agent`·빈 부모 거부·인자 충돌 거부) + 실 claude 의존 테스트 포함 전 스위트 green.

**검증 안 된 것 (된 것처럼 적지 말 것)**
- **조각 ②는 GUI 실측 없음** — 프론트 무변경이라 대상이 없다고 판단해 cdp를 안 돌렸다. 화면이 CLI 변경을 실제로 반영하는지는 **눈으로 안 봤다**(fan-out 배선은 테스트로만 확인).
- **상한 512는 부하 실측 없음** — 8스레드 경합 테스트만 있고, 실제 512개 에이전트를 띄워보진 않았다.
- **T-20~22(아래)는 재현 안 해봤다** — 리뷰어의 코드 논증만 있고 실제로 터뜨려 보지 않았다.

## ★실패한 접근 / do-not (다시 시도할 법한 것만)★

1. **프라이밍 교육 판정기를 "계열 전체"로 넓히지 말 것.** 제어 동사는 **전 스폰에 가르치므로** 도구 이름 등장이 우편 채널의 판별 근거가 못 된다. 넓히면 ① MCP 프라이밍에 제어 한 줄 들어가는 순간 비-`--cli-only` 실험이 전부 거부 ② 우편은 안 가르치고 제어만 가르친 프라이밍이 "가르쳤다"로 통과. **코더가 거부했고 리뷰어 2인이 독립 확인.**
2. **환경변수 언급을 "흔적 신호"로 내리지 말 것.** `$ENGRAM_CLI_EXE mail send` 형태는 **실행파일 이름을 담지 않는다** — ADR-0098이 기록한 실제 사고 형태다. 현행 규칙 = **부르는 토큰(exe 이름 또는 env 변수) + 계열 + 동사 인접**.
3. **ADR-0128의 부분폐기 도장만 보고 `claude.rs`의 비-MCP 전용 배선 분기를 지우지 말 것.** 결정 3 미구현이라 그 분기가 **유일한 우편 격리**다. 세 지점에 `ADR-0132` 앵커로 경고 박아뒀다.
4. **`adr.mjs index --write` 알려진 결함(8회 재발).** 부분폐기를 2건 이상 받은 ADR의 인덱스 셀에서 **둘째 개정 표기를 조용히 삭제**한다. 돌린 뒤 JSON의 `action:"rewritten"` 행을 **반드시 확인**하고 손복구할 것.
5. **리뷰를 무한정 돌리지 말 것.** 조각 ①이 4라운드까지 갔고 후반 2라운드는 주석 문구 지적으로 늘어졌다(사용자 지적: "구지 지나가면서 구현을 다 하면 언제 완성해"). 조각 ②는 **착수 시 2라운드 상한을 선언하고 지켜서** 같은 품질에 절반 시간. **단 마지막 라운드가 실질 버그를 낸 전례도 있다**(①의 파이프 본문 유실, ②의 상한 우회) — 상한은 두되 마지막 라운드를 생략하진 말 것.
6. **cross-family(GPT) 리뷰어를 빼지 말 것.** 두 번 결정적이었다 — ①에서 Claude 계열이 "주석뿐"으로 판정한 라운드에서 **메시지 유실 버그**를, ②에서 상한의 **경로-국소성·비원자성**을 단독 적출.

## 정지 조건 (만나면 사용자에게)

- **리뷰어 판정이 정면으로 갈리면**(FIX vs BLOCK) 메인이 임의 확정 금지 → 사용자 판정(review 스킬 SEALED).
- **트리 깊이 확장·스폰 내용물(프리셋/스킬 조합)은 사용자 소관** — 다른 워크트리에서 직접 작업 중이라고 명시했다. 제어 쪽에서 건드리지 말 것.
- **T-20~22를 "지나가는 김에" 고치지 말 것** — 전부 매니저 생명주기·저장 계약 변경이고 WS 경로도 같이 겪는다. 단독 슬라이스로만.

## 미결 (추적 항목)

- **T-19** 우편 CLI 조회 판정이 빈 응답(`200 {}`)을 성공으로 봄. **agent 계열은 전용 판정기로 이미 닫힘** — 우편만 남았다.
- **T-20** 깨우기 중 동시 삭제 → 프로필 되살아남. 필요한 것 = `register_for_spawn`이 "재등록 vs 되살림"을 profiles 락 안에서 구분.
- **T-21** 종료 중 시작된 에이전트가 종료 명단 누락. 필요한 것 = 세션 쓰기 락 안 플래그 게이트 또는 제어 작업 join.
- **T-22** 명부 저장 실패를 성공으로 보고. 필요한 것 = `ProfileRegistry::mutate`가 save 결과를 전파 + 실패 시 정책 결정.
- 셋 다 **선재 결함이고 WS 경로도 동일** — 이번 조각이 만든 게 아니다.

## 남은 조각

- **③ 우편 거절 + 전체 개방** — 실질적 마지막 덩어리. 데몬이 MCP 자격증명의 우편 요청을 거절 → CLI를 전 스폰에 배선 → 프라이밍에 "제어가 필요하면 `engram help`" 한 줄. 여기서 ADR-0132 §영향의 "결정 3 미구현" 경고 항목을 지운다.
- **④ 앱 실행파일 옛 CLI 철거** — `src-tauri/src/cli.rs` 삭제 + `main.rs` 선행 분기 제거. 그 4동사(`list`/`send`/`spawn`/`kill`)는 ①②에서 이미 새 도구로 옮겨졌다(단 `kill`은 미이관 — ③/전용 스텝과 함께).
