## ★사용자 결정 (이번 세션 — 반드시 승계)★

1. **주석 판정 기준을 "AI 독자가 도출 가능한가"로 재정의**(§아래 v2). 기존 "의심 시 보존"의 근거
   (누락 비용 10~100배)는 *사람 독자* 경제학이라 AI 독자에 전이되지 않는다는 판단.
2. **길이 제약 금지.** "헤더는 길어도 상관없다 — 필요 없는 내용이 섞여 혼선이 되는 게 문제다."
   → 기준에 숫자 상한 0개. 제약은 **주어와 내용**으로만.
3. **타입도 무조건 다는 게 아니다.** "이름 + 주변 내용으로 이해되면 안 적어도 된다."
4. **함수 기본값 = 이름이 다 말한다.** 이름이 못 담으면 1차 처방은 주석이 아니라 이름 수정.
5. **관련 없는 주석은 있으니만 못하다**(주제 이탈 = 값 0 이 아니라 마이너스).
6. **★Codex 적대 제외의 범위 정정★** — 앞 핸드오프(`21b8502`)에 "주석 작업에서 Codex 제외"로 넓게
   적혀 있으나 **메인의 과잉 일반화였다.** 실제 사용자 의도 = "주석 **diff 하나하나**에 Codex 를 붙이면
   토큰이 없다". **기준 수립·리서치처럼 산출물이 앞으로를 구속하는 건에는 붙인다**(이번 리서치에 실제로

7. **커밋은 하되 푸시는 사용자 지시 시에만** → 이번엔 "다른 PC에서 해야 하니 푸시까지" 지시로 **푸시 완료**.

## ★주석 기준 v2 — 확정본 (clean-comment 정본에 반영 완료)★

정본 = `~/.claude/skills/clean-comment/references/{rules.md, style-base.md}`.
아래는 **요지**다 — 실제 판정은 정본을 읽는다.

### 판정 = 2단
1. **도출 가능한가?** 이름·시그니처·본문·**주변 코드·테스트·호출부**를 읽으면 아는가 → **알면 삭제**
   (정확해도 삭제. 독자는 주변을 다 읽을 수 있는 AI 라 도출 가능한 서술은 정보가 아니라 중복이다).
2. 도출 불가능한 것 중 **모르면 문제가 되는가?** → 되면 남김.

**1단을 통과하는 것 = 코드 어디를 읽어도 안 나오는 네 부류뿐:** ① 부재(왜 그게 없나) ② 외부 세계의
사실(실측·상대 프로세스·OS 동작) ③ 결정·의도 ④ 알려진 미확인. 여러 파일 상호작용에서만 드러나는
불변식(락 순서·race)은 통과하되 **"오래 읽으면 언젠가 안다"는 통과 사유가 아니다.**

### 신설 금지 4종
- **일기** — 날짜·작성자뿐 아니라 **설계 변경 서사**("옛 판은 …였다"). 판별은 시제가 아니라 **행동**:
  "되살리지 마라 + 이유"는 남고 "무엇이 있었다"는 삭제.
- **심의 전사** — 논증·기각한 대안·범위 밖 선언 = **ADR 소유**. 대안 둘 이상 열거 = 자동 위반.
- **주제 이탈** — 주어가 그 코드가 아닌 것. **처방 순서 = ① 이 코드 주어로 재진술 → 안 되면 ② 삭제.**
- **포인터-rot** — 라인번호·교차파일 호출처 열거·자기 인용. 위치보다 계약을 쓴다.

### 보존(무조건 — 시험 미적용) 6종
도구 지시 · ADR/리뷰 앵커 · **의도적 부재의 이유** · 경계 관례 · **실측 기록 + 알려진 미확인** ·
와이어/바이트 레이아웃.

### 그 외
- **대상 단위 표**(모듈/타입/공개함수/비공개함수/본문) — 별도 규칙이 아니라 "무엇이 자주 시험에 걸리나".
- **앵커 중복 정리 단위 = 한 정의(doc 블록)**, 한 파일이 아니다(grep-locality 가 앵커의 존재 이유).
  앵커가 삭제 대상 문장에만 실리면 **토큰을 트레일링 앵커 라인으로 이동**. 파일 내 0 은 위반.
- **정정의 형태** — 거짓 절만 삭제가 기본, 편집 후 남은 문장이 단독으로 참인지 재독,
  **계약 주석 재작성은 조건 3개 충족 시만**(계약 자리 · 실코드 확인 · 근거 위치 보고).
- **테스트 코드** — assert 메시지가 같은 말이면 삭제 / 메시지 없거나 변수명이 불투명하면 역할 라벨 보존.
- **분량 = 재검토 트리거**(금지 아님, 줄 수로 자르지 않음).
