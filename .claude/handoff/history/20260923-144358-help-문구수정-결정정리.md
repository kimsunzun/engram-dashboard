## do-not (이번 세션이 실제로 물린 것)

1. ★**`!` 는 bash 로 돈다**★ — PowerShell 문법(`$b=…; … | ForEach-Object`)을 주면 통째로 안 돈다. 사용자에게 줄 명령은 bash 로, ★**한 줄을 짧게**★(붙여넣을 때 줄바꿈이 들어가 첫 줄만 실행된 실발생).
2. ★**`rm -rf` 는 공용 `settings.json` 의 거부 규칙 `Bash(rm -rf *)` 에 막힌다**★ — 삭제는 사용자에게 `! rm -rf <경로>` 로 넘긴다. `sed -i` 도 자동 모드 분류기에 막힌 적이 있다 → Edit 도구로 고친다.
3. **자기가 띄운 앱·데몬의 `taskkill` 도 자동 모드에서 막힌다** — 사용자에게 `! MSYS_NO_PATHCONV=1 taskkill /PID <pid> /T /F` 로 넘긴다.
4. **Edit 도구는 심볼릭 링크를 안 쓴다** — `~/.claude/settings.json`·`agents/`·`references/` 는 `I:\Engram\core\claude-global-shared\…` 실경로로 고친다.
5. **핀 고정 툴체인 저장소에서 `rustup toolchain install` 은 rustup 자체 업데이트를 부를 수 있다**(실발생 — 1.29.0 → 1.29.1).
6. **codex 리뷰 스레드를 `--resume` 로 이을 땐 첫 줄에 「직전에 뭘 했나」를 묻는다**(조용한 오물림 방지 — codex-call-spec §2).
