## 결정 후보 1~9 (전부 방향 확정 · ADR 미작성)

1 OS 의존 코드 → `platform` crate(함수 + 핸들 타입, 컴파일 시점 분기) · 2 command·messaging 도 base 사용 · 3 로그는 base 경유만(입구 = 위험도·카테고리·메시지, 안쪽 매크로, 가리기 중앙화) · 4 base 공용 함수 `file`·`text`·`time`·`path`·`sync` + `Clock` 통합(네 벌) + `testing` 플래그 · 5 셸 → agent 끊기(이름 충돌은 데몬 거절 + 셸 메시지 박스, 슬롯 스폰을 `agent.new` 경로로 바꾼 **뒤** 셸 검사 제거) · 6 discovery 를 데몬·셸로 · 7 transport 부착 뒤 net 걷기 · 8 패킷은 남의 구조체를 품지 않음 — 고정 패킷은 `protocol` 타입, 명령 버스 칸 넷만 `Box<RawValue>` · 9 engram CLI 독립 패키지(`crates/` · 이름 `engram-dashboard-` 접두 · bin 이름 `engram` 유지).

사용자 원칙(이번 세션): 「클라는 데몬과 별개라 agent 를 모른다」 · 「애매한 건 일단 데몬으로, 데몬은 마지막에 정리」 · 「패킷은 남의 구조체를 품지 않는다」 · 「base 입주는 지금 여러 곳에서 쓰이면 메인이 판단해 옮긴다」 · 셸 안쪽 분리는 플러그인 설계와 함께 나중.

## 진행 방식 (사용자 결정)

- 0~2단계 = 브랜치 하나(`v0.3.3/refactor/...`) · 3단계(transport) = 별도 브랜치·별도 TRD.
- **단계마다 push → CI 초록 → master 머지**(체크아웃 없는 통합 절차). push·머지는 매번 사용자 확인.
- **핸드오프마다 origin 업데이트를 받아 작업 브랜치에 병합.** 다른 워크트리 동기화는 사용자가 전달.
- **작업하며 보이는 리팩터링 거리는 묻지 않고 메모 11절에 적립**, 결정 필요한 것만 묶어 올린다.

## 검증 상태

- 문서만 바꿨다 — 코드·테스트 변경 없음. CI 는 브랜치 첫 push 에서 돌아 초록(master 흡수 커밋이 비교 범위에 들어와서) · master 머지 push 는 문서 경로라 CI 미실행.
- 경계 사실(의존 · 사용처)은 코드·`cargo metadata` 로 대조했다. 데몬 구조 문제 다섯(순환 · `control` 섞임 · 우편 분산 · `command_delivery` 네 덩어리 · 테스트 서버 공개)은 지난 수집 자료 기준이고 재대조 안 함. command 정리 후보 넷과 그 근거 일부는 워커 보고(메인은 핵심 위치만 대조).
- rust-analyzer 아키텍처 문서 원문 대조는 못 했다(확인 시도 중단).

## 실패한 접근 / do-not

1. **load 직후 핸드오프의 다음 액션을 바로 실행하지 말 것** — 사용자에게 먼저 묻는다(지난 세션 실발생).
2. **「`RawValue` 면 두 번 파싱 안 한다」고 말하지 말 것** — 바깥에서 검증 훑기 1회 + 끝자락 파싱 1회다(적대 리뷰가 serde_json 구현으로 반증). 아끼는 것은 중간 트리뿐.
3. **`codex exec` 에 긴 지시문을 인자로 넘기지 말 것**(Git Bash `cmd //c` 경유 시 따옴표가 깨져 리뷰 0회로 조용히 끝난다) → `codex exec ... -o <out> - < <지시문파일>`. research `feedback.md` 에 적립.
4. **새 브랜치 첫 push 는 문서뿐이어도 CI 가 돈다** — master 흡수 머지가 들어 있으면 그 코드가 비교 범위에 잡힌다. 「문서만이니 CI 없다」고 단정하지 말고 `gh run list` 로 본다.
5. **tracking 번호를 미리 잡아 두지 말 것** — 이번 세션에 T-36 · T-46 이 master 와 두 번 겹쳤다(지금 T-47). 머지 직전에 master 의 tracking·archive 최대 번호를 다시 본다.
6. nmfc 플러그인 훅(HANDOFF-TRIGGER · WIKI-PRECONSULT)은 이 저장소와 무관(Origin UE5용) — 무시하고 전역 `handoff` 스킬을 쓴다.
