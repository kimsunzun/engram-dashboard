## ★Step 2 남은 조각 (계획 요약 — 다음 세션이 그대로 집행)★

**착지 완료:** 슬라이스 0(도구 crate 씨앗) · 2(CLI가 평평한 모양 함께 수용) · **5a(등록 wire 프로토콜)** · **1(데몬 자기 표)**. 남은 것은 3 → 5b → 4, 그리고 결정 대기인 6.

**~~슬라이스 5a — 프로토콜 variant 4종(등록 wire)~~ ✅ 착지.** 아래는 이력이다. `protocol`에 `RegisterCommands`/`UpdateCommands`/`ListCommands` + `CommandList` 이벤트, `CommandListEntry`는 protocol에 선언(데몬→클라 투영이지 버스 계약이 아니다). protocol의 워크스페이스 의존이 0→1이 된다(TRD §5가 이미 계상). **`src-tauri/src/daemon_client/protocol_state.rs`의 두 match가 catch-all 없는 전수 match라 variant를 늘리면 셸 빌드가 깨진다** — 같이 고쳐야 한다. 파일 충돌 없음 → 지금 바로 단독 착수 가능.
- **ts-rs 판단 = 실측으로 닫혔다.** 도구 crate에 ts-rs를 들이지 **않는다** — 타입 문자열 오버라이드가 `TS` 바운드를 건너뛴다는 것을 붙였다 떼어 양방향 확인했다(떼면 컴파일 에러, 붙이면 import도 안 생긴다). 아래는 착수 전 근거였다. Step 2가 wire에 올리는 도구 crate 타입은 두 개뿐이고(둘 다 문자열 필드), `#[ts(type = "…")]` 오버라이드가 `TS` 바운드 자체를 건너뛴다(ts-rs 매크로 소스 확인). 이 repo에 선례 20여 곳. **단 이건 소스 읽기 결론이지 빌드 확인이 아니다** — 5a 착수 시 5분 스파이크로 먼저 확인하고, 실패하면 도구 crate에 ts-rs를 들이는 쪽으로 전환. 봉투가 실제로 wire를 건너는 건 Step 3이고 그때 다시 본다.

**~~슬라이스 1 — 데몬이 자기 표를 갖는다~~ ✅ 착지.** 아래는 이력이다. 데몬 `Cargo.toml`에 도구 crate 추가, `control/commands.rs` 신설(`make_daemon_table`), `mcp_server.rs`에 표 슬롯, `lib.rs` 조립. **위험:** `make_table`은 알림 대상을 필수로 받는데 데몬 쪽은 `Option`이라 no-op 어댑터가 필요하고, **슬롯이 채워지기 전에 어댑터를 만들면 영원히 `None`을 붙든다**(→ 트리가 조용히 낡는다).

**슬라이스 3 — ★벽 교체(가장 위험)★.** `control/agent.rs`의 5동사 match를 표 조회로. 지우는 함수가 20개 가까이 되고 전부 코어에 쌍둥이가 있다. **지우면 안 되는 것 2개:** `resolve_target`/`TargetResolution` — 죽은 코드처럼 보이지만 우편 입구와의 해석 일치 교차검증 테스트가 그걸 import한다(코어 쪽 등가물은 private). **반드시 함께 서야 하는 것:** ADR-0136 입구 거절(`check_args` 호출) — 안 부르면 오타 인자가 성공으로 보고된다. **바꾸면 안 되는 관측 가능한 것:** HTTP 상태 4종·오류 봉투 모양(`{status,code,hint}` — 이걸 바꾸면 CLI가 반려를 못 알아봐 종료코드 1이 2로 뒤집힌다)·hint에 `help`가 들어간다는 성질·동사별 명부 알림 횟수(깨우기는 알리지 않는다 — 「고치지」 말 것).

**슬라이스 5b — 등록 wire 데몬 쪽.** `connection_core.rs` dispatch에 arm 3개(추가만), 연결 끊김 → 명부 tombstone. **주인 토큰 = 연결 id**(권고 채택, v1 단일 인스턴스 전제). `register`가 이제 `Result`를 돌려주니 **그 실패를 답장으로 바꿔야 한다 — 무시하면 안 된다.**

**슬라이스 4 — 축소 단계.** CLI에서 중첩 모양 독해 제거.

**슬라이스 6 — 우편 명령 = ★사용자 결정 전 착수 금지★**(아래).

**순서·병렬:** 5a는 지금 단독 가능 · 1은 5a와도 병렬 가능 · 3은 1 다음 · 5b는 1·5a 다음(3과 병렬 가능하되 `lib.rs`가 겹치니 1이 먼저 착지해야) · 4는 2·3 다음.

## ★결정 완료 — 이 세션에서 사용자가 닫은 것★

1. **버전 불일치는 끊지 않고 알린다 — ADR-0137.** 프로토콜 버전 안 올림(상향 기준을 「봉투 문법이 깨질 때」로 좁힘) · 보내기 전 상대 능력 확인 · **데몬 자동 종료 없음** · 고지 = **앱 시작 시 1회, 알리기만, 닫으면 작은 흔적**(행동 버튼 없음, 모달은 아예 못 붙을 때만) · 버전과 무관하게 **마감 시한 + 오류의 상관관계 표시**를 함께 깐다. 근거 조사 = `docs/research/daemon-version-mismatch-2026-08-14.md`(적대 리뷰가 BLOCK을 내 초안을 깎았고 그 경위도 그 문서에).
   - ★**Step 3(셸이 자기 이름을 등록하는 시점)에 이 셋이 함께 서야 한다**★ — 능력 광고 · 마감 시한 · 상관관계 표시. 하나라도 빠지면 옛 데몬을 만난 요청이 조용히 멈춘다.
   - **알림 표면은 프론트에 아직 하나도 없다**(모달·띠·토스트 전부 0 — 실측). 만들 때 **LLM 호출 경로를 함께** 만들 것(CLAUDE.md 「LLM-우선 제어」), 새 전역 핸들을 늘리지 말고 기존 제어 표면에 얹을 것.
2. **우편 명령은 Step 2에서 뺀다 → Step 3.** 막힌 이유 = 도구 crate에 「누가 불렀나」를 나르는 자리가 없음. 그 계약 변경은 Step 3에서 셸 명령이 붙을 때 어차피 필요하므로 그때 함께 설계한다. **슬라이스 6은 이 결정으로 Step 2에서 제외됐다.**
3. **오류 코드는 늘리지 않는다(현 상태 유지).** 이미 커밋된 코어 표가 필요한 구분을 하고 있고 테스트가 고정한다. 늘리면 각 명령이 광고한 오류 목록·CI가 지키는 생성물과 어긋난다. 실질 손실이 관측되면 그때 ADR과 함께 늘린다.

**장기 방향 적립(지금 범위 아님):** 세대를 겹쳐 돌리고 **옛 데몬은 자기 세션이 끝날 때까지 살려 두는** 방식. 「데몬을 죽이면 안 된다」를 구조로 푸는 유일한 길이고, 데몬 수명·업그레이드를 다시 볼 때 1순위 후보다.

## ★실패한 접근 / do-not★

1. **오류 코드를 슬쩍 늘리지 말 것** — 위 미결 2. 이미 한 번 되돌렸다.
2. **`resolve_target`을 TODO만 보고 지우지 말 것** — 교차검증 테스트가 쓴다(슬라이스 3).
3. **깨우기에 명부 알림을 「추가」하지 말 것** — 의도적으로 안 알린다.
4. **오류 봉투 모양을 도구 crate 오류 그대로 바꾸지 말 것** — CLI 종료코드 계약이 깨진다.
5. **`check_args`를 안 부르고 벽만 교체하지 말 것** — ADR-0136이 무력화된다.
6. **도구 crate에 워크스페이스 의존·CLI 어휘를 들이지 말 것** — 의존 상한 게이트 1줄, 어휘는 테스트가 지킨다.
7. **선언을 한 crate에 모으지 말 것 · 명령 정의에 「주인」 칸을 만들지 말 것 · 전역 자동등록 표에 핸들러를 박지 말 것(T-1) · 데몬이 인자·help를 뜯게 만들지 말 것.**
8. **조사 보고서(`docs/research/unified-command-bus-survey-2026-08-12.md`)를 확정으로 읽지 말 것** — BLOCK 상태.
9. **컨텍스트 사용량을 체감으로 단정하지 말 것.**
10. **blind 리뷰어의 BLOCK을 그대로 옮기지 말 것** — 이번 세션 3회 모두 심각도 과대였고, doc-aware 판별을 거치면 대부분 NIT로 내려갔다. **단 실재하는 것을 잡아내는 비율은 높다** — 판별은 반드시 거치되 무시하지도 말 것.
