## 사용자에게 물을 것 (하나씩 · 맥락 먼저)
1. 다른 연결 사건(일시적 끊김 · 재시도 중 · 유실 알림 · 명령 하나 실패 — ADR-0180 결정 2 · ADR-0181 이 띠로 보내는 것)도 덮개에 얹나? — ADR-0277 열린 것. 지금 「연결 띠」 = 오늘의 ConnectionNotice(데몬 기동 실패 이유)뿐.
2. 「줄 바깥 빈 영역」 — 사용자가 나중에 얘기하자고 함.

## 검증 안 된 것
- 33vh 스크롤 넘침 · light/e-ink 구분선 · 실제 연결 실패로 띠 띄우기 · 트리 창을 화면에 띄운 채 보기(창 띄우는 명령 없음 · window.show 권한 없음 → 숨긴 채 잼) · 가드 ⅱ 에서 「새로 시작」 · 버스 restore.status 의 saves.
- 선재(셸·프론트 빌드 어긋남 전용): 답 뒤 · 이벤트 재당기기가 못 읽는 crash_copy 에 재시도 없음.

## do-not
- ★Python/heredoc 으로 정규식 · 이스케이프를 파일에 쓰지 말 것★ — `\b` 가 0x08 로 깨진 사고 2회. 쓴 뒤 `rg -n "[\x00-\x08\x0b\x0c\x0e-\x1f]"` 로 확인.
- Radix ScrollArea 루트에 위치 클래스 주지 말 것(인라인 position:relative) — NoticeOverlay 감싸개가 위치를 쥔다.
- ADR 채번: adr 스크립트는 로컬만 본다 — 원격 ref · 형제 워크트리 최대값 확인(다음 = 0278 이상).
- qa.md 통째 읽기 비쌈 — 지시서에 필요한 절만(분리 실행 · §full · 조리법 B). 연결 띠 합성은 창마다 disconnect()/connect().
- GUI 감시용 백그라운드 `gh run watch` 가 메모리 부족으로 강제 종료된 적 있음 — 단발 조회로.
