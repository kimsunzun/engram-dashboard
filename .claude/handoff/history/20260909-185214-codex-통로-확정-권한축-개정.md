## 결정된 것

### ADR-0187 — Phase 2 통로 = `codex app-server` (확정)

기각 둘 다 실측이다. `codex exec --json` 은 ★**글자를 흘리지 않는다**★ — 이벤트가 `thread.started`·`turn.started`·`item.completed`·`turn.completed` **넷뿐**이고 4.5 초에 죽였을 때 나온 것이 앞 두 줄이었다(같은 시각 app-server 는 조각 10 개 송신). 공식 SDK 는 **존재하지 않는다**(도움말·설치본 검색 0).

**보낼 요청은 셋뿐이다** — `thread/start` · `turn/start` · `turn/interrupt`. ★**서버가 우리에게 먼저 묻는 요청은 실측 0 건**★(읽기 전용 + 승인 없음 조건. 선언은 11 종) — 그래서 2a 는 인바운드 **응답 라우팅만** 필요하다. **그 조건이 바뀌면 이 면제가 죽는다.**

### ADR-0188 — 권한·승인을 백엔드 중립 축으로 (확정, ADR-0097 부분 개정)

사용자 지적에서 나왔다 — 「codex 를 읽기 전용으로 띄울까요」가 나온 것 자체가 구조 결함 신호다. 확인 결과 **프론트에 권한 코드 0 줄 · `Capabilities` 에 그 영역 없음 · 두 백엔드가 각자 문자열로 박아 놓고 정책이 서로 다름**(claude=승인 끔, codex=요청 시 승인).

★**값 설계(축 개수·값 이름)는 아직 못 짠다**★ — claude 6 값이 **실제로 무엇을 하는지 도움말에 한 줄도 없다**. codex 도 샌드박스 세 값에 설명이 없다. 그래서 **값끼리 짝지을 근거가 지금 0**이고, 이름으로 묶으면 화면이 거짓 신고를 한다. 재고 나서 후속 ADR.

### 메인이 정하고 보고한 내부 결정 넷 (TRD 에 아직 반영 안 됨)

- **capability 독자는 2a 에서 만들지 않는다** — 값만 정직하게 신고. 근거: 챗 표면은 리사이즈를 안 부르고, `canInterrupt` 는 읽는 화면 코드가 0 이다.
- **새 모듈 = `backend/codex/app_server/` 아래 셋** — 요청·응답 짝 맞추기 / 드라이버(초기화·id·준비 장벽) / 번역기. **통로 모드는 `AgentCommand::Codex` 의 칸**으로 둔다(자유 문자열 아님) — 컴파일러가 누락을 잡고, 버전 판정도 「기존 변형에 기본값 칸 추가」라 관용된다.
- **인바운드는 디코더에 채널을 주는 쪽** — `OutputCore::subscribe` 쪽은 응답이 화면에 그려지는 문제를 되열고, 세션 대기표는 새 간선이 더 크다.
- **프로필 접근은 조립점이 좁은 포트를 건넨다** — `spawn_agent` 이 백엔드 파생 사실 여섯을 이미 그렇게 내려보낸다(일곱째가 붙는 모양). ★포트 이름이 중립이 아니면 ADR-0004 가 샌다.★

- **ADR lint** `ok: true`(남은 findings 는 선재 — 번호 공백·레거시 링크·폐기 앵커).

### 검증 안 된 것

- ★**TRD 3 판은 리뷰를 안 거쳤다**★ — 2 라운드 지적 21 건 + 신규 다섯을 반영해 다시 쓴 판이고, **그 반영이 맞는지 아무도 안 봤다.**
- ★**push 는 했지만 CI 결과를 확인하지 않았다**★ — 문서 전용 델타라 초록일 것으로 보지만 **확인 안 함**. 게이트 성립 = CI 초록이므로 다음 세션이 먼저 확인할 것.
- **도구를 실제로 실행하는 codex 턴** — 안 재 봤다. 그래서 명령 실행 결과가 조각으로 오는지, **승인 요청 11 종이 실제로 오는지** 모른다(읽기 전용·승인 없음으로 띄웠으니 안 온 게 당연).
- **턴 도중 stdin 을 닫으면** 어떻게 되나(잰 것은 「턴 없을 때 46ms 종료 0」).
- **프로세스 사망 후 재부착** 시 서버가 진행 중 턴을 다시 알려 주나.
- **살아 있는 대화의 승인 정책을 바꿀 수 있나**(클라 요청 155 종에 그런 메서드가 있는지 안 봄).
- **claude 6 값의 실제 동작** — ADR-0188 값 설계의 선행 조건.
- **GUI 실측 없음**(소스 0 변경이라 해당 없음) · **`master` 미머지**.

## do-not (이번에 실제로 데인 것)

1. ★**재기 전에 설계하지 말 것**★ — 통로를 안 재고 TRD 세 판. 문서 자신의 §1 이 「Phase 0 을 앞에 두는 값어치는 틀렸을 때 배선을 안 짓는 것」이라고 적어 놓고 그 원칙을 어겼다.
2. ★**층 이름으로 설계하지 말 것**★ — `transport`·`backend`·`decoder`·`capabilities` 이름 위에서 판단하면 리뷰가 BLOCK 을 준다. **블로커 13 건 중 12 건이 외부 도구가 아니라 우리 구조와 충돌했다.** 소유권 지도(PART B·C)를 먼저 펴고 그 위에서 판단할 것.
3. ★**blind 리뷰어에게 「근거를 스스로 읽지 말라」를 명시할 것**★ — `codex exec --sandbox read-only` 는 저장소를 읽을 수 있어서 아무 말 안 하면 `docs/decisions/` 를 자기 손으로 집는다(주입 0 인데 blind 아님). 이번엔 열람 금지를 프롬프트에 넣어 막았다. review 스킬 feedback 에 적립함.
4. ★**`index --write` 가 지운 ADR-0082 큐레이션 셀을 다시 복원하지 말 것**★ — **일부러 복원하지 않기로 결정했다**(사용자 위임). 그 경고의 정본은 ADR-0082 본문 6 행에 온전히 있고, 매 실행 손복원은 4 회 반복된 비용이다. 원인·제안은 adr 스킬 feedback 에 적립함.
5. ★**사용자 보고에 지어낸 은유를 쓰지 말 것**★ — 이번 세션에 두 번 지적받았다(「문이 없다」·「값을 매겨라」). 규율은 **이름을 빼라**고 했지 은유를 쓰라고 하지 않았다. 검사 = 이름 뺀 자리에 들어간 게 명사면 틀린 것, 문장으로 바꾼다. **그리고 내부 지시서에서 만든 약칭을 정의 없이 대화로 들고 나오지 말 것.**
6. **긴 보고를 한 번에 쏟지 말 것** — 또 발생했다(사용자가 「무슨 상황임?」으로 끊음). 목록은 한 줄씩, 펼치는 건 하나만.
7. **python heredoc 에 한글 넣지 말 것**(조용히 손상) — `cat > file <<'EOF'` 또는 Write 툴을 쓴다.
8. **ADR 채번 전 `git fetch` + 전 ref 조회** — 이번에도 걸렀다. 그리고 ★기존 ADR 존재 확인이 `new` 를 `supersede` 로 바꿨다★(0097 을 모른 채 박았으면 고아 결정이 됐다).
