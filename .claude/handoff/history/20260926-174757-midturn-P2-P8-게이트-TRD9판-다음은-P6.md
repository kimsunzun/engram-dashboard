## Working pattern (keep — learned this session)

- Coders `worker-senior` (critical) / `worker-scout` (small); brief = `coder-brief-common.md` (now also: never `sed -i` a CRLF file). Chunks cost 340–490k tokens / 100–125 tools / 18–30 min — split at planning time (P2e2 → P2e2a/P2e2b worked).
- Review payloads: `git diff --histogram` (default Myers inflated P2 to +12k/−4.5k vs real +7.2k/−0.2k); split production vs tests by cutting Rust files at `#[cfg(test)]` + `mod` (scratch `split.py`); re-review with diff-of-diffs to the same Claude reviewers via SendMessage; codex re-verify with `--resume` + 「first line = what you did last turn, else WRONG THREAD」 **only if no other codex call ran since** — otherwise `--fresh` with the previous findings listed.
- Long-line docs: `changed_rows.py` (per changed line, changed spans ±160 chars) as the doc-review payload.
- Push code only via a temp `GIT_INDEX_FILE` + `commit-tree -p <remote tip>` + `git push origin <sha>:refs/heads/<branch>`; then `git reset --soft <pushed>` + one docs commit locally (verify tree equality). Never force-push.
- M15/GUI measurement: a direct WS client to the daemon works (no GUI needed); RUST_LOG does not reach a WMI-spawned daemon — launch the daemon directly with `launch-detached.ps1 -EnvVars`; release build for latency.
