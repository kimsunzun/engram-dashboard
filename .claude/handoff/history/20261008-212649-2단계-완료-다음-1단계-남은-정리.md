## do-not
- **새 번호 앵커를 코드에 박는 순간 ADR 번호 선점 커밋을 push 한다** — 이번에 U1 이 `ADR-0284` 앵커만 박고 파일을 안 내 다른 브랜치에 번호를 뺏겼다. 채번 전 원격 전부 확인: `git -c core.quotepath=off ls-tree --name-only <ref>:docs/decisions`.
- **지시서에 옮겨 적는 실측 주장은 그 패키지에서 다시 잰다** — 2-4 에서 메인이 TRD 2-1 의 `-p net -i agent → rc=101` 을 셸에 옮겨 「게이트가 안 선다」고 적었다가 틀렸다(셸은 dev 간선으로 대상이 resolve 에 있어 rc=0).
- master 머지 직전 `git merge-tree` 재확인 — 이번에도 그 사이 다른 브랜치가 들어와 흡수 머지가 필요했다. 충돌이 양쪽 보존뿐인 문서면 `git show --remerge-diff` 를 메인이 보고 넘어갔다.
- 같은 브랜치에 연달아 push 하면 앞 CI 는 취소된다(동시성 그룹) — 마지막 커밋의 CI 만 본다.
- CRLF 저장소 · `sed -i` 금지 · adr 스크립트가 README · ADR 을 LF 로 쓴다(코더가 CRLF 로 되돌린 적 있음 — index 는 LF 로 저장되니 어느 쪽이든 커밋은 같다).
- `rm -rf` 는 이 환경에서 권한 거부된다 — 정리 대상이 있으면 사용자에게 명령을 준다.
- 백그라운드 대기(gh run watch)는 메모리 부족 때 강제 종료된다 — 1분 간격 `until` 루프로 가볍게.
