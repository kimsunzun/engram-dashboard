## 검증 상태(쌍)
- **돌린 것:** daemon 전 스위트(build+test-harness) 연속 3회 clean + roundtrip-smoke 단독 49/49 · fmt --check clean · qa quick PASS · 스모크 라이브 2런 PASS. 재실행: `cargo test -p engram-dashboard-daemon --features test-harness` / 전 멤버는 `cargo test -p engram-dashboard-core -p engram-dashboard-protocol -p engram-dashboard-discovery -p engram-dashboard-daemon`.
- **안 된 것:** 인수 실측 잔여(위 2번 ①~⑤) · 새 노브의 라이브 런(단위·통합만 green, 실 claude로 미실행) · 피어 감사 교정본 2차 적대 리뷰(1차 30건 반영으로 갈음) · OpenClaw 큐 상세·MS Durable Agents(보고서에 ○ 표기).

## do-not (누적 + 신규)
bare `cargo test` 금지(멤버 열거) · 공유 데몬 불가침(내가 안 띄웠으면 kill 금지 — 빌드 os error 5의 원인이기도) · Fable 워커 스폰 금지 · v2 기능 편입 금지 · 유저 전역 설정 수정 금지 · qa cdp smoke `forward_daemon_command`는 JS 객체·request_id는 유효 UUID · **[신규] ws_e2e `case09_slow_consumer_closed_others_unaffected` = 부하 민감 flaky**(CPU 부하 하 재현 확정·무부하 12연속 통과·이번 diff 무관 — step-log 백로그, 수리 시 ADR-0038 절차, 임계값 튜닝 금지) · **[신규] Bash 백그라운드에서 `$TMPDIR` 미정의**(빈 값 → `/파일명` 권한 오류 — 스크래치 절대경로 직접 쓸 것) · **[신규] 봉투 관측을 텍스트 파싱으로 만들지 말 것**(본문 위조 가능 — 구조화 값 스레딩이 정답, 리뷰 실격추).
