## 실패한 접근 (do-not)

- **`tracing_appender`의 non-blocking writer를 쓰지 말 것** — 워커가 비동기인데 데몬은 `std::process::exit`로 끝나 소멸자를 건너뛴다. **하필 기동 실패 줄이 유실된다.** (기본 버퍼 128,000줄·가득 차면 조용히 버림·종료 타임아웃 100ms/1000ms — 크레이트 소스 확인.)
- **로그 마스킹 계층을 짓지 말 것** — 토큰이 같은 폴더에 평문으로 있어 사본만 가리는 건 아무것도 안 지킨다. 대신 **우리가 쓰는 로그 문장에 자격증명을 넣지 않는다**가 규약이다(ADR-0138).
- **토큰 파일에 권한(ACL)을 걸지 않기로 했다** — 1인 PC + 본인 폴더면 값이 없고, 배포·USB 형식에서 무력하다. 재론 조건 = 배포판을 남에게 주기 시작하면.
- **단일 인스턴스 판정을 데이터 폴더 기준으로 바꾸려 하지 말 것** — 플러그인이 이름 override를 안 열어 직접 재구현해야 한다(창 앞으로 꺼내기 포함). ADR-0137이 identifier 분리를 택한 이유.
- **런처를 이미지 이름 kill로 되돌리지 말 것**(ADR-0139).
- 어젯밤 인계의 do-not 8건(경로 해시 잠금·`FILE_SHARE_WRITE`·구간 잠금·자진 종료 등)은 **그대로 유효**하다 — `docs/decisions/0134~0136`과 `crates/engram-dashboard-net/src/instance.rs` 헤더.
