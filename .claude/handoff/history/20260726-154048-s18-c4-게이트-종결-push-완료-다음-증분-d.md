# 핸드오프: S18 C4 게이트 종결·커밋·push 완료 — 다음 = 증분 D(MCP 툴·CLI 미러·--settings)

## 한 줄 상태 · 다음 첫 액션
- **상태:** C4 완전 종결. 리뷰 blind(codex) 재판정 4라운드(FIX 3→1→1→**PASS**) + `/qa full` PASS(라이브 smoke 포함) + `/review doc` PASS(BLOCK 2건 반영 후) → feat `0486d83` + docs `289d2bd` 커밋 → **push 완료**(`601920c..289d2bd`, 23커밋). 워킹트리 clean(`_wip/` 미추적 스크래치만 잔존 — 기존분, 지우지 않았음).
- **다음 첫 액션:** **증분 D 착수.** 설계 논의 불요(spec §6 확정 — 사용자 결정): ① MCP 툴 2개 `messages{id?}`(장부 조회/내 미결) · `group{group?,add?,remove?,delete?}`(명단 관리 — 현 test-harness 임시 통로는 D에서 삭제 표기됨) ② CLI 미러(`engram-send status|pending|group ...` + `--body-stdin`) ③ `--settings` 주입(스폰 시 engram MCP 허용 조각 세션 한정 — 전역 무변경) + merge 실증 ④ 프라이밍에 새 툴 교육. 그 뒤 **인수 실측 3건**.

## 이 세션이 한 것 (C4 게이트 재작업 round 6~9 — 근거 정본 = ADR-0107)
1. round-6 blind 판정 FIX 3건 → 코더(worker-senior) 수정: ① in-flight 회계(park 분모 = 큐+주입중, RAII 정산) ② stale 판정 = 동명 생존 목록 비소속(`park` 시그니처: current 단일값 → `live: &[(AgentId,u32)]` 슬라이스, 빈 슬라이스 = 회수 0) ③ 회수 시 TTL 경과분 `expired` 분류.
2. round-7 FIX 1건(FIFO 합류가 in-flight 배치를 못 봄 — **C2부터 있던 기존 결함**, 스코프 편입 = 사용자 선택 "지금 고치고 간다") → `has_pending_ahead`(큐+in-flight, 양 레인 무필터 — 과차단=지연만) + flush 중첩 유예(stage 0)/정산 재타(stage 6).
3. round-8 FIX 1건(유예 마커 last-writer-wins lost wakeup) → 마커 = 이름당 **id 집합**(중복 배제·정산 시 전원 재타·죽은 id는 no-op). round-9 **PASS**.
4. 문서: **ADR-0107 신설** + ADR-0103 **두 조항** 부분 폐기("notice cap 예외 통로" + "파킹 단일 수신자 전용" — 병합 도장, 손편집 + lint clean) + spec §1/§3/§4/§5 정합 + step-log. 코드 앵커 `// ADR-0107` 7개.

## 검증 상태(쌍)
- **돌린 것:** blind 재판정 4라운드(각 수정 mutation 검증 동반) · qa full 7게이트 PASS — rust 980(core 285·discovery 45·protocol 53·daemon 597)·vitest 634·tsc 0·격리 0줄·fmt clean·**라이브 smoke = 신빌드 데몬**(사전 실행 데몬 없음 확인) spawn-kill 실 IPC 완주 · /review doc 9건 적발 전건 반영 후 재판정 PASS. 재실행: `cargo test -p engram-dashboard-core -p engram-dashboard-protocol -p engram-dashboard-discovery -p engram-dashboard-daemon` / `npm test` / `npx tsc --noEmit`.
- **안 된 것(이월):** ① **최종 인수 실측 3건**(D 이후): 실 claude가 8자 id를 `reply_to`로 옮겨 적는가 · `--settings` allowedMcpServers merge 실증 · 중첩 Task 서브에이전트 `result` 누수(부모 턴 종료 오판) ② GUI 레벨 에이전트 간 실제 메시지 송수신(qa smoke는 spawn-kill 범위 — 메시징은 cargo 통합 테스트 커버) ③ roundtrip-smoke의 XML 봉투 재검증(spec §1 — C2 이월).

## do-not (누적·갱신)
- v2 항목(wake·cc·그룹 request·priority) 슬쩍 편입 금지 · 실험 bin 3종(C1 동작) 게이트 검증에 쓰지 말 것 · bare `cargo test` 금지(멤버 열거) · `cargo test -p engram-dashboard --lib` = pre-existing DLL 로더 오류(게이트 아님, 무시) · blind 리뷰어 payload엔 "의도적 미배선" 명시(아니면 false BLOCK) · replay로 busy 부트스트랩 금지 · 유저 전역 `allowedMcpServers: []` 수정 금지(해법 = 스폰 `--settings`) · **공유 데몬(`engram-dashboard-daemon.exe`) 불가침**(내가 띄운 게 아니면 kill 금지 — qa 바인딩) · Fable(메인 모델)을 워커로 스폰 금지(fork 포함 — 이번 세션 실수 1회, TaskStop 후 worker-senior SendMessage로 정정).

## 수용된 잔여(알고 있을 것 — 재발견 방지)
notice 레인 +1 일시 초과(명시 계약·자기수정) · 생존 판정 근거 = reachable 로스터(산-비structured 결박분은 회수 가능) · FlightSettle drop의 poisoned lock 삼킴(release=abort) · flush panic 시 유예 마커 잔존 = 무해한 잉여 도어벨 1회 · 유예 Vec 성장은 배치 중 경쟁 id 수(0~2)로 유계(병리적 스프레이는 미방어·플래그만) · 장부 종점 = best-effort(링 evict 시 debug 강등) · 인덱스 생성기는 첫 Amended-by만 렌더(0103의 0107 개정이 인덱스에 안 보임 — adr 스킬 feedback 기록됨).
