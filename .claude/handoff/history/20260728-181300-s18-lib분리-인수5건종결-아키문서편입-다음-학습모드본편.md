3. **인수 실측 5건 전부 종결**(`b7956b8`·`48804d8`):
   - ① request 전사 PASS(REPLY_IN_REPLY_TO 일치) ③ messages 툴 PASS(실조회 open:0) + 그룹 PASS(census delivered=true — 초기 자기보고 판정 보류 → census 증분 후 확정).
   - **하네스 delivery census 신설**: 전 배달 덤프(from/to/entrance/msg_id/in_reply_to/bytes/delivered/err), happy tail + fail_setup! 실패 경로 양쪽. light 리뷰 FIX 2건(배달 상태 축·실패 경로) 반영.
   - ② --settings 주입 PASS: CLAUDE_CONFIG_DIR 샌드박스(`allowedMcpServers:[]`) 하에서 스폰 에이전트 ENTRANCE=mcp — 주입 조각(`{"allowedMcpServers":[{"serverName":"engram"}]}` mcp_config.rs:131)이 유저 차단을 merge 관통. 증거 사슬·오귀속 정정은 step-log.
   - ④ 중첩 Task 누수 없음: 원시 stream-json 캡처 — 중첩 Task 완료는 result 라인을 안 만듦 + 디코더는 result만 MessageDone(claude.rs:716). busy 조기 idle 경로 없음.
   - ⑤ MCP 툴 지연 로딩 확인(공식 문서): 이름만 선로드·스키마 지연 페치 — **프라이밍 슬림화 PRD 전제 성립** + 노브(`ENABLE_TOOL_SEARCH`·`alwaysLoad`) 재료 확보.
   - **야생 관측**: B가 자발적으로 기한 10분 request 사용 + alice가 in_reply_to 물고 자율 회신 = 쟁점2(reply_by) "실사용률 관측" 첫 실데이터.
4. **architecture-overview 메시징 편입**(`8a7a065`): 공개 드리프트 해소 — 문서 워커 초안 → /review doc 2인(codex cut-advocate + doc-aware 수호, 둘 다 FIX·대립 없음) → 취합 19건(사실 13·축소 6) 반영.
