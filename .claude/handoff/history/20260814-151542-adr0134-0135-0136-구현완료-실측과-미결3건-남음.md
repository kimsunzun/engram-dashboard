## 실패한 접근 (do-not)

- **경로를 정규화·소문자화·해시해 잠금 이름을 만들지 말 것.** 두 라운드 짜고 버렸다. 근거 = ADR-0134 「거부한 대안」.
- **파일 내용을 신원으로 쓰지 말 것.** ADR-0135가 파일에 싣는 건 신원이 아니라 접속 데이터다 — 이 구분을 지우지 말 것.
- **`FILE_SHARE_WRITE`를 열지 말 것.** 그 플래그 뜻이 "다른 프로세스의 쓰기 열기 허용"이라 **두 번째 데몬이 그냥 들어와 단일 인스턴스가 조용히 사라진다.** 메인이 실제로 이렇게 지시했고 코더가 실측으로 반박해 막았다. 리뷰어가 독립 프로브로 재확인.
- **구간 잠금(`try_lock`)으로 돌아가지 말 것.** 남의 **읽기까지** 막아 파일을 합칠 수 없게 된다.
- **읽는 쪽이 공유를 좁히지 말 것.** 공유 판정은 양방향이라 읽기 전용이어도 쓰기 공유를 함께 허용해야 통과한다(.NET `FileStream` 기본값이 그래서 실패). 지금 모든 읽기 경로가 통과하는 건 표준 라이브러리 기본 공유 덕이다.
- **지워진 연결키를 데몬이 다시 쓰게 하지 말 것.** 사용자가 반려했고, 조사한 사례 전부에서 버그로 신고돼 있다(바이트 동일해도 — GitHub Desktop #4602).
- **데몬 자진 종료(PostgreSQL 방식)로 가지 말 것.** 유비가 반증됐다 — Postgres는 인터록 자체를 감시하고 그 종료는 비상 종료다.
- **전용 종료 코드 + 프로세스 관측을 다시 짓지 말 것.** 지어봤는데 화면 표시 칸이 없어 체감이 그대로였다.
- **디버그·릴리스 데이터 폴더 이름의 대칭을 맞추지 말 것.** ADR-0136이 비대칭을 의도로 박았다.

## 미결 — 사용자 판단 필요

**① 개발용 앱과 릴리스 앱이 창을 동시에 못 띄운다 — ★실측 미완, 판단 전에 확인할 것★**
앱 껍데기에 별도 단일 인스턴스 장치(`tauri_plugin_single_instance`)가 **앱 식별자 기준**으로 박혀 있어, 두 빌드를 같은 앱으로 본다. 두 번째 프로세스가 자기 폴더를 확인하기도 전에 종료하고 첫 창이 앞으로 나온다. 데이터·데몬 짝짓기 로직 자체는 폴더 기준으로 이미 맞게 짜여 있고 데몬은 각각 뜬다 — **창만 하나다.**
**이건 코드를 읽고 나온 리뷰 지적이지 실측이 아니다.** 릴리스 실측 때 개발용 앱 켜둔 채 릴리스 앱을 실행해보면 2분에 답이 난다. 실제로 안 뜨면 그때 결정하고, 뜨면 결정할 게 없다.
선택지(실측 후): (가) 그대로 — 왜 무시되는지 설명이 없다 · (나) 그 장치 기준을 데이터 폴더로 — 데몬 판정과 일치, 추천 · (다) 장치 제거 — 창 둘이 같은 데몬에 붙는다.

**② 토큰 폴더 권한** — 데이터가 실행 폴더 밑으로 오면서 접속 토큰이 그 폴더 권한을 물려받는다. **공용 계정이 있는 PC에서 공용 자리에 풀 때만** 다른 계정이 읽어 에이전트를 조종할 수 있다(원격은 불가 — 포트가 로컬 전용). **이번엔 일부러 안 걸었다** — 위협 모델 설명 후 "쓸모가 좁다"로 판단. 재론 조건 = 공용 PC·USB 배포가 실제로 생기면.

**③ 런처 회귀** — `run-dashboard-release.bat`이 이름 대신 pid로 죽이게 바뀌면서 "연결키가 없는데 데몬만 살아 있는" 상태를 복구 못 한다. 옛 방식은 항상 복구했다. ADR-0135로 그 상태 자체가 잘 안 생기게 됐지만 런처는 안 고쳤다.

## 남은 잔여 (코드에 기록됨, 고치지 않기로 함)

- 획득→발행 창(`bind` + MCP 서버 기동 + 배선 전체)이 400ms 재시도 예산을 넘으면 진짜 중복을 "일시적 방해"로 오진 — 결과는 로그 한 줄과 아무도 안 읽는 종료 코드뿐.
- 폴더 되감기의 ABA(지웠다 다시 만든 남의 폴더를 지울 수 있음) — 빈 폴더만 지우고 피해자는 재시도로 복구되므로 계약을 좁히는 쪽 선택.
- 제한적 제3자 점유 + 살아 보이는 낡은 레코드 = `AlreadyRunning` 오판. **오판을 고정하는 테스트를 넣어뒀다** — 동작이 바뀌면 소리 나게.
- 동기화 폴더에 풀면 발급된 토큰이 그 서비스 버전 이력에 누적된다(파일 교체가 불가해 추가만 된다). README에 문단 있음.
- `robocopy /MIR` 기본 재시도(`/R:1000000`)면 잠긴 파일에서 사실상 무한 재시도 — 거부가 아니라 멈춘 것처럼 보인다.
