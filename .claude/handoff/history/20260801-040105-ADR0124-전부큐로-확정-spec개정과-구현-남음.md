## ★결정 내용 (ADR-0124가 정본 — 여기 요약은 보조)

**직발송 지름길 폐지. 모든 발송은 큐에 적재하고 flush 레인이 뺀다.**
- 발송 응답에서 `delivered` 소멸 → 정상 발송은 `pending` 단일.
- `failed` **4종**은 큐 적재 *전* 판정으로 존치: 이름 없음 · 동명 모호 · 보관함 초과 · **`REQUEST_CAPACITY`**. (3종으로 줄여 적으면 추적 없는 request가 배달된다.)
- 장부(ledger) **종점** 어휘·의미는 무변경(`delivered` = 실제 주입 시점). 단 **초기 상태가 일률 `pending`**이 된다 → spec §6 전이표의 `delivered` 시작 행이 도달 불가, `messages` 무인자에 전 발송이 일시 노출.
- 순서 보장은 **락 안 적재 순서**로 자연 성립 — 좌석 예약·직발송 합류 판정은 불필요해진다.

## ★구현 시 반드시 지킬 것 (리뷰가 3라운드에 걸쳐 적출한 함정)

- **`deferred_inline` 드레인을 "발신 스레드 inject = 위반"으로 오독해 걷어내지 말 것.** `handle_send`가 `ring_or_defer`(service.rs:1031)로 도어벨을 걸고, 트리거 미배선이면 응답 확정 후 :1096–1097 `for id in deferred_inline { self.flush_for_agent(id); }`로 발신 스레드가 직접 flush를 돈다. 이건 직발송이 아니라 **flush 레인의 동기 실행**이고, 커널 단위 테스트가 결정성을 얻는 수단이다(`with_flush_trigger` doc :627–628이 명시 계약). 전부-큐가 되면 **이 드레인이 주 폴백 실행점**이 된다. 운영 조립(daemon lib.rs:547·857)은 항상 트리거를 꽂으므로 예외가 운영으로 새지 않는다.
- **"편지 고립"은 지금 살아 있는 버그가 아니다.** 좌석 예약이 이미 닫아뒀고 `a_direct_injection_holds_a_seat_so_a_concurrent_send_cannot_overtake_it` 말미의 `parked_len == 0`("고립 없음")이 봉인 중이다. **좌석을 걷어내면 다시 열리므로 새 구조가 그 성질을 재제공해야 한다** — 테스트로 단언할 것(ADR-0124 §영향 미검증 ①②).
- **뒤집히는 테스트는 삭제가 아니라 이전이다.** `empty_queue_idle_send_still_injects_directly`(:6160) · `idle_recipient_injects_immediately`(:5791) · `deliver_ok_marks_delivered_and_injects_wrapped`(:4915) · `a_direct_injection_holds_a_seat_...`(:5089)가 새 계약으로 바뀐다. **단언을 지우면 봉인이 사라진다** — 약화(stop)와 이전(진행+보고)을 구분해 지시할 것.
- **동기 flush 기각 사유는 "남의 백로그를 발신자가 치른다"뿐** — 락 규율은 사유가 아니다(인라인 폴백도 락 밖에서 돈다).
