## D가 만든 것 (요지 — 정본 ADR-0108/0109 + spec §3~§6)
MCP 툴 `messages{id?}`(미결 3축·수신자별 행·`may_be_truncated`) · `group{...}`(@ 필수·암묵 생성·전원 수정·조용히·파킹분 무영향·배치 원자성·test-harness 임시 통로 삭제) · CLI 미러(status|pending|group·`--body-stdin` lossy UTF-8·ENGRAM_TOKEN 단일 신원) · 스폰 `--settings` **파일** 주입(전역 무변경·mcp-config 수명주기 동승) · 프라이밍 교육. **request 계약 수명(ADR-0108):** 기한 초과 ≠ 종결 + cap 512 은퇴 = **mark-and-sweep**(핵심 불변식: 미정산 항목의 수명은 가드 소유 — 잠정은 은퇴 후보 제외·닫혀도 자리 무게 유지·purge 면제·스윕 제외). 앵커 `rg "ADR-0108|ADR-0109" crates/` = 5+5개.

## 인수 실측 4건 (다음 세션 첫 작업 후보)
1. **실 MCP 클라이언트 tool call 라운드트립** — qa smoke는 Tauri IPC 경로만 실측(spawn-kill 완주). `send_message`/`messages`/`group`을 실 claude 스폰 에이전트에서 호출·데몬 도달 확인.
2. **`--settings` merge 실증** — 유저 전역 `allowedMcpServers: []` 차단이 조각 파일로 실제로 뚫리는지 + engram 툴 가시성(spec §7 마지막 항).
3. **실 claude 8자 id 전사** — request 받은 claude가 `m-xxxxxxxx`를 `reply_to`로 옮겨 적는가(soft 절반).
4. **중첩 Task 서브에이전트 `result` 누수**(부모 턴 종료 오판 여부).
- 참고: 인수 시나리오 정본 = spec §7. roundtrip-smoke 확장(파킹→스폰→자동배달)·idle 게이트 배치 실측(사용자 강조 항목)도 §7에 있음.
