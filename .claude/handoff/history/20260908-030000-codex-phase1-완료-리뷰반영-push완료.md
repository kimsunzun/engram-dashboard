## 검증 상태

### 돌린 것

- **QA full PASS**(`ab872b2` 기준) — GUI 실측 포함. 트리 우클릭 → 「에이전트 생성 ▶ 코덱스 터미널」 → 등록만 됨 → 활성화 → 스폰 → **OS 에서 읽은 실 argv = `cmd.exe /c codex --cd <폴더> -s workspace-write -a on-request`** → 슬롯에 xterm + codex 배너 + **신뢰 확인 모달** → **엔터 넣으니 지나고 입력 프롬프트로 진행**
- **2 인 적대 리뷰**(doc-aware 불변식 + cross-family blind) — 양쪽 FIX, 지적 12 건(중복 제외 9). **12 건 중 10 반영, 2 는 사유와 함께 보류**
- **최종 게이트**(두 워커 변경 **합친 상태**에서 다시 돌림) — 워크스페이스 **2116 통과 · 0 실패 · 52 바이너리** · fmt · tsc · npm 889 · 시험대 ignored 레인 **11/11**(codex-cli 0.153.4)
- **네거티브 테스트 실측** — 각 정책 검사를 하나씩 지워 빨개지는 것을 확인하고 복원

### ★검증 안 된 것 / 안 고친 것★

- ★**CI 결론을 아직 안 봤다**★ — push 는 했으나 `gh run view <id> --json conclusion` 미확인. **머지 전 필수**
- **`%VAR%` 확장** — 폴더 이름에 `%USERNAME%` 이 실제로 들어 있으면 shim 이 확장해 엉뚱한 곳을 가리킨다. 안 고쳤다(유일 해법이 claude 공용 `console_command` 를 건드리고 틀리면 모든 스폰이 죽는다). 한계·근거·「고치려면 무엇이 필요한가」는 `backend/codex/mod.rs` 조립 지점 주석이 정본
- **`agents.json` 다운그레이드** — codex 프로필이 디스크에 `{"kind":"Codex"}` 로 박히므로 옛 빌드로 되돌리면 명부를 잃는다(T-33 수용분). **미지 `kind` 회귀 테스트는 여전히 0 건**
- **시험대가 안 재는 것 셋** — ① `workspace-write`·`on-request` **아래의 모델 동작**(재려면 쓰기 권한 에이전트를 자동 레인에서 돌려야 한다) ② 우리가 안 쓰는 인자(`-m`·MCP 오버라이드·`codex resume`) ③ `%VAR%` 한계. **정본 = `backend/codex/mod.rs` 헤더**(「전부 실측」이라 적던 옛 문장은 거짓이었고 고쳤다)
- **문 ① 의 정책 팔은 오늘도 도달 불가** — 어휘가 `Claude` 하나뿐이라 구조적이다. 그 팔이 막으려는 편집(어휘 확장 + 팔 삭제)은 재현해 빨개지는 것을 확인했다

## ★내가 틀렸던 것 (같은 실수 반복 방지)★

1. **「구조화 여부는 백엔드가 선언한다」** — 틀렸다. 그 칸은 `TransportCaps` 소유다.
2. **「번역기 갈림길에 codex 줄 하나 추가하면 된다」** — 틀렸다. `output_decoder`·`input_encoder` 는 trait 메서드가 아니라 자유 함수였다(`fdb6890` 에서 계약으로 승격해 해소).
3. **「PTY 경로에도 번역기가 선다」** — 틀렸다. PTY 전송은 decoder 를 아예 버린다.
4. ★**「문이 둘이다」 — 틀렸다. 셋이었다.**★ 트리 메뉴 항목이 registry 등록 명령이라 **사람 메뉴이자 LLM 표면을 겸직**한다. 백엔드 낱말로는 못 닫아서(사람 길까지 닫힌다) **호출자 축**으로 갈랐다 — LLM·버스 경로만 반려, 사람 경로(`fireAndForget`)는 그대로.
5. ★**「출시 전이라 PROTOCOL_VERSION 을 안 올려도 된다」 — 틀렸다.**★ `AgentSpawnCommand` 는 `#[serde(tag="kind")]` 라 `Codex` 는 **변형** 추가이고 모르는 변형은 **경성 파싱 실패**다. 그리고 **데몬이 셸 재빌드보다 오래 사는 것은 설계**라, 「릴리스 상대가 없다」가 이 실패에 안 걸린다 — 로컬 개발 중에 온다.
6. ★**「drift 시험이 갈림을 잡는다」 — 틀렸다.**★ 한쪽 문은 스키마 어휘만 비교하고 실제로 돌리는 건 하나뿐이었다. 정책 블록을 지워도 초록이었다.
7. ★**「argv 가 실측됐다」 — 반만 맞았다.**★ 실 argv 는 GUI 실측이 OS 에서 읽어 맞았지만 **시험대는 그걸 안 쟀다**(`--cd` 를 아예 안 넘기고, 「실측값과 같다」가 같은 파일 상수를 자기와 비교하는 동어반복).
8. **「게이트 안 걸렸다」를 한 번 성급히 보고했다** — 시험대 1 차본의 Q8·Q10 이 자기 질문을 안 재고 초록이었다. **초록의 근거를 그 단언이 실제로 재는지까지 봐야 한다.**
9. **지시서에서 호출부 개수를 두 번 과소평가했다**(6곳→15파일, 7곳→16파일 50건). **같은 형태 반복 편집은 넘기기 전에 `rg -c` 로 재서 지시서에 박는다.**

## do-not

1. ★**`v*` 태그를 승인 없이 push 하지 말 것**★
2. ★**게이트 명령을 파이프에 물리지 말 것**★ — `cargo test ... | tail` 은 **tail 의 종료코드**를 읽는다. 로그 파일로 받고 `$?` 를 따로 찍는다
3. ★**`run-detached.ps1` 에 `&` 로 명령을 이어 붙이지 말 것**★ — 첫 명령 뒤가 통째로 사라지고 실패 마커까지 소실된다(조용한 false PASS 경로). 별도 `.bat` 을 만들어 `call` 로 넘긴다
4. ★**Git Bash 에서 `cmd /c "codex exec ... \"긴 프롬프트\""` 금지**★ — 중첩 따옴표가 깨져 명령이 시작조차 못 한다. 지시서를 파일로 빼고 프롬프트는 한 줄로
5. ★**`--lib`·`--all-targets` 로 셸 패키지를 부르지 말 것**★ — `0xc0000139` 즉사. `--test lib_unit` 하나뿐
6. **CI 판정을 종료코드로 하지 말 것** — `gh run view <id> --json conclusion` 으로 결론을 직접 읽는다
7. **`gh -q` 표현식에 `/` 를 쓰지 말 것** — Git Bash 가 경로로 바꿔 먹는다
8. **`launch/실행.bat` 을 개발 중에 쓰지 말 것** — 이미지 이름으로 모든 데몬을 죽인다
9. **codex 는 스스로 자동 업데이트한다** — 측정 중 발생했고 teardown 이 업데이터를 죽여 전역 shim 이 잠깐 깨졌다. 측정 전후 버전을 기록할 것
10. **실 CLI 하네스에서 「환경 격리」 수정은 파일럿 1 건(격리 후 화면 덤프)을 먼저** — 임시 홈으로 돌리자 **모달이 하나 더 뜨는** 조건이 드러났고 모른 채 전체 레인을 두 번 버렸다
11. ★**TUI 화면 매칭에 공백 포함 문자열을 그대로 쓰지 말 것**★ — 부하가 걸리면 이 TUI 가 낱말 단위로 커서 이동하며 그려서 `"Do you trust"` 가 안 맞고, 그러면 하네스가 **조용히 「모달 안 떴음」으로 판정**해 하류가 엉뚱한 이유로 죽는다. 공백 무시 매칭을 쓴다

## 남은 일

### 즉시 (기록 셋 — 코드 작업 아님)

1. ★**ADR — ADR-0058 을 대체하는 새 결정**★. `spawn_into` 가 모든 명시 backend 를 거부하던 근거(「wire 에 고를 칸이 없다」)가 죽었다. **새 동작** = 모르는 낱말만 거부 + 정책 표가 닫은 낱말은 사유와 함께 거부, 판정·안내를 wire enum 에서 파생. ★**지켜야 할 성질은 그대로 — 「요청한 것과 다른 에이전트가 조용히 뜨지 않는다」**★. 폐기 도장은 ADR-0058 본문에. **사용자에게 물을 것 = 거부한 대안과 그 이유.**
2. **step-log** — 마지막 스텝이 `S20.19`(2026-08-25)에서 멈춰 있다. 이번 작업이 통째로 미기록
3. **브리핑 재게시** — 소스는 `docs/process/S21-codex-backend/briefing.html` 에 커밋돼 있으나 **아티팩트 링크가 죽었다**(계정 조회 불가) **+ 내용이 낡았다**(「새는 곳 셋」 중 둘을 고쳤고, 그 뒤 배선·리뷰까지 갔다). ★사용자가 「풀 브리핑」을 요청해 둔 상태★
4. **CI 결론 확인 → master 머지**

### Phase 2 (codex 상주 서버 — 착수 전 사용자 선택)

- `codex app-server` = 상주 양방향 JSON-RPC. **세션 복원·우편·구조화 챗이 여기서 함께 열린다**
- **프로세스 모델은 「대화마다 하나」로 확정**(성숙 피어 선례 — paseo·vibe-kanban)
- 번역기를 짜는 자리이고 **중립 낱말을 몇 개 늘릴지가 실제 작업**
- LLM 창구·배너도 여기서 함께 연다

### Phase 3

프론트에 샌 claude 스키마 해석 회수(도구 결과·생각 블록). **claude 쪽 정리라 codex 와 독립**

### 별건

- `daemon/src/experiment/transcript.rs:72` 가 `~/.claude/projects` 를 직접 짓는다 — **이름 게이트에 안 걸린다**. 기본 꺼진 feature 뒤라 릴리스엔 안 실린다
- **첫 사용자는 시작 모달이 둘이다** — 폴더 신뢰 다음에 **샌드박스 설치 모달**, 기본 선택이 「관리자 권한 필요」. 개발자 실 홈은 이미 지나 있어 안 보인다. 배포를 볼 때
- 백엔드 폴더 내부 재분할 — Phase 2 에서 codex 가 커질 때 **같이** 하는 게 낫다(`backend/mod.rs` 를 두 번 안 만지려면)
