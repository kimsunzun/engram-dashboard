## do-not
- Git Bash 에서 CRLF 문서에 `sed -i` 금지 · `grep $'\r'` 로 CRLF 판정 금지 → Edit 도구 · `perl -pi` · 셈 `tr -cd '\r' | wc -c`.
- 테스트에서 복원 팝아웃 ↔ label 매핑 가정 금지(무작위 UUID 순).
- 전경 판정은 `EVENT_SYSTEM_FOREGROUND` 만 보지 말 것 — `GetForegroundWindow` 폴링 병행.
- codex 리뷰 래퍼 지시서엔 「깨끗한 task 호출 — 추가 플래그 · stderr 숨김 · `|| true` 금지」.
- implement 하드캡(3)은 과업 단위로 센다 — 앞 조각 리뷰 후속을 다음 조각에 실으면 한 라운드다. 하드캡에 닿으면 사용자 승인.
- 사용자에게 질문할 땐 맥락(무엇에 대한 수락/거절인지 · 누가 언제 그 상황을 만나는지)을 먼저 깔 것 — 이번에 맥락 없는 질문을 두 번 되물음 받았다.
