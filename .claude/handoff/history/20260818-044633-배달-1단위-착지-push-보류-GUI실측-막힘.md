## ★실패한 접근 / do-not★

1. ★**「실측」이라고 쓰기 전에 무엇을 쟀는지 범위를 확인할 것**★ — 이번에 실제로 당했다. 다른 구간을 재고 그 결과로 미확인 질문에 도장을 찍었고, 그 과장이 두 문서에 번진 뒤 리뷰가 잡았다. 이 저장소는 코드 읽기를 실측이라 부르는 것이 관례라 말 자체는 맞았고, 미끄러진 것은 **범위**였다.
2. ★**리뷰어·워커가 「아직 안 고쳐졌다」고 하면 직접 확인할 것**★ — 이번에 같은 워커가 **세 번** 낡은 스냅샷으로 오보했다. 마지막 것은 부정문 안의 문자열을 매칭해 정반대로 읽은 것이다.
3. **디버그 단언을 아무 데나 넣지 말 것** — 연결 수립 경로는 net이 「여기서 패닉하면 정리 훅과 등록 해제를 통째로 건너뛴다」를 명시한 자리다. 이번에 메인이 승인했다가 리뷰가 잡았다.
4. ★**주인 토큰 접두(`conn-`)를 파싱해 연결을 되짚지 말 것**★ — 그 파생은 자기 주석이 잠정이라 못 박았고, 테스트가 `conn-01`·`conn-+1`로 그 구현을 떨어뜨린다.
5. **명부의 제거 지점을 늘리지 말 것** — 새 표도 같은 `detach` 한 곳에서 함께 비운다. 잠금이 하나라 순서는 관측되지 않지만 코드에는 남겨 뒀다.
6. **`sink_of`가 내준 사본을 대기표에 보관하지 말 것** — 회수 수단이 없어 그 사본이 `on_disconnect`를 넘겨 살면 연결이 샌다. 계약으로만 막혀 있고 컴파일러가 강제하지 않는다.
7. **`docs/` 밑 문서 5개는 이 세션에서 대폭 손댔다** — 옛 인용 좌표를 그대로 믿지 말고 다시 열 것.
8. **테스트 로그를 재는 테스트를 새로 만들 땐 구독자로 감쌀 것**(적립 ㊅).

## 시연 준비 상태 (사용자가 영상 촬영 예정 — 내일로 미룸)

**요구 5개는 전부 오늘 됩니다. 배달 구간 없이도 성립한다** — LLM이 앱에 붙어 명령을 직접 호출하는 경로가 살아 있다.

- **메시지** — 진짜 배달(받는 쪽 입력에 실제로 글자가 들어간다). ★상대가 턴 중이면 배달이 아니라 보류★ — 받는 에이전트를 놀려 두고 찍을 것.
- **스폰** — ★한 방 명령(`spawn_into`)은 claude가 아니라 맨 셸을 띄운다★(데몬 코드로 직접 확인). 진짜 claude는 **프로필 생성 → 스폰 2단계**.
- **자식 붙이기** — 실재하고 화면에도 보인다(들여쓰기·접기·드래그). ★깊이 한 단계뿐 · 「자식으로 스폰」은 없어서 띄운 뒤 옮기는 2단계★.
- **창 띄우기·분할·슬롯에 물리기** — 전부 명령 있음. 물리면 출력이 자동으로 흐른다.
- **★분할 방향 인자 값이 빌드마다 다르다★** — master 계열은 `left_right`/`top_bottom`, 이 브랜치는 `horizontal`/`vertical`. 한쪽 값은 무조건 실패한다.
- **★CLI는 평범한 터미널에서 안 된다★** — 토큰이 engram이 띄운 에이전트에게만 주입된다. CLI를 화면에 담으려면 스폰된 에이전트 안에서 쳐야 한다.
- 레이아웃은 디스크에 안 남는다(재시작 시 초기화) · 뷰 id가 매 기동 재생성되므로 대본에 하드코딩 금지.
- **미검증** — 스폰·물리기·분할·자식 붙이기·창 띄우기의 실제 호출은 **살아 있는 세션을 건드려야 해서 일부러 멈췄다.** 「된다」는 코드 근거이지 실행 확인이 아니다.

## 다음 단위 (배달 나머지)

지시서 초안이 스크래치에 있으나 휘발된다 — 핵심만 여기 남긴다.

1. **발신자 왕복 2종** — `AgentCommand::Command { envelope }` + `AgentEvent::CommandReply { reply }`. TRD §3-2가 필드까지 정해 뒀다. ★함정: 상관 함수는 protocol의 `RequestId`를 돌려주는데 봉투는 command crate의 `RequestId`를 품는다(같은 모양, 다른 타입, 변환 없음)★. 두 상관 함수는 **한 쌍으로 움직인다** — 한쪽만 `Some`이면 셸이 연결 끊길 때까지 매달린다.
2. **배달 + 요청 상관 표 + 마감시각** — ★마감시각을 같은 커밋에 넣을 것★(적립 ㊀ 2026-08-18 블록). 없으면 큐 full이 요청을 무한 대기로 바꾼다. 기본 10초(TRD §4-⑥).
3. **배달은 신규 구현이 아니다** — 3단계(`route()`)는 이미 도구 crate에 있고 셸이 운영에서 쓴다. 데몬이 그걸 부르게 잇고 링크 구현이 `OwnerToken → 연결`을 넘으면 된다(그 자리가 이번에 만든 `sink_of`).
