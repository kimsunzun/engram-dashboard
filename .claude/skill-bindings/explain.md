# explain 바인딩 — engram-dashboard

## 보관 위치

- 작업의 PRD·TRD 설명 페이지 = `docs/process/<작업>/spec-brief.html` — explain 「설계 검토 문서」다(고칠 때 회차 표시를 단다). 파일 이름의 brief 는 explain 「브리핑」 종류가 아니다.
- PRD·TRD를 따로 보이는 작업(implement 바인딩 「사용자용 HTML」) = `docs/process/<작업>/prd.html` · `trd.html` — 이것도 「설계 검토 문서」다.
- 작업의 최종 리뷰 보고서 = `docs/process/<작업>/final-report.html`
- `<작업>` = 그 작업의 `prd.md` · `trd.md`가 있는 폴더(예: `S25-preset-library`).
