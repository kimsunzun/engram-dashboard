# 라이브러리 항목을 묶음(프리셋)에 넣는 방법 — UI 관행 서베이

- **상태:** 적대 리뷰(FIX) 반영본 · 결정 대기(프리셋 PRD 이전 구상 — 프리셋 편집에서 부품을 담는 메인 길)
- **날짜:** 2026-10-14
- **방법:** research medium. 수집 갈래 1(UI 관행) · 메인 grounding · cross-family 적대 리뷰 1회(아래).
- **확신도 범례:** 확실 = 원문 확인 + 독립 교차확증 · 가능성 높음 = 원문 확인(단일 출처) 또는 2차 출처 · 불확실 = 검색 요약 · 기억.
- **수집 한계:** 수집자는 검색 요약만 읽었다(페이지 본문 0). 아래 「원문 확인」은 메인이 따로 연 것뿐이다.

## 묻는 것

이미 아는 길 셋 — ① 편집 칸 「+ 담기」 검색 팝오버(언리얼 에셋 칸 드롭다운) ② 라이브러리에서 골라 두고 편집 칸 「← 선택한 것 담기」(언리얼 「콘텐츠 브라우저에서 선택한 에셋 쓰기」 — 사용자가 언리얼에서 확인) ③ 끌어다 놓기 — 밖에 무엇이 있나.

## 결론 (위층)

0. **순서 있는 묶음에는 「맨 끝에 붙이기」와 「고른 자리에 끼워 넣기」가 갈린다(리뷰가 찾음 · 메인 원문 확인).** Final Cut Pro: 브라우저에서 클립을 고르고 재생헤드를 원하는 자리에 둔 뒤 Insert(W 키) → 그 자리 뒤 클립이 밀린다 · Append 는 끝에 붙인다. 프리셋은 순서가 곧 지시서 이어 붙임 순서라 이 구분이 그대로 걸린다. **가능성 높음.**
0-1. **언리얼 에셋 칸 컨트롤(원문 · UE 4.27 문서)** = 드롭다운(검색 · 복사 · 붙여넣기 · 지우기) · **Use Selected Asset**(콘텐츠 브라우저에서 고른 에셋을 넣음) · **Find in Content Browser**(넣어 둔 에셋을 찾아 보여 줌) · Reset. 끌어다 놓기는 그 문서에 없다. **가능성 높음.**
1. **일반 앱에서 문서화된 길 = 끌어다 놓기 + 항목 우클릭 「…에 추가」(어느 쪽이 주로 쓰이는지는 문서에 없다 — 리뷰 지적으로 「기본 길」 표현 철회).** Apple Music: 「라이브러리 어디서든 항목을 사이드바의 재생목록으로 끌어 놓는다」 · 「Control-클릭 → Add to Playlist → 재생목록 고르기」 · 새 재생목록도 같은 두 길(원문). **가능성 높음**(단일 원문).
2. **전송 목록(왼쪽 「고를 것」 ↔ 오른쪽 「고른 것」 + 화살표 버튼)** 은 큰 풀에서 일부를 골라 결과를 나란히 보며 정할 때 쓴다 — 주로 대화상자 · 설정 화면. Ant Design Transfer = 「두 열 사이에서 요소를 옮기는 선택 제어」 · 열마다 검색 가능 · **오른쪽 목록 순서 바꾸기는 기본 기능에 없다**(원문). 끌어다 놓기보다 접근성이 낫다는 서술은 Smashing Magazine(요약만). → 늘 열려 있는 라이브러리 슬롯과 겹치고, 순서가 중요한 프리셋엔 순서 바꾸기를 따로 붙여야 한다. **가능성 높음.**
3. **대상 지정 모드(Lightroom Target Collection + B 키)** 는 대상을 한 번 정해 두고 라이브러리에서 키 하나로 계속 넣는 고급 사용자 길이다. 대상이 눈에 안 띄면 잊는다는 약점이 있다(블로그 · 포럼 — 공식 문서 아님). **가능성 높음.** 우리 즐겨찾기 묶음의 「★ 대상」과 같은 모양이다.
4. **검색 팝오버 · 명령 팔레트(Notion `/` · VS Code Quick Pick)** 는 이름을 알 때의 키보드 길이고, ① 과 같은 갈래다. **확실**(메커니즘 · 요약).
5. **항목 하나 → 묶음 여러 개** 는 Spotify 식 체크 목록(우클릭 「…에 추가」) — 우리 반대 방향 팝오버(라이브러리 우클릭 「프리셋에 추가」)와 같다. 「묶음 편집 중 라이브러리 줄마다 소속 체크박스」(Plex · iTunes 등)는 **확인 못 함**.
6. 스포이트(언리얼 액터 피커)는 이슈 트래커 언급뿐이고 3D 뷰가 있어야 성립 — 우리 목록에는 대상 지정 모드의 변형일 뿐. **불확실.** Apple Music 「추천 곡 + 추가 단추」는 원문에 없어 뺐다.
