## 한계 (먼저 읽기)

- 언리얼 · Unity 쪽은 **한국어 번역 문서**이지 편집기 화면 문자열이 아니다 — 화면은 다를 수 있다(예: 문서 「이름변경」).
- Windows 빈 화면 · 상태 문구(「N개 항목 선택함」 · 세부 정보 칸 빈 문구 등)는 **기억**이다 — 원문 페이지를 못 가져왔다. Microsoft 용어 포털에 닿지 못했다.

## 원칙

1. **메뉴 · 단추 = 명사 또는 동작 명사**(삭제 · 이름 바꾸기 · 새로 만들기 · 새로 고침) — 「하세요」 꼴 없음. 확인 창 단추만 동작 자체(휴지통으로 이동 · 취소).
2. **개수 = Windows 꼴** — 「3개 항목 선택함」 · 「항목 2개」 · 「프리셋 2개」. 종류별 내역은 가운뎃점 뒤.
3. **안내 · 빈 화면 = 「~습니다」 평서문이나 짧은 명사구** — 사용자가 할 일을 시키는 문장으로 쓰지 않는다.
4. **피어가 가진 말은 피어 그대로** — 라이브러리 개념은 언리얼(즐겨찾기 · 필터 · 검색), 파일 조작은 Windows(새로 만들기 · 이름 바꾸기 · 삭제 · 새로 고침 · 이동).
5. **한 개념 = 한 낱말, 모든 화면에서** — 고름 → 선택 · 지우기 → 삭제 · 옮기기 → 이동.
6. **우리 말이라 여겼던 것도 피어 낱말이 있으면 피어 낱말로**(사용자 2026-10-17 「관용이 먼저야 글자는」 — 2026-10-16 「컬렉션이라고 하면 뭔 소린지 모른다」 를 뒤집음) — 지시서 → 지침 · 쓰는 곳 → 참조 · 묶음 → 컬렉션 · 내장 → 기본 제공 · 쉼 → 사용할 수 없음 · 다시 잇기 → 다시 연결 · 다시 이어짐 → 다시 연결됨 · 미리보기 → 미리 보기 · 담기 → 추가. 피어 낱말이 정말 없는 개념(프리셋 등)만 우리 말을 지키고 한 번만 정의한다.
