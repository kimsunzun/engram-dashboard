04핵심

두 층으로 가른다

이 가름이 “나중에 리팩터링 안 하게”의 유일한 장치다. 같은 crate 안이라 컴파일러가 안 막아 주니, 게이트가 대신 막는다.

규칙 층 · 순수 시간을 인자로 받는다 · 네트워크 호출 0줄
pending.rs — 보낸 요청과 온 답 짝짓기 stream.rs — 세대·순번·구멍 검출 machine.rs — 연결 하나의 상태 기계
게이트 tokio · 소켓 · 워크스페이스 crate 참조 → 0줄
구동 층 위 기계를 실제 소켓과 시계 위에서 돌린다
peer.rs — 상대 하나를 감독 · 단일 writer · 유계 큐 registry.rs — N개 명부 · 팬아웃 · 올라오는 한 줄

덕분에 재연결·시한·유실 검증이 실제 소켓 없이 돈다. 8초를 기다리지 않고 잰다.

05파일 배치

평평한 src/*.rs 14개

파일무엇을 소유하나층
lib.rs경계·게이트·불변식의 정본. 재수출만헤더
frame.rs프레임 어휘 · 닫기 코드와 문구자료
wire.rs소비자가 주는 패킷 어휘 전부계약
link.rs전송 seam — 걸기 · 보내기 · 받기계약
clock.rs시간 seam — 지금 · 기다리기 · 시한계약
policy.rs정책 값과 기본값자료
event.rs위로 올리는 사건 어휘자료
pending.rs요청/응답 상관 · 시한 · 만료 번호 재사용 거절순수
stream.rs세대 대조 · 중복 제거 · 구멍 검출 · 유효 하한순수
machine.rs연결 하나의 상태 기계. 사건 + 시각 → 할 일 목록순수
peer.rs감독 태스크 · 단일 writer · 유계 큐 · 손잡이구동
registry.rsN개 명부 · 출처 표식 · 팬아웃 · 올라오는 한 줄구동
ws.rsWebSocket 어댑터feature
testing.rs인메모리 통로 · 손으로 돌리는 시계 · 사건 수집기feature

셋은 순수라 하네스가 필요 없고, 둘은 feature 뒤라 기본 빌드에 없다. 실제 구동 코드는 둘뿐이다.

06갈아끼우는 자리

타입은 제네릭, 자원은 지운다

제네릭 — 절대 안 지운다

패킷 어휘

  • 내가 보내는 것과 받는 것의 타입
  • 짝짓기 번호 · 스트림 키
  • 봉투를 여닫는 법 · 답장인지 판별하는 법

지우면 crate가 그냥 바이트 파이프가 된다 — 그건 이미 기각한 안이다.

지운다 — 섞여야 하니까

전송 · 시간

  • 전송 — 한 명부에 WS 상대와 (나중) TLS 상대가 섞일 수 있어야 한다
  • 시간 — 제네릭이면 네 타입 시그니처에 다 번지고 명부 컬렉션까지 오염된다

둘 다 저장소에 이미 같은 형태의 선례가 있다.

그래서 검증이 이렇게 된다

전송을 인메모리로 바꾸고 시계를 손으로 돌리면 — 붙었다 끊었다, 8초 시한, 재연결 3회, 유실과 구멍을 전부 실제 기다림 없이 잰다.

07밖에서 보는 모양

명부 → 손잡이 → 한 줄

// 1. 명부를 세운다. 받는 쪽 손잡이가 함께 나온다.
let (registry, mut inbound) = Registry::new(wire, dialer, clock, policy);

// 2. 상대를 등록하면 손잡이가 나온다. 재연결을 가로질러 살아남는다.
let peer = registry.add(PeerId("local"), addr, handshake);

// 3. 손잡이로 요청한다. 시한·끊김·큐 포화가 Err.
let reply = peer.request(cmd).await?;
peer.notify(cmd)?;              // 답장을 안 기다린다
peer.reconnect_now();           // 「지금 다시 해라」 — 셸이 누른다

// 4. 올라오는 것은 한 줄뿐이다.
while let Some(item) = inbound.recv().await {
    match item {
        Incoming::Message(a) => /* a.peer · a.generation · a.msg */,
        Incoming::Event(e)   => /* 붙음·끊김·거절·재시도·유실 */,
    }
}

들어온 조각마다 어느 상대에게서 어느 연결 세대에 왔는지가 붙는다 — 재연결 경계가 조용히 지나가지 않는다.

08연결 하나의 수명

거절과 못 붙음은 다른 길이다

미연결등록만 됨
→
거는 중주소로 통로 열기
→
인사 중왕복 횟수는 안 센다
→
운영주고받기 · 살아있음 확인
못 붙었다 데몬이 죽었거나 망이 끊겼다. 예산을 쓴다 — 3회까지 다시 시도하고, 다 쓰면 포기.
붙었는데 거절당했다 버전이나 토큰이 안 맞는다. 예산을 안 쓴다 — 다시 해도 결과가 같으니 즉시 포기.
포기다시 붙지 않는다 — 사람이 눌러야 깨어난다

닫을 때 코드와 문구를 함께 싣는다. 문구를 파싱해 분기하지 않는다 — 코드가 판단용이다.
