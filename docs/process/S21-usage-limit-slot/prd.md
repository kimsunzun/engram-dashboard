## 1. 무엇·왜

- 여러 에이전트가 5시간·주간 한도에 걸려 멈춘다. 웹뷰 슬롯에 새 타입을 두어 **Claude·Codex 의 남은 한도를 한 곳에 작게** 보인다.
- 지금 데몬은 대화 중 오는 한도 정보를 버린다 — Claude `rate_limit_event` 는 건너뛰고, Codex `account/rateLimits/updated` 는 받고 버린다(UI §4-1·§4-2). 줍기는 새로 까는 배관이다.
- 분할 레이아웃의 한 칸에 두는 선례는 조사한 제품에서 찾지 못했다 — 최근접 = 사이드바 상시 게이지(TokenTelemetry)(UI §0-6).

## 3. 요구사항

**작은 표시(상시)**
- **R1** 퍼센트 방향 = **남은 양**(Codex 방식 — 쓸수록 막대가 줄어든다). Claude 는 사용률을 주므로 100 에서 뺀다. (결정)
- **R2** 회사별로 두 창(5시간·주간) 모두 · 막대 + % + ~~**남은 시간**~~ **리셋 시각**. (결정) · ★개정(사용자 결정 2026-09-29)★: 작은 표시는 남은 시간 대신 리셋 시각을 보이고 남은 시간은 팝업에만 둔다. ~~표기는 글리프가 아니라 낱말 — 「리셋 00:58」 · 영어 「resets 00:58」(한국어가 더 짧다 · 팝업의 「리셋 …」 과 같은 낱말 · 전역 ⟳ 버튼(R12)과 글리프가 겹치지 않는다).~~ ★재개정(사용자 결정 2026-09-30 — 「그냥 모레시계 통일로 하자」 · ADR-0259)★: 표기는 **모래시계 아이콘 + 시각**이고 작은 표시·팝업이 같다 — 툴팁·스크린리더 이름은 「리셋 00:58」. 화살표 아이콘은 쓰지 않는다(전역 ⟳ 와 섞인다). 아래 날짜 규칙은 그대로다 — 예의 「리셋」 낱말 자리에 아이콘이 선다. 리셋이 오늘이 아닌 날이면 요일이 아니라 **날짜**를 날짜 → 시각 순으로 — 「리셋 10/1 01:48」 · 「resets Oct 1 01:48」. 거부한 표기와 그 사유(제시 때의 트레이드오프) = ADR-0258 「거부한 대안」. 피어 = `docs/research/usage-reset-time-format-peers-2026-09-29.md`. (ADR-0258)
  - ~~남은 시간~~ **리셋 시각** 요구는 R3 의 1·2단(회사당 한 줄 · 창마다 한 줄)에만 걸린다 — 3단(숫자만)은 % 만 보이고 리셋 시각·남은 시간은 팝업으로 간다. (리뷰 반영 기본값 — D16 · 2026-09-29 개정: 작은 표시는 남은 시간 대신 리셋 시각)
- **R3** 슬롯 폭에 따라 회사당 한 줄 → 창마다 한 줄 → 숫자만으로 줄어든다. 판정은 글자 수가 아니라 **실제 그려진 폭** 기준. (결정) · ★개정(사용자 결정 2026-09-29 — TRD §3 #103)★: 작은 표시의 회사 이름은 작은 **회사 아이콘**으로 바꾼다(지금 도형은 자리표시 — 최종 모양 미정 · 팝업은 아이콘 + 이름). 1단 = 두 회사 줄을 **한 격자**에 얹어 열(창 이름·막대·%·리셋)을 세로로 맞춘다 · 2단 = 아이콘이 그 회사의 두 창 줄에 걸친다 · 3단 = 아이콘 + 숫자. ★개정(사용자 결정 2026-09-30 — ADR-0259)★: 단계는 **폭으로만** 고른다 — 높이 때문에 단계를 바꾸지 않고, 높이가 모자라면 아래가 잘려 가려진다(R31 의 배지도 잘린 줄에선 가려진다).
  - 3단 폭보다 더 좁으면 줄바꿈·스크롤 없이 말줄임(…)으로 자른다. (리뷰 반영 기본값 — D16)
- **R4** 두 회사를 다 끄면 ~~"우클릭해서 표시할 항목 고르기"~~ "클릭해서 표시할 항목 고르기" 안내 한 줄. (결정) · 개정(사용자 결정 2026-09-29 — 켜고 끄기가 팝업으로 옮겼다, R8): 안내를 클릭하면 팝업이 열리고 팝업엔 켜고 끄기 줄만 보인다.

**팝업(상세)**
- **R5** 작은 표시를 클릭하면 연다 — 전부 보인다 · **목표 시각**(리셋 시각) · 플랜(값이 있을 때만) · 각 사 사용량 설정 링크 · ~~⟳~~ · 맨 아래 켜고 끄기 줄(R8). (결정) · ~~개정(사용자 결정 2026-09-29): 회사별 ⟳ 는 팝업에서 뺀다 — 새로고침은 작은 표시의 전역 ⟳ 하나(R12).~~ ★재개정(사용자 결정 2026-09-30 — ADR-0259)★: 회사마다 머리에 「<회사> 플랜: max · 1분 전 ⟳」 — 나이는 회사 머리에 한 번(시계 아이콘 없음 · 창 줄마다 반복하지 않음)이고 ⟳ 는 그 회사만 새로 고친다(작은 표시의 전역 ⟳ 는 그대로 — R12). 팝업을 열어도 새로 받지 않는다. 팝업의 목표 시각도 오늘이 아닌 날이면 요일 없이 날짜 + 시각이다(R2 와 같은 규칙). ★개정(사용자 결정 2026-10-01 — ADR-0261)★: 팝업은 두 회사 칸 전체를 **한 표**로 열을 맞춘다 — 이름 | 막대 | %(오른쪽 끝 맞춤) | 리셋 시각(모래시계 + 시각) | 남은 시간 「(… 뒤)」. 이름 열의 폭은 팝업 전체에서 가장 긴 이름(예 `gpt-reserve`)이고, 숫자는 고정폭이며, 줄 간격은 모두 같다. 오늘 리셋(날짜 없는 시각) 줄은 시각 뒤에 빈칸이 생긴다(받아들인 모양). 거부 = 리셋 시각과 남은 시간을 한 덩어리로 두기(모래시계 시작점까지만 맞춤). 회사 머리의 「갱신 중」 글자는 없다 — 조회 중이면 그 회사 ⟳ 가 돈다(R12).
  - 「전부」 = **켠 회사의** 상세 항목 전부(D8)다 — ~~우클릭 메뉴로~~ 끈 회사는 작은 표시·팝업·배지 hover 어디에도 없고, 그 회사는 조회 수요에서도 빠진다. (사용자 확인 2026-09-27) · 끈 회사는 구독하지 않아 보일 값이 없다 — 그래서 팝업 상세도 켠 회사만이다(사용자 결정 2026-09-29 — 「끄면 사용량도 안보내고 좋네」).
- **R6** 링크 이름 = 「사용량 페이지 ↗」 + 마우스를 올리면 목적지 설명. Codex `chatgpt.com/codex/settings/usage` · Claude `claude.ai/settings/usage`. (결정)
- **R7** ~~보기 전용.~~ 켜고 끄기 줄(R8) 말고는 보기 전용(사용자 결정 2026-09-29 — 팝업이 켜고 끄기를 갖게 되어 보기 전용이 아니다). 슬롯 밖으로 뜰 수 있다 — 기존 슬롯 우클릭 메뉴와 같은 `position: fixed` 방식. (결정)

**색**
- **R10** 남은 양 기준 — 50% 초과 초록 · 50~20% 노랑 · 20% 미만 빨강 ~~+ ⚠~~. (결정) · ★개정(사용자 결정 2026-09-29 — TRD §3 #103)★: 20% 미만 옆 ⚠ 는 작은 표시·팝업 모두에서 없앤다 — 오류 표시처럼 보이고 숫자가 이미 말한다. 색 밖의 단서는 e-ink 의 빨강 막대 모양(R11)이 진다.
  - 경계: `x > 50` 초록 · `20 ≤ x ≤ 50` 노랑 · `x < 20` 빨강 ~~+ ⚠~~ (50·20 은 노랑 · 0 은 빨강 · 100 은 초록). 0–100 밖의 값은 막대·숫자 모두 0–100 으로 자른다. "없음"(R21)은 색 없이 중립 회색 "—". **보이는 숫자 = 남은 양을 정수로 내림**(남은 양을 부풀리지 않게 — 19.6 → 19) · **색은 보이는 숫자로 정한다**(숫자와 색이 어긋나지 않게). (리뷰 반영 기본값 — D17)
- **R11** e-ink — 노랑 = 빗금 · 빨강 = 검정 채움 + 굵은 테두리 ~~+ ⚠~~(⚠ 제거 — 사용자 결정 2026-09-29 · R10). (결정)

- **R32** 창의 값은 그 창의 리셋 시각까지만 유효하다. 리셋이 지나면 그 창의 %·카운트다운을 숨기고 "리셋됨 — 갱신 대기"를 보인다 — 조회는 R29 의 규칙대로(리셋 경과가 조회를 앞당기지 않는다). **만료는 한 번 관측되면 그 창에 새 값이 올 때까지 유지한다** — 시계가 뒤로 가도 옛 % 가 되살아나지 않는다. 들고 있는 값이 30분보다 오래되면 옛 값으로 보인다 · ~~팝업은 값마다 나이를 늘 보인다.~~ 팝업은 회사 머리에 나이를 한 번 보인다 — 5시간·주간 두 창 가운데 가장 오래된 나이이고 모델별 창은 넣지 않는다 · 5시간·주간 가운데 값이 있는 창이 없으면 나이를 쓰지 않는다. 30분을 넘으면 그 나이를 호박색으로 바꾼다(사용자 결정 2026-09-30 — 머리 나이 기준은 메인 추천 B · ADR-0259). 대가 = 늙은 모델별 줄은 오래됨이 화면에 드러나지 않는다 — ⟳ 가 그 줄도 새로 받는다. (→ D10 · 리뷰 반영 기본값 — D21)
  - 오래된 값의 표시: 작은 표시에선 **숫자만 흐리게**(나이 문구 없음) · "N분 전" 은 팝업에만. (사용자 결정 2026-09-27) · 팝업의 "N분 전" = 회사 머리에 한 번 · 30분 넘으면 호박색(사용자 결정 2026-09-30).

**LLM 제어**
- **R26** 사용자 동작마다 LLM 경로를 **기존 명령 표면에** 얹는다 — 슬롯 생성·켜고 끄기 = 기존 `layout.setSlotContent`(R9 — 상태가 슬롯 내용) · 새로고침 · 현재 값 읽기. 새 전역 핸들을 늘리지 않는다. (원칙 「LLM-우선 제어」 · UI §5 ③) (→ D15)
- **R27** 표시 값은 DOM 텍스트로 둔다 — LLM 이 읽는다. (UI §3-5 · §5 ③)

**로컬라이징**
- **R28** 문구는 전부 `t(키)`(ADR-0069) · 날짜·시간은 `Intl` 로케일 포맷. (결정)

**불변 제약 (원칙 — 요구가 아니라 지켜야 할 벽)**
