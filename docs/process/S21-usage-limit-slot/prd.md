## 1. What and why

- Several agents stall on the 5-hour and weekly limits. A new type in the webview slot shows **the remaining Claude·Codex quota small, in one place**.
- Today the daemon discards the quota information that arrives during a conversation — it skips Claude `rate_limit_event`, and it receives and drops Codex `account/rateLimits/updated` (UI §4-1·§4-2). Pickup is new plumbing to lay down.
- We found no precedent among the surveyed products for putting this in one cell of a split layout — the nearest is the always-on sidebar gauge (TokenTelemetry) (UI §0-6).

After the reset passes, hide that window's % and countdown and show "리셋됨 — 갱신 대기" (reset — waiting for refresh) — queries follow R29's rule (reset passing does not bring a query forward). **Once expiry is observed it is kept until a new value arrives for that window** — even if the clock goes back, the old % does not revive. When the held value is older than 30 minutes it is shown as an old value · ~~the popup always shows an age on every value.~~ The popup shows the age once in the company header — the oldest age among the 5-hour·weekly windows, and per-model windows are not included · if no 5-hour·weekly window has a value, no age is written. The cost = the old per-model lines do not reveal their staleness on screen — ⟳ refreshes those lines too. (→ D10 · review-applied default — D21)
  - Display of old values: in the compact display **only the number is dimmed** (no age wording) · "N분 전" (N minutes ago) only in the popup. (user decision 2026-09-27) · The popup's "N분 전" = once in the company header · amber over 30 minutes (user decision 2026-09-30).

**LLM control**
- **R26** For each user action, put an LLM path **on the existing command surface** — slot creation·on/off = the existing `layout.setSlotContent` (R9 — the state is the slot content) · refresh · reading current values. Do not add a new global handle. (principle 「LLM-우선 제어」 · UI §5 ③) (→ D15)
- **R27** Displayed values are kept as DOM text — the LLM reads them. (UI §3-5 · §5 ③)

**Localization**
- **R28** All wording through `t(키)` (ADR-0069) · dates and times in `Intl` locale format. (decision)

**Invariant constraints (principles — not requirements but walls to keep)**
- Vendor knowledge (`get_usage`·usage address·app-server methods·units) is collected in one place — 「백엔드 확장」.
- The token location differs per OS (`~/.claude/.credentials.json` · macOS Keychain · `CLAUDE_CODE_OAUTH_TOKEN` — Query §0-1). OS branching only inside the one place that owns that job — 「플랫폼 중립」.
