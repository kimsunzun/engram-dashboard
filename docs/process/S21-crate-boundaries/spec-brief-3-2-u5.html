연결 띠 상황표

Engram Dashboard 창 위쪽에 뜨는 「데몬에 연결하지 못했습니다.」 띠가 상황마다 어떻게 보이고, 버튼을 누르면 어떻게 되는지 정리했습니다.

설계 3판 기준 — 재리뷰 중이라 내부 동작은 바뀔 수 있음, 화면에 보이는 부분은 사용자 결정으로 확정

띠는 두 종류뿐입니다

연결 안 됨
데몬에 연결하지 못했습니다. (원인 한 줄 — 있을 때만)
다시 연결✕

원인 줄은 토큰 거절 문구나 데몬 시작 실패 문구가 있을 때만 붙습니다.

버전 다름
데몬에 연결하지 못했습니다. 실행 중인 데몬이 이 앱과 버전이 다릅니다
데몬 끄기✕

「데몬 끄기」는 끌 수 있는 경우에만 보입니다 (떠 있는 데몬이 이 앱보다 이전 버전일 때).

데몬에 연결하지 못했습니다.

연결 안 됨
데몬에 연결하지 못했습니다. 데몬이 이 앱의 인증을 거절했습니다
다시 연결✕

데몬을 켜려는데 데이터 폴더가 쓰기 금지일 때. 지금 쓰는 문구가 원인 줄로 그대로 붙습니다 (경로는 예시).

연결 안 됨
데몬에 연결하지 못했습니다. 데이터 폴더에 쓸 수 없음(C:\Program Files\Engram\data): 액세스가 거부되었습니다 — 쓰기 가능한 위치에 압축을 풀어 주세요
다시 연결✕

누르면 → 「다시 연결」 흐름 (폴더 문제가 그대로면 같은 띠)

이전 버전 데몬이 떠 있음

누르면 → 확인 창 → 「데몬 끄기」 흐름 (아래). 꺼지면 ① 띠로 바뀌고 「다시 연결」로 새 데몬이 켜집니다.

✕

버튼 없음. 추가 안내 문구도 없습니다 (사용자 결정으로 뺌).

✕로 띠를 닫음

같은 띠 · 같은 원인이 이어지는 동안은 다시 뜨지 않습니다. 띠 종류나 원인 문구가 바뀌면 새로 뜹니다. 한 번 연결되면 닫은 기억이 지워져, 다음에 같은 이유로 끊기면 다시 뜹니다.

띠 없음 (닫은 이유가 그대로인 동안)

트레이 「데몬 끄기」 · 트레이 「종료」

사용자가 일부러 끈 것이라 띠를 띄우지 않습니다. 상태는 트레이 아이콘이 보여 줍니다. 두 경우 모두 이전 버전 데몬도 끕니다.

띠 없음

「데몬 끄기」 뒤에는 트레이 「데몬 켜기」나 앱의 「다시 연결」로 다시 붙습니다. 「종료」는 데몬을 끄고 앱도 닫습니다.

팝아웃 창

메인 창과 같은 띠 문구가 보이지만 버튼은 없습니다. 버튼은 메인 창에서만 누릅니다.

✕

「다시 연결」을 누르면

앱을 처음 켤 때와 같은 동작입니다. 데몬이 없으면 이 PC의 데몬을 켜고 붙습니다.

  1. 데몬에 연결하지 못했습니다.
    다시 연결
    ① 띠에서 누름
  2. 데몬에 연결하지 못했습니다.
    연결 중…
    버튼이 「연결 중…」으로 바뀜
  3. 떠 있는 데몬이 없으면 이 PC의 데몬을 켬, 그다음 연결
  4. 연결됨 → 띠 사라짐
    여전히 안 됨 → ① 띠 그대로
    버전 다른 데몬이 떠 있음 → ② 띠

「데몬 끄기」를 누르면

② 띠에서 이전 버전 데몬을 끄고, 새 데몬으로 넘어가는 순서입니다.

  1. 데몬에 연결하지 못했습니다. 실행 중인 데몬이 이 앱과 버전이 다릅니다
    데몬 끄기
    ② 띠에서 누름

  2. 이전 데몬을 끕니다. 실행 중인 에이전트가 멈춥니다 — 나중에 이어서 실행할 수 있지만 진행 중인 응답은 사라집니다

    취소끄기
    앱 안의 확인 창. 「취소」면 아무것도 바뀌지 않음
  3. 데몬에 연결하지 못했습니다. 실행 중인 데몬이 이 앱과 버전이 다릅니다
    끄는 중…
    「끄기」 → 띠는 그대로, 버튼이 「끄는 중…」(누를 수 없음)
  4. 이전 데몬을 정상 종료. 안 꺼지면 같은 데몬인지 확인한 뒤 강제 종료 (정상 종료는 최대 10초 기다림)
  5. 데몬에 연결하지 못했습니다.
    다시 연결
    꺼짐 → ① 띠로 바뀜
  6. 「다시 연결」 → 새 데몬을 켜고 연결 → 띠 사라짐

끄기에 실패하면 (데몬이 끝까지 남음) 앱이 다시 붙어 보고, 그 결과에 맞는 띠가 보입니다. 보통은 ② 띠 그대로입니다.
