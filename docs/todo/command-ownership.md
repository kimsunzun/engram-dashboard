# 명령 표면 — 주인이 선언되지 않는다 (ADR-0176이 넘긴 것)

> **상태:** 트리거 대기 · **정본 색인:** [`../todo.md`](../todo.md)

> 둘은 **한 덩어리다.** 아래 ①을 고치면 ②의 충돌이 부산물로 사라진다. 에이전트 트리 시스템을 손볼 때 함께 본다(사용자 결정 2026-08-26). *왜*의 정본 = ADR-0176.

- **① 명령이 자기 주인을 밝히지 않아 뺄셈으로 구한다** — 지금 웹뷰 몫은 `프론트 레지스트리 − 데몬이 답하는 이름 − 셸 표가 답하는 이름`으로 계산된다(`src-tauri/src/view_commands.rs`의 `reserved_names`). 프론트 레지스트리에 **자기가 안 답하는 것도 들어 있어서**(`tab.create`는 셸 표가, `agent.spawn`은 결국 데몬이 답한다) 선언으로는 구별이 안 되는 탓이다. 그 뺄셈이 `engram_dashboard_agent::commands::COMMAND_SPECS`를 읽는 유일한 이유이고, 셸에 남은 **마지막 agent 심볼**이다. 선언으로 바꾸면 필터·간선·접두가 한꺼번에 필요 없어진다. **지금 안 하는 이유:** ADR-0176 참조 — 간선을 닫아도 의존 상한 게이트 수치가 안 변하고(매니페스트 선언 + `daemon` dev-dependency 전이로 어느 쪽이든 7), 실이득인 릴리스 바이너리 크기는 미측정이다.
  - ★**`reserved_names`를 먼저 지우지 말 것 — 앱이 깨진다**★. 데몬이 겹친 이름을 **전부 모아 패킷을 통째로 반려**하고(`crates/engram-dashboard-daemon/src/connection_core.rs:675` + 호출부 `:1279-1280`) 반려되면 등록이 아예 안 돈다 — 겹친 하나 때문에 셸의 나머지 이름까지 명부에 못 오른다.
  - **분류 축이 필요하면 필드로 푼다.** `category`가 이미 선언에 있고(`src/commands/registry.ts:48`) `list()`가 노출한다(`:127-131`) — 다만 오늘 값은 명사 축(`agent`·`slot`)이라 「누가 답하나」를 안 담는다. ★식별자 접두로 푸는 안은 ADR-0176이 기각했다★.
  - **선행 실측 1건** — 겹친 이름의 라우팅 우선순위(데몬 표가 먼저인가). 주석은 *"route는 표를 먼저 본다"*지만 확인 안 했다. 「데몬 반려 검사를 없앤다」 선택지의 기각 근거가 그만큼 약하다(ADR-0176 §거부한 대안).
- **② 프론트가 데몬 소유 프리셋을 복제해 해소한다** — 프론트 `agent.spawn`이 `preset`(id)을 받아 `store.presets`에서 cwd를 찾은 뒤 데몬을 부른다(`src/commands/agentCommands.ts:41`). 그런데 ★프리셋은 데몬이 소유한다★(`crates/engram-dashboard-agent/src/persistence/presets.rs` `FilePresetStore`). **고치는 방향은 같은 파일이 이미 보여 준다 — 데몬 `agent.new`는 `preset`을 직접 받는다**(`cwd`와 상호배타, 둘 중 정확히 하나). `agent.spawn`도 그렇게 하면 프론트 껍데기가 사라지고 **충돌 2건(`agent.spawn`·`agent.rename`)도 같이 사라진다.** **지금 안 하는 이유:** 데몬 명령 인자 변경 + 프론트 명령 삭제 + 소유권 정리라 에이전트 트리 작업과 묶이는 것이 자연스럽다(사용자 결정).
  - **부수 관측 — 같은 이름이 부르는 표면에 따라 다르게 동작한다.** 필터가 프론트의 `agent.spawn`을 등록 패킷에서 빼내므로 명부에는 데몬 것만 오르고, 프론트 것은 `window.__engramCmd`로만 닿는다. 데몬 경로 = cwd만, 프론트 경로 = 프리셋도. ★이 어긋남을 만드는 것이 필터 자신이다.★
  - **`agent.rename`이 같은 구조인지는 안 봤다.** ②를 착수할 때 함께 확인할 것.

## 명령 표면 주인 선언 — ★지금 착수 대상 아님★

- **무엇:** 명령이 자기 주인을 선언하지 않아 웹뷰 몫을 뺄셈으로 구한다. 그 뺄셈이 셸에 agent 심볼이 남은 마지막 이유다.
- **왜 지금 아닌가:** 「에이전트 트리 시스템을 손볼 때 함께 본다」로 이미 정해져 있다(사용자 결정 2026-08-26). 트리 작업이 잡히기 전엔 열지 않는다.
- **정본:** *왜* = ADR-0176 · *무엇* = 이 문서 위 절. ★이 문서의 「`reserved_names` 를 먼저 지우지 말 것」 경고를 반드시 읽고 착수할 것★ — 지우면 앱이 깨진다.
