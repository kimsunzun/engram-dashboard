# ADR-0256: Usage values do not distinguish the source (picking · query)

- 상태: 확정 (2026-09-28, basis: user decision + TRD §7 #12 — replaces PRD D18)
- 관련: TRD §7 #12 · §3 #88(D12 source-agnostic) · PRD D18(the one being replaced) · step-log S21

## 맥락
When showing a usage value to the user, we had to decide whether to show it distinguishing whether the value came from an active query or was picked up in passing (passive).

## 결정
Usage values **do not distinguish the source (picking · query)**. There is only one merge rule — **what is newly carried overwrites, and what is not carried is kept.** An observation that contains a window value is treated as `Ready` in any state (the rejection deadline remains inside it). The wire snapshot has no source marker. What a query gives is only the **account state** (installed or not · logged in or not · no limit info · 429).

## 거부한 대안 (user)
- Distinguish the source so that **only the query** decides the state (PRD D18 — if the query is null or missing, "none") — replaced by this decision. The user does not need to know the source, and the arrival of a new value itself means it is being updated.

## 근거
User decision 2026-09-28 (「유저에게는 조회 줍기 구분하지말고 그냥 주고 데몬도 거기에 맞춰서 구성해」) · TRD §7 #12.
