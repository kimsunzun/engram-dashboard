# ADR-0256: 사용량 값은 출처(줍기·조회)를 가르지 않는다

- 상태: 확정 (2026-09-28, 근거: 사용자 결정 + TRD §7 #12 — PRD D18 대체)
- 관련: TRD §7 #12 · §3 #88(D12 출처 무관) · PRD D18(대체 대상) · step-log S21

## 맥락
사용량 값을 사용자에게 보여줄 때, 그 값이 능동 조회로 왔는지 지나가며 주운(passive) 값인지 구분해서 보여줄지 정해야 했다.

## 결정
사용량 값은 **출처(줍기·조회)를 가르지 않는다**. 병합 규칙은 하나뿐이다 — **새로 실린 것은 덮고, 안 실린 것은 유지한다.** 창 값이 든 관측은 어느 상태에서든 `Ready`로 본다(거절 기한은 그 안에 남는다). wire 스냅숏에는 출처 표시가 없다. 조회가 주는 것은 **계정 상태**(설치 여부·로그인 여부·한도 정보 없음·429)뿐이다.

## 거부한 대안 (사용자)
- 출처를 구분해 **조회만** 상태를 정한다(PRD D18 — 조회가 null 이거나 빠지면 "없음") — 이 결정으로 대체. 사용자는 출처를 알 필요가 없고, 새 값이 온다는 것 자체가 갱신되고 있다는 뜻이다.

## 근거
사용자 결정 2026-09-28(「유저에게는 조회 줍기 구분하지말고 그냥 주고 데몬도 거기에 맞춰서 구성해」) · TRD §7 #12.

## 영향 / 불변식
PRD D18을 대체한다(TRD §3 #88 — D12 출처 무관). D18을 참조하는 다른 문서가 있으면 이 ADR을 가리키도록 갱신이 필요하다(이번 라운드에서 확인 못 함 — 근거 미기록, 사용자 확인 필요). 구현 커밋: `088266e`(usageStore 병합 규칙).
