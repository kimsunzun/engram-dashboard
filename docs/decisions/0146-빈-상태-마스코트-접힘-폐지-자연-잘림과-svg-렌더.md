# ADR-0146: Retire the empty-state mascot collapse; natural clipping and SVG rendering

- 상태: 확정 (2026-08-18, grounds: user decision + on-screen measurement)
- 관련: Amends ADR-0145 (mascot threshold-height collapse) · `src/components/slot/RichSlot.tsx` · `src/components/slot/ClaudeMascot.tsx`

## 맥락

ADR-0145 decision 7 made the mascot hide as a whole when the slot height is below a threshold. Seen on screen after implementation, **the mascot vanishes abruptly while the slot is being shrunk.** User report (2026-08-18): when space shrinks, it is natural for it to be covered gradually until it is no longer visible, and isn't that the default behavior — correct. The threshold value itself was also a debt that had to be recalculated whenever the grid size changed (it was pushed once, from 240 to 300px).

In the same measurement round the mascot shape, color and text were also changed after user confirmation, and the rendering method was moved from a DOM grid to SVG (442 DOM nodes went into a single empty state).

## 결정

1. **Retire the threshold-height collapse (replaces ADR-0145 decision 7).** Remove the height observation device · the threshold constant · the collapse branch · its debounce entirely, and let the mascot **get clipped away** when space shrinks.
2. **Only the mascot gets clipped.** The text and the input box are excluded from shrinking and clipping. The extreme range where the slot becomes smaller than the input box is left to be squashed as it is — user decision: that range is not a concern.
3. **The mascot is drawn in SVG (makes "grid elements" in ADR-0145 decision 4 concrete).** The dot data stays as an array of strings, and horizontally contiguous cells are merged into one rectangle when drawing. The merge calculation runs once at module load.
4. **The color is the terracotta family of the original mascot, not red (amends ADR-0145 decision 3).** The reference is the Clawd shape of the official sticker.
5. **The empty state text is 「메시지를 입력하세요」 (type a message).** 「오늘 어떤 도움을 드릴까요?」 (how can I help you today?) gave the impression of a verbatim copy of claude.ai wording, so the user rejected it.
6. **No working directory (cwd) line is put in.** It was put in once and removed by user decision — the identity of an agent in this app is not based on a folder path.

## 거부한 대안

- **Keep the collapse but make it smooth (fade · shrink animation)** — what the user wanted was not a show but "the default behavior." An animation also conflicts with ADR-0145 decision 6 (snap).
- **Just re-set the threshold value** — the debt of recalculating it whenever the grid size changes stays. In fact it was pushed twice during this work alone.
- **Add a width-based collapse** — as the mascot got larger, its left and right were observed being clipped in a narrow slot. It is not added, for the same reason as vertical (being clipped is the normal behavior).
- **Keep the DOM grid** — 442 nodes for one empty state. If it shows in several slots at once, that is multiplied accordingly. After the SVG switch, 37.
- **Switch to a PNG asset** — already rejected in ADR-0145 (theme · scaling). It is not reopened this time either.

## 근거

- **User decision (2026-08-18)** — retiring the collapse · the text · removing the path line · the mascot shape were all specified by the user after seeing the screen. The rendering method (SVG) was delegated by the user to main.
- **On-screen measurement** — a release build was launched and checked through CDP. The pre-retirement behavior (only the mascot vanishes on passing the threshold) was actually reproduced before it was retired.

## 영향 / 불변식

- **If code that measures height comes back into this component, it violates this decision.** Do not put in collapse · shrink · responsive branches; leave it to the CSS flow.
- **The text and the input box are not clipping targets** — only the mascot cell absorbs shrinking and clipping. If this structure breaks, the input box gets eaten in a narrow slot.
- **The dot data is kept as a constant in one place** — the property that adjusting the shape should be a one-line edit remains valid after the SVG switch.
- **The mascot is decoration** — it carries no meaning, so it is hidden from the accessibility tree. No interaction is attached to it.
