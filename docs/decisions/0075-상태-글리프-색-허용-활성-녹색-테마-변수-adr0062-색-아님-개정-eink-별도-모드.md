# ADR-0075: Allowing color for status glyphs (active = green, theme variable) — amending ADR-0062 "not color" (premised on separating e-ink into its own mode)

- 상태: 확정 (2026-07-13) · 부분 폐기 by ADR-0168 (replacing the glyph mapping symbols)
- 관련: ADR-0062 (5-glyph vocabulary — shape, not color) · `src/styles/theme.css` (--status-running) · `src/components/agent/statusGlyph.ts` (statusGlyph/statusGlyphColor) · `AgentList.tsx` · Amended by ADR-0168 (replacing the glyph mapping symbols)

## 맥락

ADR-0062 decided to express status by "shape" rather than color, and the **only basis** for excluding color was that **color is lost on e-ink (black and white)** (§32). The user wants the active (Running) agent glyph in green, and decided that e-ink will be separated into its own mode.

## 결정

Color is **added to** shape (not a replacement) — only active (Running) is green (theme var `--status-running`), everything else is muted (as is). Keep no color literals and variable-only (ADR-0062 §44): the green value is owned by theme.css, and the e-ink block neutralizes it with `--status-running: var(--text-muted)` so only shape remains on e-ink. statusGlyph/statusGlyphColor are pure functions placed in the shared `statusGlyph.ts` module, and AgentList re-exports them.

## 거부한 대안

- **Keep pure shape-only (the ADR-0062 original)** — the only basis for excluding color (e-ink) disappears with the separation into a separate mode, so there is no reason to give up color even in dark/light.
- **Hardcoded hex** — violates the variable-only invariant (ADR-0062 §44) and makes e-ink neutralization impossible.

## 근거

Shape is still the primary signal (color is auxiliary), so nothing is lost on e-ink. In dark/light, color reduces the cognitive load of recognizing the active state. statusGlyphColor is pure + a unit test for every branch (the same shape as the statusGlyph discipline).

## 영향 / 불변식

- ADR-0062 §32 (rejecting status by color) and §44 (no color literals) are **partially amended** by this ADR — color is allowed, but the spirit of §44 is kept through variable-only + e-ink neutralization.
- Until e-ink is actually separated into its own mode, the e-ink theme preserves shape-only through var neutralization.
