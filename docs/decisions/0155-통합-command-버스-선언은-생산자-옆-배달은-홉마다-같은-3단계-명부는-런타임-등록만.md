# ADR-0155: 통합 command 버스 — 선언은 생산자 옆, 배달은 홉마다 같은 3단계, 명부는 런타임 등록만

## 맥락

명령 어휘가 셋으로 갈려 서로를 모른다 — 화면 33개 점 구분 id(`src/commands/`) · CLI 2그룹 8동사(`crates/engram-dashboard-core/src/agent/types.rs:237`·`:246`·`:179`·`:212`) · wire 25 variant(`crates/engram-dashboard-protocol/src/messages.rs:25-214`). 그 귀결로 **LLM이 창·탭·테마를 부를 통일 경로가 없다**(`docs/process/step-log.md:1673` ②).

지금의 벽은 데몬 에이전트 문(HTTP `/control`)의 5동사 손 match다 — `crates/engram-dashboard-daemon/src/control/agent.rs:222-239`(5동사 arm `:223-235`). 새 동사는 이 match를 고쳐야 생긴다.

**[포인터 정정 2026-08-16 — 결정 불변]** 그 손 match는 **S20 Step 2 슬라이스 3에서 삭제됐다** — 위 줄번호로 찾지 말 것. 지금 그 자리는 `{verb}`로 명령 이름을 만들어 표에서 찾아 부르는 어댑터 하나다(`crates/engram-dashboard-daemon/src/control/agent.rs`의 `handle_agent`). 이 ADR이 겨눈 벽이 실제로 사라진 것이고, 결정 본문은 그대로다.

이 결정은 ADR-0022(방향만 고정한 제안)의 구체화이고, ADR-0055가 세운 프론트 레지스트리 골격 위에 선다. 설계 정본은 `docs/process/S20-command-bus/trd.md`이고 여기는 그 문서가 확정한 **형태**만 박제한다.

## 결정

1. **선언과 본문을 한 세트로 생산자 모듈 옆에 둔다.** core = `agent.*` · daemon = `mail.*` · src-tauri = `window`/`tab`/`slot` · 웹뷰(TypeScript) = `theme`/`chat`. **선언에 「주인」 칸을 두지 않는다 — 선언이 사는 곳이 곧 주인이다.**
2. **도구 crate `engram-dashboard-command`를 신설한다.** 담는 것은 봉투·오류·선언 매크로·표·라우팅뿐이고 **워크스페이스 의존 0, 명령 0개**다.
3. **배달은 홉마다 같은 3단계다** — 내 표에 있나 → 명부에 있나 → 오류. 2단 배달(데몬 → 셸 → 웹뷰)도 같은 규칙이고 **홉마다 특별 케이스를 두지 않는다.**
4. **받은 자리(연결 태스크)에서 실행하지 않는다.** 인바운드 수신기는 즉시 반환하고 적용은 그 밖에서 돈다. 셸·데몬·웹뷰 전부에 걸리는 전역 규칙이다.
5. **전역 자동등록 금지.** 자동 수집이 다루는 것은 이름·인자 스키마·오류 집합까지이고, **핸들러 실물은 `make_table(deps)`로 조립 때 주입한다.**
6. **데몬은 빌드 목록을 컴파일에 넣지 않는다** — 명부는 런타임 등록으로만 찬다. 봉투에 **방향 필드를 두지 않고**(어느 연결에 썼는가가 방향이다), **`name`은 겉봉에 노출한다**(명령 단위 인가·관측이 거기 달려 있다. `args`는 여전히 데몬 불투명).
   - ★**개정 표식 — 이 명부의 「주인 토큰 산출」은 ADR-0150가 폐기했다**★ 이 ADR 하에서 주인 키는 **연결 id에서 파생**됐고(그래서 재접속이 남남이 됐다), 지금은 **클라이언트가 스스로 만들어 첫 인사에 실어 보낸 식별자**다(식별자를 안 보낸 연결만 연결 id 파생 유지 — fail-open). 끊긴 주인의 등록은 **자취 없이 제거**된다. **런타임 등록만이라는 이 조항 자체와 나머지 결정 전부는 유효하다** — 범위는 ADR-0150 영향절이 정본이다.

## 거부한 대안

- **A. 선언을 `engram-dashboard-protocol` 한 crate에 모은다** — 사용자 지적 「생산자와 사용자가 명확히 분리돼야 한다」로 폐기(`.claude/handoff/history/20260813-140452-command-bus-설계-방향-확정.md:53`). `protocol`은 **wire 계약**이라 명령 어휘의 집주인이 아니다. 부수 효과로 `core`가 `agent.*`를 선언하려면 wire 타입까지 보게 된다 — 도구 crate(결정 2)가 그 유입을 막는다.
- **B. 선언에 `#[owner(...)]` 칸을 둔다** — 정의 위치가 곧 주인이라 **중복**이다(`docs/process/step-log.md:1669`, 사용자 지적 2026-08-12). 사용자가 두 번 철회시킨 제안이고, 되살아난 이유는 전제(A의 중앙화)가 그것을 요구했기 때문이다. 고칠 것은 칸이 아니라 전제였다.
- **C. 데몬이 전량 빌드 목록을 갖고 명부와 대조한다** — 둘 다 치명적이다. ㉠ **결합:** 데몬이 `tab.create`·`theme.set` 같은 셸·화면 이름을 정적으로 알게 되어, A가 피하려던 결합이 다른 문으로 들어온다. ㉡ **거짓 가용성:** 앱이 꺼져 있어도 "그 명령 있다"고 답한다. 명부가 런타임 등록만으로 차야 「지금 부를 수 있는가」가 사실이 된다. **대가는 대칭적 부정확이다** — 데몬이 **한 번도 본 적 없는** 주인의 이름은 `UNKNOWN_COMMAND`로 나간다(데몬만 켜고 앱을 한 번도 안 띄운 경우). 즉 이 결정은 부정확을 없앤 게 아니라 **거짓 긍정에서 거짓 부정으로 옮겨** 결합을 피한 것이고, 금지를 만든 쪽이 여기이므로 그 대가도 여기 적는다.
- **D. 전역 자동등록 표에 핸들러 실물을 박는다** — 테스트가 **가짜 관리자를 꽂을 자리가 없어진다.** `agent.spawn` 하나를 단언하려는 단위 테스트에 진짜 `AgentManager`가 딸려와 **실제 프로세스를 띄운다.** ADR-0012 「외부 의존을 seam으로 끊는다」의 직접 위반이다.
- **E. 웹뷰 명령은 선언만 Rust에 두고 본문은 TypeScript에 둔다**(구판, C++ 헤더식 분할) — 이 안의 유일한 근거는 「화면 전용 명령은 Rust 모듈이 없어 목록에서 빠진다」였는데(`docs/process/step-log.md:1669` 뒷문장), **런타임 등록(결정 6)이 그 구멍을 메우면서 불필요해졌다.**
- **F. 봉투에 방향 필드를 추가한다** — 같은 봉투가 진실을 둘(필드 값 / 실제 연결) 갖게 되고, 어긋나는 순간 라우팅이 갈린다.
- **G. 2단계 라우팅(내 표에 있으면 실행, 없으면 보낸다)** — **보낼 곳이 하나뿐이라는 전제**가 깔려 있어 홉이 둘이 되면 깨진다. 3단계는 특별 케이스 없이 모든 홉에서 같으므로 새 주인이 붙어도 배달 코드가 아니라 등록이 하나 는다.

## 근거

**코드 실측(2026-08-13).** `crates/engram-dashboard-core/Cargo.toml`·`crates/engram-dashboard-protocol/Cargo.toml` 모두 `path =` 0줄(워크스페이스 의존 0) · 프론트 등록 명령 33개(`src/commands/*Commands.ts`의 `register(` 31건 + `registerSplit`(`slotCommands.ts:35`) 2회 호출 `:48-49`) · **데몬 → 셸 인바운드 0건**(`src-tauri/src/daemon_client/connection.rs:805`의 `Message::Text` 처리가 `AgentEvent`로만 디코드) · 중계 심볼(`RegisterRole`/`RelayUi`/`UiCommand`/`UiResult`) `.rs` 히트 0.

**설계 조사의 지위 — 이 ADR의 거부 근거가 아니다.** 선례 조사(`docs/research/unified-command-bus-survey-2026-08-12.md`)는 deep 6갈래 후 타계열 적대 리뷰에서 **BLOCK 판정**을 받았고 반증 6건을 정정 반영했다. 보고서 스스로 열린 항목이 닫히기 전 거부 근거 사용을 금지했으므로 **위 대안들은 조사가 아니라 우리 구조에서 기각됐다** — 호출자 수(발견·병합을 복제해야 하는 지점이 셋 이상) · 홉 균일성 · 테스트 격리.

**TRD 개정 시 `file:line` 23항목 재검증에서 드리프트 7건을 발견·수정했다**(속성줄을 함수줄로 인용한 off-by-one 5건 등). 이 ADR의 포인터는 그 재검증 이후 값이다.

## 영향 / 불변식

- **`core`의 워크스페이스 의존이 0 → 1이 된다**(도구 crate 하나). **이 수치를 지키는 CI 게이트는 오늘 없다** — 조용히 바뀌므로 「코어는 아무것도 안 본다」가 「코어는 도구 하나만 본다」로 완화된다는 사실을 여기 남긴다.
- **메시징 커널 격리 게이트 정규식에 새 crate 이름을 반드시 더한다**(`.github/workflows/ci.yml:252`, 현재 `engram_dashboard_(core|daemon|protocol|discovery)`). 메시징엔 net 같은 의존 상한 게이트가 없어 **정규식이 유일한 벽**이고, 빠뜨리면 ADR-0110 불변식이 무방비가 된다.
- **net 게이트 둘은 바뀌지 않는다** — core 심볼 allowlist 정확히 2줄(`ci.yml:276-293`)과 직접 워크스페이스 의존 정확히 3줄(`ci.yml:300-317`). 이유 한 줄: **이 설계는 네트워크 행에 아무 개념도 추가하지 않는다**(ADR-0129 계층 분리 그대로).
- **생성물 sync 게이트는 확장이 필요하다** — `.github/workflows/ci.yml:124-131`이 보는 경로가 `crates/engram-dashboard-protocol/bindings/` 하나뿐이라 신설 `core/bindings/`와 기존 `src-tauri/bindings/`를 아무도 안 본다.
- **하드 제약:** `static`/`lazy_static`/링커 수집이 **`Arc<dyn CommandHandler>`를 담으면 위반**이다. 담아도 되는 것은 `CommandSpec`(이름·스키마·오류)까지다. 감시자 = `make_table` 주입 하네스(가짜 의존으로 핸들러를 프로세스 없이 단언).
- **이름을 다른 crate로 옮기는 것은 additive가 아니다** — 선언 위치가 주인이므로 **이사는 주인 교체**이고 명부가 재편된다. 옮겨야 하면 **새 이름으로 선언하고 옛 이름을 deprecate**한다.
- **★두 옛 ADR의 도장은 라벨이고, 무엇이 죽고 무엇이 사는지의 정본은 여기다.★** 상태줄 도장은 인덱스 표 셀에 그대로 실려 짧아야 하므로 사유를 이 자리에 둔다.
  - **ADR-0081 = 결정 1·2만 대체된다.** 살아 있는 조항: **단일 `request_id` 왕복 보존** · **연결 cleanup sweep과 라우팅 표 수명 바운드** · **dedup는 적용 후에만 커밋** · **데몬 opaque 유지** · **UI 어휘 컴파일 가드**. 대체된 것은 결정 1 `RegisterRole{UiApp}`과 결정 2의 3-variant opaque relay 봉투 `RelayUi`/`UiCommand`/`UiResult`뿐이고, 그 자리를 등록 wire `RegisterCommands`/`UpdateCommands`/`ListCommands` + 주인 토큰 명부와 통합 command 봉투가 받는다. **도장만 보고 0081 전체를 죽은 것으로 읽지 말 것.**
  - **ADR-0022 = 방향은 유효하다.** 단일 출처 command registry라는 결정 위에 이 ADR과 ADR-0156가 서고, 소진된 것은 그 ADR이 「미해결」로 남긴 **세 갈래**(레지스트리 위치 · LLM 발견 경로 · 백엔드 미러)뿐이다 — 그 절 본문은 이력이므로 열린 갈림길로 읽지 말 것.
- **ADR-0055가 「지금은 거부」한 백엔드 미러를 이 결정이 만든다** — 데몬 명부가 곧 그 미러다. 0055 자신이 결정 「레지스트리 위치 = 프론트 단독 … 백엔드 미러 = 후속」과 거부 대안 「백엔드 미러 레지스트리(**지금**)」로 **시한을 걸어 미룬 것**이라, 이건 폐기가 아니라 **그 후속의 실현**이다. 그래서 0055에 폐기 도장을 박지 않는다 — 이 저장소는 「구체화」에 도장을 안 찍는 선례가 둘 있다(0002↔0030 · 0022↔0055).
- ADR-0081 「Opaque 결합 가드」에 **폐기 도장은 필요 없다.** 가드가 금지하는 것은 UI 타입 import이고, 데몬이 아는 것은 이름 문자열뿐이며 그것도 런타임 등록으로 받는다 — 컴파일에 들어가는 UI 타입은 0이다.
