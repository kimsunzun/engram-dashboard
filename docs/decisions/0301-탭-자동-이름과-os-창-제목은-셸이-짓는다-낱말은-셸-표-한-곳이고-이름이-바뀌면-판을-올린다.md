# ADR-0301: 탭 자동 이름과 OS 창 제목은 셸이 짓는다 — 낱말은 셸 표 한 곳이고 이름이 바뀌면 판을 올린다

- 상태: 확정 (2026-10-26, 근거: 사용자 결정 2026-10-23(Q6 — 자동 이름 · D16 — 옛 파일 탭은 자동 · 리뷰 1차 지적 ⑥ — 빈 이름은 저장하지 않음 · Q3 · D4 — 제목 꼴) · 2026-10-24(T2 — 낱말) + 메인 결정 M4 · M4′ · M5 · M6 · M15 · M16(TRD §12-3) · D17(PRD — 메인 결정 · TRD 몫) · U3a · U3b 리뷰의 메인 결정(2026-10-25) + 구현 U1 `4cefce48` · U3a `2c7b7fd9` · U3b `a698ac26` · U4 `ef8922ce`)
- 관련: PRD `docs/process/S21-window-chrome/prd.md`(0.5판 — R3 · R4 · R29 · D4 · D16 · D17 · AC3 · AC4 · AC21 · AC35 · AC36) · TRD `docs/process/S26-window-chrome/trd.md`(0.3판 — §1-4 · §2-4 불변식 2 · 4 · §3-1 · §3-3 · §3-5 · §4-2 · §4-3 · §4-4 · §5-1 · §5-7 · §10-4) · ADR-0066(탭별 포커스 슬롯) · ADR-0101 · ADR-0120(에이전트 표시 이름 · 유일화는 데몬이 짓는다) · ADR-0300(창 번호) · `src-tauri/src/layout/tab_name.rs` · `src-tauri/src/layout/apply.rs`(`agent_names_updated`) · `src-tauri/src/chrome/book.rs`(제목 판) · 트래킹 T-68(로컬라이제이션) · step-log S26

## 맥락

탭의 처음 이름이 갈래마다 시스템이 지은 「View N」 · 「Tab」 · 「Popup N」이었고, 창 제목은 메인 「Engram Dashboard」 고정 · 팝아웃 「Engram — slot-popup-N」이었다 — 제목이 내용을 말하지 않았다(PRD §1 · Q6). 창 제목이 활성 탭 이름을 따르므로(R3) 탭 이름을 바꾸지 않으면 제목도 대개 「View N - Engram」이다.

탭 이름은 화면만이 아니라 OS 제목 · 버스 `tab.list` · `window.list` 가 함께 쓴다. 그 답이 창 웹뷰 없이도 맞아야 한다(CLAUDE.md 「LLM-우선 제어」). 에이전트 표시 이름 · 유일화는 데몬이 짓는다(ADR-0101 · ADR-0120).

## 결정

1. **탭 이름 = 자동 이름**(사용자 결정 2026-10-23 — Q6) — 사람(화면 이름 바꾸기) · LLM(`tab.rename`)이 이름을 정하기 전까지 탭 이름 = 그 탭 포커스 슬롯(`View.focused_slot_id` — ADR-0066)의 표시 이름이고, 포커스가 옮거나 에이전트 이름이 바뀌면 따라간다. 정하면 굳는다. 자동 이름과 같은 글자로 「바꿔도」 정한 이름으로 굳는다(TRD §3-1 · 리뷰 codex ⑨) — 같은 글자는 Enter(일부러 한 확정)에서만 보낸다(메인 결정 · U3a 리뷰 2026-10-25).
   - **빈 이름 · 공백뿐인 이름은 저장하지 않는다**(사용자 결정 2026-10-23 — 「빈이름으로 저장하면 그냥 저장을 안하게」) — 화면은 무시 · `tab.rename` 은 `INVALID_ARGUMENT` · 모델도 거절한다(`LayoutError::EmptyName` — TRD §3-1 · 새 경계가 생겨도 빈 정한 이름이 굳지 않게).
   - **옛 상태 파일의 탭(「정한 이름인가」 칸 없음)은 자동 이름이다**(사용자 결정 2026-10-23 — D16 · 「지금껏 저장된건 신경쓰지말고」).
2. **이름은 셸이 짓고 낱말은 셸 표 한 곳에 둔다**(메인 결정 M4 — PRD R4 의 기본값 「i18n 을 따른다」에서 벗어남 · TRD §1-4) — `layout/tab_name.rs` 의 `word`: 빈 칸 · 에이전트(이름을 아직 모를 때) · 에이전트 트리 · 프리셋 · 사용량(사용자 결정 2026-10-24 — T2) · 이 판이 모르는 내용을 쥔 슬롯 = 「알 수 없는 내용」(메인 결정 — `SlotContent` 갈래가 아니라 모르는 내용 곁표를 `match` 앞에서 본다 · TRD §4-2). 셸에는 i18n 층이 없고 사용자 낱말을 상수 표로 쥔 선례가 있다(`tray::core::MenuAction::label`). 로컬라이제이션(T-68)이 이 표를 웹 i18n 과 합친다.
3. **「정한 이름인가」를 타입으로 든다** — `View.name: TabName { Auto, Named(String) }`(메인 결정 M4′). 저장 = `TabEntry.named` 선택 칸 + `name` 은 그 순간의 유효 이름(이 판은 정한 이름이 아닌 탭의 `name` 을 이름으로 쓰지 않는다 — 부팅 시드에만 쓴다).
4. **슬롯 표시 이름은 `SlotContent` 위 와일드카드 없는 `match` 하나로 짓는다**(D17 — 메인 결정) — 함수 `slot_label` 에 `#[deny(clippy::wildcard_enum_match_arm)]` + CI `shell gate 2` 의 양성 검사(변형 덮기 · 갈래 모양 — CI 가 clippy 를 돌리지 않아서 · 메인 결정 M15 · U1 리뷰 2). 슬롯 종류를 더하면 이름을 짓기 전에는 통과하지 못한다.
5. **에이전트 이름의 출처 = 데몬 `AgentListUpdated` 의 `AgentInfo.name`** — 셸은 이름을 다시 짓지 않는다. 장부 = 모델 안 `ViewManager.agent_names`(메인 결정 M5 — 레이아웃 락 하나 안에서 이름 셈이 끝난다). 데몬은 개명(`Renamed`) 뒤와 명부 통지 포트(`RosterFanout::roster_changed` — 버스 · CLI `agent.rename`)에서도 `AgentListUpdated` 를 낸다(U3b · 메인 결정 · U3b 리뷰 2026-10-25). 부팅 시드 = 저장 파일의 `named == Some(false)` 이고 포커스 슬롯이 에이전트인 탭의 저장 이름만(메인 결정 M16 — 옛 파일은 시드하지 않는다).
6. **유효 이름이 바뀌면 레이아웃 판(`version`)을 올리고 그 창의 탭 목록을 알린다** — 불변식 「창 제목이 바뀌는 쓰기는 그 창의 탭 목록을 새 판 번호로 알린다」(TRD §2-4 불변식 2). 바뀐 것이 없으면 아무것도 내지 않는다.
7. **OS 창 제목은 셸이 입힌다**(메인 결정 M6) — 꼴 「<활성 탭 유효 이름> - Engram:<n>」(사용자 결정 2026-10-23 — Q3 · D4) · 탭 없음 「Engram:<n>」 · 번호 없음(숨은 예열 창 · 모델 밖 창) 「Engram」 · 자르지 않는다. 탭 알림 페이로드가 `title` · `version` 을 싣고, 그 알림의 Tauri 어댑터가 메인 스레드에서 창별 마지막으로 입힌 판보다 새 판일 때만 `set_title` 한다(`chrome::ChromeBook::accept_title` — 옛 판 버림 · 같은 글자는 OS 호출 건너뜀 · 실패하면 글자만 잊어 다음 새 판이 다시 입힘). 새 포트는 없다. 창 빌드 제목 · main 설정 제목 = 「Engram」.

## 거부한 대안

- **웹이 낱말을 셸에 보고하기**(TRD §1-4 의 거부한 갈래) — 창 웹뷰가 하나도 보고하지 않은 동안 OS 제목 · 명령 답이 낱말 없이 선다. 기각 강도 = 서술(구조).
- **`View.name: String` 을 두고 「정한 이름인가」 칸을 덧대기**(TRD §3-1) — 자동 탭의 낡은 문자열(「View 1」)을 누가 바로 읽으면 AC3(시스템이 지은 옛 기본값이 사람 눈에 안 보인다)이 깨진다. 타입을 바꾸면 옛 `name` 을 직접 읽던 자리가 컴파일에서 깨져 전부 유효 이름 셈으로 옮겨진다. 기각 강도 = 서술(타입 안전).
- **셸이 `ProfileListUpdated` 에서 이름을 다시 셈하기**(TRD §4-3) — 유일화 접미사를 놓친다(유일화 · canonicalize 는 데몬 안에 있다 — 셸이 흉내 내면 갈라진다). 기각 강도 = 코드.
- **이름 장부 갱신에 판을 올리지 않기**(TRD 0.1판 · 리뷰 Claude ③ · codex ⑤) — 웹이 같은 판 번호의 탭 알림을 버리고(`viewStore.ts` 의 `payload.version <= prev.version`) 제목 입히기도 옛 판으로 본다. 기각 강도 = 코드.
- **제목을 판 비교 없이 알림 차례대로 입히기**(TRD 0.1판 · 리뷰 codex ⑤) — 알림은 락 밖에서 여러 스레드가 내 순서가 뒤바뀔 수 있다(`layout::apply` 「락 규율」). 메인 스레드 한 줄 + 판 비교가 늦게 온 옛 판을 버린다. 기각 강도 = 코드.
- **Q6 의 다른 갈래**(PRD §5-2) — ① 새 창 팝아웃만 에이전트 이름: 옮기는 순간의 이름으로 굳어 뒤에 이름이 바뀌어도 안 따라간다 · ② ① + 기존 창 팝아웃 · ③ ② + `+` · `window.create` 도 「새 탭」: 「새 탭」이 여럿 겹친다 — ①–③ 이면 제목은 대개 「View N - Engram」이다 · ⑤ 탭 이름은 두고 창 제목만 에이전트 이름: 탭바와 제목이 다른 말을 한다. 기각 = 사용자 결정 2026-10-23(Q6 ④ 꼴).
- **옛 파일 탭의 다른 규칙**(PRD D16 의 고르지 않은 갈래) — 이름이 기본 꼴(「View N」 · 「Tab」 · 「Popup N」)이면 자동 · 그 밖은 정한 이름: 사람이 일부러 「View 2」로 지은 탭도 자동이 된다 · 옛 탭 전부 정한 이름: 옛 창 제목이 「View N - Engram:<n>」으로 남는다. 기각 = 사용자 결정 2026-10-23.
- **빈 이름 = 자동 이름으로 되돌림**(PRD 리뷰 1차 지적 ⑥ 의 갈래) — 화면과 `tab.rename` 을 같게 하려면 `tab.rename` 의 빈 인자 거부를 걷어야 해, 안 채운 셸 변수로 부른 `tab.rename` 이 오류 대신 이름을 지운다. 기각 = 사용자 결정 2026-10-23. 되돌리기를 명시 인자 · 별도 명령으로 두는 길은 기각이 아니라 범위 밖이다(PRD §2 — 메인 제안).
- **D17 게이트를 위반 꼴의 음성 정규식으로**(TRD 0.3판 한 줄 · 리뷰 1 의 네 갈래) — `Other =>` · `other | other =>` · `other @ &_ =>` · 원시 문자열의 0 열 `}` 로 범위가 잘리는 것 · 주석 글자 오탐에 계속 샜다(TRD §10-4 · 메인 결정 U1 리뷰 2 · 2026-10-24). 허용 꼴만 통과시키는 양성 검사는 그 열거가 필요 없다. 기각 강도 = 리뷰 실측.

## 근거

- 사용자 결정 PRD §5-1 — Q6 · D16 · 빈 이름(2026-10-23) · T2(2026-10-24).
- 피어(PRD R4 — 메인이 결정 때 든 피어 · 조사 문서는 없다): WezTerm(작업 폴더 이름 · 사람이 바꾸면 그 이름) · Windows Terminal · tmux(손으로 바꾸면 `automatic-rename` 이 꺼진다) · 제목 꼴의 선례 = Excel `Book1.xls:2`(조사 식별 결론 1).
- Tauri 2.11.3 사실(U4 리뷰 소스 독해 — TRD §4-4): 메인 스레드에서 부른 `run_on_main_thread` 는 그 자리에서 돈다 · `Destroyed` 때 Tauri 가 사용자 처리기보다 먼저 창을 지운다 — 그래서 제목 일은 창이 있는지부터 보고, 잊은 뒤 온 늦은 일은 장부 항목을 되살리지 않는다.

## 영향 / 불변식

- **불변식 2** — 활성 탭 · 탭 유효 이름 · 번호 중 하나라도 바꾸는 쓰기는 `version` 을 올리고 그 창의 `WindowTabsPayload` 를 낸다. 어기면 웹이 그 알림을 버리고 OS 제목이 낡은 채 남는다.
- **불변식 4** — `slot_label` 에 와일드카드 · 묶음 이름 갈래를 두지 않는다. 게이트가 못 잡는 일부러 속이는 꼴(가짜 `match` 를 담은 원시 문자열 · 문자열 속 `SlotContent::<새 변형>` · 망라 `match` 앞의 묶음 갈래 도우미로 일찍 돌아가기 — TRD §10-4)은 코드 리뷰가 본다.
- 낱말이 셸 상수 표라 웹 i18n 과 두 곳이다 — T-68 이 합친다.
- 받아들인 것(TRD §5-7 — 메인 결정 · U3b 리뷰 2026-10-25): 잠든 · 죽은 에이전트의 개명은 그 에이전트가 다시 살아날 때까지 탭에 안 비친다 · `AgentListUpdated` 를 내는 쪽끼리 차례가 없어 옛 목록이 잠깐 옛 이름을 되살릴 수 있다(진짜 해법 = protocol 의 목록 판 번호 — 범위 밖).
- 한 번 정한 이름을 자동 이름으로 되돌리는 길은 없다(PRD §2 — 범위 밖). 옛 빌드로 내리면 정한 이름이 자동으로 돌아간다(TRD §3-3).
- 앵커 — `layout/tab_name.rs`(`slot_label` · `word` · 유효 이름 셈) · `apply::agent_names_updated` · 제목 판 판정(`chrome::book`)에 `// ADR-0301` 을 단다.
