# ADR-0301: The automatic tab name and the OS window title are built by the shell — the words live in one shell table, and when the name changes the revision is raised

- 상태: 확정 (2026-10-26, 근거: user decision 2026-10-23 (Q6 — automatic name · D16 — tabs from old files are automatic · review round 1 point ⑥ — an empty name is not saved · Q3 · D4 — title shape) · 2026-10-24 (T2 — words) · 2026-10-25 (U1 review — accepted the deliberately deceptive shapes the gate cannot catch) + main-agent decisions M4 · M4′ · M5 · M6 · M15 · M16 (TRD §12-3) · D17 (PRD — main-agent decision · TRD's share) · main-agent decisions of the U3a · U3b reviews (2026-10-25) + implementation U1 `4cefce48` · U3a `2c7b7fd9` · U3b `a698ac26` · U4 `ef8922ce`)
- 관련: PRD `docs/process/S21-window-chrome/prd.md` (edition 0.5 — R3 · R4 · R29 · D4 · D16 · D17 · AC3 · AC4 · AC21 · AC35 · AC36) · TRD `docs/process/S26-window-chrome/trd.md` (edition 0.3 — §1-4 · §2-4 invariants 2 · 4 · §3-1 · §3-3 · §3-5 · §4-2 · §4-3 · §4-4 · §5-1 · §5-7 · §10-4) · ADR-0066 (per-tab focus slot) · ADR-0101 · ADR-0120 (the agent display name · uniqueness is built by the daemon) · ADR-0300 (window number) · `src-tauri/src/layout/tab_name.rs` · `src-tauri/src/layout/apply.rs` (`agent_names_updated`) · `src-tauri/src/chrome/book.rs` (title revision) · tracking T-68 (localization) · step-log S26

## 맥락

The first name of a tab was a system-built 「View N」 · 「Tab」 · 「Popup N」 depending on the branch, and the window title was fixed to 「Engram Dashboard」 for main and 「Engram — slot-popup-N」 for a popout — the title did not say anything about the content (PRD §1 · Q6). Since the window title follows the active tab name (R3), if the tab name is not changed, the title is usually 「View N - Engram」 too.

The tab name is used not only by the screen but also by the OS title · the bus `tab.list` · `window.list`. Those answers must be right even without a window webview (CLAUDE.md 「LLM-우선 제어」). The agent display name · uniqueness is built by the daemon (ADR-0101 · ADR-0120).

## 결정

1. **Tab name = automatic name** (user decision 2026-10-23 — Q6) — until a person (renaming on screen) or the LLM (`tab.rename`) sets a name, the tab name = the display name of that tab's focus slot (`View.focused_slot_id` — ADR-0066), and it follows when the focus moves or the agent name changes. Once set, it is fixed. Even if it is 「바꿔도」 to the same letters as the automatic name, it becomes fixed as a chosen name (TRD §3-1 · review codex ⑨) — the same letters are sent only on Enter (a deliberate confirmation) (main-agent decision · U3a review 2026-10-25).
   - **An empty name or a whitespace-only name is not saved** (user decision 2026-10-23 — 「빈이름으로 저장하면 그냥 저장을 안하게」) — the screen ignores it · `tab.rename` returns `INVALID_ARGUMENT` · the model also rejects it (`LayoutError::EmptyName` — TRD §3-1 · so that an empty chosen name does not become fixed even if a new boundary appears).
   - **A tab from an old state file (no 「정한 이름인가」 field) is an automatic name** (user decision 2026-10-23 — D16 · 「지금껏 저장된건 신경쓰지말고」).
2. **The shell builds the name, and the words live in one shell table** (main-agent decision M4 — a departure from the PRD R4 default 「i18n 을 따른다」 · TRD §1-4) — `word` in `layout/tab_name.rs`: empty cell · agent (when the name is not yet known) · agent tree · preset · usage (user decision 2026-10-24 — T2) · a slot that holds content this edition does not know = 「알 수 없는 내용」 (main-agent decision — it looks at the side table of unknown content before the `match`, not at a `SlotContent` branch · TRD §4-2). The shell has no i18n layer and has a precedent of holding user words in a constant table (`tray::core::MenuAction::label`). Localization (T-68) merges this table with the web i18n.
3. **Carry 「정한 이름인가」 in the type** — `View.name: TabName { Auto, Named(String) }` (main-agent decision M4′). Storage = an optional field `TabEntry.named` + `name` is the effective name at that moment (this edition does not use the `name` of a tab that is not a chosen name as a name — it is used only for the boot seed).
4. **The slot display name is built by a single `match` over `SlotContent` with no wildcard** (D17 — main-agent decision) — `#[deny(clippy::wildcard_enum_match_arm)]` on the function `slot_label` + a positive check in CI `shell gate 2` (variant coverage · branch shape — because CI does not run clippy · main-agent decision M15 · U1 review 2). If a slot kind is added, it cannot pass until its name is built.
5. **The source of the agent name = `AgentInfo.name` of the daemon's `AgentListUpdated`** — the shell does not build the name again. The ledger = `ViewManager.agent_names` in the model (main-agent decision M5 — the name calculation finishes inside one layout lock). The daemon also emits `AgentListUpdated` after a rename (`Renamed`) and at the registry notification port (`RosterFanout::roster_changed` — bus · CLI `agent.rename`) (U3b · main-agent decision · U3b review 2026-10-25). The boot seed = only the stored name of a tab whose stored file has `named == Some(false)` and whose focus slot is an agent (main-agent decision M16 — old files are not seeded).
6. **When the effective name changes, raise the layout revision (`version`) and notify that window's tab list** — the invariant 「창 제목이 바뀌는 쓰기는 그 창의 탭 목록을 새 판 번호로 알린다」 (TRD §2-4 invariant 2). If nothing changed, nothing is emitted.
7. **The OS window title is applied by the shell** (main-agent decision M6) — shape 「<활성 탭 유효 이름> - Engram:<n>」 (user decision 2026-10-23 — Q3 · D4) · no tab 「Engram:<n>」 · no number (a hidden prewarmed window · a window outside the model) 「Engram」 · not truncated. The tab notification payload carries `title` and `version`, and the Tauri adapter of that notification calls `set_title` on the main thread only when the revision is newer than the last one applied per window (`chrome::ChromeBook::accept_title` — an old revision is dropped · the same letters skip the OS call · on failure only the letters are forgotten so the next newer revision applies them again). There is no new port. The window build title · the main config title = 「Engram」.

## 거부한 대안

- **The web reports the words to the shell** (the rejected branch of TRD §1-4) — while no window webview has reported, the OS title and the command answers stand without the words. Strength of rejection = description (structure).
- **Keep `View.name: String` and add a 「정한 이름인가」 field to it** (TRD §3-1) — if someone reads the stale string of an automatic tab (「View 1」) directly, AC3 (the old system-built default is not visible to people) breaks. If the type is changed, the places that read the old `name` directly break at compile time and all move to the effective-name calculation. Strength of rejection = description (type safety).
- **The shell recalculates the name from `ProfileListUpdated`** (TRD §4-3) — it misses the uniqueness suffix (uniqueness · canonicalize are inside the daemon — if the shell imitates it they diverge). Strength of rejection = code.
- **Do not raise the revision when the name ledger is updated** (TRD edition 0.1 · review Claude ③ · codex ⑤) — the web drops a tab notification with the same revision number (`payload.version <= prev.version` in `viewStore.ts`) and the title application also treats it as an old revision. Strength of rejection = code.
- **Apply the title in notification order without a revision comparison** (TRD edition 0.1 · review codex ⑤) — notifications are emitted outside the lock by several threads, so their order can be swapped (`layout::apply` 「락 규율」). One line on the main thread + the revision comparison drops an old revision that arrives late. Strength of rejection = code.
- **Other branches of Q6** (PRD §5-2) — ① only a new-window popout gets the agent name: it is fixed to the name at the moment of moving, so it does not follow if the name changes later · ② ① + popout of an existing window · ③ ② + `+` · `window.create` also 「새 탭」: several 「새 탭」 pile up — with ①–③ the title is usually 「View N - Engram」 · ⑤ keep the tab name and make only the window title the agent name: the tab bar and the title say different things. Rejected = user decision 2026-10-23 (the Q6 ④ shape).
- **Other rules for tabs from old files** (the branch of PRD D16 that was not chosen) — automatic if the name has the default shape (「View N」 · 「Tab」 · 「Popup N」), otherwise a chosen name: a tab that a person deliberately named 「View 2」 also becomes automatic · all old tabs are chosen names: the old window title stays as 「View N - Engram:<n>」. Rejected = user decision 2026-10-23.
- **Empty name = revert to the automatic name** (the branch of PRD review round 1 point ⑥) — to make the screen and `tab.rename` the same, the rejection of an empty argument in `tab.rename` would have to be removed, so a `tab.rename` called with an unfilled shell variable would erase the name instead of failing. Rejected = user decision 2026-10-23. Putting reverting behind an explicit argument · a separate command is not rejected but out of scope (PRD §2 — main-agent proposal).
- **The D17 gate as a negative regex of violation shapes** (TRD edition 0.3 one line · the four branches of review 1) — it kept leaking on `Other =>` · `other | other =>` · `other @ &_ =>` · the range being cut by a column-0 `}` in a raw string · false positives on comment text (TRD §10-4 · main-agent decision U1 review 2 · 2026-10-24). A positive check that lets only the allowed shape pass does not need that enumeration. Strength of rejection = review measurement.
- **Tighten the D17 gate to catch even the three deliberately deceptive shapes** (U1 review codex FIX — a raw string containing a fake `match` · `SlotContent::<새 변형>` inside a string · returning early through a grouped-branch helper before the exhaustive `match`) — it is a limit of a text-check gate and the gate's purpose is preventing mistakes (code review looks at deliberately deceptive shapes — invariant 4). Rejected = user decision 2026-10-25 (U1 review · commit `4cefce48` 「사용자 수락(글자 검사 게이트의 한계 · 목적은 실수 방지)」).

## 근거

- User decisions in PRD §5-1 — Q6 · D16 · empty name (2026-10-23) · T2 (2026-10-24).
- Peers (PRD R4 — the peers the main agent cited at decision time · there is no survey document): WezTerm (working folder name · the name a person sets if changed by hand) · Windows Terminal · tmux (changing it by hand turns `automatic-rename` off) · the precedent for the title shape = Excel `Book1.xls:2` (survey `docs/research/window-identity-display-2026-10-23.md` conclusion 1).
- Tauri 2.11.3 facts (U4 review source reading — TRD §4-4): `run_on_main_thread` called on the main thread runs on the spot · at `Destroyed` Tauri removes the window before the user handler — so the title work first checks whether the window exists, and a late job that arrives after forgetting does not revive the ledger entry.

## 영향 / 불변식

- **Invariant 2** — any write that changes the active tab · the tab effective name · the number raises `version` and emits that window's `WindowTabsPayload`. If violated, the web drops that notification and the OS title stays stale.
- **Invariant 4** — do not put a wildcard or a grouped-name branch in `slot_label`. The deliberately deceptive shapes the gate cannot catch (a raw string containing a fake `match` · `SlotContent::<새 변형>` inside a string · returning early through a grouped-branch helper before the exhaustive `match` — TRD §10-4) are looked at by code review. That the gate does not catch those three was accepted by the user (U1 review · commit `4cefce48` — 「사용자 수락(글자 검사 게이트의 한계 · 목적은 실수 방지)」 · 2026-10-25).
- The words are a shell constant table, so there are two places with the web i18n — T-68 merges them.
- Accepted (TRD §5-7 — main-agent decision · U3b review 2026-10-25): the rename of a sleeping or dead agent does not show in the tab until that agent comes alive again · the parties that emit `AgentListUpdated` have no order among them, so an old list can briefly revive an old name (the real fix = a list revision number in the protocol — out of scope).
- There is no path to revert a once-chosen name to the automatic name (PRD §2 — out of scope). If you go back down to an older build, the chosen names go back to automatic (TRD §3-3).
- Anchors — put `// ADR-0301` on `layout/tab_name.rs` (`slot_label` · `word` · the effective-name calculation) · `apply::agent_names_updated` · the title revision decision (`chrome::book`).
