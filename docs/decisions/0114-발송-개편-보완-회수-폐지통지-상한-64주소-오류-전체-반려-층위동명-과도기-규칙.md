# ADR-0114: 발송 개편 보완 — 회수 폐지·통지 상한 64·@주소 오류 전체 반려 층위·동명 과도기 규칙

- 상태: 확정 (2026-07-29, 근거: 사용자 결정 — spec 개정 /review doc full 2인 적출 갈림길 4건, 질의응답으로 개별 확정)
- 관련: Amends ADR-0107 (결정 2 압력 회수와 결정 1 NOTICE_CAP 20) · Amends ADR-0108 (결정 2 REQUEST_CAPACITY 반려 층위) · ADR-0111·0112(발송 개편 본체 — 이 ADR은 그 리뷰 라운드의 보완 결정) · ADR-0115(동명 근본 해결 — 스폰 이름 유일성, 쌍) · `docs/process/S18-messaging-v1/spec/messaging-v1-spec.md` §3·§4·§5·§6

## 맥락

ADR-0111/0112를 spec에 반영한 개정을 `/review doc full` 2인 적대 리뷰(doc-aware 수호 + cross-family blind)가 검증하며 정책 갈림길 4건을 적출했다 — 전부 ADR-0111이 정하지 않은 빈틈이라 사용자 결정으로 개별 종결했다.

## 결정

1. **압력 회수 폐지.** 보관함(message 레인) 가득 = 즉시 그 수신자 행 실패(`MAILBOX_FULL`), 회수 시도 없음. 근거: 결박 폐지(ADR-0111 결정 6) + 부재 반려(결정 1)로 "배달 불가 확정 잔해" 카테고리가 소멸해 회수 기준이 논리 공집합이 됐다(리뷰 적출 — 워커의 재정의 기준으론 회수 대상이 존재할 수 없음). TTL 만료분 청소는 60초 주기 sweep이 유일 경로.
2. **다중 request 타임아웃 통지 = 계약별 1건 유지 + NOTICE_CAP 20 → 64 상향.** 병합 시스템은 만들지 않는다(필요 실증 시 추가 — 사용자). 레인 초과 시 최고령 통지 은퇴 규칙 유지. 유실 규칙은 단건 request N발과 동일 — 개편이 신설한 경로가 아니다(리뷰 프레이밍 정정: 발신자가 idle이면 통지가 즉시 꽂혀 적체 자체가 드물다).
3. **@주소 오류 = 전체 반려 유지 + 층 분리 명문화.** 이름 부재 = 런타임 상태 → 수신자 행 실패(부분 진행) / @주소 오류(미존재 주소) = 주소 공간 오류 → 전체 반려(발신자가 고쳐 재발송). `GROUP_EMPTY` 전체 반려는 **최종 수신자 집합이 공집합일 때만** — `["@all", 자기이름]`에 생존자가 발신자뿐이면 @all 기여 0 + 명시 지목 1행 배달(두 조항 모순 해소).
4. **동명 과도기 규칙.** @all 펼침에서 동명(살아있는 중복 이름)은 `RECIPIENT_AMBIGUOUS` 행 실패로 명시("전원에게"의 명문화된 예외). 근본 해결 = ADR-0115(스폰 이름 유일성)가 이 모호 클래스 전체를 소멸시킬 예정 — 그때까지의 계약이다.

## 거부한 대안

- **회수 기준 확장(TTL 경과분 + 로스터 부재분 회수)** — 위협이 소멸했는데 장치만 유지하는 비용, TTL 청소는 60초 sweep과 중복. 사용자: "회수 돌리지 마".
- **타임아웃 통지 메시지당 병합** — 병합 시스템 신규 추가 필요, 발생 빈도 낮음. 사용자: 필요시 추가.
- **통지 유실 명시 수용(cap 20 유지)** — 상수 상향이 더 싸고 유실 창 자체를 줄임.
- **@주소 오류 행 실패 강등** — "없는 게 있으면 안 되지, 고쳐서 다시 보내라"(사용자). 주소 오류를 부분 성공으로 흡수하면 오타가 반쯤 성공한 채 지나간다.
- **@all 실체(id) 단위 펼침(동명 우회)** — 파킹·장부·계약이 전부 이름 키라 실체 키 병행 트랙 연쇄 재설계 필요 — 비용 과다(ADR-0115가 더 싼 뿌리 해결).

## 근거

- 리뷰 실적출: doc-aware 수호(reviewer-deep) findings #2(회수 공집합)·#3(통지 레인)·#4·#5(@주소 층위)·#9(동명×@all) + blind(codex) F1(혼용 모순). 판정 FIX/FIX 일치.
- 사용자 질의응답 확정(2026-07-29, 4건 개별): 회수 폐지 / 기존 통지 로직 유지+상한 상향(단건 N발 동치 지적은 사용자가 정정) / @주소 전체 반려 / 동명은 스폰 유일성으로 뿌리 해결.

## 영향 / 불변식

- mailbox의 압력 회수 분기 제거(ADR-0107 앵커 지점 수술 대상) · `NOTICE_CAP=64`.
- `REQUEST_CAPACITY` = 수신자별 행 실패 + 그 수신자 미배달(계약을 못 연 request는 배달하지 않는다 — 추적 없는 request 배달 금지). ADR-0108의 은퇴 정책(mark-and-sweep·은퇴 가능 조건)은 불변.
- `GROUP_EMPTY` 판정 시점 = 해석 완료 후 최종 집합 기준(원소 단위 아님).
- 동명 행 실패는 과도기 — ADR-0115 구현 후 사문화 예정(코드 제거 여부는 그때 결정).
