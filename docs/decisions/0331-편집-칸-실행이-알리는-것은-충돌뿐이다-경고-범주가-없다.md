# ADR-0331: What the edit area and a run report is conflicts only — there is no warning category

- 상태: 제안 (2026-10-31, basis: user decisions 2026-10-18 · B3 (2026-10-19) + main M19 · G28 · TRD §7 22)
- 관련: ADR-0337 (codex terminal notice — a user exception) · ADR-0332 · S25 draft AA (unnumbered) · PRD R22 · R51

## 맥락
What do the edit area and a run report to the user and the LLM?

## 결정
1. What is reported is conflicts only — there is no warning category. A conflict line = all the entries involved + the path each came by · the same line as the run-block reason.
2. The problem list above the edit area (B3) only gathers those lines and the line states (not found · error) at the top, and does not revive a warning category.
3. The list of non-blocking notices `notices` (what the codex terminal did not load · dimmed lines not loaded on this backend · schema dimming — M19 · G28) is a factual notice, not a warning category. The codex terminal notice is a user exception of P4-FINAL.

## 거부한 대안
- **Yellow warning lines** (「다음 실행은 새 대화」 · raising the codex size limit · the share of context taken · automatic relink) — rules such as which edit calls for a new conversation can change, so the screen would have to compute along with them, and the old conversation stays in the old list and is not lost (user reason · 2026-10-18).

## 근거
User decision 2026-10-18.
