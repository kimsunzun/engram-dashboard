# ADR-0148: A slot with no agent freezes its content, dims it, and shows a symbol

- 상태: 확정 (2026-08-18, grounds: user decision) · 부분 폐기 by ADR-0149 (single decision of agent absence) · 부분 폐기 by ADR-0165 (the scope of the no-text clause is widened to the veil shared by the three slots)
- 관련: ADR-0145(empty state decision) · ADR-0146(collapse retired) · ADR-0019(termination classification) · ADR-0163(meaning and comparison rule of the incarnation marker) · ADR-0164(reattach trigger · subscription deps) · ADR-0226(the takeover loading decision `awaitingHistory` folding liveness is intended — it is separate from the empty state decision, so it is not an amendment of this ADR (interpretation) · pins the veil's pointer pass-through as a user decision (2026-09-24) — that ADR's 「구현 중 정정」) · `src/components/slot/RichSlot.tsx` · Amended by ADR-0149 (single decision of agent absence) · Amended by ADR-0165 (the scope of the no-text clause is widened to the veil shared by the three slots)

## 맥락

The empty state decision of ADR-0145 looks only at "restore complete + 0 conversation items + not yet sent" — **it does not ask whether the agent is alive.** So an agent that is already dead also passes the condition if it has no history, and the mascot and "Claude Code" appear, and **a dead slot looks like "이제 시작하면 됨"** (gloss: you can start now). The only signal of death is one line of text inside the disabled input box, which does not catch the eye. Pulled out by review (2026-08-18) → user confirmation.

While examining a plan to plant a large text in the center, the user changed direction: do not explain the state in words but tell it **through the mood of the whole screen**.

## 결정

1. **Decision criterion = "the agent this slot points to is absent right now."** A process that died (`Exited`/`Killed`/`Failed`) and a connection that dropped so it cannot be reached are treated **the same**. From the user's viewpoint both are the state of "the targeted agent is absent."
2. **The screen content is not reset.** If there is a conversation, it stays; if it was the empty state (mascot), it stays — it is frozen as it looked at that moment. If there is already nothing for a special reason, that empty screen is left as it is too.
3. **Dim the whole slot to death and lay one symbol in the center.** The icon is taken from the existing icon set.
4. **No explanatory text is put in.** User instruction (2026-08-18): "화면에 정보 남기는 건 하드하게 하지 말고 자연스럽게." (gloss: do not leave information on the screen in a hard way, do it naturally.) The existing disabled treatment and text of the input box are left as they are.

## 거부한 대안

- **Show a state sentence large in the center** (「에이전트가 종료되었습니다」 and the like) — even candidate wordings were drawn up, but the user rejected it. The judgment is that planting a sentence in the middle of the screen is "hard," and dim + symbol conveys the same information less loudly.
- **Show nothing (a black screen)** — it goes back to "뭐가 뜬 건지 모르겠다" (gloss: I cannot tell what came up), the starting point of this work.
- **Erase the content and leave only the state** — if the conversation from before death disappears, you cannot tell what the slot was doing. Frozen, the content itself is the context.
- **Express death and connection loss differently** — main proposed it (death is per slot and loss is whole-scope, so their natures differ). The user rejected it: the decision criterion is the single one, "the agent I targeted is absent," and the user need not distinguish the causes beneath it.
- **Add next-action guidance alongside** (「우클릭으로 다시 시작」 and the like) — it was not confirmed that a path to revive through slot right-click really exists. Guidance that does not exist is better absent.

## 근거

- **User decision (2026-08-18)** — the decision criterion · content freeze · dim + symbol · no text were all specified by the user.
- **Review finding** — the doc-aware reviewer caught "a terminated agent also draws the first-run screen if it has 0 items." The grounds are the asymmetry: ADR-0145 decision 8 deliberately excluded the empty state for *subscription failure*, while *agent death* was going the opposite way.

## 영향 / 불변식

- **Liveness is not folded into the empty state decision** — the decision stays as the three conditions of ADR-0145 decision 1 (restore complete · 0 items · not sent) (`showEmpty` in `RichSlot.tsx`). What this decision requires is not **not drawing** the mascot but **covering** it — liveness sits on the overlay layer above, not inside the decision. If liveness is folded into the decision, a dead slot draws an empty screen instead of the mascot and breaks decision 2 (content freeze).
- **The dimming is a display layer** — it does not touch data · subscription · accumulation. Freezing is not "not drawing" but "leaving as is."
- **Death and disconnection went into the same commit together — do not look for a half implementation** — the disconnection side needed the connection state to reach this component, and if the wiring was expensive there was room to apply only death first, but that condition did not trigger. It ended with two lines that **only read** the existing connection state surface (`connected` in `RichSlot.tsx`), and the condition of not creating a new global handle or a new store attaches there. Decision 1 is the implemented state, not a target state.
