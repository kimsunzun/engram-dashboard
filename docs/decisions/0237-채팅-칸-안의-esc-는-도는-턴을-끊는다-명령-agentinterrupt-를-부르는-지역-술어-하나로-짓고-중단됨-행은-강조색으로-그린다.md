- 관련: Amends ADR-0235 (decision 10, UI stop shortcut on hold) · TRD `docs/process/S21-chat-ux/trd.md`(§1 U6 · U8 · §3-1 · §3-2 · §3-3 · §3-6 · §7 FE-1.2 · FE-2 · §8-2 F2 · §10 0237) · research `docs/research/chat-ux-four-features-2026-09-27.md`(§2) · ADR-0238(claude JSON interrupt — the claude transport this command reaches) · ADR-0241(orange 「거부됨」 — separate from the interrupt-row color) · ADR-0055 · ADR-0167(command registry · a window command without `help` = in-window only) · ADR-0173(orange warning token `--status-blocked`) · ADR-0155(the command declaration sits next to the producer) · `docs/tracking.md` T-42(shortcut system — on hold) · step-log S21 · Amended by ADR-0243 (decision 6: for claude the display row carries the accent and that turn's interrupt row is omitted) · Amended by ADR-0244 (decision 1, optimistic state unchanged, and decision 4, the predicate, gain an interrupting display and an ignored state)

## 맥락
ADR-0235 decision 10 was 「UI 정지 버튼·단축키는 지금 넣지 않는다」 (we do not add a UI stop button or shortcut now) [user 2026-09-26] — 「나중에 단축키 시스템 만들때 넣을거임」.

The behavior of the four chat-screen items (scroll follow · Esc interrupt · tool-call grouping · claude text streaming) was agreed with the user in the previous session's handoff memo, and the PRD was skipped (user 2026-09-27 · TRD head). The orchestrator made the design decisions and the TRD turned them into an implementable spec. This ADR records the key, command and display of the Esc interrupt among them — the interrupt on the claude path is ADR-0238, and the display of an interrupted tool row is ADR-0241.

We add Esc now, but the shortcut system is still on hold (`docs/tracking.md` T-42). So Esc is built not as an entry in a shortcut table but as one **local predicate** that calls a command, and when T-42 sets up the keybinding table it moves into that table as one line (TRD §1 last paragraph).

## 결정
Notation — **[사용자]** = a decision the user answered (TRD §1 U#) · **[메인]** = an orchestrator decision (TRD §11) · **[고름]** = an internal implementation with no user-visible effect, so the TRD picked it.

1. **A bare Esc inside a JSON chat slot (RichSlot) = interrupt the running turn.** When it fires it calls `e.preventDefault()` and `fireAndForget('agent.interrupt', { agentId })` (`src/commands/dispatch.ts:15`) — a human key and an LLM shake the same handle. ★It does not change the optimistic state★ — that it was interrupted is announced by the turn-end event (for claude, receiving the response is not 「멈췄다」 (it stopped) — ADR-0238). ★It does not touch the text in the input box.★ The PTY/xterm slot (`TerminalSlot`) does not change by one byte — Esc goes to the PTY as it does now.
2. **The command `agent.interrupt` = window + daemon bus** (precedent `agent.cancelQueuedInput` — the declaration is in the agent crate, the hosting is in the daemon · the daemon crate does not change).
   - The window command (`src/commands/agentCommands.ts`) calls `agentClient.interruptAgent` (`src/api/protocolClient.ts:988-992`) and returns `{ outcome: 'requested' }`. ★No `help`★ — the daemon answers the same name on the bus. An input-lease refusal is surfaced with the `CONFLICT:` prefix — [고름] that mapping is pulled out into a small function and shared with `cancelQueuedInput`.
   - Bus declaration (`crates/engram-dashboard-agent/src/commands.rs`): `catalog_version` 5 → 6 · `#[effect(Write)] #[since(6)]` · `"agent.interrupt" => args AgentInterruptArgs { target: String } -> ok AgentInterruptOk { outcome: String } errors [NOT_FOUND, CONFLICT]`. `outcome` = `requested` (the interrupt was sent — whether the turn actually stopped is announced by the turn-end event). It is included in `INPUT_AFFECTING` — the same as the WS `Interrupt` looking at the lease (`connection_core.rs:1222-1230`).
   - Outcome mapping: `Ok` = `requested` · no live session = NOT_FOUND · `PtyError::Unsupported` (codex 「중단할 턴이 없다」 (there is no turn to interrupt) `backend/codex/transport.rs:4045-4061` · claude's turn-open gate closed — ADR-0238 · a transport without the capability) = CONFLICT (「끊을 턴이 없다 · 이 에이전트는 끊기를 지원하지 않는다」) · anything else = INTERNAL.
3. **Scope = anywhere inside that chat cell** [사용자 U6] — the input box + the conversation body. The cell root receives focus by click (`tabIndex={-1}` + `outline-none`). Constant `ESC_SCOPE: 'slot' | 'input' = 'slot'`. The handler is the root `onKeyDownCapture` — the input box's `onKeyDown` does `e.stopPropagation()` first (`RichSlot.tsx:471-472`), so by bubbling the Esc in the input box does not reach the root. Capture covers the input box and the body with one handler.
4. **The firing condition is one pure predicate** `isInterruptEscape(e, ctx)` (new `src/components/slot/interruptKey.ts`) [고름]. It is true when **all** of the following hold:
   - `e.key === 'Escape'` · no modifier key · `!e.repeat`
   - not during IME composition (`!e.nativeEvent.isComposing && e.keyCode !== 229`)
   - `!e.defaultPrevented` (a Radix layer consumes it first at the document capture) · no overlay marker `[data-engram-overlay]`
   - `streaming` · `!agentUnavailable` · `agent?.capabilities?.control?.interrupt === true`
   - (only when `ESC_SCOPE = 'input'`) the target is the input box

   The predicate does not read the DOM — the root handler measures whether an overlay is present and passes it in `ctx`. [고름] We put `data-engram-overlay` on four overlay roots (`SlotContextMenu` · the `AgentMonitoringPicker` backdrop · the `AgentList` and `PresetPalette` row menus) — it measures the three that close with a document-wide Esc (research §2-1) and the right-click menu with one marker. **This predicate moves as is into one line of the T-42 keybinding table as its `when`** — the interrupting action lives in the command, so there is nothing to touch when moving it.
5. **We do not touch the global shortcut guard (`src/commands/keybindings.ts:11-35`)** — it is load-bearing. We do not put Esc in `BINDINGS` (`:54-57`).
6. **We slightly emphasize the turn-outcome 「중단됨」 row** [사용자 U8] — only the `interrupted` branch of `OutcomeRow` (`src/components/slot/StructuredTextView.tsx:289-316`) becomes bold + the theme accent color `var(--accent)` (dark `#4a9eff` · light `#0066cc` · e-ink black). The icon (`CircleStop`) and the text (「응답이 중단됐습니다」) stay · `failed` and `unknown` are the same as today. It is neither red (failure) nor orange (`--status-blocked` = refusal — ADR-0241), so the three are told apart · 「중단·모름은 붉게 칠하지 않는다」 (`StructuredTextView.tsx:286-287`) stays as is. The user: 「너무 눈에 띄지 않음?」 → 「색깔은 살짝 강조해야될것같음」. We fix the text and color after seeing it (「나중에 보고 개선하면 되지」).
7. **We reverse ADR-0235 decision 10 within this scope** [사용자 — previous session's handoff memo `.claude/handoff/history/20260927-140032-midturn-master-머지-공개저장소-정리-다음은-브랜치47-결정-기능4건-설계.md:16`: 「에이전트 돌리다가 말치다 끊는거」 · 「Reverses ADR-0235 decision 10」 · the scope is U6, the color is U8].
   - **What changes = only the interrupt key (Esc).** Without waiting for the shortcut system, we add it now as a local predicate that calls the command `agent.interrupt` (decisions 1 · 4).
   - **What stays = the other two of decision 10.** ① The UI stop button stays on hold — this round adds no button (there is no button in TRD §3-1, the place that changes). ② The shortcut system stays on hold — U6 · `docs/tracking.md` T-42 (see 「거부한 대안」 below).

## 거부한 대안
- **Put Esc in the global shortcut table** [메인] — it would require opening the global shortcut guard (`src/commands/keybindings.ts:11-35`), and that guard is load-bearing (TRD §3-1).
- **Build the shortcut system now** [사용자 — **on hold, not a rejection** (together with U6 · `docs/tracking.md` T-42)] — Esc is now a local predicate that calls the command `agent.interrupt`, and when T-42 sets up the keybinding table it moves into that table as one line (decision 4).
- **Only when the input box has focus** (`ESC_SCOPE = 'input'`) [사용자 U6 — chose anywhere in the cell] — the recommended option (anywhere in the cell) lets you interrupt even while clicking the body to read. This alternative matches the peers (Claude Code · codex · paseo) and had the advantage of no focus change. It is cheap to revert: one constant + one line of root `tabIndex`.
- **Double Esc (clear text · rewind)** — out of scope this time (TRD §1 last paragraph). The TRD gave no other reason.
- **Leave the interrupted row in today's shape (`text-muted`)** [사용자 U8] — the user: 「너무 눈에 띄지 않음?」.
- **Keep only the window command, without the bus** [고름] — only a window command without `help` is left, and an LLM on the bus cannot call the interrupt (TRD §3-3 size decision — the bus share is one declaration · one trait method · one verb · tests, the same share as `cancelQueuedInput`).

## 영향 / 불변식
- **An Esc before the turn opens = no-op.** The frontend `streaming` turns on optimistically right after sending and turns off late, at the turn-end event. An Esc at the front end is refused by the transport with `Unsupported` (codex · claude's turn-open gate — ADR-0238) and `fireAndForget` swallows it as a warn — the user can press it again. A late Esc at the back end can interrupt the next turn in claude (a residual race — ADR-0238).
- **One control surface** — the registry command and the bus command have the same name and there is no new global handle (CLAUDE.md 「LLM-우선 제어」). The window command has no `help` because the daemon answers the same name on the bus (the same reason as the `cancelQueuedInput` comment at `agentCommands.ts:130-133`).
- **The global shortcut guard is unchanged** — putting Esc in `BINDINGS` goes beyond this decision (that is what T-42 will do).
- **Esc with a right-click menu open = nothing happens** (no interrupt · the menu stays) — `SlotContextMenu` has no Esc handler and closes only by an outside `mousedown` (`SlotContextMenu.tsx:110-114`). We do not add Esc-to-close this time.
- **Generated files** — `crates/engram-dashboard-agent/bindings/AgentInterruptArgs.ts` · `AgentInterruptOk.ts` · `commands.schema.json` are baked by the tests and the CI sync gate is their owner — we do not write them by hand.
- **Known risk of U8** — chat links may use the same accent color. We fix it after seeing it (the user).
