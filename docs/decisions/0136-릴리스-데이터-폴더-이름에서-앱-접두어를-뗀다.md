# ADR-0136: 릴리스 데이터 폴더 이름에서 앱 접두어를 뗀다

- 상태: 확정 (2026-08-14, 사용자 지적 — 접두어가 자기 부모를 되풀이한다)
- 관련: Amends ADR-0134 (릴리스 데이터 폴더 이름) · ADR-0100(릴리즈 패키징 포터블 폴더) · `crates/engram-dashboard-discovery/src/lib.rs`(`RELEASE_DATA_DIR`)

## 맥락

ADR-0134 결정 1이 릴리스 데이터 폴더를 `<실행 폴더>/engram-data/`로 정했다. 이름은 별도 심의 없이 **디버그 쪽 이름(`.engram-data`)을 그대로 따라간 것**이고, 결정 기록에도 이름에 대한 논의가 없다.

사용자가 지적했다 — 그 폴더는 사용자가 이미 이름 붙인 배포 폴더 **안에** 고정으로 살고, 밖으로 나갈 일이 없다. 그런데 자기 이름으로 자기 부모를 다시 설명한다. 더해 **같은 폴더의 형제 `prompts/`는 접두어가 없다.** 하나만 접두어를 달면 규칙이 아니라 습관이고, 규칙으로 만들려면 나머지 전부에 붙여야 한다.

## 결정

1. **릴리스 데이터 폴더 = `<실행 폴더>/data/`.** 앱 접두어를 뗀다.
2. **디버그 쪽 `.engram-data`는 그대로 둔다.** 저장소 루트에는 다른 폴더가 많아 접두어가 실제로 구분 값을 하고, 앞의 점이 숨김 역할을 한다. **두 이름의 비대칭은 의도된 것이다** — 대칭을 맞추려 하지 말 것.
3. **`.gitignore`는 폴더 이름이 아니라 비밀이 든 파일 이름으로 막는다** — `**/data/daemon.json` · `**/data/agents.json`.

## 거부한 대안

- **`engram-data/` 유지** — 부모를 되풀이하고 형제와 어긋난다. 기각 근거 = 논리 + 사용자 판단.
- **`.gitignore`에 `data/` 규칙** — 이름만 보는 규칙이라 저장소 안 **무관한 `data` 폴더를 전부 삼킨다.** 실측으로 확인: `src/data/agents.ts` · `src/data/config.json` · `packages/data/index.ts`가 전부 무시 대상이 된다. 기각 근거 = 실측(`git check-ignore`).
- **`.gitignore` 규칙을 아예 빼기(기존 `target/`·`release/`가 덮으니 불필요)** — 실측으로 반증됐다. 조립 출력 두 곳은 이미 덮이지만 **두 경로가 안 덮인다**: 배포판 zip을 저장소 안 임의 위치에 푼 경우, 그리고 `build-release.ps1 -OutDir`를 다른 곳으로 준 경우(`launch/빌드.bat`이 이미 그 플래그를 쓴다). 기각 근거 = 실측(`git check-ignore` 경로별 확인).
- **경로로 고정한 규칙(`/release/data/` 등)** — 실제 조립 출력은 `release/`·`launch/release/` 둘뿐이고 **이미 통째로 무시되고 있어** 순수 중복이다. 기각 근거 = 실측.
- **`presets.json`도 함께 무시** — 자격증명이 없고, `data/` 아래 `presets.json`은 앞으로 가장 그럴듯한 오탐 후보다. 기각 근거 = 논리(막을 대상은 비밀이지 데이터 일반이 아니다).

## 근거

- 사용자 지적(2026-08-14): "engram 폴더 내에 데이터 폴더가 고정인데 접두어가 의미 있나. 붙인다는 건 다른 모든 것에도 붙여야 한다는 거잖아."
- **지금이 가장 싼 시점** — 이 이름으로 릴리스가 나간 적이 없어 이전할 데이터가 0이다(ADR-0134 결정 5와 같은 근거).
- 메인이 처음 든 반대 근거(`.gitignore`가 이름에 기댄다)는 **과장이었다** — 그 파일은 이 저장소 안에서만 효력이 있고 조립 출력은 이미 무시된다. 최종 사용자가 자기 저장소에 풀면 우리 규칙은 애초에 무관하다. 다만 위 거부 대안대로 **규칙을 아예 빼는 것도 실측으로 반증**돼, 이름이 아니라 파일로 막는 3안으로 갔다.

## 영향 / 불변식

- **ADR-0134 결정 1의 폴더 이름만 바뀐다.** 위치(실행 폴더 하위)·하위 폴더로 묶는다(결정 2)·이전 안 함(결정 5)·디버그 무변경(결정 6)은 그대로 살아 있다.
- **ADR-0134 §영향의 `.gitignore` 관련 문장이 낡았다** — "`.gitignore`의 `engram-data/` 규칙이 함께 덮는다"는 이제 파일 두 개를 이름으로 막는 규칙이다.
- **`RELEASE_DATA_DIR` 상수에 "되살리지 마라" 주석이 달려 있다** — 접두어를 다시 붙이거나 디버그 이름과 대칭을 맞추려는 시도를 막는다. 코드가 이 결정의 발견 표면이다.
- **비밀 파일 이름이 곧 무시 규칙의 열쇠가 됐다** — `daemon.json`·`agents.json` 파일명을 바꾸면 `.gitignore`도 같이 고쳐야 한다. 종전(폴더 이름 한 줄)보다 결합이 늘었고, 그 대가로 오탐이 사라졌다.
