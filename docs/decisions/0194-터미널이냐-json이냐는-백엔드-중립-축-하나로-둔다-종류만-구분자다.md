# ADR-0194: Terminal vs JSON is one backend-neutral axis — only the kind is the discriminator

- 상태: 확정 (2026-09-11, basis: user decision)
- 관련: ADR-0044(input encoding and output cleaning — the decision that first made this axis) · ADR-0192(backend defaults match claude) · ADR-0188(permissions as a neutral axis — a precedent of the same shape) · ADR-0191(transport creation) · ADR-0004(isolating backend knowledge) · `docs/process/S21-codex-backend/trd-phase2a.md` §10-7 ① · step-log S21

## 맥락

Once codex had two transports (a terminal conversation screen · app-server), it needed a place to hold 「이 에이전트를 어느 쪽으로 띄우나」 (“which way do we launch this agent”), and how to express that was the last open item of Phase 2a (§10-7 ①).

★**But that axis already exists, is already used as a shared one, and carries one backend's name.**★ The facts:

- `crates/engram-dashboard-agent/src/profile.rs:29-37` — `ClaudeOutputFormat { Terminal, StreamJson }`. **Its values are already neutral**, and the type's own comment says 「claude 출력 포맷 — **프로세스 기동 방식(= transport)과 프론트 렌더러를 함께 가른다**(ADR-0044)」 (“claude output format — **decides both the process launch method (= transport) and the frontend renderer**”). So it is not an output format but a **mode axis**.
- ★`crates/engram-dashboard-agent/src/backend/gemini/mod.rs:135`·`:179` — **the gemini backend already borrows that type**★ (`crate::profile::ClaudeOutputFormat::Terminal`). A third backend already uses a type that carries another's name.
- `crates/engram-dashboard-agent/bindings/AgentNewArgs.ts:17` — **the name that goes outside is already neutral** (`output_format?: AgentOutputFormat`). Only the Rust type name lags behind.

## 결정

**Terminal vs JSON is one backend-neutral axis.**

- **Only two things are exposed outside — ① the agent kind (Claude · Codex …) ② this mode axis.** Nothing else is exposed under a different name or shape per backend (user decision).
- **Rename the Rust type to a neutral name** — match the wire name that is already neutral (`AgentOutputFormat`). ★Fix the claude side too (user decision) — leaving only one side alone keeps today's state of 「남의 이름을 빌려 쓰는」 (“borrowing another's name”).★
- **Add that field to codex.** `#[serde(default)]`, default = terminal.
- ★**The on-disk contract does not change**★ — the stored field name (`output_format`) and values (`Terminal`·`StreamJson`) stay as they are. So **there is no migration**: old claude profiles are read as they are, and old codex profiles have no such field, so they are absorbed into the default (terminal). The precedent for that absorption is already written in the comment at `crates/engram-dashboard-agent/src/profile.rs:47-52` (user decision 2026-09-07 — 「칸을 더할 땐 `#[serde(default)]` 를 달면 옛 프로필이 그대로 흡수된다」 (“when adding a field, attach #[serde(default)] and old profiles are absorbed as they are”)).
- **What the mode selects is decided inside each backend** — the same 「JSON」 is a headless NDJSON stream for claude and the app-server for codex. That difference stays inside `backend/<name>/` and the axis is shared (ADR-0004 · the transport creation path of ADR-0191 reads this value).

## 거부한 대안

- **Each backend has a type under its own name** (today's state + one more for codex) — ★that state is already leaking★: gemini borrows the claude-named type (the `file:line` above). Each time a backend is added, the same axis either grows under a different name or borrows another's.
- **Mix the mode into the free-form `extra_args` argument string** — there is no new field, so the change is the smallest, but **the code cannot tell whether that string is a mode choice or arguments the user appended.** ADR-0188 already rejected this shape on the permission axis for the same reason (「자유 문자열 인자에 섞어 흘리면 공통인지 전용인지 구분이 안 보인다」 (“if it is mixed into a free-form string argument and passed along, you cannot see whether it is common or specific”)).
- **Split terminal codex and JSON codex into separate agent kinds** — the declaration-table check would split automatically, but the user would see more kinds, and the axis of this decision, 「종류는 도구, 모드는 축」 (“the kind is the tool, the mode is the axis”), would collapse.

## 근거

- The three `file:line` above are all of it — the axis is already shared, the values are already neutral, and the outside name is already neutral. This ADR **does not create an abstraction that was not there; it catches up on a name that lagged behind.**
- A direct application of ADR-0192 (match backend defaults to claude) — claude does it as a field, so codex does it as a field too.

## 영향 / 불변식

- **No migration** (the on-disk contract clause of the decision above). The stored file version is not bumped either.
- **`AgentCommand` is `#[serde(tag = "kind")]`**, so the kind is already the discriminator (`crates/engram-dashboard-agent/src/profile.rs:44-46`) — this decision tidies **outside** that discriminator.
- ★**The declaration-table tripwire must be fixed in the same change**★ — that table assigns **one tuple to one variant** of `AgentCommand::Codex { .. }` (`crates/engram-dashboard-agent/src/backend/mod.rs:779`, assertion `:800-802`), so if the mode is carried as a field, **the second mode does not go through that check.** If it is not fixed, the check stays green while measuring nothing.
- **Gemini's borrowing is cleaned up** — once the name is neutral, that backend no longer calls another's name.
- **Reopen triggers** — ① if a third mode appears that does not split into 「터미널이냐 JSON이냐」 (“terminal vs JSON”) (e.g. a remote transport method), reopen the value set of this axis ② when ADR-0188's permission value design lands, decide whether it and this axis sit in the same declaration bundle.
