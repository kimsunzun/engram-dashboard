# ADR-0330: Relink = pick one and the rest are linked by name — the scan does not suggest candidates

- 상태: 제안 (2026-10-31, basis: user decision B11 (2026-10-19 「ㅇㅇ 그게 더 자연스러운것같네」 — D10 resolved) · practice research 2026-10-18 · P1 · main M14)
- 관련: PRD R19 · ADR-0335 · research `docs/research/relink-and-error-popup-practice-2026-10-18.md` · §7 8

## 맥락
How do we relink a reference whose target file has disappeared (moved from outside, or because an operation was interrupted)?

## 결정
1. A line whose target is missing = 「찾을 수 없음 · [다시 연결] ×」. [Relink] = a search popover filtered to the same kind · the old name prefilled (our convenience · no peer basis) · the old parent folder is read again when it opens (M14).
2. When the user or the LLM picks one file, the rest are linked without asking — (a) all references that point to the same old path (b) among other not-found entries whose old folder was the same, those whose same name exists in the new file's folder (same kind only — M14). It is reported with 「N개 더 찾아 연결함」.
3. The scan does not suggest candidates · nothing is linked before a pick. From edition 1 (P1).

## 거부한 대안
- **Applying automatically by name alone** (memo 68) — no peer relinks by name before the user starts searching (§7 8).
- **At scan time, suggest one candidate with the same name and keep it blocked 「다시 연결 확인 대기」 until confirmed** (the D10 shape of 2026-10-18) — user 「ㅇㅇ 그게 더 자연스러운것같네」 (2026-10-19) · peers make the user find the first one by hand.
- **Picking one per entry** — practice = 「N개 더 찾음」 (§7 8).
- **A redirector file** (leaving a file at the old place that points to the new place) — the decision is the user's (memo 68 「No redirector files」 — the reason is not in the record). Basis (main 2026-10-31 — reported): there is nothing left for a redirector to do — moves and renames inside Engram fix references on the spot (ADR-0335 Decision 1 · memo 106 — user decision), and a move from outside is not seen by Engram (no watching — memo 99 · G43), so none can be left. The recovery path for that is the relink of this decision.
- (Question gone) **Relink across roots** — there is one root (ADR-0312 · G36), so there is no root to cross. It may be removed from the rejection list of §7 8 (document cleanup).
