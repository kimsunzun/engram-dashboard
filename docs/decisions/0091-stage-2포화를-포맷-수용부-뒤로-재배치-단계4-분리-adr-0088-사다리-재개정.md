# ADR-0091: Move Stage 2 (saturation) behind the format-acceptance part + split out stage 4 — re-amending the ADR-0088 ladder

- 상태: 확정 (2026-07-20, basis: the ADR-0090 Stage 2 pilot finding (policy isolation) + the result report + the user's reordering decision)
- 관련: Amends ADR-0088 (ladder order + stage 4 split (saturation moved behind the format-acceptance part; escaping deferred)) · ADR-0090(pilot execution design — the finding that grounds this amendment) · ADR-0086(dual entrance · immediate push — the main body stays valid)

## 맥락
The ADR-0088 ladder was **delivery correctness (saturation included) → then format**. But in the Stage 2 (context saturation) pilot (ADR-0090), a policy-compliant claude **decided that an agent-to-agent message carrying instructions (the `[message from ...]` envelope) was a prompt injection and isolated it** (confirmed directly in the transcript thinking trace, reproduced across many runs). The point: delivery (the bytes) is fine, but **acceptance** fails — the agent does not process the message at all, so whether the context is saturated or not, there is nothing to measure.

So to measure saturation, **"which framing gets a legitimate message accepted and processed" (the format-acceptance part) is a precondition**. In the ladder, saturation (old stage 2) depends on format work (part of old stage 4) — the order ADR-0088 assumed has been inverted. This finding changes the ladder order and the definition of stage 4, so ADR-0088 is **partially amended** (the remaining clauses stay valid).

## 결정
1. **Move saturation.** Move saturation (old stage 2) behind the format-acceptance part. New order: **format-acceptance part → saturation.** The main saturation run only makes sense once the "accepted message" baseline is in place.
2. **Split old stage 4 (envelope format + escaping) into two branches:**
   - **(4a) Format-acceptance part** — the framing/placement under which a legitimate agent-to-agent message is accepted and processed instead of being isolated as an injection (readability · compliance · **acceptance**). **Promoted to the critical path — the next thing to start.**
   - **(4b) Escaping (forgery defense)** — blocking a malicious body from breaking out of the envelope boundary. **Deferred (low priority, user decision 2026-07-20).**
3. **The entrance comparison (old stage 3) can go in any order** — not blocking. Any time.
4. **The remaining ADR-0088 clauses stay valid** — the decision criterion (sustained processing, not an immediate ack), the delivery semantics, escaping = the forgery-defense core, the harness safety requirements, and instrumentation first all stay as they were.

## 거부한 대안
- **Keep the original ADR-0088 order (saturation first)** — no message gets accepted, so there is nothing to measure saturation on. Delivery is fine, but the agent does not process it.
- **Switch the metric to task-channel retrieval and measure saturation now (fork a)** — valid and possible immediately, but it would measure saturation of the **task channel**, not of "real agent-to-agent messages" (a different measurement target). The user wanted to measure real message behavior and chose the reordering.
- **Pull escaping (4b) forward now** — with the format undecided, the escaping rules depend on the envelope delimiter, so rework is a risk (CLAUDE.md §0 "high-cost, uncertain = shell only"). Deferred.

## 근거
- **ADR-0090 Stage 2 pilot finding (certain):** the policy-compliant claude (`claude-sonnet-4-6`) isolated the envelope carrying instructions as an injection — every codeword/sender/id retrieval failed, and the pre-justification wording backfired. Details = `docs/process/S17-llm-control-surface/stage2-context-saturation-pilot-findings.md`.
- **User reordering decision (2026-07-20):** "포화 이상현상은 나중, 포맷 먼저" + escaping deferred + "진짜 메시지 거동을 재고 싶다".

## 영향 / 불변식
- **Next start = the format-acceptance part (4a) spike.** The main saturation run comes after it. If a later session tries to reverse the order and measure saturation first, this ADR is the anchor.
- **Format-acceptance measurement depends on the account** — an instruction applied to the account (instructions inside tool content = data) contaminates that account's claude's acceptance decision. On such an account, model-level acceptance cannot be measured cleanly (an account without the instruction is needed). Whether this isolation comes from the instruction or from model training is also settled by that measurement.
- **Escaping (4b) is deferred, but is promoted to mandatory when a local model is introduced** — local models have weak injection-resistance training, so without system-layer (daemon `wrap_message`) escaping they get breached. Deferred = not now, not unnecessary.
- **Decision = sustained processing stays** (ADR-0088). An immediate ack is not used as acceptance success.
