# ADR-0281: 데몬이 셸 명령 등록을 거절하면 셸이 OS 오류 박스를 띄운다 — 가름은 답 경계의 출처 타입이다

## 맥락

셸은 데몬에 붙을 때마다 자기 명령(창 · 탭 · 슬롯)과 웹뷰 명령을 **한 패킷으로** 등록하고, 웹뷰 명령이 바뀌면 차분을 올린다. 데몬은 자기 이름과 겹치면 `CONFLICT`, 이름 · 설명 길이나 개수 상한을 넘으면 `INVALID_ARGUMENT` 로 **패킷 통째** 거절한다 — 등록이 거절되면 그 셸의 명령이 다음 재연결까지 0 개라 LLM 이 창 · 탭 · 슬롯을 못 만진다. 지금은 그 거절이 warn 로그 한 줄로만 남는다.

2-1(ADR-0270)이 셸에서 agent crate 를 걷으며 셸의 예약 이름 거르기(데몬 이름 목록이 agent 에 있었다)를 걷었으므로, 이름 충돌의 벽은 데몬의 등록 거절 하나다. ADR-0270 결정 4 는 「거절을 셸이 OS 메시지 박스로 띄운다 · LLM 통지는 두지 않는다 · 방법은 구현 때 고른다」를 정했다. 이 ADR 은 그 방법이다.

풀어야 했던 것: 셸의 대기 슬롯(`CommandReply` = `oneshot::Sender<Result<AgentEvent, String>>`)은 **데몬의 `Error` 답과 셸 로컬 실패(미연결 · 끊김 · 답 유실 등)를 같은 `Err(String)` 으로 접었다.** 끊김은 데몬 재기동 · 절전 복귀마다 흔하므로, 둘을 못 가르면 박스가 평범한 재연결마다 뜬다.

## 결정

1. **트리거 = 데몬이 등록 · 차분에 `Error` 로 답한 것 전부** — 코드와 무관하게(`CONFLICT` · `INVALID_ARGUMENT` · ★모르는 · 새 코드★). 그 답은 「적용되지 않았다」이고 결과가 같다. **빼는 것은 셸 로컬 실패뿐**이다.
2. ★**가름은 답 경계에서 남기는 출처 타입이다 — 문자열을 읽지 않는다.**★ 데몬의 짝 답은 대기 슬롯을 채우는 한 자리(`connection.rs`)에서 접지 않고 그대로 넣는다(`Error` 도 `Ok(AgentEvent::Error{..})`) — 그래서 슬롯의 `Err` 에는 셸 로컬 실패만 남는다. `classify_reply` 가 슬롯 결과를 `CommandFailure { Daemon { message }, Local(String) }` 로 가르고, 형제 `send_command_with_origin` 이 그 타입을 돌려준다. 기존 `send_command` 는 그것을 `to_string` 으로 접어 **기존 호출자가 받는 글은 바이트 단위로 같다**.
3. **두 자리** — 등록 결말 태스크(`RefusalSite::Register`) · 웹뷰 차분(`RefusalSite::Update`, `view_bus.rs`). `Daemon` → warn + 박스 · `Local` → warn 만. warn 라벨은 지금 것을 그대로 두되 **차분 자리의 `Daemon` 팔만 제 라벨을 얻는다** — 옛 라벨 「다음 재연결의 전량 등록이 해소한다」는 로컬 실패 쪽에 남긴다(그쪽은 재연결이 목록을 다시 싣고, 그래도 거절되면 등록 자리가 warn · 박스로 알린다 — 라벨은 낙관이지만 조용히 묻히지는 않는다). 데몬 거절이면 셸이 거절된 이름을 쥔 채라 다음 전량 등록도 거절될 수 있다(코드 리뷰 2026-10-07). 등록 자리의 라벨(끊김에도 「거절」이라 찍히는 선재 결함 — TRD §8 O4)은 그대로다.
4. **박스 = tauri-plugin-dialog 의 Rust API · 종류 `MessageDialogKind::Error` · `show`(막지 않음)** — `blocking_show` 는 쓰지 않는다. capability 를 늘리지 않는다(Rust API 는 IPC 를 거치지 않는다). 셸에 OS `cfg` 가 들지 않는다(OS 차이는 플러그인 안). 문구는 결과(LLM 이 그 명령을 못 쓴다)와 조치(원인이 된 명령 선언을 고친 뒤 다시 빌드)를 앞에 두고 데몬 문구 원문을 싣는다 — 코드별 문구는 두지 않는다. 차분 박스는 「원인을 고치지 않은 채 재연결하면 이 셸의 명령 등록 전체가 거절될 수 있다」를 함께 적는다 — 셸은 거절된 이름을 쥔 채라 선언이 그대로면 다음 전량 등록에 그 이름이 다시 실린다. 「될 수 있다」인 이유 = 재연결 전에 선언이 바뀔 수 있고, 차분에서만 나는 거절(남의 주인 이름 · 목록 겹침)은 전량 등록에서 다시 나지 않는다(코드 리뷰 2026-10-07 두 리뷰어).
5. **새 좁은 포트 `RefusalNotice`** — `DaemonEvents` 를 넓히지 않는 형제 포트다. 운영 어댑터 `TauriRefusalBox` · 시험 대역(`RecordingRefusals` · `NoRefusalNotice`).
6. **되풀이 억제 — 키 = (자리, 데몬 문구) · 수명 = 셸 프로세스.** 판정은 락 안, 포트 호출은 락을 놓은 뒤(ADR-0006). warn 은 매번 찍는다. ★**차분 자리는 다리의 순서 문(`outbound` — tokio `Mutex`)을 놓은 뒤 띄운다**★ — 차분 송신(`push_delta`)이 그 문 안에서 돌므로 데몬 문구를 돌려받아(`Option<String>`) `report_and_push` 가 돌아온 뒤 부른다. 박스를 그 클로저 안으로 되돌리지 말 것.
7. **LLM 에게는 알리지 않는다**(ADR-0270 결정 4 그대로 — 원인은 로그에 남는다).

## 거부한 대안

- **문자열 코드로 가른다(`CONFLICT:` · `INVALID_ARGUMENT:` 접두를 읽는다).** 기각 = 코드 — 코드 추가는 허용된 확장이다(`crates/engram-dashboard-command/src/error.rs` 의 `ErrorCode` doc 「코드 추가는 additive」). 모르는 코드가 오면 박스가 조용히 죽는다. TRD 리뷰 C1 이 걷었다.
- **트리거를 `CONFLICT` 로 좁힌다.** 기각 = 코드 — `INVALID_ARGUMENT` 거절(이름 128 B · 설명 4096 B · 주인당 512 · 전체 4096 — `roster.rs`)도 결과가 같다(등록 0 개 · 차분 미반영). TRD §8 O3.
- **슬롯의 `Err` 를 새 타입(`LocalFailure`)으로 바꿔 「슬롯 `Err` = 로컬뿐」을 컴파일러가 지키게 한다.** 기각 = 코드(번지는 범위) — 로컬 송신 일곱 자리 · `register_pending` · 시험 두 파일(`daemon_client/tests.rs` · `tests/daemon_client_pending.rs`)로 번진다. 최소 변경을 골랐고, 그 대가는 배치가 지킨다(아래 「영향」 첫 항목 · 실 소켓 시험이 잡는다).
- **`DaemonEvents` 를 넓혀 박스를 싣는다.** 기각 = 코드 — 그 포트의 doc(`daemon_client/events.rs`)이 넓히기를 금한다(emit 만 끊는 포트).
- **`blocking_show`.** 기각 = 코드 — 플러그인 소스가 「main thread 에서 쓰지 말 것」을 적고(tauri-plugin-dialog 2.7.1 `lib.rs:351-358`), 연결 태스크가 멈춘다.
- **억제를 연결마다 한 번으로.** 기각 = 코드 — 거절은 같은 빌드 · 같은 이름이면 결정적이라(재연결마다 같은 패킷이 같은 문구로 거절된다) 「연결마다」는 재연결이 잦을 때 창이 쌓이는 바로 그 반복을 못 막는다. 데몬 문구가 원인(겹친 이름 · 넘친 크기 · 상한 수치)을 싣으므로 다른 사고는 다른 키라 새로 뜬다.
- **경고(`Warning`) 종류.** 기각 = 사용자 결정 2026-10-07(「개발 단계에서만 일어나는 일이라 강하게 경고 표시」).

## 영향 / 불변식

- ★**데몬 답을 대기 슬롯에 넣는 자리는 하나이고 `Error` 도 `Ok` 로 넣는다 — `Error` 를 `Err` 로 접지 말 것.**★ 접으면 데몬 거절이 `Local` 로 분류돼 박스가 조용히 죽는다(컴파일은 된다). 실 소켓 왕복 시험(등록 자리 — `CONFLICT` · `INVALID_ARGUMENT` · 모르는 코드 · 답 전 끊김)이 이 회귀를 잡는다.
- **기존 `send_command` 호출자의 글은 바이트 단위로 같다** — `CommandFailure` 의 `Display` = 원문. 시험이 바이트 대조로 잰다.
- **순서 의존** — 슬롯 채우기를 뒤집는 변경이 `send_command` 의 분류보다 먼저 들어가면 데몬 거절이 `Ok(Error)` 로 호출자에 가서 `expect_ack` 류가 성공으로 넘긴다(TRD §3-4).
- **dialog 플러그인을 빼지 말 것** — `dialog()` 는 플러그인 상태가 없으면 panic 하고 릴리스는 `panic = "abort"` 다. 폴더 고르기 기능과 함께 플러그인을 걷으면 거절 박스가 앱 종료가 된다(`src-tauri/src/lib.rs` 의 등록 주석).
- **박스 결정은 info 로그로도 센다**(띄움 · 눌러 둠 + 자리) — GUI 실측이 그 로그를 센다.
- **억제의 대가** — 같은 사고의 두 번째부터는 warn 만 남는다. 키를 박스 전에 적으므로 플러그인이 창 띄우기에 실패하면(실패는 삼킨다) 그 키는 이 프로세스에서 다시 안 뜬다.
- **코드 앵커 = `// ADR-0281`** — 슬롯 채우기 · `classify_reply` · `send_command_with_origin` · `refusal.rs`.
- **범위 밖** — 등록 거절 뒤 재시도 · LLM 통지 · 거절의 원인 이름을 셸이 미리 거르기(ADR-0270 이 걷었다).
