# ADR-0321: The working folder is an agent value — locked after a conversation and while running

- 상태: 제안 (2026-10-31, basis: user decisions 2026-10-18 · D3 · P2-REVISED · 「ssi 박히잖아. 그게 있으면 못바꾸게」 · 「대화 뒤 잠금은 있어야지」 + main M28 · M32 · M42 (reported — re-review A2 · A6 · R2 C4))
- 관련: ADR-0226 (first-submit latch — persisted session id) · ADR-0006 (lock order) · ADR-0122 · S25 draft AA (unnumbered — block after creation) · TRD `docs/process/S25-preset-library/trd.md` §1-5 「작업 폴더 `cwd`」 · 「`display_name` 고정」 · §8 · §7 25

## 맥락
Where is an agent's working folder decided, and when can it be changed?

## 결정
1. Working folder = an agent value. Change it with the agent slot's 「작업 폴더」 field + `agent.setWorkspace {agent, cwd}`. The folder choice at creation (`cwd` required) stays as it is now.
2. It cannot be changed if there is a persisted backend session id (after a conversation — ADR-0226) or the agent is running. There are two lock-reason texts (running · has conversed — P2-REVISED).
3. It changes only before a conversation, so there is no session to release — we do not build session-release logic.
4. **`agent.setWorkspace` does the lock check and the `cwd` change while holding that agent's spawn reservation (RAII)** — it does not write the profile while holding the `spawning` leaf lock (ADR-0006). A spawn that lost the reservation to setWorkspace = `CONFLICT` (changing the working folder) · when setWorkspace meets a spawn's reservation = `CONFLICT` (preparing to run). The reservation table tells apart the kind of the holder (the form is an implementation judgment — M28). Exception = the gap where `agent.spawn --cwd` put it in the registry before activation — that spawn takes the block-after-creation path (`INTERNAL` + the created id — S25 draft AA (unnumbered) Decision 6 · M42).
5. **If the name is being derived from the `cwd` basename (no `display_name`), setWorkspace pins the current name as `display_name` within the same reservation before changing `cwd`** — so that changing the working folder does not silently change the name (mail address · tree name) (M32).

## 거부한 대안
- **Change even after a conversation and make the next run a new conversation** (`launched_workspace` · `release_session_id` — the old design moved to §8) — user 「대화 뒤 잠금은 있어야지」.
- **The working folder as a preset part** — we do not add library kinds (D3 recommendation).
- **Lock check and profile write while holding the `spawning` leaf lock** — a lock-order violation that calls outside while holding a leaf lock (ADR-0006 · M28 · re-review A2).
- **A spawn that lost the reservation turns into `Moot(None)`** — it silently does not come up · M28 changed it to `CONFLICT` carrying the reason.
