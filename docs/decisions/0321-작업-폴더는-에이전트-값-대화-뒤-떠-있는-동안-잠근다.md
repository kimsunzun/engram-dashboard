# ADR-0321: 작업 폴더는 에이전트 값 — 대화 뒤 · 떠 있는 동안 잠근다

- 상태: 제안 (2026-10-31, 근거: 사용자 결정 2026-10-18 · D3 · P2-REVISED · 「ssi 박히잖아. 그게 있으면 못바꾸게」 · 「대화 뒤 잠금은 있어야지」 + 메인 M28 · M32 · M42(보고 — 재리뷰 A2 · A6 · R2 C4))
- 관련: ADR-0226(첫 제출 래치 — 영속된 세션 id) · ADR-0006(락 순서) · ADR-0122 · S25 초안 AA(미채번 — 만든 뒤 막힘) · TRD `docs/process/S25-preset-library/trd.md` §1-5 「작업 폴더 `cwd`」 · 「`display_name` 고정」 · §8 · §7 25

## 맥락
에이전트의 작업 폴더를 어디서 정하고 언제 바꿀 수 있나.

## 결정
1. 작업 폴더 = 에이전트 값. 에이전트 슬롯 「작업 폴더」 칸 + `agent.setWorkspace {agent, cwd}` 로 바꾼다. 만들 때 폴더 선택(`cwd` 필수)은 지금 그대로.
2. 영속된 backend 세션 id 가 있거나(대화 뒤 — ADR-0226) 떠 있으면 바꿀 수 없다. 잠긴 까닭 문구는 둘(실행 중 · 대화함 — P2-REVISED).
3. 대화 전에만 바뀌므로 놓을 세션이 없다 — 세션 놓기 로직을 짓지 않는다.
4. **`agent.setWorkspace` 는 그 에이전트의 스폰 예약(RAII)을 쥔 채** 잠금 확인 · `cwd` 바꾸기를 한다 — `spawning` 잎 락을 쥔 채 프로필을 쓰지 않는다(ADR-0006). 예약을 setWorkspace 에 진 스폰 = `CONFLICT`(작업 폴더 바꾸는 중) · setWorkspace 가 스폰의 예약을 만남 = `CONFLICT`(실행 준비 중). 예약 표는 쥔 쪽의 종류를 가른다(꼴은 구현 판단 — M28). 예외 = `agent.spawn --cwd` 가 활성화 전에 명부에 올린 틈 — 그 스폰은 만든 뒤 막힘 길(`INTERNAL` + 만든 id — S25 초안 AA(미채번) 결정 6 · M42).
5. **이름이 `cwd` basename 에서 파생 중이면(`display_name` 없음) setWorkspace 가 `cwd` 를 바꾸기 전에 같은 예약 안에서 지금 이름을 `display_name` 으로 고정한다** — 작업 폴더 바꾸기가 말없이 이름(우편 주소 · 트리 이름)을 바꾸지 않게(M32).

## 거부한 대안
- **대화 뒤에도 바꾸고 다음 실행을 새 대화로 맞추기**(`launched_workspace` · `release_session_id` — §8 에 옮겨 둔 옛 설계) — 사용자 「대화 뒤 잠금은 있어야지」.
- **작업 폴더를 프리셋 부품으로** — 라이브러리 종류를 늘리지 않는다(D3 추천).
- **`spawning` 잎 락을 쥔 채 잠금 확인 · 프로필 쓰기** — 잎 락을 쥔 채 밖을 부르는 락 순서 위반이다(ADR-0006 · M28 · 재리뷰 A2).
- **예약을 진 스폰을 `Moot(None)` 으로** — 말없이 안 뜬다 · M28 이 사유를 실은 `CONFLICT` 로 바꿨다.
