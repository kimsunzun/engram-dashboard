## 맥락

base 의 입주자는 둘이다 — `logging` · `platform`. 입주 조건은 ADR-0175 가 셋으로 박았다(영향): ① 소비자가 둘 이상 ② 도메인 지식 0 ③ 이 crate 안에서 서로를 참조하지 않을 것. 같은 자리가 ★세 번째 입주자가 생기면 「거부한 대안」 첫 항목(logging · platform 을 각각 독립 crate 로)을 다시 연다 — 그때가 `bevy_core` 경로에 들어서는 지점이다★를 박았다. 그 경고의 출처는 ADR-0151 이다 — 「거부한 대안」 E(계층 위치만 가리키는 이름의 바닥 crate 에 도메인 중립 코드를 모은다 — Bevy `bevy_core` 가 시간 · 이름표 · 태스크풀까지 빨아들이다 해체돼 목적별로 흩어진 선례)와 영향(「덩어리별로 따로 판정한다 — 셋을 뭉쳐 하나에 넣을 근거는 없고, 목적 이름을 가진 작은 crate 여러 개가 나올 수 있다」). ADR-0175 는 이름 후보 `-common` · `-util` 도 「잡동사니 이름」으로 기각했다.

도메인 지식이 없는 작은 도우미가 여러 crate 에 손으로 복사돼 있다(조사 2026-09-26 — 경량 워커가 조사하고 메인이 정의 위치만 대조했다. ★동작 차이 · 비공개 게이트 서술은 워커 보고이고 메인이 재확인하지 않았다★).

## 결정

1. **base 는 범용 코드를 받는 자리다. 이름은 base 그대로 두고, 안에서는 목적 이름의 모듈로 가른다**(사용자 2026-10-02). 목적별 작은 crate 로 쪼개는 것은 미룬다 — base 는 의존 그래프 바닥에 있고 서로 엮인 데가 적어 나중에 쪼개도 품이 적다(사용자).
2. **base 에 범용 도우미 모듈을 들인다**(사용자 2026-09-26). 제공 방식은 **상태 없는 공개 함수**다(메인 제안) — 호출은 `engram_dashboard_base::file::set_aside_corrupt(…)` 꼴. 함수 이름은 가안이다.

   | 모듈 | 함수(가안) | 흡수 대상 |
   |---|---|---|
   | `file` | `set_aside_corrupt(path, stamp_ms) -> 새 경로` | 아래 「영향」의 손상 사본 목록(★원자적 쓰기 `write_atomic` 은 빠졌다 — Windows 전용 rename 재시도를 품어 platform 으로 간다 · ADR-0266 결정 8 · 메인 판단 2026-10-03★) |
   | `text` | `truncate_bytes(s, max)`(앞을 남김) · `keep_tail_bytes(s, max)`(뒤를 남김) · `hex_lower(bytes)` (XML 이스케이프 두 함수는 보류 — 오른쪽 칸) | 위 표의 UTF-8 자르기 · hex · XML(★XML 이스케이프는 지금 옮기지 않는다 — 소비자가 messaging 하나이고 messaging 은 base 가 필요해질 때만 의존한다 · ADR-0267★) |
   | `time` | `now_epoch_ms()` + 「지금 읽기」 트레이트(결정 3) | agent 세 벌 · `Clock` 중 `now` 부분(`UsageClock` 은 보류 — 결정 3) |
   | `path` | `normalize_spelling(raw)` | agent `normalize_cwd`(→ 셸) |
   | `sync` | 락 오염 복구(결정 4) | 57곳(★command 하네스 `testing.rs` 의 3곳은 제자리 — ADR-0267★) |
   | `testing`(기능 플래그 뒤) | `wait_until` · 가짜 `Clock`(결정 5) | 테스트 9개 파일 |

3. **사용자 규칙 「시간은 공용이면 무조건 합친다」(2026-09-26)를 이렇게 적용한다**(메인 판단 2026-10-03 — 근거 = `docs/research/clock-seam-placement-2026-10-03.md`, 교차 리뷰 BLOCK 반영 · 4 는 사용자 결정 2026-10-03). 「트레이트를 두지 않는다」의 유일한 예외다.
   1. base `time` 에 **「지금 읽기」 트레이트 하나**(`now() -> Instant`)를 둔다. 테스트용 가짜는 base `testing`(기능 플래그 뒤 — 결정 5)에 둔다.
   2. 기다리기가 필요한 transport(비동기 sleep)와 discovery(막는 sleep)는 **base 트레이트를 상위 트레이트로 둔 자기 트레이트**를 둔다. 가짜 시계 하나가 둘을 같은 상태로 구현한다 — 지금의 가짜가 sleep 으로 now 를 앞으로 미는 연동을 지키려는 것이다(transport `src/testing.rs` 의 수동 시계 · discovery 의 시험 시계).
   3. 데몬 `command_delivery` 의 `Clock`(now 하나)은 base 것으로 바꾼다.
   4. 데몬 `UsageClock` 은 **보류한다**(사용자 2026-10-03) — 1-1 때 깔끔히 맞으면 합치고, 안 맞으면 그때 사용자에게 묻는다. 걸리는 것은 계약 차이다 — 「그 시계가 만들어진 뒤 경과」(원점을 쥔다)와 부호 있는 epoch 초이고, 가짜가 두 축을 따로 움직인다(`usage_service/clock.rs`).
   5. transport 는 `std::time::Instant` 를 돌려주며 tokio 로 잔다. `tokio::time::pause` 는 std `Instant` 를 멈추지 않으므로 **시계 영역을 바꾸지 않는다**(시험은 수동 시계를 쓴다).

   세부 모양은 1-1 착수 때 정한다. ★「지금 읽기만 합치는 것이 피어 표준이라서」는 근거가 아니다★ — 피어는 갈린다(zed · Materialize 는 나누고, `cruxi_clock` · `async_speed_limit` · quinn 은 읽기와 기다리기를 한 트레이트에 묶는다). 이 모양은 설계 선택이다.
4. **락 오염 복구를 base `sync` 모듈로 모은다**(사용자 2026-09-26). 한 곳으로 모으면 지금은 조용히 삼키는 오염을 **복구할 때 경고 로그를 남기는** 식의 통제가 생긴다. 그 경고는 `tracing::warn!` 을 직접 부른다 — base 는 이미 `tracing` 을 의존하고, 로그는 감싸지 않는다(ADR-0268). 그래서 `sync` 가 base 의 `logging` 모듈을 부르지 않아 입주자끼리 무참조(입주 조건 ③)가 그대로 선다.
5. **테스트 대기 헬퍼는 base 의 `testing` 기능 플래그 뒤 모듈로 둔다**(메인 판단) — 가짜 `Clock` 도 같은 자리. 운영 빌드에는 안 실리고 dev-dependency 에서만 켠다. `wait_for_output` · `wait_for_text` 처럼 도메인을 아는 것은 제자리에 남는다.
6. **지킬 것:**
   - **base 에 무거운 의존을 들이지 않는다** — JSON 직렬화는 호출부에 남기고(base 가 serde 를 안 끌어옴) `file` 은 바이트만 받는다. hex 는 직접 루프다(`hex` crate 안 씀).
   - **입주자끼리 무참조(입주 조건 ③)** — 손상 파일 이름의 시각은 `file` 이 `time` 을 부르지 않고 **인자로 받는다**.
   - **오류는 `std::io::Result`** 다.
   - **`file` 은 여러 벌의 동작을 하나로 정한 뒤 옮긴다** — 손상 사본 치우기를 작업 순서 1-1 에서 정한다(아래 영향). 원자적 쓰기 여러 벌을 하나로 정하는 일은 platform 이 생긴 뒤 1-3 으로 간다(ADR-0266 결정 8).
7. **입주 판단 규칙 = 「기준을 미리 잡지 않고 지금 여러 군데 쓰는 걸로 판단」**(사용자 2026-09-26). 도메인 지식이 없고 **지금 여러 곳에서 쓰이거나 복사돼 있으면** 메인이 판단해 base 로 옮긴다 — 사용자에게 묻지 않고 보고한다. ADR-0175 입주 조건 ①(소비자 crate 둘 이상)을 이 규칙이 대신한다. ②(도메인 지식 0 · 워크스페이스 의존 0) · ③(입주자끼리 무참조)은 그대로다.
8. **이 규칙을 다음 세션이 따르게 유도한다**(사용자 2026-09-26 — 「나중」) — 새 범용 헬퍼가 생기면 메인 세션이 알아서 base 로 옮기도록 CLAUDE.md(또는 다른 자리)의 아키텍처 서술을 갱신한다.
9. **base 라는 이름의 뜻**(사용자 2026-10-03) — base 는 모든 crate 가 올라서는 **바닥 기반층**이다. 범용 도우미와 기반 인프라(로깅 출력 설정처럼 외부 의존을 가진 것 포함)를 담고, 도메인 지식과 워크스페이스 의존은 두지 않는다. 선례 = Chromium `//base`(파일 · 문자열 · JSON · 시간 + 로깅 · 프로세스 · 스레드 · 작업 스케줄링 — `chromium/chromium` 의 `base/` 목록, 2026-10-03 확인). 사용자: 「우리 프로젝트 규모에 util 빼면 나중에 공용 필요할 때 어디다 넣기 애매하니」.

## 거부한 대안

- **목적별 작은 crate 로 지금 나눈다(ADR-0151 영향의 「덩어리별 판정」 · ADR-0175 의 되열 조건이 가리키던 쪽).** 기각 = 사용자 결정(2026-10-02) — 「Base 쪽에 잡동사니 넣어도 돼. 그러기 위한 base 인데」 · 「목적별 작은 crate는 나중에 base 쪼개는 걸 고려해도 될 듯 — base는 상위(바닥)에 있고 연관관계도 적을 테니 쪼개는 데 공수도 없을 테고」. 즉 `bevy_core` 선례가 경고하는 해체를 막는 것이 아니라 그 비용이 이 자리에서는 작다고 본 것이다. 「연관관계도 적을」을 지금 받치는 장치는 입주자끼리 무참조(입주 조건 ③) 게이트다(코드 — CI `rg` 게이트).
- **입주 조건 ①(소비자 crate 둘 이상)을 유지한다.** 기각 = 사용자 결정(결정 7 — 「기준을 미리 잡지 않고」). 그 밖의 사유는 메모에 없다.
- **도우미를 트레이트 뒤에 둔다.** 기각 = 바꿔 끼울 구현이 없다(메인 제안). **기각 근거 자평: 약함**(서술). 예외 = `Clock`(결정 3 — 테스트가 시간을 갈아끼운다).
- **`Clock` 네 벌을 한 트레이트로 통째 합친다**(이 결정의 옛 결정 3 문구가 가리키던 쪽). 기각 = 네 벌의 모양이 다르다(위 「맥락」 표) · 비동기 sleep 구현까지 base 로 옮기면 base 가 tokio 를 끈다(트레이트 시그니처만이면 끌지 않는다 — 리뷰 정정) · `UsageClock` 의 계약이 다르다(원점 보유 경과 + 부호 있는 epoch 초 — 코드 `usage_service/clock.rs`). 메인 판단 2026-10-03(결정 3).
- **`util` 로 개명한다.** 피어 표본에서 가장 흔한 이름이다(zed `util` · Firecracker `utils` · TiKV `tikv_util` · nushell `nu-utils` — 다른 이름으로는 rust-analyzer `stdx` · Materialize `mz-ore`). 기각 = 사용자 결정(2026-10-03 · 결정 9) + util 은 대개 상태 없는 도우미 모음을 뜻해, 기반 인프라(로깅 초기화 · 파일 sink)를 담는 지금의 base 보다 좁다 + 개명 비용(crate 이름 · import · CI 게이트 · CLAUDE.md · ADR 다수 · 옛 기록이 흐려진다 — `core` → `agent` 개명 때 겪은 것, ADR-0175). ★ADR-0175 는 `-common` · `-util` 을 「잡동사니 이름」으로 기각했는데, 그 사유는 더 서지 않는다★ — 사용자가 이제 base 가 범용 코드를 담는 것을 승인했다(결정 1 · 9). 그래서 이 기각은 위 사유들에 선다.
- **테스트 도우미를 개발 전용 crate 로 따로 세운다.** 기각 = 범용 헬퍼가 std 만 쓰는 함수 하나뿐이라 값어치가 없다(메인 판단 — 정량: 함수 하나).
- **입주시키지 않는 것(후보 조사의 「안 된다」 판정):**
  - **글자 수 자르기(`clip` · `truncate`)** — agent 쪽은 비밀값 가리기를 거쳐서만 부르도록 테스트가 막는 의도된 비공개다. base 로 빼면 그 문이 뚫린다(코드 — 워커 보고, 메인 재확인 안 함).
  - **데이터 폴더 찾기(`default_data_dir`)** — Engram 고유 지식이다(ADR-0134).
  - **토큰 생성(32바이트 난수 hex)** — 공유 금지가 명시돼 있다(ADR-0086). 인코딩 루프(`hex_lower`)만 범용이다.
  - **`sha256_hex`** — `sha2` 를 끌고 온다(코드 — 의존).
  - **재연결 백오프** — transport 가 이미 더 풍부한 정책을 가졌다(`transport/src/policy.rs`). 셸이 transport 를 붙일 때 그쪽으로 흡수하면 사라진다(코드).
  - **`dunce::canonicalize`** — 라이브러리 한 줄 호출이라 뺄 것이 없다(코드).
  - **비어 있지 않은 환경변수 읽기 · discovery `retry_if_vanished`** — 앞은 모양이 비슷한 곳이 daemon 9 · agent 3 · protocol 1 · 셸 1 이나 대부분 `ENGRAM_*` 도메인 읽기라 뽑을 몫이 작다(정량 + 서술). 뒤는 discovery 전용 정책이다 — **기각 근거 자평: 약함**(서술). ★**뒤(`retry_if_vanished` · `probe_write_in`)는 ADR-0271 이 작업 순서 2-2 에서 다시 본다**★ — discovery 를 나누면 데몬 쪽 `ensure_data_dir_writable` 과 셸 쪽 `check_data_dir_writable` 이 그 둘을 함께 쓴다(ADR-0271 영향 「열린 것」). 그 판정은 결정 7 의 규칙을 따른다 — 2-2 의 나누기가 실제로 사본 둘을 만들면 base 로 옮기고, 그 전까지는 이 제외가 선다.

## 영향 / 불변식

- **입주 조건이 바뀐다** — ①은 결정 7 의 규칙으로, ② · ③은 그대로. 정본 = `crates/engram-dashboard-base/src/lib.rs` 헤더(같은 변경에서 고친다). CLAUDE.md 「백엔드 모듈 맵」 base 항목의 입주 조건 서술과 「셋째 입주자를 받기 전에 ADR-0175 「거부한 대안」 첫 항목을 다시 연다」 문장도 함께 고친다 — 그 되열 조건은 결정 1 이 답했다.
- **이름은 base 를 유지한다**(결정 9). ADR-0175 의 이름 기각(`-common` · `-util` = 잡동사니 이름)은 결론만 남고 사유는 바뀐다 — 지금은 「거부한 대안」 `util` 개명 항목의 사유에 선다. 범용 코드를 모으는 것은 이 결정이 자리의 목적으로 처음 적고(결정 1 — 사용자 「그러기 위한 base」), 모양 없는 잡동사니가 되지 않게 하는 것은 이름이 아니라 목적 이름의 모듈 가름이다.
- **base 가 무거워지면 기능 플래그로 나눈다** — Materialize `mz-ore` 가 그 형이다(쓰는 쪽이 `default-features = false` 로 필요한 기능만 켠다 — `src/persist/Cargo.toml`, 2026-10-03 확인). 지금은 나누지 않는다.
- **CI 입주자 상호 참조 게이트에 새 모듈 이름을 더한다** — `rg "(crate|super)::(logging|platform)" crates/engram-dashboard-base/src/` 의 이름 알파벳에 `file` · `text` · `time` · `path` · `sync` · `testing`(그리고 결정 후보 1 로 `platform` 이 빠진다). 이름을 손으로 박는 게이트라 안 더하면 새 입주자가 안 보인다. 나중에 base 를 쪼갤 때 이 게이트가 쪼갤 단위(모듈)를 이미 가르고 있다.
- ★**손상 사본의 하나로 정한 동작 = 열린 것, 작업 순서 1-1 에서 정한다 · 원자적 쓰기는 platform 으로 가 1-3 에서 정한다**★(ADR-0266 결정 8 — base 는 platform 을 의존하지 않으므로 Windows 전용 rename 재시도를 품은 `write_atomic` 을 받을 수 없다 · 메인 판단 2026-10-03). 현재 사본(재실측 `d5ac725`):

  - 손상 사본(→ base `file` · 1-1) — agent `persistence/mod.rs` · `persistence/presets.rs`(`.corrupt-<ms>`) · 셸 `settings/store.rs` 의 `set_aside`(ADR-0265 판 — 겹치면 `-<n>` · 1 MiB 상한 · `sync_all` 뒤 갈아끼우기).
