# ADR-0269: base 에 범용 도우미를 목적별 모듈로 들이고 입주는 지금 여러 곳에서 쓰이는지로 판단한다

- 상태: 확정 (2026-10-02, 근거: 사용자 결정 2026-09-26 (`docs/refactoring/architecture-discussion-2026-09-26.md` 결정 후보 4 — 입주 · `Clock` · `sync` · 입주 판단 규칙) + 사용자 결정 2026-10-02 (base 는 범용 코드를 받는 자리 · 목적별 crate 쪼개기는 미룬다) + 제공 방식은 메인 제안 + `testing` 은 메인 판단 + 후보 조사(경량 워커 · 메인 정의 위치 대조, 2026-09-26))
- 관련: Amends ADR-0175 (영향의 입주 조건 1번과 세 번째 입주자 되열 조항) · Amends ADR-0151 (거부한 대안 E의 판정과 영향의 덩어리별 판정 기대) · Amends ADR-0265 (결정 4의 원자적 쓰기 함수 자리) · ADR-0086(토큰 생성기 공유 금지) · ADR-0134(데이터 폴더는 Engram 고유 지식) · ADR-0264(경로 정본을 base 에 두지 않는다) · ADR-0266(platform crate) · ADR-0267(command · messaging 도 base 의존) · ADR-0270(`normalize_cwd` 이전) · `crates/engram-dashboard-base/src/lib.rs`(입주 조건 · 게이트) · step-log S21

## 맥락

base 의 입주자는 둘이다 — `logging` · `platform`. 입주 조건은 ADR-0175 가 셋으로 박았다(영향): ① 소비자가 둘 이상 ② 도메인 지식 0 ③ 이 crate 안에서 서로를 참조하지 않을 것. 같은 자리가 ★세 번째 입주자가 생기면 「거부한 대안」 첫 항목(logging · platform 을 각각 독립 crate 로)을 다시 연다 — 그때가 `bevy_core` 경로에 들어서는 지점이다★를 박았다. 그 경고의 출처는 ADR-0151 이다 — 「거부한 대안」 E(계층 위치만 가리키는 이름의 바닥 crate 에 도메인 중립 코드를 모은다 — Bevy `bevy_core` 가 시간 · 이름표 · 태스크풀까지 빨아들이다 해체돼 목적별로 흩어진 선례)와 영향(「덩어리별로 따로 판정한다 — 셋을 뭉쳐 하나에 넣을 근거는 없고, 목적 이름을 가진 작은 crate 여러 개가 나올 수 있다」). ADR-0175 는 이름 후보 `-common` · `-util` 도 「잡동사니 이름」으로 기각했다.

도메인 지식이 없는 작은 도우미가 여러 crate 에 손으로 복사돼 있다(조사 2026-09-26 — 경량 워커가 조사하고 메인이 정의 위치만 대조했다. ★동작 차이 · 비공개 게이트 서술은 워커 보고이고 메인이 재확인하지 않았다★).

## 결정

1. **base 는 범용 코드를 받는 자리다. 이름은 base 그대로 두고, 안에서는 목적 이름의 모듈로 가른다**(사용자 2026-10-02). 목적별 작은 crate 로 쪼개는 것은 미룬다 — base 는 의존 그래프 바닥에 있고 서로 엮인 데가 적어 나중에 쪼개도 품이 적다(사용자).
2. **base 에 범용 도우미 모듈을 들인다**(사용자 2026-09-26). 제공 방식은 **상태 없는 공개 함수**다(메인 제안) — 호출은 `engram_dashboard_base::file::write_atomic(…)` 꼴. 함수 이름은 가안이다.

   | 모듈 | 함수(가안) | 흡수 대상 |
   |---|---|---|
   | `file` | `write_atomic(path, bytes)` · `set_aside_corrupt(path, stamp_ms) -> 새 경로` | 아래 「영향」의 현재 사본 |
   | `text` | `truncate_bytes(s, max)`(앞을 남김) · `keep_tail_bytes(s, max)`(뒤를 남김) · `hex_lower(bytes)` · `escape_xml_attr` / `escape_xml_text` | 위 표의 UTF-8 자르기 · hex · XML |
   | `time` | `now_epoch_ms()` + `Clock` 트레이트(결정 3) | agent 세 벌 · `Clock` 네 벌 |
   | `path` | `normalize_spelling(raw)` | agent `normalize_cwd`(→ 셸) |
   | `sync` | 락 오염 복구(결정 4) | 57곳 |
   | `testing`(기능 플래그 뒤) | `wait_until` · 가짜 `Clock`(결정 5) | 테스트 9개 파일 |

3. **`Clock` 네 벌을 base `time` 으로 합친다**(사용자 2026-09-26 — 규칙 「시간은 공용이면 무조건 합친다」). 「트레이트를 두지 않는다」의 유일한 예외다.
4. **락 오염 복구를 base `sync` 모듈로 모은다**(사용자 2026-09-26). 한 곳으로 모으면 지금은 조용히 삼키는 오염을 **복구할 때 경고 로그를 남기는** 식의 통제가 생긴다(결정 후보 3 과 같은 결).
5. **테스트 대기 헬퍼는 base 의 `testing` 기능 플래그 뒤 모듈로 둔다**(메인 판단) — 가짜 `Clock` 도 같은 자리. 운영 빌드에는 안 실리고 dev-dependency 에서만 켠다. `wait_for_output` · `wait_for_text` 처럼 도메인을 아는 것은 제자리에 남는다.
6. **지킬 것:**
   - **base 에 무거운 의존을 들이지 않는다** — JSON 직렬화는 호출부에 남기고(base 가 serde 를 안 끌어옴) `file` 은 바이트만 받는다. hex 는 직접 루프다(`hex` crate 안 씀).
   - **입주자끼리 무참조(입주 조건 ③)** — 손상 파일 이름의 시각은 `file` 이 `time` 을 부르지 않고 **인자로 받는다**.
   - **오류는 `std::io::Result`** 다.
   - **`file` 은 여러 벌의 동작을 하나로 정한 뒤 옮긴다** — 정하는 시점은 작업 순서 1-1(아래 영향).
7. **입주 판단 규칙 = 「기준을 미리 잡지 않고 지금 여러 군데 쓰는 걸로 판단」**(사용자 2026-09-26). 도메인 지식이 없고 **지금 여러 곳에서 쓰이거나 복사돼 있으면** 메인이 판단해 base 로 옮긴다 — 사용자에게 묻지 않고 보고한다. ADR-0175 입주 조건 ①(소비자 crate 둘 이상)을 이 규칙이 대신한다. ②(도메인 지식 0 · 워크스페이스 의존 0) · ③(입주자끼리 무참조)은 그대로다.
8. **이 규칙을 다음 세션이 따르게 유도한다**(사용자 2026-09-26 — 「나중」) — 새 범용 헬퍼가 생기면 메인 세션이 알아서 base 로 옮기도록 CLAUDE.md(또는 다른 자리)의 아키텍처 서술을 갱신한다.

## 거부한 대안

- **목적별 작은 crate 로 지금 나눈다(ADR-0151 영향의 「덩어리별 판정」 · ADR-0175 의 되열 조건이 가리키던 쪽).** 기각 = 사용자 결정(2026-10-02) — 「Base 쪽에 잡동사니 넣어도 돼. 그러기 위한 base 인데」 · 「목적별 작은 crate는 나중에 base 쪼개는 걸 고려해도 될 듯 — base는 상위(바닥)에 있고 연관관계도 적을 테니 쪼개는 데 공수도 없을 테고」. 즉 `bevy_core` 선례가 경고하는 해체를 막는 것이 아니라 그 비용이 이 자리에서는 작다고 본 것이다. 「연관관계도 적을」을 지금 받치는 장치는 입주자끼리 무참조(입주 조건 ③) 게이트다(코드 — CI `rg` 게이트).
- **입주 조건 ①(소비자 crate 둘 이상)을 유지한다.** 기각 = 사용자 결정(결정 7 — 「기준을 미리 잡지 않고」). 그 밖의 사유는 메모에 없다.
- **도우미를 트레이트 뒤에 둔다.** 기각 = 바꿔 끼울 구현이 없다(메인 제안). **기각 근거 자평: 약함**(서술). 예외 = `Clock`(결정 3 — 테스트가 시간을 갈아끼운다).
- **테스트 도우미를 개발 전용 crate 로 따로 세운다.** 기각 = 범용 헬퍼가 std 만 쓰는 함수 하나뿐이라 값어치가 없다(메인 판단 — 정량: 함수 하나).
- **입주시키지 않는 것(후보 조사의 「안 된다」 판정):**
  - **글자 수 자르기(`clip` · `truncate`)** — agent 쪽은 비밀값 가리기를 거쳐서만 부르도록 테스트가 막는 의도된 비공개다. base 로 빼면 그 문이 뚫린다(코드 — 워커 보고, 메인 재확인 안 함).
  - **데이터 폴더 찾기(`default_data_dir`)** — Engram 고유 지식이다(ADR-0134).
  - **토큰 생성(32바이트 난수 hex)** — 공유 금지가 명시돼 있다(ADR-0086). 인코딩 루프(`hex_lower`)만 범용이다.
  - **`sha256_hex`** — `sha2` 를 끌고 온다(코드 — 의존).
  - **재연결 백오프** — transport 가 이미 더 풍부한 정책을 가졌다(`transport/src/policy.rs`). 셸이 transport 를 붙일 때 그쪽으로 흡수하면 사라진다(코드).
  - **`dunce::canonicalize`** — 라이브러리 한 줄 호출이라 뺄 것이 없다(코드).
  - **비어 있지 않은 환경변수 읽기 · discovery `retry_if_vanished`** — 앞은 모양이 비슷한 곳이 daemon 9 · agent 3 · protocol 1 · 셸 1 이나 대부분 `ENGRAM_*` 도메인 읽기라 뽑을 몫이 작다(정량 + 서술). 뒤는 discovery 전용 정책이다 — **기각 근거 자평: 약함**(서술). ★**뒤(`retry_if_vanished` · `probe_write_in`)는 ADR-0271 이 작업 순서 2-2 에서 다시 본다**★ — discovery 를 나누면 데몬 쪽 `ensure_data_dir_writable` 과 셸 쪽 `check_data_dir_writable` 이 그 둘을 함께 쓴다(ADR-0271 영향 「열린 것」). 그 판정은 결정 7 의 규칙을 따른다 — 2-2 의 나누기가 실제로 사본 둘을 만들면 base 로 옮기고, 그 전까지는 이 제외가 선다.

## 영향 / 불변식

- **입주 조건이 바뀐다** — ①은 결정 7 의 규칙으로, ② · ③은 그대로. 정본 = `crates/engram-dashboard-base/src/lib.rs` 헤더(같은 변경에서 고친다). CLAUDE.md 「백엔드 모듈 맵」 base 항목의 입주 조건 서술과 「셋째 입주자를 받기 전에 ADR-0175 「거부한 대안」 첫 항목을 다시 연다」 문장도 함께 고친다 — 그 되열 조건은 결정 1 이 답했다.
- **ADR-0175 의 이름 기각(`-common` · `-util` = 잡동사니 이름)은 그대로다** — 이름은 base 를 유지한다. 범용 코드를 모으는 것은 이 결정이 자리의 목적으로 처음 적고(결정 1 — 사용자 「그러기 위한 base」), 모양 없는 잡동사니가 되지 않게 하는 것은 이름이 아니라 목적 이름의 모듈 가름이다.
- **CI 입주자 상호 참조 게이트에 새 모듈 이름을 더한다** — `rg "(crate|super)::(logging|platform)" crates/engram-dashboard-base/src/` 의 이름 알파벳에 `file` · `text` · `time` · `path` · `sync` · `testing`(그리고 결정 후보 1 로 `platform` 이 빠진다). 이름을 손으로 박는 게이트라 안 더하면 새 입주자가 안 보인다. 나중에 base 를 쪼갤 때 이 게이트가 쪼갤 단위(모듈)를 이미 가르고 있다.
- ★**원자적 쓰기 · 손상 사본의 하나로 정한 동작 = 열린 것, 작업 순서 1-1 에서 정한다**★. 현재 사본(재실측 `d5ac725`):
  - 원자적 쓰기 — 셸 `src-tauri/src/fsutil.rs` 의 `write_atomic`(rename 재시도 · `sync_all` — `settings/store.rs` · `ui_settings.rs` 가 부른다) · daemon `usage_service/reject_store.rs` · agent `persistence/mod.rs` · `persistence/presets.rs`.
  - 손상 사본 — agent `persistence/mod.rs` · `persistence/presets.rs`(`.corrupt-<ms>`) · 셸 `settings/store.rs` 의 `set_aside`(ADR-0265 판 — 겹치면 `-<n>` · 1 MiB 상한 · `sync_all` 뒤 갈아끼우기).
