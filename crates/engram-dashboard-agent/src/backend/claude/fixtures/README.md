# claude fixtures

Measured stdout (`--output-format stream-json`) lines, one per line, in the order they happened. Like the existing fixtures (`claude_text.jsonl`·`claude_tool.jsonl`), it carries **only lines the CLI emitted** — lines we wrote to stdin are not carried; what was written when is noted below.

## Common processing (mid-turn input fixtures — `lifecycle_m1` · `cancel_m3` · `drain_m7` · `slash_m13` · `transcript_queued_m5`)

- **Source:** only the `line` with `dir:"out"` was taken from the `{t,dir,line}` envelopes of `.claude/handoff/attachments/20260925-midturn-phase0/logs/*.jsonl`. `meta`·`err`·`in` were dropped. "Line range" is the 0-based line number in that log file. What each log measured: `docs/research/mid-turn-phase0-measurements-2026-09-25.md` (M1·M3·M5·M7) · `docs/research/mid-turn-phase0b-measurements-2026-09-26.md` (M13).
- **Noise lines removed:** `system/hook_started` · `system/hook_response` · `system/thinking_tokens` · `rate_limit_event`. The order of the remaining lines is unchanged.
- **`system/init` edits:** the installed-environment lists (`slash_commands` · `agents` · `skills` · `plugins` · `mcp_servers`) were replaced with neutral values (plugin names are placeholders). The rest, such as `capabilities`·`tools`·`model`·`claude_code_version`, is as measured.
- **Personal data replaced:** cwd → `C:\work\proj` · OS user home → `C:\home\user` · encoded project folder name → `C--work-proj` · messaging pipe name → `cc-msg-0000`. uuids and session ids are random, so they were left as is.
- claude 2.1.280 · model haiku · our JSON-mode spawn arguments (Phase 0 report §1).

## Text streaming fixture (`partial_stream_p1` — ADR-0240)

- **Source:** B1 capture log `claude-main-2026-09-27T15-17-20-649Z.jsonl` (`{t,dir,chunk,nl,raw}` envelopes · only `raw` with `dir:"out"` was taken). ★The source log was outside the repository (the capturing worker's scratch) and is not kept★. "Line range" is a 1-based number counting only that log's `out` lines.
- **Spawn:** our JSON-mode arguments as is — `--permission-mode bypassPermissions -p --input-format stream-json --output-format stream-json --replay-user-messages --verbose --include-partial-messages --session-id <sid>` · env `MAX_THINKING_TOKENS=8000` · no control channel · no `extra_args` (so model = CLI default). claude 2.1.280 · model claude-opus-5-5.
- **Processing:** same as "Common processing" above — the four noise lines removed · the `system/init` installed-environment lists replaced with neutral values · personal data replaced with the same placeholders. `system/task_started` · `system/task_notification` were left as measured (the decoder skips them).
- **Removed turn:** T4 (long answer — `out` lines 104–694) was removed entirely. Ring-pressure figures (number of deltas streamed · number of characters) are carried by the B1 return — not measured with this fixture.
