# claude fixtures

Contains the measured stdout (`--output-format stream-json`) lines one per line, in the order they occurred. As in the existing fixtures (`claude_text.jsonl`·`claude_tool.jsonl`), it holds **only lines the CLI emitted** — lines we wrote to stdin are not included, and are described below under 「무엇을 언제 썼나」.

## Common processing (mid-turn input fixtures — `lifecycle_m1` · `cancel_m3` · `drain_m7` · `slash_m13` · `transcript_queued_m5`)

- **Source:** from the `{t,dir,line}` envelope of `.claude/handoff/attachments/20260925-midturn-phase0/logs/*.jsonl`, only the `line` with `dir:"out"` was extracted. `meta`·`err`·`in` were discarded. 「줄 범위」 is the 0-based line number in that log file. What each log measured is in `docs/research/mid-turn-phase0-measurements-2026-09-25.md` (M1·M3·M5·M7) · `docs/research/mid-turn-phase0b-measurements-2026-09-26.md` (M13).
- **Noise lines removed:** `system/hook_started` · `system/hook_response` · `system/thinking_tokens` · `rate_limit_event`. The order of the remaining lines is unchanged.
- **`system/init` cleanup:** the installed-environment lists (`slash_commands` · `agents` · `skills` · `plugins` · `mcp_servers`) were replaced with neutral values (plugin names are placeholders). The rest — `capabilities`, `tools`, `model`, `claude_code_version`, etc. — is as measured.
- **Personal information substitution:** cwd → `C:\work\proj` · OS user home → `C:\home\user` · encoded project folder name → `C--work-proj` · messaging pipe name → `cc-msg-0000`. uuids and session ids are random, so they were left as they are.
- claude 2.1.280 · model haiku · our JSON-mode spawn arguments (Phase 0 report §1).

## Character streaming fixture (`partial_stream_p1` — ADR-0240)

- **Source:** the B1 capture log `claude-main-2026-09-27T15-17-20-649Z.jsonl` (`{t,dir,chunk,nl,raw}` envelope · only the `raw` with `dir:"out"` was extracted). ★The original log is outside the repository (the capturing worker's scratch), so it does not remain★. 「줄 범위」 is the 1-based number counting only the `out` lines of that log.
- **Spawn:** our JSON-mode arguments as they are — `--permission-mode bypassPermissions -p --input-format stream-json --output-format stream-json --replay-user-messages --verbose --include-partial-messages --session-id <sid>` · env `MAX_THINKING_TOKENS=8000` · no control channel · no `extra_args` (so model = CLI default). claude 2.1.280 · model claude-opus-5-5.
- **Processing:** same as 「공통 가공」 above — four noise lines were removed · the `system/init` installed-environment lists were replaced with neutral values · and personal information was replaced with the same placeholders. `system/task_started` · `system/task_notification` were left as measured (the decoder skips them).
- **Turn removed:** T4 (long answer — `out` lines 104–694) was removed entirely. The ring-pressure figures (number of dropped deltas · number of characters) are carried by the B1 return — this fixture does not measure them.
