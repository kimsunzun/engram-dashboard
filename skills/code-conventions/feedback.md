## 검증 상태 (정직)

- **실측 — retrofit(정리) 경로:** engram-dashboard 프론트 전량(19,638줄 −28%) + 백엔드 전량 스윕 완주, master 머지 + CI green. 게이트 통과 다수(tray·daemon_client·protocol). stale 정정·커버 앵커 대조 = protocol 재스윕 A/B 1회(v1 보존분을 v2가 정확히 처리 · 8파일 실말미 일치). 구판 이력은 git(흡수·소멸한 clean-comment 스킬)에 있다.
- **실측 — 주입(작성) 경로, 첫 회:** 실결함 수정 1건에 A/B 1회(engram-dashboard `control/mcp_config.rs` — 보안 sweep의 에러 삼킴). 같은 티어·같은 과업, 캐논 주입군만 ① §기준 1 위반 주석(바로 아래 `warn!` 재진술)을 **안 씀** ② 바인딩 부재를 **보고** ③ `///` 헤더를 §기준 5로 검토 후 근거를 대고 **안 고치는 판정** ④ 범위 밖 후보를 적출하되 **미편집**. 베이스라인은 넷 다 없음. `cargo check` + 해당 모듈 유닛 6/6 green. **n=1이다 — 효과 크기 주장 아님.**
- **미검(0회):** **C++ 적용 전 경로**(doc 채널 미정·`//!`가 C++에선 다른 뜻·UPROPERTY 툴팁에서 §기준 1/3/7 판정 충돌 — 소비처 좌석 프로브 2026-08-11 적출, 바인딩 선결) · 구획 분담·순차 구획 워커·재배정 루프·다중 워커 병렬·워커당 상한 도달 · **바인딩 실소비**(소비처 파일명이 구 스킬명이라 지금껏 한 번도 안 읽힘) · 개정 R4로 돌린 재패스 · 흡수 후 재배선 steady-state. 문서 게이트 통과 ≠ 실측.
- **근거:** 주입≠준수 보장(instruction-compliance 45~84% 실측, arXiv 2605.10039) → 게이트 병행이 설계 근거 · 1,500 분리 트리거 = 사용자 결정(팩토리 ADR-0013 — 도구 친화 라벨, 코드 품질 실증 아님). 정본 = experiments/2026-07-31-code-conventions-precedent-research.md(팩토리).
